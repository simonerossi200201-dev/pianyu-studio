## 背景

现在这张表只能一行一行敲。用户的真实场景是：**一天几百条短文案，从 Google Sheet
整块复制过来**。所以这张表必须像 Google Sheet 一样能用，否则光贴数据就要一小时。

---

## 1. 「+ 加一行」→「+ 行…」，能一次加很多

按钮文字改成 `+ 行…`。点一下 = 加 1 行（保持现在的手感）。
按钮右侧带一个窄输入框（宽度约 4 个字符），填数字再点 = 加那么多行。
- 范围 1~2000，超了提示。
- 输入框记住上次的值，`Enter` 直接加。
- 加 100 行以上时先确认一句 `要加 160 行吗？`。
- 新行的默认值沿用最后一行的「任务类型 / 账号 / 时长」（这三列在批量作业里几乎总是一样的），
  其余留空。这一条很省事，别漏。

---

## 2. 单元格语义：单击选中，双击才进去编辑

Tabulator 配置：

    selectableRange: true,          // 区域选择
    selectableRangeColumns: true,
    selectableRangeRows: true,
    selectableRangeClearCells: true,
    editTriggerEvent: "dblclick",   // 双击才进编辑态
    editorEmptyValue: undefined,

配合键盘：
- 方向键移动选中格；`Shift+方向键` 扩选区域；`Ctrl+A` 全选。
- `Enter` / `F2` 进入编辑；`Esc` 取消编辑回到选中态。
- `Delete` 清空选中区域的内容。
- 选中态下直接打字 = 覆盖式进入编辑（和 Sheet 一样）。

## 3. 和 Google Sheet 无缝互贴（这条是重点）

    clipboard: true,
    clipboardCopyStyled: false,
    clipboardPasteAction: "range",
    clipboardCopyRowRange: "range",

**关键在 TSV 的解析必须正确**，Tabulator 默认的解析器对付不了带换行的单元格。
自己写一个 `parseTSV(text)`：

- 列分隔 `\t`，行分隔 `\r\n` / `\n`。
- **双引号包起来的字段里，`\n` 和 `\t` 都是内容，不是分隔符**；`""` 是一个字面双引号。
  文案列里几乎必然带换行，这一条做错，一条长文案就会被拆成十几行 —— 
  **这是本规格最容易做砸的地方，写完专门拿一段带换行的长文案测。**
- 反过来复制出去时也要按这个规则加引号，保证贴回 Google Sheet 一模一样。

粘贴的落位规则（照 Sheet 来）：
- 选中的是**单个格** → 从这个格往右下铺开，行不够就**自动加行**（加多少提示一句
  `粘贴时自动加了 143 行`）。
- 选中的是**一块区域**，粘贴内容正好等于这块 → 就地覆盖。
- 选中区域比内容大且是整数倍 → 平铺重复（Sheet 就是这个行为）。
- 粘贴前后各存一次快照，`Ctrl+Z` 能整块撤销（见第 6 节）。

## 4. 填充柄（右下角小十字）

选区右下角画一个 6×6 的小方块，鼠标移上去变十字光标。

- **往下/往上拖** → 按规律填充：
  - 纯数字（`01`、`7`）→ 递增，**保留前导零位数**（`01` → `02` … `10`）。
  - 结尾带数字的文本（`李良v01`、`shot_7`）→ 只递增结尾那段数字，前缀不动。
  - 选中的是两个格且能看出等差（`2`、`4`）→ 按步长 2 继续。
  - 认不出规律（纯文字、下拉列）→ 复制填充。
- **按住 `Ctrl` 拖** → 一律复制填充，不递增（用户明确要这个）。
- 往上拖是递减；拖回选区内部是清空（Sheet 行为，做了更像）。
- 拖动过程中在光标旁显示一个小气泡，实时显示将要填入的最后一个值，
  比如 `→ 李良v160`。这个小细节能省掉大量「拖多了再撤销」。

Tabulator 6 没有现成的填充柄，自己在表体上叠一层绝对定位的小方块 +
`mousedown/mousemove/mouseup`，通过 `table.getRanges()` 拿当前选区、
`row.update()` 写值。**别去改 Tabulator 源码。**

## 5. 行选择：小复选框，能刷、能 Shift

第一列固定一个复选框列（宽 36px，居中）：

- 表头的复选框 = 全选 / 全不选（只作用于当前筛选出来的行）。
- 按住鼠标**从一行往下滑** → 沿路全部勾上（`mousedown` 记起点，`mouseenter` 沿途设值，
  `mouseup` 结束）。往回滑是取消。
- `Shift+点击` = 从上一次点的那行到这行整段勾选。
- 底部状态栏 `已选 12 / 共 480`，点一下能「只看已选」。
- **「只准备选中的」从此只认这些复选框**，不再看单元格选区 —— 
  两套「选中」并存是现在最容易搞混的地方，界面上把复选框那一列的表头写死成「选」字。

样式：圆角 3px，未选是 1px 描边，选中填强调色 + 白色对勾，
和现在的深色主题一致，别用浏览器默认的方块。

## 6. 其他该有的表格能力

- **查找 / 替换**：`Ctrl+F` 打开一个浮条：`查找 [___] 替换为 [___] ☐区分大小写 ☐整格匹配
  [上一个][下一个][全部替换]`。作用范围：有选区就只在选区里，没选区就全表。
  「全部替换」前告知会改多少格，替换后可整体撤销。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`。至少 50 步。粘贴、填充、替换、
  删行、批量加行**都要算一步**（整块一次撤销，不是一格一格退）。
- **斑马纹**：`.tabulator-row:nth-child(even)` 给一层极淡的底色（深色主题下
  用 `rgba(255,255,255,.025)` 这个量级，别太重）。**悬停行**再加一层，
  **当前行**用左侧 2px 强调色竖条标出来 —— 几百行时这三层视觉线索缺一不可。
- **冻结列**：`#`、`选`、`任务名` 三列冻结在左边（`frozen: true`），
  横向滚动看账号/时长时不会迷路。
- **行高两档**：工具条上一个「紧凑 / 舒适」切换，紧凑档一屏能看 30 行以上。
- **列宽可拖 + 记忆**：拖过的列宽存 `settings` 的 `ui.tasks.colwidths`，下次打开还原。
- **虚拟滚动**：Tabulator 默认就是（`renderVertical: "virtual"`），确认开着 ——
  2000 行不能卡。做完拿 2000 行实测一次滚动流畅度，写进报告。
- **粘贴校验**：粘完立刻扫一遍，把明显不对的格标黄：任务类型不在下拉选项里、
  账号名不存在、时长不是数字、文案为空但其他列有值。底部一条
  `12 处可能有问题 [逐个看]`。**不阻止保存**，只是提醒 —— 批量作业里
  拦着不让保存比标出来烦人得多。

## 7. 验收（每条都要真跑）

1. `+ 行…` 输 160 → 一次加 160 行，新行继承了最后一行的类型/账号/时长。
2. 从 Google Sheet 复制 200 行 × 8 列（**其中文案列必须包含带换行和带引号的长文案**）
   → 选中第一格粘贴 → 200 行整整齐齐，**没有一条长文案被换行拆开**，
   也没有整块挤进一个格。自动加行的提示出现了。
3. 反过来：在 Orante 里框选 200×8 复制 → 粘回 Google Sheet，和原表逐格一致。
4. 单击选中不进编辑，双击才进；`Esc` 退出编辑内容不变。
5. 一个格填 `李良v01`，拖填充柄往下 20 行 → `李良v02`…`李良v21`，
   拖动时气泡显示 `→ 李良v21`。按住 `Ctrl` 再拖 → 20 行全是 `李良v01`。
6. 两个格填 `2`、`4`，往下拖 → `6, 8, 10…`。
7. 按住复选框往下刷 30 行 → 全勾上；`Shift+点击`第 100 行 → 30~100 全勾；
   底部显示 `已选 71 / 共 480`；「只准备选中的」正好准备这 71 个。
8. `Ctrl+F` 把某一列里的 `TIK-G-SIMONE` 全部替换成 `Lucy` → 提示会改 N 格，
   替换后 `Ctrl+Z` 一次性全退回去。
9. 造 2000 行滚到底，滚动不卡（报告里写实测感受和帧率大概值）。
10. 关掉 Orante 重开 → 列宽、行高档位还在。
