## 要解决的事

手写描述语的时候，很多张图其实是同一个人、同一个场景，描述语几乎一样。
现在只能一张张复制粘贴，或者花 API 额度让 Gemini 重写一遍。
**想要的是：写好一张，勾上另外十张，右键 → 同步过去。**

顺带把这个面板缺的基本操作补上：打开图片、打开所在文件夹、多选。

## A. 复选框与多选

### 长相

- 每张 `.img-card` **左上角**一个复选框，叠在缩略图上。
  平时**不显示**；鼠标移到卡片上时淡入；**已勾选的常显**。
- 不要用系统原生 checkbox —— 自己画一个 20×20 的圆角方框，未选是半透明描边，
  选中填主色 + 白色对勾，切换时 120 ms 缩放一下。
- 已勾选的卡片：整张加 2px 主色描边 + 轻微下沉的阴影，一眼看得出选了哪些。

### 顶部工具条

`subjects` 那一栏的标题行右边，选中数 > 0 时**滑入**一条：

    已选 6 张    全选   反选   取消全选        [ 同步描述语到选中… ]

- 选中数为 0 时整条不显示（不要留个空条占位）。
- 「全选」只选**当前这一组**（主体图 / 空镜分开算，两组各自独立选，别混）。

### 选择手势

| 操作 | 效果 |
|---|---|
| 点复选框 | 单张加 / 减 |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + 点卡片 | 单张加 / 减 |
| <kbd>Shift</kbd> + 点卡片 | 从上一次点的那张到这张，**整段选中** |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选当前组（焦点在这个面板、且不在输入框里时） |
| <kbd>Esc</kbd> | 取消全选 |

**普通单击卡片仍然是"把焦点放到这张"**（现有 `focusP` 行为），不要变成选中 —— 那会毁掉现在编辑描述语的顺手劲。

## B. 右键菜单

在卡片任意位置右键。**交互和 ③编排 那个菜单完全一致**（`placeMenu` 定位、点外面关、Esc 关、
超出屏幕自动翻边），把 `track.js` 里那套抽出来共用，别复制一份。

菜单长这样（分隔线就是这么分的）：

    打开图片
    打开图片位置
    ──────────────
    选中这张 / 取消选中
    全选（12 张）
    取消全选
    ──────────────
    同步描述语到选中的 6 张
    同步音色到选中的 6 张
    描述语 + 音色 一起同步
    ──────────────
    复制描述语到剪贴板
    清空这张的描述语

样式上比现在的 `.ctx` 再精致一点：**12px 圆角、1px 描边 + 柔和投影、条目 32px 高、
悬停整行填充而不是只变字色、分隔线用 1px 且左右留 10px 内缩、带 120 ms 的淡入 + 2px 上移**。
危险项（清空）用警示色，且放在最后、和上面隔开。

### 菜单项什么时候灰掉

| 项 | 灰掉的条件 |
|---|---|
| 打开图片 / 打开图片位置 | 文件不存在（`im.exists === false`） |
| 同步…到选中的 N 张 | **一张都没勾**，或者只勾了右键这一张本身 |
| 同步描述语 | 右键这张的描述语是空的 |
| 同步音色 | 右键这张的音色是空的 |
| 清空这张的描述语 | 本来就是空的 |

灰掉的项**仍然显示**（让人知道有这个功能），但点不动，`title` 写清楚为什么灰：
比如「先勾选要拷贝到的卡片」。

## C. 同步描述语（核心）

### 语义，写死别含糊

- **源** = 右键点的那一张，**不是**"选中的第一张"。
- **目标** = 当前所有勾选的卡片，**排除源自己**（源也被勾上了也不管它）。
- 覆盖式写入，目标原来有没有内容都直接盖掉。
- 空镜和主体图**可以互相拷**（都有描述语），不做限制。

### 接口

    POST /api/tasks/{tid}/images/copy-desc
    body {"from_p":"p03","to_ps":["p05","p07",…],"fields":["desc"]}   # fields 可含 desc / voice
    → {ok, n, changed:[{p, desc_old, voice_old}], skipped:[{p, why}]}

- `changed` 里**必须带旧值** —— 撤销要用。
- 目标里有不存在的图 / 已被删除的 → 进 `skipped`，不让整个请求失败。
- 走现有的 `images.patch`，一次事务写完再存盘，别一张一张 save。

### 撤销，必须有

一次覆盖十几张，手工恢复不了。所以：

- toast 上带一个<span class="btn-ref">撤销</span>按钮，**15 秒内有效**。
- 点撤销 → 用返回的 `changed` 里的旧值原样写回去。
- toast 文案：`✓ 描述语已同步到 6 张（p05 p07 p09 …）` + 撤销按钮。
- 撤销成功再给一条 `已撤销，6 张恢复原样`。
- **撤销数据只放在前端内存里**，不落库；页面刷新就没了，这可以接受（15 秒窗口）。

## D. 打开图片 / 打开图片位置

后端两条新路由，平台分支**照抄 `server.py` 第 135 行和第 890 行现成的写法**，别另写：

    POST /api/tasks/{tid}/image/{p}/open      # 系统默认看图程序打开
    POST /api/tasks/{tid}/image/{p}/reveal    # 资源管理器里选中这个文件

- 文件不存在 → `OranteError`，前端 toast 一句人话，不要 traceback。
- 路径必须**限制在任务目录内**（和 `/media/{tid}/{rel}` 一样做一次 `resolve()` + 父目录校验），
  别让 `p` 拼出任务目录外的路径。这条写进测试。
