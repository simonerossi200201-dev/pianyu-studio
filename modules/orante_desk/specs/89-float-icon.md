# 规格 89 · 悬浮图标：窗口最小化之后，Orante 融成屏幕上一个始终置顶的小图标

日期：2026-09-24。起因是用户的原话：「当用户将软件最小化的时候，要让这个软件融化成一个
小小的始终置顶在屏幕上的悬浮图标，而且不管用户同时多开多个窗口，都要融化在这个图标里面。」

## 要的效果

- 所有 Orante 窗口都最小化 → 屏幕上留一个小图标（用根目录的 `Orante me.png`），永远在最上层。
- **多开几个窗口也只有这一个图标**。任意一个窗口被唤醒 → 图标自己藏起来。
- 双击图标 → 把全部窗口一起叫回来。
- 右键 → 呼出全部 / 单独呼出某一个 / 图标大小 / 贴边隐藏开关 / 隐藏本次 / 退出 Orante。
- 滚轮缩放（40–256 像素），拖动摆位置；大小和位置都记住。
- 贴边隐藏：拖到屏幕边上就**缩成一个小徽标**贴在边上，鼠标碰上去恢复整张图。默认**开**。
- 默认大小 **96 像素**。

## 怎么做的

### A. 不引入任何依赖、不产生任何二进制

用 Python 自带的 tkinter 画（`orante/floaticon.py`），独立进程跑：`pythonw -m orante.floaticon`。
64 / 65 / 90 号已经为了杀毒软件把编译产物清干净了，这里不许开倒车：
不用 PyQt、不用 pystray、不用 pywin32、更不打包成 exe。

画法两档，自动降级：

1. **分层窗口**（`UpdateLayeredWindow` + 预乘 alpha 的 BGRA 位图）：逐像素透明，PNG 的羽化边干净，
   透明的地方鼠标穿透。
2. 上面那条任何一步失败 → 退回 **抠背景色**（`-transparentcolor`），边上会有一点毛刺，但一定显示得出来。

置顶不是设一次就完事：有些全屏程序会把别人压下去，所以每 3 秒重新宣告一次
（`-topmost` + `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)`）。

### B. 多开窗口怎么共用一个图标

`orante/winlist.py` —— 窗口登记表。每个窗口在 `data/windows/<端口>.json` 留一条
`{port, pid, hwnd, title, beat}`，主程序每 8 秒刷一次心跳（`main.py::_bind_float_icon`）。

- 心跳超过 30 秒没刷 = 这个窗口不算数了。进程被强杀、掉电、忘了注销，都不会留下假记录。
- 图标进程每 400 毫秒看一眼：把每个登记在册的窗口拿 `IsIconic` / `IsWindowVisible` 问一遍，
  **全都最小化了才浮出来**；句柄还不知道（浏览器模式）的按「开着」算，免得图标挡着人。
- 图标进程自己也有锁 `data/floaticon.lock`（pid + 心跳）：第二个窗口启动时发现锁还新鲜就不再起一个。
- 一个窗口都不剩、撑过 20 秒 → 图标进程自己退出。

### B2. 贴边收起来是「缩成徽标」，不是「推出屏幕」（0924 修）

第一版是把整张图推出屏幕、只留 12 像素。**这是个会把图标弄丢的设计**：
图标是圆的，最边上那 12 列几乎全是透明像素，而分层窗口的透明处鼠标是穿透的——
于是那条缝既看不见也点不着；图标放得越大越明显（用户把它滚到最大之后，
「一下子就消失了，再也不会出现了」）。

现在：贴边 = 缩成一个 `max(28, 34% × 当前大小)` 的小徽标，**整块都在屏幕里**，
一定看得见、一定点得着；鼠标碰上来恢复整张图（必要时整张拉进屏幕）。

配套的三条保险：

1. `tick()` 每一轮都兜异常。循环一旦断掉，图标就再也不出现——这是那次「找不回来」的
   另一半原因（进程死了没人管）。
2. 每个鼠标回调都套 `@_guard`：出错只写日志，并把状态复位回「能看见」。
3. 主程序的心跳线程每 8 秒看一眼：图标进程没了（或被用户结束了）就重新拉起来（30 秒冷却）。
4. 窗口大小一变，tk 的 Enter/Leave 会漏事件，所以每一轮还按鼠标实际坐标对一次账
   （`_sync_peek`），不靠事件也能正确展开 / 收起。

### C. 设置

| 键 | 默认 | 说明 |
|---|---|---|
| `ui.float_icon` | 开 | 总开关。关掉之后图标进程下一轮心跳时自己退出 |
| `ui.float_icon.size` | 96 | 40–256，滚轮 / 右键菜单也能改 |
| `ui.float_icon.edge_hide` | 开 | 贴边隐藏 |
| `ui.float_icon.pos` | 空 | `"x,y"`，图标自己记，不进设置页（HIDDEN_KEYS） |

### D. 退出 Orante

右键菜单里的「退出 Orante」给每个窗口发 `WM_CLOSE`，**不杀进程**——正在出片的任务要走自己那套收尾
（`_bind_closing` 里的 flush）。发完等 1.5 秒，图标自己退出。

## 验收

`tools/test_spec89.py`（22 条，Linux 上就能跑）：登记表读写 / 过期 / 坏文件，
「什么时候浮出来」的判断（含只剩一个开着、句柄未知两种），大小钳制，位置解析与越界拉回，
四条边的贴边几何与滑回，单实例锁（自己的锁不算别人、过期不算、别人的锁不许删），
图片处理（等比放进方块、透明边、抠色兜底、图标回退），设置页三项与中英文案，
以及「不许引入新依赖」。

`tools/test_spec89_tk.py`（4 条界面冒烟）：真的把图标跑起来，对**每个尺寸 × 每条边**
量一次窗口几何，要求任何时候至少有 24×24 像素落在屏幕里；还专门走一遍用户踩的那条路
（滚轮一路放大 → 鼠标移开 → 收起）。没有 tkinter 或没有显示器就跳过，
Windows 上和带 Xvfb 的机器上都跑得起来。

置顶、右键菜单、分层窗口画得好不好看，还是只有 Windows 上看得见：
双击 `tools\悬浮图标-自测.bat`，图标会直接显示出来（`--demo`，不用等窗口最小化），
拖一拖、滚一滚、右键看看菜单，右键 →「隐藏图标（本次）」或关掉那个控制台窗口即可结束。
