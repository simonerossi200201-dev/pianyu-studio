## 现状

每张卡片底部已经有一条 `.bar > i`，`onTime` 按 `currentTime/duration` 改它的宽度 ——
**只能看，不能碰**。`.stage` 整块点一下是播放/暂停。播完 `onEnded` 把条子清零。
用户检查片子时想：拖回开头再看一遍刚才那一下；暂停后一帧一帧往前往后蹭，看嘴型、看手、看穿帮。
现在只能等它重放。

## 要做的

### A. 悬停出现、离开消失

- 鼠标进入 `.stage` → 进度条 120ms 淡入；离开 → 200ms 淡出到 `opacity:0`。
  **拖动过程中鼠标跑出 `.stage` 也不消失**（`pointer capture` 期间强制显示），松手后才按规则淡出。
- 不悬停时**完全不显示**（不是变细，是没有），画面不被遮。
  例外：正在拖动、或键盘刚做过逐帧（1.2 秒内），也显示。
- 现有那条 `.bar` 直接改造成新的，不要留两条。

### B. 长相（要好看）

    ┌──────────────────────────────────────────────┐
    │                                              │
    │                 （视频画面）                    │
    │                                              │
    │                 ▲ 00:03.12                    │   ← 悬停/拖动时的时间气泡，跟着鼠标
    │ ━━━━━━━━━━━━━━━●─────────────────  0:03 / 0:08 │   ← 底部：已播（主色）· 圆点 · 未播（半透明白）· 时间
    └──────────────────────────────────────────────┘

- 轨道贴底，左右各留 8px；高度 4px，鼠标进入轨道区域（上下各扩 10px 的命中区）时变 6px；
  圆角；未播部分 `rgba(255,255,255,.28)`，已播部分用界面主色（`var(--accent)` 或现有播放高亮那个色）。
- 圆点直径 12px，只在悬停轨道或拖动时出现，拖动时放大到 14px 并带一圈 4px 半透明光晕。
- 时间气泡：等宽数字，`mm:ss.ff`（ff = 帧号，按 C 节的 fps 算），黑底 80% 透明、圆角 4px，
  跟随鼠标横坐标，靠边时不出界。
- 右下角 `当前 / 总长` 小字，只在悬停时显示；和现有的 `.rate`（倍速角标）别叠在一起，倍速挪到右上或左下。
- 底部 24px 的渐变遮罩（透明 → 黑 45%）垫在进度条后面，浅色画面上也看得清；遮罩同样只在悬停时出现。
- 深色 / 浅色主题都要过一遍（`css_theme_check.py` 那套如果还在用，跑一次）。

### C. 拖动与点击

- 指针事件（`pointerdown` / `pointermove` / `pointerup`），`setPointerCapture`，
  鼠标拖出卡片也继续跟手。
- 点击轨道任意位置 = 跳到那里；按住拖 = 连续 seek。拖动时每帧最多 seek 一次（`requestAnimationFrame` 合并），
  seek 用 `currentTime =`，**不要用 `fastSeek`**（那个是找关键帧，看不准）。
- 拖动开始时如果在播放：先暂停，松手后**恢复播放**；本来暂停的松手后仍暂停。
  记在 `wasPlaying` 上，别用 `playingS` 猜。
- **轨道上的所有指针事件 `stopPropagation`**，否则会触发 `.stage` 的点击切换播放/暂停（现在就是这么绑的）。
- 播完之后（`onEnded`）：**不再把条子清零**，停在 100%，圆点在最右，可以直接拖回去。
  `play(true)` 从头播的逻辑不变（它自己把 `currentTime` 归零）。
  `resetBarS` 只在切换到别的段、换片重载时调用。
- 拖到位置后 `onTime` 照常更新宽度，别出现拖完一松手条子跳回去的抖动（`pointerup` 之后先手动同步一次宽度再放开）。

### D. 逐帧

- 键：`,` 上一帧、`.` 下一帧（Premiere / YouTube 的习惯，`←` `→` 现在是切上一段 / 下一段，**不动**）。
  按住 `Shift` 变成 ±1 秒。只对当前卡片（`curS`）生效，视频不存在就忽略。
- 一帧 = `1 / fps`。fps 从收片数据里拿（`review.get_review` 的段里如果已经带 `fps`，用它；没有就让
  `_seg_payload` 从 `tails.video_info` 补一个 `fps` 字段，缓存到 manifest 里别每次都探；实在拿不到按 24）。
- 逐帧时自动暂停；进度条按 A 节规则显示 1.2 秒；时间气泡显示到帧号。
- `?` 帮助（如果 ⑤ 已有快捷键说明）加这两行；没有就在 `review.hint` 那行文字里补上。

### E. 别拖慢视频墙

- 五列几十个 `<video>` 同时在页面上。**监听器只挂在当前悬停的那一张**（在 `.stage` 的 `pointerenter` 时绑、
  `pointerleave` 时解），不要给每个 video 都常驻 `mousemove`。
- `timeupdate` 一秒才 4 次，拖动时要靠 rAF 自己算位置，不要等它。
- 不新增任何依赖，不引入播放器库，原生 `<video>` 上叠一层就够。

### F. 测试 `tools/test_spec71_ui.js`（沿用现有 `test_spec*_ui.js` 的挂法，jsdom 里 `HTMLMediaElement` 要打桩）

- 未悬停时进度条 `opacity` 为 0；`pointerenter` 后为 1；`pointerleave` 后回 0；拖动中 `pointerleave` 仍为 1。
- 点轨道 60% 处 → `video.currentTime ≈ duration × 0.6`。
- 拖动：`pointerdown` 时 `paused=false` → 立即 `pause()`；`pointerup` 后 `play()` 被调一次；
  本来暂停的拖完不调 `play()`。
- 轨道上的 `pointerdown` 不触发 `onStageClick`（播放状态没被切换）。
- `ended` 后条子宽度仍是 100%（不再清零）。
- `.` 键 `currentTime` 增加 `1/fps`；`Shift+.` 增加 1；焦点在输入框里时不响应。
- `python -m pytest tools/` 全过。

## 验收

1. ⑤收片 随便一张卡片：鼠标不在上面时画面干干净净；移上去底部淡出一条进度条，移开又没了。
2. 播放中按住圆点来回拖：画面跟手，松手继续播；暂停时拖，松手仍是暂停。
3. 播完停在最右，拖回开头能再看一遍，不用先点播放。
4. 暂停后按 `,` `.` 一帧一帧走，气泡里帧号在变；按住 Shift 一次一秒。`←` `→` 仍是切上一段 / 下一段。
5. 拖动时鼠标划出卡片、划到别的卡片上，进度条不掉、不会误触别的卡片播放。
6. 五列满屏视频时悬停、拖动不卡顿。
