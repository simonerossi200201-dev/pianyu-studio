## 问题（截图已看）

机位表 7 列（编号 / 名称 / 类 / 正脸 / rank / 提示词 / 操作）硬塞进 ②多模态 那张约 520px 宽的卡片里：

- 「名称」列只剩一个字宽，「观众视角」显示成「观」，「舞台侧」显示成「舞」；
- 「提示词」textarea 只有 40 来像素宽，每行一个字竖着排，根本没法读；
- 整表字号 11.5px，再加 `max-height:360px` 内滚动套在抽屉外滚动里，滚轮经常滚错层；
- 列头 `rank`、`类`、`周期` 没人看得懂是什么。

功能没问题，纯粹是排版把内容挤没了。

## 要做的

### A. 表格 → 每条一张卡片，两行

把 `<table class="cov-tbl">` 换成 `<div class="cov-list">`，每条记录一个 `.cov-row`：

    ┌────────────────────────────────────────────────────────────────┐
    │ 04  [观众视角        ]  类别 [B ▾]  ☐ 正脸  权重 [3]      ↑ ↓ ✕ │
    │ ┌────────────────────────────────────────────────────────────┐ │
    │ │ 摄影机放在观众席中后排，微微仰视舞台，人物在画面中占三分之一…  │ │
    │ │                                                            │ │
    │ └────────────────────────────────────────────────────────────┘ │
    └────────────────────────────────────────────────────────────────┘

- 第一行 flex：编号 44px 固定；名称 `flex:1`（**至少能完整显示 8 个汉字**）；其余控件按内容宽；
  操作三个按钮靠右。窄到放不下时（<480px）名称独占一行，其余换到下一行，**不许横向滚动**。
- 第二行提示词 textarea **占满整卡宽度**，`min-height` 3 行、`field-sizing: content` 或 JS 自动长高到内容
  （上限 12 行），字号 13px、行高 1.5，等宽字体不强制。
- 卡片之间 8px 间距、1px 描边、圆角 6px；当前有焦点的卡片描边高亮，让人知道在改哪条。
- 去掉 `.cov-tbl-wrap` 的 `max-height:360px` 内滚动，列表完整铺开；在「机位 / 动作」标题右边加一个
  「收起 / 展开」，默认**收起**只显示 `04 观众视角 · B · 权重 3` 这种一行摘要（因为一般人不来改这里），
  点开才展开成卡片。展开状态记在 localStorage，下次进来沿用。
- 动作表同样处理（没有类别 / 正脸，有阶段）。

### B. 列头 / 标签用中文，并解释清楚

`zh.json`：

| 键 | 现在 | 改成 | 悬停说明（`title`） |
|---|---|---|---|
| `gemini.cov.id` | 编号 | 编号 | 两位数字，决定默认排序 |
| `gemini.cov.name` | 名称 | 名称 | 给自己看的，不进提示词 |
| `gemini.cov.class` | 类 | 类别 | A/B/C/D 各是什么，**从 32 号规格抄准确的定义** |
| `gemini.cov.frontal` | 正脸 | 正脸机位 | 勾了 = 这个机位人物正对镜头；「扩图不生成正脸」开着时会跳过它 |
| `gemini.cov.rank` | rank | 权重 | 1~4，数字越大越常被挑中 |
| `gemini.cov.phase` | 周期 | 阶段 | 起势 / 展开 / 保持 / 收束——这个动作适合放在一段话的哪个阶段 |
| `gemini.cov.text` | 提示词 | 提示词 | 会原样拼进扩图提示词 |

阶段下拉的选项显示中文（起势=start，展开=develop，保持=hold，收束=resolve），值不变。
类别下拉显示 `A · <一两个字的含义>`，含义从 32 号取。
