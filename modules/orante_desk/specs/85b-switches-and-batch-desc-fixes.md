## 1. 必修（现在就是坏的）

1. **模板里用了 `window.`**：`gemini.js` 2458 / 2463 / 2464 三处 `@click="window.GeminiSwitchLogic..."`。
   Vue 3 模板只允许白名单全局（Math、Date、JSON…），**`window` 不在里面**，所以「只选缺的」、点缩略图、点缩略图勾选框
   三个操作一点就报错、什么都不发生——也就是验收第 6 条（某个任务只勾 2 张）根本做不到。
   node 逻辑测没测模板，所以没抓到。改法：在 `setup` 里把 `selectMissing` / `toggleImg` 包成方法 return 出来，模板里直接调。
2. **左栏搜索框是摆设**：`v-model="batchDlg.filter"` 绑了，但 `v-for` 遍历的还是 `batchDlg.tasks` 全量。
   做一个 computed `batchTasksShown`（按任务号 / 名字过滤 + 「只看缺描述语的」开关），`v-for` 用它。
   搜索框的 placeholder 现在写的是「只看缺描述语的」——改成「搜索任务号 / 名字…」，「只看缺描述语的」另做一个勾选。
