## 0. 设计原则：这种模式下效率不能掉

用户明确要求：**繁琐的步骤必须设计到不繁琐。** 所以本规格的核心不是「两阶段」，而是：

1. **默认无人值守。** 检查台是异常处理台，不是必经关卡。绿的自动放行，人只在红黄时被叫来。
2. **相邻依赖的流水线，不是两个大阶段串行。** 接片 s004 只依赖两件事：
   s003 已收且尾帧合格、s005 的锚点图已定（编排时就定了）。
   所以主片和接片**交错并行**：s001 一收，s002 立刻能开工，此时 s003/s005 还在生成。
   总时长 ≈ 现在的 1.1 倍，而不是 2 倍。
3. **能自动修的先自动修。** 跨度太大先自动换锚点，换不动才拦人。
4. **一次调用干完的事绝不分两次。**

## 1. 调度：从「一批」改成「按依赖的有向图」

`generate.py` 现在是「把 planned 的段全部丢进去」。锚点模式下改成：

    anchor 段：没有前置，直接进队列（和现在一样）
    bridge 段 s(n)：前置 = seg(n-1).status == collected
                         且 seg(n-1).bridge_ready == true      // 尾帧抽好+质检过+跨度<4
                         且 seg(n+1).image 已定
             满足才进队列；否则显示「等 s003 收片」，不算失败

- 主片一收片 → 自动跑 `tails.extract` → 算跨度 → 满足就把它的接片推进队列。
  **整条链不需要人点第二次「生成」。**
- 账号并发、优先级、队列规则全部沿用 19 号，不另起一套。
- 前端方块：接片段在等前置时画成**空心带虚线**，和「排队中」区分开。

## 2. 跨度处理：先自动换锚点，换不动才拦

跨度评分（36 号）出来后：

| 分 | 处理 |
|---|---|
| 0~2 | 直接放行 |
| 3 | 放行，但标黄，检查台里能看到 |
| 4~5 | **自动换锚点**：在图池里挑候选（遵守 spec 30 的间隔规则、不用 blocked 图），对每个候选重算跨度，取最低的那张；记 `auto_swapped_from`，同步钉进 ③ 配图轨。**仍然 ≥4 才拦住**，进检查台红区 |

自动换锚点每次最多试 4 张候选（4 次多模态调用），别把图池全跑一遍。
换了要在日志和检查台里写清楚：`s004 的锚点 p07 → p11（跨度 5 → 2）`。

## 4. 模式开关（④ 生成面板）

工具条加两档切换，**现有模式保持默认**：

    生成方式：  (•) 逐段首帧          ( ) 锚点 + 接片
                每段一张图起头         主片锁身份，接片补连贯

选「锚点 + 接片」后：
- 任务卡片下方画一条链：`● s001 ── ◇ s002 ── ● s003 ── ◇ s004 …`，实心=锚点、空心=接片，
  点某一段可切换 role（相邻段会受影响，切换时给一行提示）。末段强制 ●。
- 锚点段配图**自动开启间隔排列**。
- 「全部生成」一次点击跑完整条链（含自动衔接），不需要第二次点。
- 模式存进 `manifest.mode`，任务级别；新任务默认沿用上一次的选择。

## 5. 重生联动

| 动作 | 自动发生 |
|---|---|
| 重生主片 s003 | 重抽尾帧 → 重算 s004 跨度 → 若 s004 已收且跨度仍 ≤3：**不动**；否则 s004 打回 planned 重排队 |
| 重生接片 s004 | 只重生它自己 |
| 换 s005 的锚点图 | 重算 s004 跨度，同上规则 |
| 主片被拒/失败 | 它后面的接片显示「等前置」，不算失败，不消耗重生次数 |

## 6. 验收

1. 一个 9 段任务，选「锚点 + 接片」，点一次「全部生成」→ **不再点任何东西**，
   9 段全部收片。日志里能看到 s002 在 s003 还没收时就已经开工（流水线生效）。
2. 总耗时和同任务「逐段首帧」模式对比，写进报告。目标 ≤ 1.3 倍。
3. 手动把某个锚点图换成姿态差很大的 → 自动换锚点触发，日志和配图轨都有记录；
   把图池缩到只剩 1 张 → 换不动，进检查台红区，链条其他部分照常跑。
4. Flow 和 Grok 各跑一条完整链，接片的首尾帧肉眼确认对上号。
5. 成品交 Cutora 拼接 → **缺失文案清单没有因为这个模式多出任何一条。**
6. 重生 s003 → s004 按第 5 节规则联动，日志写明「s004 跨度 2，不动」或「s004 打回」。
