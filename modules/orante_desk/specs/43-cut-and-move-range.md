## 1. Ctrl+X 剪切

按 Google Sheet 的手感：**当场把内容拿走**（不是 Excel 那种虚线等粘贴才清）。

1. 和 `Ctrl+C` 一样先把选区序列化成 TSV 写进剪贴板（复用 `selectedGrid()` + `TasksSheet.serializeTSV`）。
2. 紧接着清空选区里**可写**的格子。
3. **整个剪切算一步撤销**（`pushUndo()` 开头压一次，中间 `holdUndo = true`），`Ctrl+Z` 一次全回来。
4. 清完 `markDirty()`，走 42 号的自动保存。
5. 顶栏 toast：`已剪切 3 行 × 2 列`。

**哪些格子不能清**（遇到就跳过那一格，别整体失败）：

- `_sel`（勾选列）、`id`、`status` —— 本来就不是数据列
- 文案列且该行 `status` 不是 draft/空（41 号里 `editable` 已经这么判了，**复用同一个判断，不要另写一套**）

有跳过的格子时 toast 补一句：`2 格已开工，没有清（要改先打回草稿）`。

## 2. 拖选区边框移动

### 手感

- 鼠标移到选区**边框上**（四条边，4px 宽的命中带）→ 指针变 `move`。
- 按住拖 → 一个和选区同样大小的**虚线轮廓**跟着走，**按单元格网格吸附**（不是像素级自由拖）。
- 松手 → 选区里的值搬到新位置，**源位置清空**，选区跟着跳到新位置。
- **按住 `Ctrl` 拖 = 复制**（源位置保留），轮廓右下角显示一个小 `+`。
- `Esc` 取消，轮廓消失，什么都不改。
- 整次移动 **算一步撤销**。

### 和别的手势不能打架

| 手势 | 触发区 |
|---|---|
| 拖行排序 | `#` 列左侧 14px 的六点把手（39 号） |
| 填充柄 | 选区右下角那个 7px 方块（33 号） |
| **移动选区** | 选区四条边的 4px 带，**但要排除右下角 14×14 的方块**（那是填充柄的地盘） |
| 新建框选 | 选区内部、以及选区外的任何单元格 |

实现上：给 `.tabulator-range-overlay` 里那个 `.tabulator-range-active` 外面套一层自己的
命中层（`position:absolute`，四条边各一个 4px 的 div，`pointer-events:auto`），
**不要去改 Tabulator 的 overlay 元素本身**（它每次渲染都会被重建）。
`mousedown` 时 `preventDefault()` + `stopImmediatePropagation()`，
免得被 39 号那两个 capture 监听和区域选择抢走。

### 落点规则

- 按**行偏移 + 列偏移**整体平移，保持选区形状。
- **超出下边界** → 自动加行补齐（和粘贴一致），toast 说明加了几行。
- **超出右边界 / 左边界** → 不允许，轮廓变红，松手不生效（列是固定的业务列，不能凭空长出来）。
- 目标区域里有**不能写的格子**（同第 1 节那张表）→ 整次移动**拒绝**，轮廓变红，
  松手 toast 说明是哪几格挡住的。**不做部分成功**，那样最容易出事故。
- 源和目标**重叠**也要正确：先把源的值整体读进内存，再清源，最后写目标。

### 视觉

- 轮廓：2px 虚线 `var(--accent)`，`4px` 圆角，半透明底 `rgba(217,163,79,.08)`。
- 不合法时轮廓和虚线变 `var(--bad)`。
- 跟手小标签（复用 39 号那套样式）：写 `移动 3×2` 或 `复制 3×2`。

## 3. 右键菜单补齐

现在 `rowContextMenu` 只有行级操作。在选区上右键时，菜单顶部加一组单元格操作：

    剪切          Ctrl+X
    复制          Ctrl+C
    粘贴          Ctrl+V
    清除内容      Delete
    ──────────
    （原有的行级菜单项）

不能写的格子对应的项置灰，悬停说明原因。

## 验收

1. 选 3×2 按 `Ctrl+X` → 剪贴板里是正确的 TSV（粘到记事本核对），源格子清空，
   toast 报数；`Ctrl+Z` 一次全部回来。
2. 选中含**已开工行**的文案格剪切 → 那几格没被清，toast 说明；其余格子正常清。
3. 拖选区边框移到别处 → 值搬走、源清空、选区跟到新位置；`Ctrl+Z` 一次回来。
4. 按住 `Ctrl` 拖 → 源保留，轮廓有 `+`。
5. 往下拖超出最后一行 → 自动加行，toast 说明加了几行。
6. 往右拖超出最后一列 → 轮廓变红，松手什么都不变。
7. 目标区域盖到已开工行的文案列 → 轮廓变红，整次拒绝，toast 点名。
8. 源和目标重叠（往右下挪一格）→ 结果正确，没有把自己覆盖成空。
9. 边框拖动**不会**误触发：拖行排序、填充柄、新建框选。右下角 14×14 仍然是填充柄。
10. `Esc` 取消正常。
11. 右键菜单的四项都能用，不可写时置灰。
