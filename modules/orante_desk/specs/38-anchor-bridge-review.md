## 1. 尾帧检查台

### 1.1 什么时候出现

**不是关卡。** 只在有红/黄项时，④ 生成面板顶部出现一条横幅：
`锚点链有 2 处需要看一下 [打开检查台]`。全绿时横幅不出现，链条自己跑完。
工具条上常驻一个「尾帧检查台」按钮，想看随时看。

### 1.2 长相

每个接片一张卡，三格并排，**问题最大的排最前**：

    ┌─ s004 接片 · 跨度 4 ────────────────────────────────────┐
    │  ┌────────┐    ┌──────────────┐    ┌────────┐          │
    │  │s003 尾帧│ →  │ 过渡          │ →  │p07 锚点 │          │
    │  │ [图]   │    │ ▁▂▃▅ 偏大      │    │ [图]   │          │
    │  └────────┘    └──────────────┘    └────────┘          │
    │  现在：右手举到胸口，头偏左，视线在台下                        │
    │  目标：双手交叠身前，正对听众，温和微笑                        │
    │  理由：右手要从胸口放回身前，同时头要转正，6 秒内偏赶            │
    │  台词：It comes from the Spirit of truth…                  │
    │  [自动换锚点] [挑锚点…] [重生 s003] [改提示词] [手挑尾帧] [通过] │
    └──────────────────────────────────────────────────────┘

顶部汇总 + 三个批量按钮：`全部自动换锚点（红色项）` / `全部通过（黄色项）` / `按跨度排序`。

### 1.3 五个动作

- **自动换锚点**：调 37 号第 2 节的逻辑，当场重算并刷新三格。
- **挑锚点…**：图池网格，每张图角上直接显示**对这个接片的跨度分**（悬停才算，别一打开就算全部），点选即换，同步钉进配图轨。
- **重生 s003**：走现有重生；回来后自动重抽、重算、刷新。
- **改提示词**：打开这个接片的 `prompt_final` 编辑，`prompt_locked`。
- **手挑尾帧**：滑块在倒数 1~15 帧滑动，实时预览，自动挑的那张标 ★；选定后重算 pose 和跨度。
- **通过**：黄色项人工放行；红色项不能直接通过，必须先做前四个之一。

## 2. 收片墙

- 卡片角标：锚点 ●、接片 ◇。接片卡片多一行灰字 `首帧 ← s003 尾帧 · 尾帧 → p07`。
- 连播时在接片进入的瞬间顶部闪一下 `◇ 接片` 小标，方便肉眼盯衔接。
- 接片画质略低是预期行为，卡片上用一个小 ⓘ 说明，**不要标成问题**。
- 「查漏补缺」和落盘校验（21/24 号）对接片照常生效；
  首帧对配图的校验对接片改成**首帧对上一段尾帧**（aHash 距离应很小）。

## 3. A/B 验收（**这是决定要不要把新模式设成默认的依据**）

同一段文案、同一批图、同一个账号，各跑一条：`逐段首帧` 和 `锚点 + 接片`。
两条成品都交 Cutora 拼接，报告里回答：

1. 画面连贯性：肉眼看段与段之间的姿态跳跃，哪条更自然（挑 3 个切点截图对比）。
2. 接片画质：随机 3 个接片和相邻主片各截一帧，肉眼对比 + 拉普拉斯锐度数值。
3. 总耗时：两条各多少分钟，人工介入了几次。
4. 缺失文案清单：两条各几条。
5. 检查台：这一轮出现了几个红/黄，自动换锚点解决了几个，人工处理了几个。

**在拿到这组对比之前，新模式不设为默认。**
