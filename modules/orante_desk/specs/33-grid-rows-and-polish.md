## 1. 行拖拽排序

Tabulator 自带 `movableRows`，接上就行，但**不要让整行都能拖** ——
整行可拖会和单元格框选打架（一按下去分不清是想选还是想拖）。

做法：

- 第一列（`#` 序号列）左侧留 14px 做**拖拽把手**，鼠标移上去显示六点图标（⠿）
  和 `cursor:grab`，按住才能拖。表格配置 `movableRows: true` +
  `rowHandle: true` 挂在这一列。
- 拖动时被拖的行半透明（`opacity:.55`），落点画一条 2px 的 `--accent` 横线。
- **多行一起拖**：如果拖的这一行在勾选集合里，就把**所有勾选的行**一起搬走，
  保持它们原来的相对顺序。这是批量作业里最省事的一条。
- 松手后按新顺序重排 `row_order` 并存盘：

      POST /api/tasks/reorder   body {"ids": ["T0014","T0011", ...]}   # 全量新顺序

  后端一次性 UPDATE，然后 `events.emit("tasks.changed")`。
- **拖拽要能撤销**（`Ctrl+Z`），算一步。

## 2. 批量删除

工具条上加 `删除选中`（红色描边按钮，没勾选时置灰）。

删之前按任务状态分成两堆，**弹窗里分开写清楚**：

    要删掉 12 行：
      · 9 行还是草稿（没有任务号、没建文件夹）→ 直接删掉
      · 3 行已经开工（T0011 / T0012 / T0013）→ 移进「回收」，磁盘文件不动
    [取消]  [确认]

规则：

- **草稿行**（没有 `id` 或 `status='draft'` 且没有 `dir`）→ 真删。
- **已开工的任务** → `status='trash'`，**绝不删磁盘上的任何东西**。
  这条要在弹窗里明写「磁盘文件不动」，让用户放心。
- 正在跑的任务（有 running 的 job）→ **不许删**，弹窗里单独列出来并说明
  「T0016 正在生成，先停掉再删」。
- 删完 toast 报 `删掉 9 行草稿 · 3 个任务移进回收`。
- **删除要能撤销**（`Ctrl+Z`）：草稿行整批恢复，移进回收的改回原状态。

键盘：勾选后按 `Delete` 等同于点这个按钮（要弹同一个确认窗，不能一按就没）。

## 3. 填充柄重做

现在那个 `.tg-fill` 是 8px 实心方块 + `padding/margin` 负值的 hack，又大又糙。
重做成这样：

    .tg-fill{
      position:absolute; width:7px; height:7px; box-sizing:border-box;
      background:var(--accent); border:1px solid var(--panel);
      border-radius:2px; z-index:20; cursor:crosshair;
      box-shadow:0 0 0 1px rgba(0,0,0,.55);
      transition:transform .08s ease;
    }
    .tg-fill:hover{ transform:scale(1.35) }

- **只在有选区时出现**，没选区时 `display:none`。
- 位置贴在选区右下角，**压住边框的外侧一半**（`transform:translate(50%,50%)`），
  像 Sheet 那样骑在角上，不要整个悬在格子外面。
- 命中区域可以比视觉大（外面套一层 14×14 透明的 `::before`），
  这样好点中，但**看起来还是 7px**。
- 拖动时的提示气泡 `.tg-fill-tip` 保留，字号降到 11px，圆角 5px，
  背景加 `backdrop-filter: blur(6px)`。

## 4. 整体质感

一次性把这张表调到「看着舒服、久看不累」。**只动 CSS，不动结构。**

**表头**
- 高度 32px（紧凑档 26px），底部 1px `--rule-2`，**不要竖直分隔线**（现在每列一条线太吵）。
- 列名 `--ink-2`，12px，字重 500，`letter-spacing:.02em`。
- 第一行那排灰色的说明文字（「保存后自…」「任务名（可空，自…」）现在被截断得很难看：
  改成**只在鼠标悬停时以 tooltip 显示完整说明**，表头本身只留正式列名。
  这样表头一下就清爽了。

**行**
- 行高：舒适档 34px，紧凑档 26px。
- **去掉单元格的竖直边框**，改成只在少数几处放分隔线：
  勾选列之后、`账号` 之前各一条 1px `--rule`。列之间靠留白区分就够了。
- 单元格左右内边距 10px（紧凑 6px），文字垂直居中。
- 数字和 ID 类（`#`、优先级、时长）用 `var(--mono)`，其余用 `var(--ui)`。
  等宽字体让一列数字对得整整齐齐，这一条对几百行的表帮助很大。
- 文本溢出：单行省略号 + 悬停 tooltip 显示全文（文案列尤其需要）。

**状态与色**
- 沿用 31 号定的那套叠色，不要再引入新颜色。
- `账号` 列的圆点改成 6px，和文字基线对齐。
- `状态` 列的胶囊（片齐 / 草稿）：高度 20px、圆角 10px、11px 字、
  1px 描边 + 8% 同色底，不要实心大色块。
- 整张表外面一圈 1px `--rule` + 8px 圆角，和面板其他卡片一致。

**滚动与定位**
- 表头 sticky（Tabulator 默认就是，确认没被 CSS 破坏）。
- 冻结列（`#`、`选`、`任务名`）右侧加一条 1px `--rule-2` 和一层很淡的右向阴影
  `box-shadow:6px 0 12px -8px rgba(0,0,0,.6)`，横向滚动时能看出「这里是冻结区边界」。
- 滚动条沿用全局那套细滚动条样式。

## 5. 验收

1. 按住 `#` 列左边的把手拖一行到别的位置 → 顺序变了，重开软件顺序还在（`row_order` 存住了）。
2. 勾选 5 行（不连续），拖其中一行 → 5 行一起搬走，相对顺序不变。`Ctrl+Z` 能退回去。
3. 勾选一批混合的行（草稿 + 已开工 + 一个正在跑的）点「删除选中」→
   弹窗把三类分开写清楚，正在跑的那个被拦住；确认后草稿真删、已开工的进「回收」、
   **磁盘文件一个没少**（删前后对任务目录 `dir /s` 比一遍）。`Ctrl+Z` 能全部恢复。
4. 填充柄：没选区时看不见；有选区时骑在右下角，鼠标移上去微微放大，好点中；
   拖动气泡显示最终值。截图放进报告。
5. 500 行的表滚动到底，表头一直在，冻结区边界的阴影正常，数字列对齐整齐。
6. 表头不再有被截断的灰色说明文字，悬停能看到完整说明。
7. 舒适 / 紧凑两档都截一张图放进报告。
8. 28 号和 31 号的功能各点一遍：粘贴、填充柄递增、复选框拖选、查找替换、撤销、
   框选配色 —— 一条都没退。
