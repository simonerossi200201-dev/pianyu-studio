# 第一部分 · 批量完成

## 为什么

现在完成一个任务要：切到 <span>⑤</span>收片 → 选这个任务 → 等它载入 → 点<span class="btn-ref">✓ 完成</span>。
一批片子做完，十几个任务就得来回切十几遍，每次都要等面板载入。

## 在哪做

<span>①</span>任务 面板。那张表**已经有勾选列**，右上角**已经有<span class="btn-ref">更多</span>菜单** —— 直接在那里加一项：

    完成选中的 N 个任务

灰掉的条件：没勾任何行，或者勾中的行里没有一个是"可以完成"的状态。

<span>⑤</span>收片 那个单个任务的<span class="btn-ref">✓ 完成</span>按钮**保留不动**，单条片子看完顺手点它仍然是最顺的路径。

## 点下去之后：先体检，再确认

**不许直接就完成。** 弹一个对话框，把每个任务逐一跑一遍现有的 `finish_check`，结果分两栏列出来：

    完成 5 个任务
    ┌────────────────────────────────────────────────┐
    │ 可以完成 · 3 个                                  │
    │   ✓ T0023  认真-0915-v1     12 段全收齐           │
    │   ✓ T0024  认真-0915-v2     15 段全收齐           │
    │   ✓ T0026  文雯-0915-v01     9 段全收齐           │
    │                                                │
    │ 还不行 · 2 个                                    │
    │   ✗ T0025  认真-0915-v3     还缺 2 段（s007 s011）│
    │   ✗ T0027  文雯-0915-v02    有 4 段是刚重生的，还没复查 │
    │                                                │
    │  [ 取消 ]        [ 完成这 3 个 ]                  │
    └────────────────────────────────────────────────┘

- 「还不行」的那几行**点得动**，点一下直接跳到 <span>⑤</span>收片 并切到那个任务，用户可以马上去处理。
- 拦下来的原因用现成的 `finishBlockers` 文案，别另写一套。
- 按钮上的数字是**真的会被完成的个数**，不是勾选数。

## 执行

- 逐个调现有的完成接口，**串行**，一个失败不影响后面的。
- 对话框变成进度条：`正在完成 2 / 3 · T0024`。
- 跑完汇总：`✓ 完成了 3 个任务`；有失败的话列出来 + 原因，**不要用 toast 一闪而过**，留在对话框里让人看清。
- 任何一个任务**正在生成**（有活跃 job）→ 归到"还不行"那一栏，理由写「正在生成，先停下来」。

## 礼花只放一次

批量完成成功 ≥ 1 个 → 关掉对话框，**放一次**第二部分那套礼花（不是每个任务放一次），
中间的徽章文字改成 `完成 3 个任务`，下面一行列任务号。
成功 0 个 → 不放。

# 第二部分 · 礼花炸满屏

## 现在的样子 / 想要的样子

现在：底边左右两角各喷一束，共 160 片纸屑，2.2 秒落完。屏幕中间一个 96px 的 ✓ 圆章。
在 2K 屏上基本只有下面两个角有点动静，**中间一大片是空的**。

要的是：<b>彩带 + 纸屑 + 烟花三层一起上，炸满整屏</b>。做完一条片子是件值得高兴的事，这一下要给足。

## 三层，编排好出场时间

全部画在**同一个 canvas**、**同一个 rAF 循环**里。总时长 `CELEBRATE_MS = 4800`（现在是 2200）。

### 第 1 层 · 烟花（0 ms 起）

- **6~8 发**，从屏幕底边随机横坐标升空，升到屏幕高度的 30%~65% 处炸开。
- 发射间隔 **120~260 ms** 错开，不要齐射。
- 上升阶段画一条带拖尾的亮点（拖尾用 `globalAlpha` 递减的 4~6 个残影，不要用模糊滤镜，费性能）。
- 炸开：每发 **70~110 粒**，向各方向均匀发散（角度均分 + 小扰动，不要纯随机，纯随机会结块），
  初速 4~11，重力 0.12~0.2，**带 0.985 的空气阻尼**，粒子亮度随时间衰减。
- 其中 **2 发做成"二次爆"**：主爆之后 400 ms，每粒有 15% 概率再迸出 5~8 粒小火花。
- 颜色：每发**整发同色系**（同一个色相 ±20°，亮度分层），不要一发里五颜六色 —— 真烟花是同色的。

### 第 2 层 · 纸屑彩带炮（200 ms 起）

- 现有的 `spawn()` 保留并扩展，从 2 束加到 **4 束**：底边左右两角（现有）+ **顶部左右各一束向下斜喷**。
- 每束 **110 片**，总计约 440 片（现在 160）。
- 片形保留现有的矩形 / 圆点两种，再加一种 **弯曲的带状**：用 `quadraticCurveTo` 画一小段弧，
  旋转时能看出正反面（宽度按 `Math.abs(Math.cos(rot))` 缩放，这样翻面时会变窄，像真纸片）。

### 第 3 层 · 长彩带（600 ms 起）

- **22~30 条**从屏幕顶部随机横坐标飘落，落到底部用满 **5 秒**（比纸屑慢得多，最后留在屏幕上的就是它们）。
- 每条是一条**竖直的正弦摆动带**：宽 6~12px，长 40~90px，画成 8~12 段的折线，
  每段 x 偏移 `sin(t * f + i * 0.5) * a`，看起来像卷曲的塑料彩带。
- 缓慢自转，边缘用同色深一档描边。
- 透明度 0.85，避免糊住画面。

## 中间的 ✓ 徽章也要跟上

- 圆章从 96px 放大到 **132px**，弹出动画保留，后面加一圈 **光环扩散**：
  一个同色圆环 `scale(1) → scale(2.6)`、`opacity .5 → 0`，0.9 秒，**放两圈**错开 250 ms。
- 标题下面加一行任务名（`{tid} · {任务名}`），等宽字体、小一号、半透明。
  批量完成时这一行改成任务号列表（超过 5 个写成 `T0023 T0024 T0026 … 共 8 个`）。
- 整块在 3.6 秒时开始淡出，4.8 秒结束。

## 性能：必须扛得住

这是一次性动画，但不能让机器卡住。

- **粒子总数硬上限 1100**（三层加起来）。超了就按比例砍，砍的顺序是纸屑 → 长彩带 → 烟花。
- 一个 canvas、一个 rAF、`ctx.setTransform(dpr,…)` 按现有写法。
- **自动降档**：记录前 12 帧的平均帧时间，超过 **26 ms** 就把存活粒子随机砍掉 40%，并且不再发射新的烟花。
  日志里 `console.info` 一行，方便以后排查。
- 粒子出屏（y > H + 60 或 x 在 ±80 外）立刻从数组里移除，别留着空转。
- 动画结束 `cancelAnimationFrame` + 摘掉 canvas，沿用第 1246 行现有的清理，确认新路径也被它覆盖。

## 交互

- **点一下任意位置就提前收掉**（有些人不想等 5 秒）。canvas 本身 `pointer-events:none`，
  在 `.rv-celebrate` 上挂一次性的 `click`。
- `prefers-reduced-motion: reduce` → **完全不放动画**，只显示徽章 1.2 秒。现有行为保留，别改坏。
- 窗口在动画期间被缩放 → 重算 W/H 和 canvas 尺寸，粒子按比例缩放坐标，不要重来。

## 验收

### 批量完成

1. <span>①</span>任务 里勾 5 个任务（其中 2 个明知道缺片），<span class="btn-ref">更多</span> →
   <span class="btn-ref">完成选中的 5 个任务</span>：对话框正确分成两栏，缺片那两个写明缺哪几段。
2. 点"还不行"里的一行 → 直接跳到 <span>⑤</span>收片 并停在那个任务上。
3. 点<span class="btn-ref">完成这 3 个</span> → 进度条走完 → 汇总说完成了 3 个 → 放一次礼花，
   徽章上写"完成 3 个任务"。回到表格，那 3 行状态是已完成，另外 2 行没动。
4. 勾一个正在生成的任务 → 被归进"还不行"，理由是"正在生成，先停下来"。

### 礼花

1. 做完一个任务点<span class="btn-ref">✓ 完成</span>：烟花从下往上升、错开炸开、纸屑从四个角涌进来、长彩带慢慢飘落，
   **整个屏幕都有东西**，持续约 5 秒。
2. 中间的 ✓ 圆章明显更大，带两圈扩散光环，下面有任务号和任务名。
3. 中途点一下鼠标，立刻收掉。
4. 系统开启"减少动态效果"之后再点完成：只有徽章，没有任何飞行粒子。
5. 动画期间拖动窗口大小，粒子跟着走，不会跑到画外或者卡住。
6. 在你最慢的那台机器上跑一次，不掉帧到卡顿；真卡了应该能在控制台看到降档那行日志。
