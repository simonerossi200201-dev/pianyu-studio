# 规格 97：重生时临时换账号

2026-09-29 用户要求：某一段要重生时，可以临时换一个账号来重生——比如任务本来用 Flow 生成，
这几段想改用 Grok 重生。时长自动判断：按这一段原来的时长换成新引擎能出的档位。

## 行为

- 入口：⑤ 收片「重生」抽屉、④ 生成「重生哪些段」对话框，都多了一排「用哪个账号重生」：
  默认「原账号」，其余列出所有启用着的 Flow / Grok 账号（冷却中、要重新登录的会标出来，但不拦）。
  选了别的账号，下面直接写出哪些段的时长会变，例如「时长（Grok）：s001、s003：8 → 10 秒」。
  其它地方的重生（换图重生、检查台重生、尾帧重生…）一律用原账号，不受这里的选择影响。
- 只影响这一次重生：任务本身的账号、引擎、段的时长字段都不改。这一次的 Job 占的是选中的账号
  （`jobs.start(..., account_id=…)`，调度器按它排队、加锁）。
- 时长换档：`caps.snap_duration(engine, 原时长)`——取不短于原时长的最短一档，原时长比最长一档还长
  就取最长一档。Flow 8 秒 → Grok 10 秒；Flow 4/6 → Grok 6；Grok 10/15 → Flow 8；Grok 6 → Flow 6。
  生成时统一走 `_submit_duration(seg, eng)`，原账号本来就有这一档的，时长不变。
- 收片后这一条 take 记下 `engine / account_id / duration`，以后看得出是哪个账号、几秒出的。
- 接片（锚点模式）：临时换 Grok 走 Grok 单图（起于上一段尾帧），换 Flow 走 Flow 双图；不换账号的重生
  把上次的 `bridge_engine` 清掉，按任务引擎重新定路。
- 不说话的任务：Flow 的片照旧去音轨；本来是 Flow 的不说话任务临时换 Grok 重生，也去音轨（和任务里
  其它片一致）。有台词的任务不动声音。
- 临时换账号的这一轮不接力：没做成的段留给任务自己的账号，免得接力拿 Grok 跑整个任务。
- 要补图（缺图重生）时，临时账号能生图就用它，不能（Grok）就用任务自己的账号。

## 把关（`jobs._check_run_account`）

- 换的账号要存在、启用着、是 Flow / Grok。
- 同一个任务不能同时被两个账号出片 / 重生（两边各拿一份 manifest，后存的会把先存的盖掉）：
  已有别的账号在跑这个任务的 generate / regenerate，就报错「这个任务正在用「X」出片 / 重生」。
  同一个账号的照旧排队。
