# 第一部分 · 提示词积木开关

## 现在的成品提示词是怎么拼出来的

`flow_shots.build_prompt` 按 `flow_shots.json` 里的 `组装顺序_*` 把一堆命名的块串起来：

    身份锁（= 描述语，经过整理）· 运镜卡 · 运动强制 · 镜头禁令 · 人物原地 / 站姿 / 坐姿 ·
    车辆静止锁 · 比例锁 · 人群保留 · 群像锁 · 画质锁 · 情绪 · 音色锁 · 固定结语 · 英文文案

而且**描述语本身在进来之前还会被改写**：`strip_legacy_tail` 切掉老结语、安静模式下 `strip_stillness`
删掉"别动"类句子、`defreeze` 改写静止描述、`身份锁去重` 删掉和程序块重复的句子。

用户要的是：这些块**每一块都能关**，全关掉时就是最简单的——**描述语 + 文案**，别的什么都没有。

## A. 开关长什么样、放在哪

②多模态 左侧那一列，**分成两组，用一条细分隔线隔开**：

**上组「拼进成片的积木」**——每张卡片标题右侧一个开关：

| 分组 | 包含的块 |
|---|---|
| 镜头与运动 | 运镜卡、运动强制、镜头禁令 |
| 人物姿态 | 人物原地 / 站姿 / 坐姿、比例锁、车辆静止锁 |
| 场景 | 人群保留、群像锁 |
| 画质 | 画质锁 |
| 表演 | 情绪、音色锁 |
| 结尾 | 固定结语 |
| 描述语整理 | 去老结语、去"别动"句、改写静止、去重（**这一项关掉 = 描述语原样进提示词，一个字不改**） |
| 静音提示 | 见 86 号：没有文案时加一句"人物不说话"。**默认开** |

描述语和文案**没有开关**——它们是内容，不是积木。

**下组「工具用的提示词」**——描述语提示词（给 Gemini 写描述用）、扩图覆盖库、提升画质、接片、接龙。
这些不进成片，只在你用那个工具时才用，**不加开关**，卡片标题旁写一行小字"用于 xx 时"。

### 开关本身

- 自绘，不用原生 checkbox：36×20 胶囊，关是灰底左圆点，开是主色底右圆点，切换 150 ms 滑动 + 轻微回弹。
  `prefers-reduced-motion` 下直接切。
- 关掉的卡片：整张降到 45% 不透明度、内容折叠，标题后面一个灰色小字"已关"。**但仍然能展开编辑**——
  关掉不等于删掉，内容还在，打开就回来。
- 每组有一个组开关（三态：全开 / 全关 / 部分），点它一次切整组。

### 最上面一个总开关：「极简」

左侧列最顶上一条：

    ○ 极简模式   只用描述语 + 文案，其余积木全部关掉        [ 看成品提示词 ]

- 打开 = 上组所有积木一次关掉（静音提示除外，它有自己的道理，见 86 号）；
  **记住打开前每块的状态**，关掉极简时原样恢复，而不是全部打开。
- 极简开着时单独去开某一块 → 极简自动变成"关"（因为已经不极简了），其余保持。

### 右边永远看得到结果

「看成品提示词」打开现有的预览抽屉（`previewOn`），**实时**跟着开关变：
拨一下开关，预览里对应那一段立刻消失 / 出现，并且高亮 1 秒让人看清变了哪里。
预览顶上一行显示 `12 块中开着 3 块 · 共 214 字`。

## B. 开关存在哪

- 存进提示词设置（`prompts.switches = {运镜卡: true, 画质锁: false, …, 描述语整理: true, 静音提示: true}`），
  **归 76 号套装的 `prompts` 组管**——这样用户可以建一个"极简"套装，一键切过去。
  确认 `preset.collect_suite_group("prompts")` 把它带上了（报告里写明）。
- 默认全开（和现在行为一致），**升级后第一次打开不能改变任何现有提示词**——测试里对现有任务跑一遍
  `final_prompt`，升级前后逐字相等。

## C. 拼接时怎么尊重开关

- `build_prompt` 走 `组装顺序` 时，**跳过** `switches` 里为 `false` 的块。块的内容照旧存着，只是不拼。
- `描述语整理` 为 `false` → `strip_legacy_tail` / `strip_stillness` / `defreeze` / 去重 **全部跳过**，
  描述语原样当"身份锁"那一块用。**这一条很重要**：用户手写的描述语在极简模式下一个字都不能被程序改。
- 全关时的结果必须正好是：

      <描述语原文>
      <文案>             ← 有文案时
      <静音提示>          ← 没文案且静音提示开着时

  之间用换行，没有别的东西。写一条测试逐字断言。
- 手写锁定的成品提示词（`prompt_locked`）不受开关影响（维持原规则）。

# 第二部分 · 跨任务批量填描述语

## 场景

13 个任务，每个任务一张图，描述语全都一样。现在要么一张张手填，要么让 Gemini 写 13 次（花额度、每次还写得不一样）。

## D. 入口

②多模态 顶部工具条加一个按钮 <span class="btn-ref">批量填描述语…</span>。
另外 75 号卡片右键菜单里加一项 <span class="btn-ref">把这张的描述语填到别的任务…</span>
——打开同一个对话框，并且把这张卡的描述语预先填好。

## E. 对话框（宽，左中右三栏）

    ┌──────────────────────────────────────────────────────────────────────────┐
    │  批量填描述语                                                           ✕ │
    ├───────────────────┬────────────────────────────┬─────────────────────────┤
    │ 任务      13/13 ✓ │  T0050 · LL-0921-v01         │  描述语                   │
    │ [搜索…]          │  图  1/1 ✓   [只选缺的]       │ ┌─────────────────────┐ │
    │ ☑ 全选 □ 反选    │  ┌────┐                      │ │这位中年男性坐在电脑… │ │
    │ ☑ T0050  1 图 ●  │  │ ☑  │                      │ │                     │ │
    │ ☑ T0051  1 图 ●  │  │p01 │                      │ └─────────────────────┘ │
    │ ☑ T0052  1 图    │  └────┘                      │  音色 [ 选填            ] │
    │ …                │                              │                         │
    │ □ T0048  草稿 —  │                              │  ( • ) 只填空着的         │
    │   先准备才能填    │                              │  (   ) 覆盖选中的全部      │
    │                  │                              │                         │
    │                  │                              │  会写入 13 个任务的 13 张图 │
    │                  │                              │  其中 0 张原来有描述语      │
    │                  │                              │                         │
    │                  │                              │     [ 取消 ]  [ 写入 ]    │
    └───────────────────┴────────────────────────────┴─────────────────────────┘

**左栏 · 任务**
- 列出所有**已准备**的任务，勾选框 + 任务号 + 名字 + `N 图` + 一个小圆点（有图缺描述语就是橙点）。
- 顶部：搜索框（按号 / 名字过滤）、全选、反选、`只看缺描述语的`。
- 草稿任务灰着列在最后，写"先准备才能填"——让人知道它们为什么不能选，而不是凭空消失。
- 点任务行 = 在中栏显示它的图（**不是**勾选；勾选框是单独的一个点击区）。

**中栏 · 当前任务的图**
- 这个任务的图，缩略图网格，每张左上角勾选框（75 号同款）。
- 顶部：`图 3/5 ✓`、全选、全不选、`只选缺的`。
- **每个任务的图勾选各自记住**。默认：任务被勾上时它的**全部主体图**都算选中（大多数情况就是要全部）；
  用户到某个任务里去掉几张，只影响那个任务。
- 空镜图默认不选，但能勾。
- 已经有描述语的图，缩略图下面一行灰字显示前 20 个字，悬停看全文。

**右栏 · 要填的内容**
- 描述语大文本框（13px，自动长高）；音色单行，选填（空着就不动音色）。
- 右上角一个小链接 <span class="btn-ref">从某张图拿…</span>：点了之后中栏的图变成可点选的源，
  点一张就把它的描述语填进来。
- 模式单选：**只填空着的**（默认）/ **覆盖选中的全部**。
- 实时统计：`会写入 13 个任务的 13 张图 · 其中 N 张原来有描述语`（覆盖模式下 N 显示为橙色）。
- 描述语为空时"写入"是灰的。

## F. 写入

    POST /api/images/batch-desc
    body {"items":[{"tid":"T0050","ps":["p01"]}, …], "desc":"…", "voice":"…|null", "mode":"fill_empty"|"overwrite"}
    → {ok, n_tasks, n_images, changed:[{tid,p,desc_old,voice_old}], skipped:[{tid,p,why}]}

- 按任务分组、每个任务一次事务写完 manifest，走 `images.patch`，**不要一张一张存盘**。
- 写进去的都算用户手填：`desc_manual=True`（78 号），以后 Gemini 自动写描述语会跳过它们。
- `changed` 带旧值，toast 上给 15 秒的<span class="btn-ref">撤销</span>（75 号同一套），
  撤销跨任务一起回滚。
- 某个任务 manifest 正被别的 Job 写着（77 号的文件锁拿不到）→ 那个任务进 `skipped`，其余照写，
  汇总里点名。
- 写完 toast：`✓ 已写入 13 个任务的 13 张图` + 撤销；对话框关掉；当前面板刷新。

## 验收

1. ②多模态 左边每张会进成片的卡片上都有开关；把"画质锁"关掉，右边预览里那一段立刻没了。
2. 打开"极简模式"→ 预览里只剩描述语和文案两段。关掉极简，原来关着的"画质锁"还是关着的（不是全被打开）。
3. 极简模式下手写一句"人物保持坐着不动"放进描述语 → 预览里**原样**出现，没被程序删掉。
4. 建一个叫"极简"的套装，在里面开极简模式；切回默认套装，积木全回来了；再切到"极简"，又全关了。
5. 点"批量填描述语"→ 左栏全选 13 个任务 → 右栏粘一句描述语 → 写入 → 13 个任务的图全部有了描述语，
   **一次 Gemini 都没调**。toast 里点撤销，全部回到空。
6. 在某个任务里只勾其中 2 张图，其余任务全部图，写入 → 那个任务只有那 2 张被填。
