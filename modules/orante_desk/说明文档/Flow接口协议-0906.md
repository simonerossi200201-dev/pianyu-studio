# Flow（flow.google.com 新前端）接口协议 · 0906 抓包定型

实现：`orante/engines/flow_api.py`。抓包原件：`data/capture/flow_capture_0906-03*.jsonl`（`tools/Capture-Flow.bat` 产出）。

**结论：前端不再是 tRPC，改用 Google 的 batchexecute（Angular / boq）协议；每个写操作带 reCAPTCHA Enterprise token；页面开了 Trusted Types CSP。**
Orante 的做法：在已登录的泳道 Chrome 里用 `page.evaluate(fetch)` 发请求（cookie / XSRF 都是页面自己的），用 CDP `Page.setBypassCSP` 关掉该标签的 CSP 后按需加载 reCAPTCHA 拿 token。**不找任何按钮。**

| rpcid | 作用 | 要点 |
|---|---|---|
| `maseQ` | 上传图片 | inner 里带 base64、mime、文件名、projectId、collectionId、reCAPTCHA(`UPLOAD_IMAGE`)；响应 `[0][0]` = mediaId |
| `as29s` | 查媒体 | `["mediaId"]` → 记录里有 CDN 地址（`flow-content.google/image|video/...`，签名 6 小时） |
| `eb1hJf` | 图生视频 | 模型 id 决定时长：8s `veo_3_1_i2v_lite_low_priority`，4s `veo_3_1_i2v_s_lite_4s_low_priority`，6s `veo_3_1_i2v_s_lite_6s_low_priority`；首帧 = mediaId + 9:16 裁切框；reCAPTCHA(`VIDEO_GENERATION`)；响应 `[1]` 额度（与 nzlxg 相同，57 探针：免费档不扣）、`[3][0][0]` genId |
| `jwpduf` | 轮询 | `[null,null,[["genId"],...]]`；记录 `[5][8][0]` 状态：6 刚提交 · 2 生成中 · 3 完成 |
| `ogiZ0b` | 生图（同步） | 参考图 mediaId + 种子 + 模型 `GEM_PIX_2`(Nano Banana) / `NARWHAL`(Imagen)；一次一张，前端点 4 张 = 4 个并发种子；reCAPTCHA(`IMAGE_GENERATION`)；响应 `[0][0][0]` mediaId，`[0][0][6][0][13]` 图片地址 |
| `nzlxg` | 查余额 | `[]` → 第一个数字；解析不出返回 None |
| `pGCYOe` | 归档媒体 | `[[[mediaId,null,null,[null,null,1],pid]],[["metadata.archived"]]]` |
| `WuwhI` | 前端埋点 | 不需要 |

请求外壳：`POST /_/AiSandboxAngularFrontend/data/batchexecute?rpcids=<rpc>&source-path=/project/<pid>/collection/<cid>&bl=<WIZ.cfb2h>&f.sid=<WIZ.FdrFJe>&hl=..&_reqid=<随机>&rt=c`，表单 `f.req=[[[rpc, innerJSON, null, "generic"]]]&at=<WIZ.SNlM0e>`。
响应：`)]}'` 开头，按行找 `[["wrb.fr", rpc, "<JSON>"...]]`。
