# Robota 架构与接口约定（v3）

> 计划书 v3：Robota 是**通用代理人**，项目只是挂上去的插件。本文件是所有模块共同遵守的接口约定。

## 1. 进程与端口（只监听 127.0.0.1）

| 进程 | 端口 | 启动方式 | Python 环境 |
|---|---|---|---|
| **Robota 控制台**（FastAPI：网页、对话、队列、状态） | 9600 | `Robota.bat` / 桌面图标 | `D:\0_Robota\runtime\venv` |
| **语音服务**（STT / TTS） | 9611 | 由控制台按需拉起 `robota\voice\start_voice.bat` | 复用 `D:\0_Dev\local_tts` 的 venv |
| **robota-mcp**（工具服务器，stdio） | — | 由代理按需拉起：`runtime\venv\Scripts\python.exe -m robota.mcp_server` | Robota venv |
| Ollama | 11434 | 已有 | — |
| Studio API / ComfyUI | 7870 / 8188 | 已有 | — |

## 3. 项目配置 `config/projects/<id>.toml`
```toml
id = "cutora"
name = "CUTORA 片语 Studio"
root = 'D:\0_Dev\CUTORA'
description = "视频剪辑、自动字幕、批量导出"
rules_file = "docs/plan/queue/_RULES_FOR_EVERY_TASK.md"   # 可选，代理开工前必读
test_cmd = 'runtime\venv\Scripts\python.exe -m pytest tests -q'  # 可选
default_brain = "agy"            # auto | local | agy
private = false                  # true = 只许本地大脑
plugin = "cutora_queue"          # 可选：项目专用执行器
mcp = ['D:\0_Dev\CUTORA\cutora_mcp.bat']   # 可选：项目自带 MCP
```

## 4. 任务（`data/queue/<id>.json`）
```json
{
  "id": "20261005-091200-ab12",
  "title": "一句话标题",
  "kind": "agent | command | plugin",
  "project": "cutora | null",
  "brain": "auto | local | agy",
  "model": "可选，覆盖默认模型",
  "prompt": "给代理的说明（kind=agent）",
  "command": "要运行的命令（kind=command）",
  "state": "queued | running | done | failed | stopped | quarantined",
  "created": "...", "started": "...", "finished": "...",
  "result": "摘要", "log": "data/queue/logs/<id>.log", "usage": {}
}
```
- 按顺序串行执行；`data/queue/_HALT` 存在就停
- 需要 GPU 的任务执行前，先调用 `gpu.ensure_free()` 卸载 Ollama 模型

## 5. 大脑接口（`robota/brains`）
```python
async def chat(messages, *, project=None, model=None, tools=True, on_event=None) -> BrainReply
# on_event(dict)：{"type": "text"|"tool"|"status"|"usage", ...}，用于网页实时显示
```
- **local**：Antigravity SDK `LocalOpenAIAgentConfig` → Ollama，挂 robota-mcp 和项目 MCP，权限策略限定在项目目录
- **agy**：`agy -p ... --output-format stream-json`，有 `--conversation` 可以续聊，在项目 root 下运行
- **providers（L2）**：OpenAI 兼容的 HTTP 接口，只做纯对话（翻译、问答）；没有配置 key 就自动跳过

## 6. 路由规则（`robota/router.py`）
1. 用户手动选了大脑 → 照用
2. 项目 `private = true` 或消息带 `#私密` → 只许 local
3. 涉及写代码、改项目、排错 → agy
4. 其余 → local；local 连续失败 2 次 → 升到 agy

## 7. 语音服务 HTTP（9611）
- `GET /health` → `{ok, stt, tts, voices}`
- `POST /stt`（multipart: `audio`，可选 `language`）→ `{text, language, seconds}`
- `POST /tts`（json: `{text, voice?, lang?, speed?}`）→ `audio/wav`
- `GET /voices` → 可用的声音列表

## 8. 工具服务器 robota-mcp（工具名）
| 工具 | 说明 |
|---|---|
| `gpu_status` | 显存、占用进程、Ollama 已加载的模型 |
| `gpu_free` | 卸载所有 Ollama 模型，释放显存 |
| `notify(title, message)` | Windows 系统通知 |
| `list_projects` / `project_info(id)` | 读项目配置 |
| `run_in_project(project, command)` | 在项目目录运行命令（受白名单和黑名单约束） |
| `queue_add(...)` / `queue_list()` / `queue_halt()` | 操作 Robota 队列 |
| `rclone_ls(remote_path)` / `rclone_copy(src, dst)` | 用你现有的 `gdrive` 远程 |
| `studio_health` / `studio_submit(...)` / `studio_status(id)` / `studio_fetch(id, dest)` | Studio Zero API |
| `comfy_queue` | ComfyUI 队列状态 |
| `orante_*` | Orante bridge 的常用操作（以 bridge 脚本为准） |
| `watch_file(path, pattern, timeout)` | 等日志里出现某个字样或某个文件生成 |
| `memory_read(topic)` / `memory_append(topic, text)` | 记忆（SOP、习惯、学习记录） |

## 9. 安全
- 所有服务只监听 127.0.0.1
- `agy`：白名单 `config/agy_settings.json`
- local：SDK 策略（`workspace_only` + 命令黑名单，与 agy 黑名单一致）
- `run_in_project`：统一黑名单（删除、推送、硬重置、联网下载、`pip install`、改系统目录）
- secrets 不进 git，也不写进日志
