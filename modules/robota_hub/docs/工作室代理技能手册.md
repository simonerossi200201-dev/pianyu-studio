# 片语工作室 · Robota 全流程自治代理技能手册 (End-to-End Studio Agent Playbook)

> **核心定位**：让 Robota 具备与 Antigravity 主代理完全一致的片语工作室（Orante + CUTORA + 右键表格工具 + Google Drive）端到端理解力、执行力与质量核验标准。用户只需用自然中文提要求或粘贴表格，Robota 即可全自动完成：**下载素材 → 提交 Orante 任务与生成视频 → 收集与体检视频 → 创建 CUTORA 分屏工程（含标题/电话贴纸/AI署名/人脸零穿帮校准） → 250–350 fps 高速批量导出 → 上传网盘并 MD5 双向核验**。

---

## 一、输入表格与用户意图精准解析规则

### 1. 标准五列表格（TSV / 多行文本）
用户常直接粘贴一段制表符（`<TAB>`）分隔的多行表格，每行对应一个视频任务（如 `v01`..`v66`），标准列序为：
1. **列 1（图片素材网盘文件夹链接）**：`https://drive.google.com/drive/folders/<folder_id>` — 内含该条视频对应的多张分镜配图，下载后自动命名为 `v01(1).jpg`, `v01(2).jpg`, `v01(3).jpg`...
2. **列 2（任务编号）**：`v01`, `v02`, ..., `v18`..`v66`（大小写不敏感，统一规范化为小写 `vNN`）。
3. **列 3（英文/多语种主标题）**：显示在画面顶部或分界线附近的黄金样式标题（可能带引号或跨行，解析时须用 `csv.reader(..., delimiter="\t")` 正确处理跨行引号）。
4. **列 4（主视频网盘单文件直链）**：`https://drive.google.com/file/d/<file_id>/view` 或 `open?id=<file_id>` — 主讲人口播长视频，下载后命名为 `v01.mp4`, `v02.mp4`...
5. **列 5（联系方式/行动号召文案）**：如 `"Learn the Bible Online\nJoin Us for Free\nMessage WhatsApp: +447304097480\nSend “Bible Study”"`，用于自动匹配对应的电话号码贴纸图片（如 `D:\1_PROJECT\Tiktok_Pic\乐彤+447304097480.png`）。

### 2. 工作区目录与批次结构 (`D:\1_PROJECT`)
- **日期目录**：`D:\1_PROJECT\<YYYY-MM-DD>`（如 `D:\1_PROJECT\2026-10-19`）。
- **批次子目录**：`A`、`B`、`C`（如 `D:\1_PROJECT\2026-10-19\B`）。
- **标准子文件夹**：
  - `<MMDD>图片`（如 `1019图片`）：存放按 `v18(1).jpg`, `v18(2).jpg` 命名的源图片。
  - `<MMDD>视频`（如 `1019视频`）：存放按 `v18.mp4`..`v66.mp4` 命名的主讲人口播视频。
  - `T0xxx-<MMDD>图片`（如 `T0136-1019图片`）：Orante 任务目录，内含 `manifest.json`、`images/p001..pNNN`、`clips/s001..sNNN.mp4`。
  - `成品`：存放 CUTORA 批量导出的最终成片 `v18.mp4`..`v66.mp4`。

## 二、七步全链路代理操作规范 (Seven-Step Pipeline)

### Step 1：网盘并发下载与魔数校验 (`drive_download`)
- 使用内置 `rclone.exe`（`D:\0_LTX\runtime\bin\rclone.exe`，remote 为 `gdrive:`）加 `--drive-root-folder-id <id>` 高速拉取。
- 对无扩展名或伪扩展名文件进行文件头魔数嗅探（`ftyp` → `.mp4`，`FFD8FF` → `.jpg`，`89504E47` → `.png`），杜绝把静态图片误当视频或漏掉 `.mp4` 后缀。
- 支持断点续传：目标文件已存在且大小合法（视频 `>500KB`，图片 `>5KB`）时自动跳过。

### Step 2：提交 Orante 任务与分镜描述词生成 (`orante_submit`)
- 将 `<MMDD>图片` 注册到 Orante 当日批次（`B<YYYYMMDD><A|B>`），调用 `orante.services.prepare.prepare` 生成 `p001..pNNN` 与 `s001..sNNN`。
- 为每张图片自动生成高质量图生视频英文动态运镜提示词（如温和推进、自然光影呼吸、人物微表情与肢体动作、禁止画面崩坏或文字变形），写入 `manifest.json`。
- 启动/通知 Orante（支持多开，5秒防误触冷却后可无限多开 Orante 窗口并行操作），使用 Flow / Grok 引擎批量生成 `clips/s001..sNNN.mp4`。

### Step 3：Orante 视频生成监控与落盘体检 (`orante_monitor_and_check`)
- 通过 `orante_batch` / `orante_check` 检查所有 `s001..sNNN.mp4` 是否全部落盘、文件非空、时长达标（通常 8.0s）。
- 构建 `vNN` → `[s_idx1.mp4, s_idx2.mp4, ...]` 的一主多副映射关系（通过 `manifest.json` 中 `images[].orig_name` 的 `vNN(k)` 前缀精确匹配）。

### Step 4：创建 CUTORA 分屏工程与元素装配 (`cutora_auto_project`)
调用无头工程构建器 `python -m cutora.batch.auto_project` 完成：
1. **一主多副多样化美学分屏**：
   - 根据每个主视频关联的 `clips` 数量（2/3/4/5 格），自动轮换多样化分屏布局（上下分屏、一主二副、一主三副、一主四副、黄金分割与微弧度/无边框沉浸式过渡），主视频固定在主格 `A`，副素材循环铺满其余格子（`loop=True, mute=True`）。
2. **ASR 语音对齐标题与开口原句兜底**：
   - 使用 Faster-Whisper / ASR 自动识别主视频开头口播，精确定位第一句话结束时刻 `title_end`（通常在 `3.0s–7.5s`）。
   - 若表格标题与视频实际开口内容不一致，自动提取视频开口所说的第一句完整英文原句作为标题，确保音画与字幕 100% 同步。
3. **电话号码贴纸无缝衔接**：
   - 从 `title_end` 到视频结束（`duration`），在安全区域自动叠加对应的 WhatsApp 电话贴纸 PNG（如 `乐彤+447304097480.png`），与标题在时间轴上首尾无缝衔接（`0..title_end` 显示标题，`title_end..duration` 显示电话贴纸）。
4. **AI 署名覆层**：
   - 全片添加 `.   Generated by AI #xy ` 底部微透明署名覆层（预设 `legacy.ai`）。
5. **大于 40 条自动分包**：
   - 当批次任务数较多（如 49 条）或用户要求分两个工程时，自动拆分为 `_part1.cutora` 与 `_part2.cutora`。

### Step 5：人脸与画面零穿帮自动校准与实景抽帧核验 (`face_safe`)
**【零穿帮四大铁律】**：
1. **无切脸**：使用 OpenCV YuNet (`yunet.onnx`) 检测主视频与所有副视频中的主讲人/核心人物正脸包络框，自动求解主副格 `offset_x / offset_y / scale` 及分屏分界线位置，确保没有任何一条分屏线切割人脸或脖子。
2. **无标题/贴纸挡脸**：标题框与电话贴纸框自动避开主视频人脸区域（下巴以下安全区或画面黄金分割带），绝不遮挡五官。
3. **无黑底死角**：所有分屏格子优先以 `fill`（铺满）+ 边缘延展或 `lens_blur`（镜头模糊背景填充）兜底，严禁出现任何纯黑未铺满区域（`black_ratio == 0`）。
4. **无旧字幕露白**：若原主视频底部自带烧录旧字幕，自动通过分屏边界裁剪或标题/贴纸安全覆盖，绝不露出残缺旧字幕。
- 工程生成后自动输出 `<project>_facecheck.json` 报告与双阶段实景渲染抽帧拼图（`t=1.2s` 标题阶段 + `t=title_end+1.5s` 贴纸阶段）。

### Step 6：250–350 fps 极速批量导出 (`cutora_batch_export`)
- **【工作室最高铁律】**：CUTORA 批量导出总帧率必须稳定在 **250–350 fps**！
- 调用 `python -m cutora.batch.export_cli --project <path.cutora> --out <成品目录> --workers 10 --gpu-workers 10 --skip-existing`。
- 导出完成后逐一校验 `成品/vNN.mp4` 数量、时长、文件大小与视频流完整性。

### Step 7：Google Drive 自动上传与双向一致性核验 (`drive_upload_and_verify`)
- 使用 `rclone copy <成品目录> gdrive: --drive-root-folder-id <folder_id> --transfers 8 --checkers 8` 批量上传。
- 上传后必须执行 `rclone check <成品目录> gdrive: --drive-root-folder-id <folder_id> --one-way` 进行 MD5 与文件数核验，确认 `0 differences found` 后向用户汇报。
