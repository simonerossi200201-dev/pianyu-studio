# P2 报告 — 用 agy 替换 Grok 队列

时间：2026-10-05 08:59

## 做法：CUTORA 一行都不改
`robota\agy_queue.py` 直接加载 CUTORA 自带的 `tools\queue_runner.py`（v2），**只替换其中"调用 Grok"的那一个函数**，换成调用 `agy`。其余机制全部沿用原有代码：锁文件、`_inbox`、`_HALT`、`.ok/.stop`、golden 守卫、隔离、自动提交、回滚和 rescue 标签。

新增的部分：
- 额度或频率受限时：自动等 30 分钟再重试（最多 12 次），等待期间放 `_HALT` 可以立即停止
- 每个任务的 token 用量写入 `logs\agy_usage.jsonl`
- 权限走 `agy` 的白名单（`~/.gemini/antigravity-cli/settings.json`，副本在 `config\agy_settings.json`），**不使用** `--dangerously-skip-permissions`

## 发现的问题
- **`agy` 无人值守时，只要有一条命令被拒，整个任务就会直接结束。** 已做两项调整：
  1. 白名单加入常用的只读和文件操作命令（删除、推送、联网下载、`pip install`、修改系统目录仍然禁止）
  2. 给代理的说明里要求：改文件用编辑工具、一次只跑一条简单命令
- "额度用完自动等待"的逻辑**还没有实测过**（没法人为触发额度用完）

## 用法

```
D:\0_Robota\RUN_AGY_QUEUE.bat                                 ← 默认 CUTORA，模型 claude-opus-5-5-high

```
