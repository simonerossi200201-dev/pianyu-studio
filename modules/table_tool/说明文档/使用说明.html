右键表格工具 · 使用说明

批量改名、上传 / 下载 Google Drive、批量建文件夹。下面配的是本机实际界面截图。

安装 主界面 日常用法 批量改后缀 连接 Google 账号 网盘下载 建文件夹 卸载

安装

  1. 电脑需要 Python 3.10 或更高（安装时勾选 Add python.exe to PATH）
  2. 把整个「右键表格工具」文件夹拷过去（不要拆开）
  3. 双击 安装.bat
  4. 在任意文件夹空白处右键 → 右键表格工具

不需要管理员权限。程序装在 %LOCALAPPDATA%\RightClickTableTool。

主界面

中间是改名表格：左边各列拼成新文件名，右边是预览、网盘链接和上传状态。

  • ⬇ 下载：网盘下载面板（Ctrl+Shift+D）
  • 📁 建文件夹：批量建文件夹（Ctrl+Shift+N）
  • 右上角 连接网盘 / 网盘已连接：授权或管理 Google 账号

日常用法（改名 / 上传）

  • 勾选后的行才会改名、填序号、上传。
  • 左边列从左到右拼成新文件名，Ctrl+Enter 执行改名。
  • 在「网盘链接」列粘贴目标文件夹网址（支持从 Google Sheet 直接粘带链接的单元格）。
  • 点「上传勾选」：通过本机 rclone 的 gdrive 远程上传。
  • 工程自动写入隐藏文件 .renamer_project.json，可导出 / 导入、还原原名。
还没连接 Google 账号就点上传时，会自动弹出连接窗口；连好后再点「继续上传」即可。

批量添加 / 修改文件后缀名

别人上传到网盘的文件有时候没带后缀，下载下来就是光秃秃的 a022，一个个手改很麻烦。 菜单 命名规则 → 🏷 批量设置扩展名…（视图菜单里也有，并显示当前模式）。

只改后缀，文件名部分一个字都不动。
模式效果
沿用原来的扩展名默认。a022.mp4 改名后还是 .mp4，本来没后缀的还是没有
统一用这个后缀填 .mp4（不填点也行，会自动补）。勾上「只补给本来没有后缀的文件」就只补缺，不动已有后缀的；取消勾选则全部换成这个后缀
去掉扩展名新文件名里不带任何后缀

弹窗底部实时显示「勾选的 N 个文件里，M 个的后缀会变」，并列出前几条对照。应用后先看 预览：新文件名 列，确认无误再点「执行重命名」。

作用于哪张表：弹窗顶部有「作用于：✎ 改名表 / ⬇ 下载表」，各显示勾选了几个文件，点哪个就改哪张，两张表互不影响。 默认选你正在编辑的那张；那张一个勾选都没有、另一张有时，会自动选另一张。

已经下载好的文件：在下载表里应用后，若勾选的行已经下载到磁盘、名字还没后缀，会再问一句是否一起补上，确认后直接在下载文件夹里改好（只改后缀，不会覆盖任何文件）。

只显示视频：没有后缀的文件认不出类型，不会再被这个开关藏起来。

下载面板里也能用。在下载表设成「统一用 .mp4」，下载下来的文件直接就带后缀，不用事后再改一遍。 改名表和下载表各记各的设置，都会存进工程文件。

连接 Google 账号（授权）

上传和网盘下载都要用你自己的 Google Drive。授权一般只需做一次：浏览器里登录并点「允许」，其余自动完成。

从哪里打开

  • 菜单栏右上角 连接网盘（已连接时为 网盘已连接）
  • 或 设置 → Google Drive 网盘连接
  • 上传 / 下载时若未连接，也会自动弹出

第一次连接

点 一键连接。窗口会列出四步：准备 rclone → 浏览器点「允许」→ 保存 gdrive 配置 → 测试连接。

在浏览器里授权

选择 Google 账号，在权限页点 允许（应用名显示为 rclone，属正常现象）。若浏览器没自动打开，用窗口里的「点这里打开授权页」。

已连接 / 连接成功

之后可随时点「网盘已连接」查看空间、测试连接、换账号或断开。

断开连接

安全说明：授权只保存在这台电脑的 rclone 配置文件里。工具不会上传、记录或分享它；别人拿到这个工具，连的是他自己的网盘。

若提示缺少 rclone：重新运行文件夹里的 安装.bat，再回来点「一键连接」。

网盘下载

  • 把文件或文件夹链接贴到「网盘链接」列；文件夹会展开为多个文件。
  • 左边列拼下载后的本地文件名；空行则用网盘原名。
  • 点「开始下载」。重名自动加 (2)(3)；失败会重试。

批量新建文件夹

  • 每一行 = 一个文件夹；左边列拼文件夹名。
  • 「建在」默认当前目录，可改路径。
  • 可撤销刚才创建的空文件夹。

卸载

双击 卸载.bat。只删程序和右键菜单，不动视频和工程文件。
