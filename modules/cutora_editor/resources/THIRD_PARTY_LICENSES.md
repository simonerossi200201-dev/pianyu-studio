(`.dll` / `.pyd`), not statically linked into the application.

`runtime/python/`):

    runtime/venv/Lib/site-packages/PySide6/Qt6*.dll
    runtime/venv/Lib/site-packages/PySide6/*.pyd
    runtime/venv/Lib/site-packages/shiboken6/

build over those directories, or `pip install PySide6==6.10.x` into the
runtime venv. CUTORA is **not** shipped as a PyInstaller `--onefile` blob,
so the libraries stay replaceable.
