# 片语 Studio / CUTORA 7.0.0-beta8 内测包

**internal** — 给可信内部测试者，不是对外分发。

构建：`7.0.0-beta8` internal（`PACK_BETA8.bat`，跳过测试闸门出包，同 beta6/beta7）。PySide6 6.10.2。无 PyQt6。
解压后约 **16 GB**。首次启动约 10–30 秒（CUDA 预热）；无独显会更久。

## beta8 相对 beta7 的变化

- 左右分屏：「左右」改名「左右裁切」（铺满、会裁掉一半）；「左右完整」是两条等大并排、每条都完整放进格子，空处垫**镜头模糊**背景，可选「每格各自模糊」或「整幅垫第一条」，批量加载 · 视频分页里能直接选，会记住上次的选择。修了左右完整里视频和背景相加、整条发白发透的问题。
- 背景模糊改成镜头模糊（六边形光圈、亮点散成光斑），程度前半段很细，不再一给就糊成一片；视频「背景填充」里可选「镜头模糊 / 柔化（旧版）」和「散景高光」。老工程里已经开着的模糊背景保持原样。
- 时间线快捷键：V 选择 / C 切刀 / R 变速工具，多选、跨视频复制粘贴图层，拖动不再多记一步撤销。
- 文字：预设里整段设的字体 / 字号直接成为本层字体（改字号不再变回默认），字不再被框边切掉，加大行距时整体等比缩小、折行不变。
- 自动保存：上次没正常退出时留下的快照先备份再问要不要恢复，不会再被新会话覆盖。
- 批量加载 · 文本：识别开头时间戳有进度条和逐条状态。
- 图片节点连线（一张图连多条视频）、批量流程改进、段落关键帧、中央监视器图层面板和跨视频搬图层（Grok 9/29 的升级）。

## beta7 相对 beta6 的变化

- 导出提速：保活守卫按同画布实测内存派进程（12 GB 空闲 → 2 个，20 GB → 6 个）；静态文字 / 模糊背景 / 分屏每帧的重复计算去掉；独立导出进度窗恢复。
- 预览拖动不再花屏、文字重影、视频跑偏。
- 字幕：修复「画面上显示成前一个词」（单字蹦同 id 光栅串图）；新断句法（合并碎句、按标点 / 数字 / 大写 / 连词切），排版新增「左右安全边距」「每行最多词数」「停顿断句」。
- 共享字幕风格会同步「单字蹦」等排版；轨道共享「自动匹配目标视频时长」可以取消。
- 批量加载：拼接工程预览不再黑屏；文本分页模板原样还原（位置 / 框宽 / 缩放），去掉会崩溃的「现场跑时间戳」。
- 片段智能拼接：拖入总目录自动找出每个装视频的文件夹（不限层数，跳过空镜头 / 成品 / 下划线目录）。
- 旧版（AutoSub v6）字幕预设 .json 可以导入并转换成风格包。
- 双开不再卡在闪屏；桌面图标启动时自动字幕找得到 ffmpeg、不再闪黑框。

## 硬件

- **推荐**：NVIDIA 显卡 + 支持 **CUDA 12.8** 的驱动。
  Windows 最低驱动：**572.16**（CUDA 12.8 GA 配套驱动）。
  12.8 Update 1 对应 **572.61**。`nvidia-smi` 看 Driver Version。
- **没有 NVIDIA 显卡**：ASR 退到 CPU，**很慢但必须能跑**。不要把 CPU 慢当成崩溃。
- 磁盘：SSD 强烈建议。解压后约 **16 GB**（含 small/medium 识别模型，以及 en/it/fr/es/de/pt 对齐模型）。

## 测试

全量用 `python -m pytest tests`（仓库 `runtime/venv`）。**不要**在仓库根目录直接跑 `pytest`：会把 `runtime/` 里 CPython 自带的测试也收进去。

## 怎么开

1. 解压 zip（不要在压缩软件里直接双击）。
2. 双击 `CUTORA.vbs`。桌面图标「片语 Studio」也是它：目标是
   `wscript.exe`，参数是这个 `CUTORA.vbs`，图标是 `resources\brand\app.ico`。
   包里自带 `runtime\python` 和 `runtime\venv`。就绪标记
   `runtime\venv\.cutora_ready` 和 `requirements.lock` 对得上就直接打开，
   不弹出黑窗口。启动时会把 `runtime\venv\pyvenv.cfg` 的 `home`
   改写成包内 `runtime\python`（幂等），所以换个目录解压也能开。
3. 第一次成功启动会在桌面放上「片语 Studio」。建过一次就记在用户数据目录的
   `desktop_shortcut.created` 里，不会每次都建，删掉桌面图标也不会自动补回来。
   要再放一个，双击 `CUTORA_CreateShortcut.bat`。
4. 标记丢失或依赖不完整时，启动脚本停下来，并写明请运行 `CUTORA_Install.bat`。
   装完再双击 `CUTORA.bat`。
5. 杀毒软件如果拦截了 `.vbs`，改双击 `CUTORA_console.bat`。
   它跑同一套流程，窗口可见，用来排障。
6. 只想强制重装依赖：双击 `CUTORA_Install.bat`。
   本机没有包内 Python、也没有 64 位 Python 3.10 时，窗口会写明要安装
   **Python 3.10.11（64 位）**，并给出 python.org 的下载页。安装时勾选
   "Add python.exe to PATH"，装完重新双击图标即可。

本包**含** `runtime/models/`（识别 small+medium，对齐 en/it/fr/es/de/pt）。
冒烟「自动字幕」不需要再拷模型。

应用内「模型管理」下载走 `cutora.core.net` 白名单（huggingface.co），**不走**
`huggingface_hub`，因此运行期的 `HF_HUB_OFFLINE=1` **不会挡住你点的下载**。
那是禁止识别路径静默拉模型用的。没有网就会失败，有网点下载就能下。

## 请先跑这 5 步（约 5 分钟）

1. 新建项目 → 导入一段视频 → 跑一次自动字幕（en 或 it）
2. 套一个风格预设 → 预览
3. **换一个风格预设 → 再换回来**
4. 导出一小段
5. **同一次会话里再导一次**，确认两次成片一致

## 语种

**精确词级对齐（已内置，逐词动画可用）**：英语、意大利语、法语、西班牙语、德语、葡萄牙语。

**能识别、词级为近似**（不会静默从网上拉对齐模型；应用提示
「该语种对齐模型未内置」）：荷兰语、波兰语、俄语、希腊语及其余语种。
`amber-karaoke` / `pop-word` 等逐词动画在近似词级上会变差，这是设计，不是崩溃。

**可以放心测排版的语种**（`subtitle_tier=complete`，自有字体兜底）：
英语、葡萄牙语、西班牙语、法语、德语、意大利语，以及俄语、希腊语、
波兰语、土耳其语等拉丁 / 西里尔 / 希腊语种。Anton 等显示体缺字时走包内
Noto，不会静默用系统字体。

**暂时不要用来判断质量**（`subtitle_tier=font_only`：字形保证，复杂排版未完善）：
阿拉伯语、印度系（印地 / 孟加拉 / 泰米尔等）、中日韩。
泰 / 高棉 / 老挝 / 缅甸等同属 font_only。
