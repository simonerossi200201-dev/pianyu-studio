# Q173 · 批量加载打开进度 + 监视器右键「图层」批量操作（2026-10-06）

## 1. 批量加载窗口打开慢、而且看不到进度

Luca 的日志显示，打开「批量加载」时界面线程卡了 14.5 秒。卡在语音转文本页列模型的时候：它要给每个模型的权重算 sha256，权重一共有几个 GB。

- 列模型改成快速模式（`list_status(fast=True)`）：缓存里有这个文件的 sha256 就直接用；没有就先按「已下载」显示，后台一条线程去算并记进磁盘缓存。下一次打开就能认出坏文件。
- 真正要用模型的时候（转写、对齐、打包）仍然严格校验，这一点没变。
- Q172 已经把 sha256 记到磁盘上，这次再加上「界面上不等它」，两者叠加，第一次打开也不会卡。
- 新增主窗口底部的「正在打开…」进度条（`widgets/busy_bar.py`）：
  - 圆角卡片样式，主题金色渐变的细条，右边显示百分比，步骤之间会慢慢往前爬，让人看得出没卡死；
  - 批量加载在建每一页时报一次进度：素材页 → 文本页 → 语音转文本 → 时间 / 外观 → 视频设置 → 导出设置 → 预览画布 → 收尾；
  - 智能拼接和中央监视器打开时也会显示这个进度条。

## 2. 中央监视器右键「图层：外部视频 · xxx（同一批 N 条）」

在画面上点中的那一层，加上选中的其他视频里同一批的那一层，可以一起改。「同一批」的意思是：主视频对主视频，第 N 条外部视频对第 N 条外部视频；分屏时就是同一格。右侧图层面板里选中一条视频图层，右键也有同样的子菜单。

- 左右翻转 / 上下翻转。
- 混合模式：正常 / 正片叠底 / 滤色 / 叠加 / 相加。
- 调色：
  - 亮一点 / 暗一点、对比 ±、饱和 ±、暖一点 / 冷一点、黑白；数值和右侧调色面板一致，并限制在面板的取值范围内；
  - 复制这一层的调色，粘贴到同一批（曲线、HSL、LUT 一起带过去）；
  - 清除调色。
- 叠放顺序：上移一层 / 下移一层 / 置顶 / 置底（垫在最下面当背景）。只在视频轨之间挪动，整幅背景轨始终垫在最底下，不会被挪动。
- 显示 / 隐藏这一层。

以上每个操作都是一批改完、一步撤销。改完只作废画面，看得见的格子由调度器一格一格补画。

### 顺带修的存盘 bug

片段调色 `grade` 以前不在存盘字段表 `CLIP_KEYS` 里，所以在主窗口给片段调好的色，一保存就丢了。现在已经加进去。监视器的撤销快照也会记下「没调过色」的状态，所以撤销批量调色能回到完全没调色。

## 测试

`tests/test_q173_monitor_layer_ops.py`，共 8 项：
- 叠放顺序和各项数据操作；
- 菜单批量翻转、混合模式、调色、置顶，以及逐步撤销；
- 复制粘贴调色、隐藏图层；
- 右键菜单出现的是点中那一层的子菜单；
- 图层面板的右键菜单里有这些操作；
- 片段调色存盘后读回来还在；
- 快速列模型不在界面线程里算 sha256，后台算好后照样能认出坏文件；
- 进度条能显示、不会往回退、能正常关闭；
- 打开批量加载会按顺序报进度。

另外发现了一个 PySide6 的坑：`QAction.menu()` 返回的子菜单包装会被当成 Python 自己的对象，临时变量一回收，真正的子菜单就被删掉了。测试代码改成用 `findChildren(QAction)` 来找菜单项；程序本身没有这样用。
