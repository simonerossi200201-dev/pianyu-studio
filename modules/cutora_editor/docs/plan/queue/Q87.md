# Q87 · 资产库的 GIF / 动图放到画面上后，能像图片一样在画布上拖动、缩放、旋转

**开工前先读 `_RULES_FOR_EVERY_TASK.md`、`_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。**

## 用户原话

> 从资产库里导入进来的 Gif 文件，双击添加到画面上之后，在画面画布上鼠标点击后，
> 不能像图片那样直接调整大小、旋转、缩放和鼠标直接移动，这样不太方便。

## 根因（Claude 已查明）

`cutora/assets/user.py:place_on_timeline`：`type == "animated"`（GIF / APNG / 序列帧）会先 `import_animated_as_clip`
转成**带 alpha 的视频 clip**，放到叠加视频轨（`overlay_video_track`）上。画布（`cutora/ui/canvas.py`）的选中框 / 手柄 / 拖动
只对文本覆层、图片覆层、贴纸做了，**视频 clip（包括叠加轨上的 alpha clip）没有画布变换控件**，只能去属性面板敲数字。

## 做法

1. 画布给**所有视觉 clip**（叠加视频轨上的 clip、主视频轨上的 clip 也要）加上和图片完全一致的交互：
   点中选中（命中测试按 clip 实际绘制区域 + alpha，不能整块画布都算命中——参考 Q77 的点击穿透），
   左键拖动移动、角手柄等比缩放（Q78 的 `lock_aspect`，Shift 反转）、边手柄、旋转手柄。
2. 写的是 clip 的 `x / y / scale / rotation`（有关键帧时走 Q62 的 `keyframe.set`，不弹回），一次拖动一条撤销；
   属性面板视频页同步刷新；导出帧与预览一致。
3. 选中叠加轨 clip 时属性面板显示视频 clip 页（变换 / 不透明度 / 混合等都能用）。
4. 手柄外观复用图片的，不新造样式。

## 验收（修前必红）

- `test_q87_gif_drag_moves_clip`：从资产库放一个 GIF 到画面，模拟在它中心按下拖 (120, 80) 松开 → clip.x/y 变了，导出同一帧里 GIF 位置也变了。
- `test_q87_gif_corner_scale_and_rotate`：拖角 → 等比缩放；拖旋转手柄 → rotation 改变；撤销各一次能回来。
- `test_q87_click_through_empty_area`：点 GIF 透明区域外的画面，不会选中 GIF。
- golden 不变。
