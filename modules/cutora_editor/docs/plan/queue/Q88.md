# Q88 · 预览 / 导出引擎深度提速 + 资产库存储方式可选 + 工程文件把用到的素材存完整

**开工前先读 `_RULES_FOR_EVERY_TASK.md`、`PROTECTED_INVARIANTS.md`。这是性能任务：先量，再改，每一刀都要有前后数字。每做完一个子项就提交。**

## 用户原话

> 画面启用了分屏并导入 Gif 之后，操作起来非常明显的卡顿……希望整个软件的预览要提速，对预览引擎渲染器和导出引擎渲染器进行深度的研究和优化，
> 保证速度和质量都能提升一大截。用户导入的资产库，可以让用户自行选择是随工程文件保存还是直接固定保存在软件内不受工程影响。
> 用户保存的工程文件必须要把用户用在时间线上的 gif 文件或其他文件都保存完整。

## 一、先量（不量不许改）

1. 写 `tools/_diag/q88_profile.py`：固定场景 **720×1280 竖屏、2×2 分屏（玻璃带）+ 2 个 GIF 叠加 + 1 个文本层 + 字幕**，
   - 预览：连续播放 10 秒、拖动播放头 5 秒、在画布上拖动 GIF 5 秒，分别记录每帧耗时 p50 / p95 / 最大值；
   - 导出：同场景导出 10 秒，记录总耗时和每帧平均。
   - 用 cProfile 取前 30 个热点函数，写进 `docs/plan/reports/Q88_profile_before.md`。
2. 在报告里对每个热点给出原因（解码？颜色转换？整帧 numpy？重复构建 QImage？没缓存？主线程阻塞？）。

## 二、再改（按热点排序，已知嫌疑）

- 分屏合成：见 Q86（每帧整帧 numpy 距离场 + 整帧高斯模糊）——Q86 先做，这里复测。
- GIF：已转成 alpha 视频 clip，检查预览是不是每帧都在解码带 alpha 的中间格式（prores 4444 / png 序列？）。
  动图帧数有限，应该**解码一次、按帧缓存为预乘 QImage**（内存上限可配，默认 512MB，LRU），循环播放不再解码。
- 预览渲染不许阻塞 UI 线程：解码 / 合成在工作线程，UI 只贴最后一帧；拖动时允许降一档预览分辨率（松手后补一帧全分辨率）。
  **注意约束：不加「快速模式」开关，不动导出的 CRF / preset。** 这里说的降档只是拖动交互中的临时预览帧。
- 导出：同样的缓存复用；检查每帧是否重复做了 RGB↔BGRA 转换和整帧拷贝。
- 质量不许降：导出 golden 全部逐字节不变（性能优化不应改变像素）；变了写 `.stop`。

## 三、验收数字（写进 `Q88_profile_after.md`，前后对照表）

- 预览播放 p95 帧耗时 ≤ 33ms（30fps 实时），拖动 GIF 时 p95 ≤ 40ms；**且都 ≤ 改前的 40%**。
- 导出同场景总耗时 ≤ 改前的 60%。
- golden 全部不变。

## 四、资产库存储方式

- 资产库每个素材（和导入对话框）加一个选项：**「存到软件库（所有工程共用）」**（默认，现在的行为，放 `user_assets_root()`）/
  **「随工程保存」**（复制进工程文件夹的 `assets/` 子目录，工程里用相对路径引用，工程文件夹整个拷走就能在别的电脑打开）。
- 资产库列表里「随工程」的素材只在该工程打开时显示，带一个小标记。

## 五、工程文件存完整（与 Q82 衔接）

- 先查：GIF 放到时间线时 `import_animated_as_clip` 生成的中间文件写在哪？如果在缓存目录，清缓存 / 换电脑后工程就丢素材——这是 bug。
  中间文件必须落在持久位置（软件库模式 → 资产库目录；随工程模式 → 工程 `assets/`），并且工程里记住**原始 GIF 路径**，中间文件丢了能从原始文件重建。
- 保存工程时检查时间线上用到的每个文件（视频、图片、GIF、音频、LUT、字体）是否存在；缺失的在保存时就提示，而不是打开时才发现。
- 增加菜单「文件 → 打包工程…」：把用到的所有外部文件复制进工程文件夹并改成相对路径（Resolve 的 Media Management 同理）。

## 测试

- `test_q88_gif_decoded_once`：播放一个 10 帧 GIF 循环 3 遍，解码函数只被调用 10 次。
- `test_q88_preview_off_ui_thread`：预览渲染时 UI 线程事件循环延迟 p95 < 16ms。
- `test_q88_gif_survives_cache_clear`：放 GIF → 存工程 → 清空缓存目录 → 重开工程 → GIF 能显示、能导出。
- `test_q88_project_mode_asset_relative`：「随工程保存」的素材在工程 `assets/` 下，工程文件里是相对路径；把工程文件夹移到别处打开仍正常。
- `test_q88_pack_project`：打包后工程文件夹自包含（删掉原始外部文件仍能打开导出）。
