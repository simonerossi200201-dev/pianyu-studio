# Q73 · 调色：从 0.5 秒一帧提到实时

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

## 现状

Q32 把调色的**功能**做完了，而且做对了：片段/轨道级调色挂在视频层（字幕和画中画不会被改掉），
工程级在整帧末尾，全关时 `_grade_on=False` 整条不查表（实测比上线前还快 10%），
示波器接上了预览，12 条测试绿。**这些都不要动。**

它停下是因为性能：全开时 720×1280 **506 ms/帧**，上线前 16.5 ms/帧。
用户会看到：给片段开一下曝光或 LUT，导出从一秒几十帧掉到**两秒一帧**。

## 根因（`docs/plan/reports/Q32_调色性能.md` 自己量出来的）

`apply_grade_to_qimage` 的 33³ **三线性**查表用 numpy 花式索引实现：每个像素取 8 个角点、
720×1280 一层约 250 ms，片段+轨道一次、工程一次，加上 QImage 往返，合计 494 ms。
直接按公式逐像素算更慢（单层约 160 ms、三层 500 ms），所以 Q32 选了查表——方向对，实现慢。

## 做法

**不需要任何新依赖。**

1. **3D 查表换成 Pillow 的 C 实现**：`PIL.ImageFilter.Color3DLUT(size, table)` + `img.filter(lut)`。
   Pillow 12.3 已经在 `requirements.in` 里。它就是 C 写的三线性 3D LUT，720×1280 一次大约十毫秒级。
   `BakedLut` 已经是烘焙好的 33³ 表，直接喂给它。
2. **能拆成逐通道的就走 1D**：曝光、对比、lift/gamma/gain、逐通道曲线这些**不跨通道**的修正，
   烘成每通道 256 项的表，用 `cv2.LUT` 一次过（约 1 ms）。只有饱和度、自然饱和度、HSL、色温色调、`.cube` 这些跨通道的才进 3D。
   如果一个 clip 只开了逐通道修正，**完全不走 3D**。
3. **少做一次 QImage ↔ numpy 往返**：视频层拿到的本来就是 numpy 帧（解码出来的），
   在转成 QImage **之前**就调色，别先转 QImage 再转回来。
4. 工程级是 identity 时整层跳过（确认现在是否已经这样）。

## 门禁（改了，说明理由）

Q32 任务书写的是「全开涨幅 < 12%」——对 CPU 上全开调色来说**这个门禁不现实**：
专业软件做调色靠 GPU，CPU 上哪怕一次最快的 3D 查表也要若干毫秒，而上线前一帧才 16.5 ms。
它真正该守的是两件事：

- **全关零成本**：全关时 ms/帧 与上线前相差 < 1%。**这一条 Q32 已经做到，不许退化。**
- **全开仍然实时**：全开（一级全开 + 非 identity `.cube` + 轨道 + 工程）720×1280 **≤ 33 ms/帧**（30fps 实时）。
  争取 ≤ 25 ms。

## 验收

- `docs/plan/reports/Q73_调色性能.md`：同样的四档（上线前 / 全关 / 只开逐通道 / 全开），同一台机器同一套脚本
  （`tools/_diag/q32_profile_grade.py`），前后对照。
- **`test_q73_pillow_lut_matches_reference`**：同一张图、同一个 33³ 表，Pillow 实现与现有 numpy 三线性实现的结果
  MAD < 1（证明换实现没换画面）。
- `test_q73_per_channel_skips_3d`：只开曝光时，3D 查表函数一次都没被调用。
- `test_q73_realtime`：全开 720×1280 单帧调色耗时 ≤ 33 ms（取 20 帧中位数）。
- Q32 原有 12 条测试必须继续绿，尤其 `test_q32_clip_grade_spares_subtitles` 和 `test_q32_preview_export_same`。
- golden 必须逐字节不变（没开调色的工程不许受任何影响）。


## 追加（2026-09-21）：示波器不要默认盖在预览画面上

Luca 的截图里，预览画面的**下半部分被一个 RGB 波形图整块盖住**（Q32 接上的示波器）。
示波器是给调色时看的工具，**默认关闭**；打开时放在画布旁边独立的小面板里或者用户可拖动的浮层，**不许默认遮挡画面**。
- `test_q73_scopes_off_by_default`：新开工程，预览截图里不存在示波器像素。
