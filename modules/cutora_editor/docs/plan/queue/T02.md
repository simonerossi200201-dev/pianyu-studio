## 背景（十六报第 4 节）
`render/parallel.py:258-261`：`elif not (out_path and os.path.exists(out_path)): failed.append(...)`
—— **只要文件存在就算成功**。`render_worker.py:623` 另一处只查 `getsize >= 10KB`。
所以 Luca 那 5 个花屏文件又大又在，全部被报告成「成功 6 个，需串行重试 0 个」。

## 要做
新增 `cutora/render/export_verify.py`，`verify_output(out_path, task, expect_frames, expect_dur)`，
在 `parallel.py` 判定成功的那一处**每个文件都跑**：
1. `ffprobe` 读时长，与工程时长差 > 0.5s → 失败
2. 帧数（`nb_frames` 或 `-count_frames`）与预期差 > 2 → 失败
3. `ffmpeg -v error -i out.mp4 -f null -` **整条解码一遍**，stderr 有任何 error → 失败
   （这一步就是抓花屏/断流的，约 1–2s/条，值）
4. 抽首/中/尾 3 帧，与 `PreviewEngine.frame_at` 同时刻帧比 MAD > 0.05 → 失败
任一不过 → 该视频进 `failed` 走串行重试，并在完成提示里**逐条列出失败原因**。
