**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

## 一、配色收尾（Q53 做了片段，漏了周边）

1. **视频轨整条底仍铺冷蓝**：`widget.py:2214` 用 `track_video` 渐变铺满整个可见宽度（`_draw_time_bar`，`:2031`），片段缝里看得到。改用 `bg0`/`line` 中性令牌或不画。
2. **转场胶带和手柄仍是硬编码冷色**（`widget.py:1388-1407`）；裁剪手柄 `:1930/1934/1987/1991` 还有 `QColor(255,255,255,…)`。换令牌。
3. **罗马金的 `track_text` 等于 `accent`**（`roma-gold.json:15/27` 都是 `#C8A24A`）——文本片段选中与否只差内发光强度，**选中状态很难认**。
   `track_text` 换成和 accent 拉开的暖黄，或选中态改 `accent_hi` 加 2px 外描边。
4. **悬停不一致**：只有视频和音频 clip 传了 `hovered`（`:1304/:1728`），字幕、文本、图片没有。
   悬停时视频 clip 的内发光整个换成 accent，**轨道身份色闪没了**。统一传 `hovered`；悬停只提高 alpha，保留色相。
5. 片段主体 `bg1 #1C1815` 压在车道 `bg0 #141210` 上，对比极低，整体偏暗偏平。主体在 `bg1` 和 `bg2` 之间调一档，让片段浮出来。

## 二、内发光性能与高分屏

- **缓存键带宽度**，字幕段宽度各不相同，缩放时每一档都全部失效；上限 96 条，满了 `clear()` 全清（`:125`）。
  几百条字幕时每次重绘新建几百张 QImage——**这就是字幕多时时间线卡顿的来源之一**。
- **高分屏会糊**：按逻辑像素生成，没设 `devicePixelRatio`，Windows 150%/200% 缩放下是放大后的模糊图。
- 四条边渐变在四个角重叠，SourceOver 叠加后角上是更亮的方块；直线渐变不跟圆角走；纯线性衰减显得生硬。

**做法**：改成**九宫格**——按 (h, 颜色, alpha, DPR) 缓存一张小瓦片，用 `drawPixmapFragments` 拉伸，**与宽度无关**；
`setDevicePixelRatio`；LRU 缓存；衰减用 smoothstep（多几个渐变停靠点）；四角用径向渐变补。

## 三、拖动手感（对标 Resolve）

1. **词级拖动看不到吸附线**：没设 `_snap_guide_t`。设上。
2. **词块宽 <12px 时两个 6px 手柄重叠，永远命中左边界**（`widget.py:1200`）。按离哪条边近判定。
3. **首词左边界下限 0、末词右边界没上限**（`word_trim.py:54,47`），词可以拖出字幕段。钳制在段内。
4. **Alt 在按下时就复制**（`widget.py:3081/3180`）：Alt 单击不拖也原地叠出一个副本，撤销要按两次。改成拖过阈值才复制，并和移动合并成一条撤销。
5. **「静音段吸附」其实是 clip 之间的空隙**（`snap.py:84-89`），和 clip 边界重复，开关几乎无效；还不检查 `skip`，被拖的 clip 会吸回自己原位。接入真正的波形静音检测，遵守 `skip`。
6. **波形永远显示「生成中」**：没缓存时不管是否在生成都画「生成中」（`widget.py:1024`），没音频或生成失败的素材永远显示它。区分三态；颜色走令牌、文字走 `tr()`。
7. **缩放系数不对称**：放大 ×1.2、缩小 ×0.8（`container.py:243`），缩回去会漂移；`scroll_x` 可能为负。改 1.25 与 1/1.25，钳制 scroll_x。
8. 微移（逗号句号）只对单个 clip 生效，多选不动。支持多选。
9. 加「按住 N 临时关吸附」。
