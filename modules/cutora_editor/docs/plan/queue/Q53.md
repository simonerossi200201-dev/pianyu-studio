# Q53 · 时间线片段配色跟随主题（文本轨的粉红色要去掉）

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

## 用户原话

> 把**文本轨道的粉红色外观改成跟随系统色**吧，比如现在是罗马金主题，
> 那它就可以**显示带有黄色的内发光，中间保持深灰色**就好了，
> 这样设计有高级的质感，而且整体还比较协调统一。

## 事实

`cutora/ui/timeline/widget.py` 里片段填充是**硬编码的冷色**，换主题不跟着变：

- `:1061` `#493955`（紫）/ `:1064` `#3a5a3a`（绿）/ `:1067` `#2f3b4a`（蓝）
- 选中边框 `#c084fc` / `#7ddf7d` / `#6ab0d6`
- 文字 `:674, :992` 用 `#ffffff`，`:739, :1030, :1116` 用 `#e0e0e0`（纯白 / 中性灰）
- 悬停边缘 `:764, :1072` 用 `#F2C14E`（和 `ACCENT` `#C8A24A` 接近但不相等）
- `:1069` `drawRoundedRect(rect, 4, 4)` 圆角也是硬编码

同一文件 `:102-106` 的**轨道头**已经在正确使用 `t.track_video` 等令牌了 ——
片段填充另起一套，是遗漏不是设计。

结果：一个自称 "warm black, not pure black"（`tokens.py:16`）的暖石色应用，
中间嵌着一块冷蓝紫、打纯白字的时间线。

## 要做的

按用户描述的语言去做，这是一套**明确的视觉规格**，不要自由发挥：

1. **中间保持深灰。** 片段主体填充统一用一个中性深色（建议 `bg2` 或 `bg1` 与 `bg2` 之间），
   三类轨道的主体色**不再靠色相区分**。
2. **轨道身份靠内发光的色相表达。** 视频 / 音频 / 字幕 / 文本各自取
   `t.track_video` / `t.track_audio` / `t.track_subtitle` / `t.track_text` 的色相，
   在片段内侧画一圈**内发光**（inner glow）：沿片段边缘向内 3–6px 的渐变，
   从该色相的低透明度渐隐到透明。罗马金主题下文本轨就是「深灰底 + 黄色内发光」。
3. **选中态**：内发光增强 + 边框换 `accent`，不要另起一套色。
4. **悬停态**：内发光略增强，用 `accent` 而不是 `#F2C14E`。
5. **文字**：`#ffffff` → `fg0`，`#e0e0e0` → `fg1`。暖色主题下纯白是刺眼的。
6. **圆角**：`drawRoundedRect(rect, 4, 4)` 改用 `RADIUS_*` 令牌
   （和 Q46 的圆角收敛对齐；两条任务都要改这里，以先落地的为准，不要各改一遍）。
7. 如果 `t.track_text` 令牌不存在，六套 palette JSON 都要补上
   （`_COLOR_KEYS` 会强制校验，漏一套直接抛错）。罗马金那套给暖黄。

内发光的实现建议：片段矩形 `QPainterPath` 做 `QLinearGradient` 四边各一次，
或者更省事——`QRadialGradient` 不合适，用四条边的 `QLinearGradient` 叠加即可。
每帧都要画很多片段，**注意成本**：在片段尺寸不变时缓存那张内发光图，按尺寸做 key。

## 验收

- `test_q53_clip_colors_follow_theme`：切到六套主题，每套 grab 一次时间线，
  断言片段区域的主导色相属于当前 palette，**不存在 `#493955` / `#3a5a3a` / `#2f3b4a`
  这三个硬编码值的像素**。现在必红。
- `test_q53_inner_glow_present`：文本轨片段截图，
  断言**边缘一圈**的色相接近 `t.track_text`、**中心**接近中性深灰
  （用饱和度区分：边缘 sat 明显高于中心）。
- `test_q53_no_pure_white_text`：时间线截图里不存在 `#ffffff` 像素。
- `test_q53_glow_cached`：同尺寸片段连画 100 次，断言内发光图只生成一次。
- UI 基线会变，写 `.stop`。golden 不该变（时间线不进导出）——如果变了，那是 bug。

## Claude 裁决（2026-09-20）

全文：`docs/plan/queue/_blocked/Q53.ruling.md`。要点：

1. **Q53 验收通过，不重跑。** 四条测试都绿且都有反证，golden 无新增失败，
   产品改动在 `53af9d7`。被隔离只因 `u05` 静帧变了 —— 任务书自己预告过，归 Q56 重录。
   如果这条又被调度到你手上，按《七、队列自己也会出错》处理：在 `.ok` 里写明
   「本轮为复验，产品改动已在 53af9d7」，跑一遍验收确认没被后续任务改坏，如实报告是重复调度。
2. **`.stop` 里对 `u03d`/`u04d`/`u07` 的归因是错的。** 不是 roma-gold 的 `track_text`
   （`track_text` 只出现在 `tokens.py` 和 `timeline/widget.py:176/213/215`，检查器不读它，
   `theme_dark.qss.j2` 也不用它）。真凶是 **Q51**（`0a594d3`）在
   `subtitle_style.py:431-439` 加的两个勾选「换字色」「词底方块」+ `dock_panels.py:462-463`
   的排版，`u03d`/`u07` 抓的正是 `SubtitleStylePanel`，多两行控件 → 整体下移 → 哈希必变。
3. **下次遇到这三例**：按 `_RULES_FOR_EVERY_TASK.md` 第六节，**不要写 `.stop`**，
   在 `.ok` 里记下新的 `got=` 值和本轮自己改了什么即可。Q51 漏记 got 值，才让 Q53 拿旧值误判。
4. **留下三个洞**（不靠复跑 Q53 补，等新任务书）：`_draw_time_bar`（`widget.py:1553`，
   在 `:1736` 画在片段底下）仍用 `track_video` 实心铺底，片段拉开有冷蓝缝；
   转场胶带 `:916`/`:932`/`:1556-1557` 仍是硬编码冷色；裁剪手柄与橡皮筋
   `:1452`/`:1509`/`:1792` 仍是半透明纯白（`test_q53_no_pure_white_text` 只查纯 `#ffffff`，
   混色后绕过了它）。
