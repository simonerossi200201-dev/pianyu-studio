# Q78 · 画布上直接拖动图片 + 所有素材锁定宽高比（默认开）

**开工前先读 `_RULES_FOR_EVERY_TASK.md` 和 `_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。**

## 用户原话

> 导入进来的图片，在画面画布上**无法直接通过鼠标左键点住不松的拖拽来进行移动**，这样很不方便，请你修复或者增加这条信号。
> 我希望给**所有的素材视频图片等，加上锁定/还原宽高比的功能**，避免素材变形，而且**默认应该开启锁定宽高比**，
> 这样在拖动触点进行调整大小的时候也可以避免给素材造成变形。

## 做法

1. **左键拖动移动**：画布上左键按住图片（以及视频叠加层、文本层、贴纸）不松、拖动即移动。
   先查清楚现在为什么不行——是命中测试没命中（整幅画布大小的透明图片层？见 Q77 的点击穿透）、
   还是命中了但 `mouseMoveEvent` 没接位移、还是位移写了但渲染读的是另一个键。
   **有关键帧时**走 Q62 已经接好的 `keyframe.set` 路径，不许弹回。一次拖动一条撤销。
2. **锁定宽高比**：每个视觉素材（视频 clip、图片 overlay、贴纸、文本层）加 `lock_aspect` 字段，**默认 True**。
   - 拖角上的缩放手柄时，锁定则等比缩放（以对角为锚点）；按住 **Shift** 临时反转锁定状态（Resolve / PS 的通行做法）。
   - 拖边上的手柄时，锁定则另一维按比例跟随。
   - 属性面板「变换」段加一个锁链图标开关 + 一个「还原宽高比」按钮（恢复素材原始比例，保持当前宽度）。
     **按 `_RULES_UI_OWNERSHIP.md`：只加控件、接信号，不改布局规则。** Claude 会统一外观。
   - 老工程没有这个字段的，读成 True。
3. 存盘：`lock_aspect` 进 Q82 那张共享字段表。

## 验收（修前必红）

- `test_q78_canvas_drag_moves_image`：模拟在图片中心按下、移动 (100, 50)、松开，图片位置变了，**导出帧里也变了**。
- `test_q78_corner_resize_keeps_aspect`：锁定时拖右下角，宽高比保持（误差 < 0.5%）。
- `test_q78_shift_inverts_lock`：按住 Shift 拖角，宽高比改变。
- `test_q78_restore_aspect`：先非等比拉伸，点「还原宽高比」，比例回到素材原始比例。
- `test_q78_default_locked`：新导入的每种素材 `lock_aspect is True`；老工程读成 True。
- golden 必须不变。

Q83 已经把属性面板「变换」段重做了：
- 位置 / 尺寸是成对数值框；**尺寸行右边已经有锁链按钮 `self.ov_lock_btn`**（图片 / 图片贴纸才显示，文本层隐藏），
  它和原来的 `self.ov_keep_aspect` 双向同步，`ov_keep_aspect` 仍是存盘读写的唯一来源（已隐藏，别再显示它）。
  所以：**不要再加第二个锁定开关**；你要做的是把字段从 `keep_aspect` 统一到本任务的 `lock_aspect`（老键读进来兼容），
  并让画布手柄、视频 clip 也读它。视频面板没有尺寸行，锁链按钮加在「缩放」行的 `with_trailing(...)` 里即可。
- 「还原宽高比」按钮：用 `inspector_icon_button("rotate-ccw", "还原宽高比")` 放进尺寸行 `paired_fields(..., trailing=...)`
  （可以把 trailing 换成一个装着两个图标按钮的小 QWidget）。不要自己设高度/QSS。
