# Q68 · 转场：修首尾跳变、去掉重复、给参数旋钮

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

Q55 的冻结补帧是真做完了（`render/transition_runtime.py:71-110`），导出、PreviewEngine、canvas 都传了 `extend_handles=True`，
缩放溶解/模糊溶解/Zoom In 也改成了 A 不透明打底。**这部分别动。** 问题在转场库本身的质量。

## 1. 首尾跳变（用户能直接看到的闪烁）

**测试是白送的**：`_endpoints`（`transitions.py:71`）在 t≤0 直接返回 A 的拷贝、t≥1 直接返回 B 的拷贝，
效果本身在端点**是否连续根本没被测**。已查到的跳变：

- **色散**：Plus 混合 0.45 加 0.35 叠加（`transitions.py:530-531`），t 一离开 0 亮度就接近 ×1.8，**第二帧过曝闪一下**。
  改成按通道空间偏移、不做 Plus 叠加，偏移量随 `sin(pπ)` 从 0 起步。
- **像素化**：块大小最小是 2（`:699`），t 一离开 0 就降半分辨率。从 1 起步。
- **扫描线**：常驻 0.12 透明度（`:755`），首尾两帧都跳。乘 `sin(pπ)`。
- **push_out、wipe_circle**：intensity<1 时到 t≈1 还没走完，最后一帧硬切。保证 t=1 时正好走完。

## 2. 重复实现（名字不同、效果一样）

- 「闪白」和「白场」**数学完全等价**（`anim_engine.py:934-956` 对比 `:1018-1028`）。
  闪白改成短促的峰值 + 过曝感（峰值在中点附近、持续短），白场保持平滑。
- 「黑闪」和「黑场」只差缓动曲线。同理区分。
- 「翻页」其实是裁切擦除加一条 16px 阴影（`transitions.py:350-386`），方向 up/down 时连阴影都没有。
  做真正的卷页形变，或者改名为「阴影擦除」。
- 「立方体旋转」的强度参数被 `k / max(k, 0.01)` 约掉了（`:415`），底下垫的是 A 的原图。
  用 QTransform 做真透视，去掉 A 的底图。
- 旧的 `wipe_right/up/down` 三个方向其实都按 wipe_left 画（`anim_engine.py:978-988`）。修。

## 3. 属性面板没有方向 / 强度 / 缓动旋钮

`property.py` 和 `transition_panel.py` 里都搜不到 `intensity`。「可调角度的线性擦除」实际上调不了。
**做法**：选中转场时属性面板显示方向、强度、缓动，写 trans 字段，确认 `paint_standalone_transition` 读到了。

## 4. canvas 预览走了另一条路

canvas 自己取帧（`_get_cv_frame_for_preview`）、用自己的几何函数，还**把 fps 写死成 30**（`canvas.py:1057`），导出用源 fps。
**做法**：canvas 转场改走 `RenderWorker._paint_export_transition`，fps 取 `tl.fps`。

## 5. 缩略图

源图是两块纯色（`transition_panel.py:49-50`）——模糊、散景、像素化在纯色上看不出效果，**看起来全是交叉溶解**。
35 个 QTimer 每 50ms 常驻刷新，散景每帧还做一次高斯模糊，面板开着就一直占 CPU。
**做法**：用两张有纹理和边缘的内置图；只在悬停或选中时播放动画。

## 6. 手柄

没有限制转场必须覆盖切缝，可以拖到完全离开切缝甚至跨过下一个。拖完 `transition_at_seam` 找不到它。
拖动过程中不刷新预览画面。**做法**：拖动时约束在切缝两侧；拖动中刷新画布。
