## 现象
「弹力条色横着拉得很长、看不出是什么颜色；它是一条死死的线，希望改成跟随词级画线的动画；
线型希望有直线/曲线/虚线等；粗细、发光这些参数都没有。」

## 根因（本仓库最干净的一个「读写两端各写各的」案例）
- **面板写的**（`subtitle_style.py:457-486`）：`adv_bar_color`、`adv_bar_opacity`、`adv_bar_padding`、
  `adv_bar_offset_y`、`adv_bar_radius`、`adv_bar_glow`、`adv_bar_style`、`adv_bar_border_width`、`adv_bar_enabled`
  —— **这 9 个键全部在 `style_schema.DEPRECATED_UNPAINTED_KEYS` 里**，也就是代码里明确标注了「不画」。
- **渲染读的**（`word_fx.draw_line_bar:377-384`）：`fx.line_bar.{pad_em, height_em, offset_y_em, radius_em, color, alpha}`
  —— **面板一个都没有。**
- 而且 `draw_line_bar` 画的是整行的静态圆角矩形
  （`rect = QRectF(line.x-ox-pad, …, line.w+2*pad, bar_h)`），没有任何 `t` 参与 → 「一条死死的线」。

## 要做

### 1. 参数接上（面板 → `fx.line_bar`）
删掉 9 个 `sub_adv_bar_*` 控件，新建一段「跟随句子 · 底条」：

| 控件 | 键 | 范围 | 备注 |
|---|---|---|---|
| 颜色 | `line_bar.color` | 8 位 hex | **正方形色块按钮，不是长条**（见 T25） |
| 粗细 | `line_bar.height_em` | 0.02–0.6 | |
| 左右扩张 | `line_bar.pad_em` | 0–0.6 | |
| 上下偏移 | `line_bar.offset_y_em` | -0.5–0.5 | |
| 圆角 | `line_bar.radius_em` | 0–0.5 | |
| 发光 | `line_bar.glow_em` | 0–0.4 | **新增**，0 = 不发光 |
| 线型 | `line_bar.style` | 见下 | **新增** |
| 动画 | `line_bar.anim` | `none` / `draw` | **新增**，默认 `draw` |

`FxSpec` 目前**没有 line_bar 字段**（`FX_KEYS` 里有名字，但没有对应 dataclass，现在是从原始 dict 裸读）。
本任务要**补一个 `LineBarSpec` dataclass 接进 `FxSpec`**，`from_style` 里 `_parse_line_bar`。
`follow_word` / `follow_sentence` / `box_highlight` 同样是裸读，**本任务只补 line_bar**，
另外三个写进 `.ok` 的「欠账」一节，不要顺手一起改。

### 2. 线型
`line_bar.style` ∈ `solid`（直线）/ `dashed`（虚线）/ `dotted`（点线）/ `wave`（波浪）/ `brush`（手写笔刷，两端细中间粗）。
前三种用 `QPen` 的 dash pattern；`wave` 用正弦 `QPainterPath`；`brush` 用中间宽两端窄的多边形。
**不要引入新依赖。**

### 3. 词级画线动画（Luca 的重点）
`line_bar.anim == "draw"` 时，底条右端**随当前朗读位置推进**：

- 当前时刻 `t` 落在本行第 k 个词上，进度 = 词内插值 → 底条宽度 = 行首到「当前词右边界」的距离，
  带一点 ease，不要生硬。
- 词的时间来自 `layout.lines[i].runs[j].t_start / t_end`（`draw_line_bar` 里已经在用了）。
- 一行读完后停在满宽，直到换行。
- `anim == "none"` 保持现在的整行满宽行为（老工程不变）。

### 4. 性能
`word_fx.py:394` 现在每帧 `bg.copy()` 整张 ROI。底条逐帧变化**不能进层缓存**，
但可以只在底条那个小矩形 ROI 上作画再合成。改完量 ms/帧，进 `.ok`。
