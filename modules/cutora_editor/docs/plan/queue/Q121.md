# Q121 · 文本分页接上右侧预览：点行看效果 + 现场调样式存成模板

**开工前先读 `_RULES_FOR_EVERY_TASK.md`。前置是 Q120（`46e1610`）和
Q123（`4da07a6`）：批量加载已经有「文本」分页，表格粘文案 + 自动定位已经
能用，三栏也已经可拖。别推倒重来。**

## Luca 的原话

「用户可以选择它自己之前设置好的文本的模板，或者也可以默认，**或者也可以
直接对照着最终预览画面进行现场设置直接添加进模板里面**」

Q120 只做到「选已有模板」。这一条把预览接上：**看得见**、**改得动**、
**存得下来**。

## 现状（读代码，别猜）

- 分页界面：`cutora/ui/batch_text_tab.py` → `build_text_tab(dlg, host, picker)`，
  返回的 page 上挂着 `table` / `refresh` / `apply` / `preview_plans` /
  `run_locate_asr` / `cb_preset` / `ck_auto` / `ck_asr` / `sp_dur`。
  表格列常量（Q123 调过顺序）：`COL_NAME, COL_TEXT, COL_STATE, COL_START,
  COL_DUR = range(5)`。
- 排期逻辑：`cutora/batch/text_batch.py` — `plan_rows()` 返回每行
  `{task_idx, text, start, end, how, warn, ok}`；`apply_rows()` 落地。
  **纯逻辑，不许往里塞 Qt。**
- 右栏预览：`cutora/batch/batch_dialog.py` 里 `dlg.preview_canvas` 就是工程
  里那个 `VideoCanvas`。对话框自己维护一个合成的 `dlg._preview_task`
  （`_ensure_task()`），背景帧走 `_paint_background()` 从第一条勾选视频抓，
  时间点是 `_preview_time()`。画布已经能拖、能缩放 overlay，拖完发
  `item_dragged`，对话框里已经接了 `_pull_from_canvas`。
- 文本预设：`cutora/subtitle/text_preset.py` — `list_presets()` /
  `resolve_preset(ref)` / `template_from_preset(preset)` / `save_preset(raw)` /
  `get_default_preset_id()`。**存模板只能走 `save_preset`，不许自己写文件。**

## 要做到的

1. **点表格某一行 → 预览立刻变成那一行的样子**
   - 背景帧换成**这一行那条视频**的画面（不是第一条勾选的），时间点用
     `plan_rows` 算出来的 `start`（没定位到就用它的起点）。
   - 预览里画出这条文本，内容就是表格里那一格的字，样式用当前模板。
   - 换行、空文本、定位失败都不许让预览崩或者白屏。

2. **在预览里直接改，改的是「这一批」的样式**
   - 画布上拖位置、拉大小、转角度，改完回写到分页自己的一份样式字典
     （page 上开一个 `style` 或类似的东西），不是回写到某一条 task。
   - 属性面板不在这个对话框里，所以**至少**要能在预览里改位置 / 大小 /
     旋转；字号、颜色、描边这些给一排小控件（放在表格上方那条工具栏的
     第二行，别挤成一团）。控件用 `cutora/ui/widgets/inspector.py` 里现成的
     `SliderSpin` / `ValueCombo`，别自己造。

3. **「存为模板…」按钮**
   - 把当前这份样式存成一个新的文本预设（`save_preset`），名字让用户填
     （`QInputDialog.getText`，重名要问「覆盖还是改名」）。
   - 存完刷新 `cb_preset` 并选中新存的这个。
   - 存的是**样式**，不许把表格里某一行的正文当成模板内容存进去。

4. **模板下拉换一个 → 预览跟着变**，并且 `apply()` 用的还是同一份样式。
   也就是「预览里看到的」和「点按钮加进去的」必须是同一个东西。

## 不许做的

- 不许把 Qt 塞进 `cutora/batch/text_batch.py`。界面归界面，逻辑归逻辑。
- 不许在这个对话框里另起一套预览（右栏就是工程里那个 VideoCanvas）。
- 不许改 `plan_rows` / `apply_rows` 的返回结构 —— Q120 的测试锁着它。
- 不许动 CRF / preset，不许碰 golden。
- 预览用的临时 overlay **不许留在真 task 里**：点完行、关掉对话框，工程里
  不能多出任何东西。只有按了「按表格加文本」才落地。

## 测试 `tests/test_q121_text_preview.py`（要 Qt 的登记进 `qt_isolate`）

每条都要能说明「改之前是红的」：

1. **点行换预览**：点第 2 行，断言预览用的背景视频路径是第 2 行那条，
   预览时间等于 `plan_rows` 给第 2 行算出的 `start`。
2. **预览里有这行的字**：预览 task 的 `text_overlays` 里正好一条，
   `content` 等于表格第 2 行那一格；再点第 3 行，还是正好一条（不许越点越多）。
3. **预览不落地**：点了几行之后，真 task 的 `text_overlays` 仍然是空的。
4. **改样式跟着走**：把样式里的 `fontsize` 改掉，断言预览 overlay 和
   `apply()` 出来的 overlay 用的是同一个值。
5. **存模板**：打桩 `save_preset`，断言传进去的是样式、`content` 不是表格
   里的正文；断言存完下拉里多了一项并且被选中。
6. **空行不炸**：文本那格是空的时候点它，预览不抛异常、也不画文本。
