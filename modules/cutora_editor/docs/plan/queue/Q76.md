# Q76 · 玻璃背景从第二段起被第一段最后一帧永久盖住（导出）

**开工前先读 `_RULES_FOR_EVERY_TASK.md` 和 `_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。**

## 用户原话

> 字幕用的是玻璃质感模糊背景。这个玻璃的透明效果，只在软件的第一段视频有真正的穿透视频的透明效果，
> 而到了第二段，也就是 8 秒以后，时间线上第二段往后的所有视频，都不再具有玻璃穿透的效果，
> 而是**直接被第一段的最后一帧给永久的遮盖**，这样瞬间就失去了玻璃质感。
> 修复的过程中也要保证不会拖慢预览、导出渲染的速度。

## 根因（已查清，源码行号见下）

导出时玻璃的底图不是当前合成好的视频画面，而是在「按源存帧的字典」里**取第一个有帧的源**：

- `render/render_worker.py:71-78` `_glass_backdrop_from_states`：
  `for st in states.values(): if st["last_frame"] is not None: return ...` —— 时间、当前片段都不参与判断。
- 字典的插入顺序 = 各源第一次打开的顺序（`:176-181` `_ExportCapPool._open`），**第一段的源永远排第一**。
- 第一段播完后 `:229-235 evict_done` → `:193-209 _release` 只重置解码游标，**不清 `last_frame`**（`:183` 注释写明「last_frame 保留」）。
- 于是第一段的最后一帧从此冻结，而遍历每次都先碰到它。
- 调用点：`:1093-1096 _paint_export_background` 里 `project["_fx_backdrop"] = _glass_backdrop_from_states(...)`；
  串行路径 `export_renderer.py:119-120` 取用；并行路径 `render_worker.py:1135-1138` → `compose_parallel.py:258/263/296-299` 随帧传下去。
- 附带问题：就算只有一个源，这里拿的也是**原始源帧**，没经过 fit / 缩放 / 位移 / 轨道变换 / 转场，和画面上的位置对不上；
  主轨 + 叠加轨时拿到的是被盖住的主轨源。

**预览没有这个问题**：`preview/engine.py:240-252` 用的是 `backdrop = video`（当帧合成好的视频层）。导出要和它一致。

## 做法

1. **删掉 `_glass_backdrop_from_states`**。backdrop 统一用「当帧的视频层合成图」。
2. 并行路径：`_compose_video_frame` 里 `video` 已经画好，直接 `backdrop = video if (有玻璃字幕) else None`，
   `_paint_export_background` 不再写 `_fx_backdrop`。**零新增开销**，还省掉原来每帧一次的 BGR→QImage 转换。
3. 串行路径：`ExportRenderer.render_frame` 里 `draw_background(painter)` 之后，**只在需要玻璃的帧上**取 `canvas.copy()` 当 backdrop
   （1080×1920 约 1ms 量级）。或者让串行也走 `_compose_video_frame` + `_compose_overlay_frame`。
4. `PROTECTED_INVARIANTS.md` 里 `_ExportCapPool` / 解码池的段落**不许动**——这次改的只是 backdrop 从哪来，不碰解码。

## 验收（修前必红）

- **`test_q76_glass_follows_second_clip`**：两段拼接，源 A 纯红、源 B 纯绿各 1 秒，字幕用玻璃背景。
  `compose_workers=1` 和 `=2` **各导出一次**，取 t=1.5s，在字幕玻璃区域采样应该**偏绿**。修前是红（A 的最后一帧）。
- `test_q76_glass_backdrop_matches_video_layer`：`_compose_video_frame(1.5, ctx)` 返回的 backdrop 中心像素与 `video` 一致。
- `test_q76_glass_respects_transform`：视频片段缩放 0.5 放在画面左上，玻璃区域采样到的是**画面上看得见的像素**，不是源帧对应位置。
- **性能**：`docs/plan/reports/Q76_glass_perf.md`，同一工程修前修后 ms/帧，**不许变慢**。
- golden：有玻璃字幕的用例如果变了，写 `.stop`——那说明旧基线录的就是这个 bug（第四次了），等 Luca 拍板。
