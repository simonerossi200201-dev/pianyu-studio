# Q77 · 时间线选中状态卡住：点了视频，视频条就一直选中

**开工前先读 `_RULES_FOR_EVERY_TASK.md` 和 `_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。**

## 用户原话

> 我如果点击了视频，视频就一直保持选中，再点击文字轨道上的文字条也会被同时选中，这样就导致了我无法再调节视频条的参数了。
> 然后我再点击图片条，图片条能选中，文字条取消选中了，但是视频条一直在选中状态，两个同时占用，就只能调整图片的属性参数，
> 这样视频就卡死在这里，鼠标只要一松开，就被其他的属性给占用了，这根本没法用。

## 根因（已查清）

`cutora/ui/timeline/widget.py` 里选中状态**一共七套**（`:564-587`）：`selected_indices`（字幕段）、`selection`（TimelineSelection）、
`_clip_sel`（Ctrl 多选 clip）、`selected_overlay`（文字和图片**共用**一个）、`selected_video_clip`、`selected_audio_idx`、`selected_transition`/`selected_seam`。

视频条高亮取自三个来源之一（`:1983-1987`）：`selected_video_clip`、`_clip_sel`、`selection.has_clip`——任何一个没清都继续亮。

`mousePressEvent` 里每个命中分支只清一部分：
- **点视频正文**（`:3463-3496`）：只设 `_clip_sel`，**不清 `selected_overlay`、`selected_audio_idx`、`selected_transition`**。
  两侧拉伸手柄分支（`:3420-3460`）连 `_clip_sel` 都不动。
- **点文字/图片 overlay**（`:3608-3671`）：只设 `selected_overlay`，**视频的三套一个都不清，也不调 `_publish_selection`**。
  文字和图片共用 `selected_overlay`，所以点图片会顶掉文字、但视频留着——**正是用户看到的现象**。
- **点字幕段**（`:3795-3817`）：只清 `selected_overlay` 然后 `_publish_selection()`，而 `:2577-2591` 又把残留的视频选中塞回 `selection`。
- 只有点空白处（`:3822-3824`）才清视频。现成的 `clear_selection()`（`:2614-2624`）能全清，单击时没调用。

属性面板那边残留状态还会把面板抢回去：
- `main_window.py:7364-7369`（`on_canvas_drag` 兜底）：只要 `timeline.selected_overlay` 还在，画布一拖，面板就被切回图片。
  批量插入的图片 overlay 是**整幅画布大小**，画布命中时总在最上层，每次都触发。
- `on_timeline_select` 的 overlay 分支（`:7049-7057`）把 `video_canvas._selected_item` 设成图片，`video_clip` 分支（`:7112-7125`）不清它。
- `:7299-7322` 用残留的 `selected_video_clip` 拦住 overlay 的面板刷新。

## 做法

1. widget 里加 `_reset_selection(keep_ctrl=False)`，清掉全部七套。
2. 视频、音频、overlay、字幕段、转场、seam、拉伸手柄**每个命中分支**的非 Ctrl 路径开头先调它，再设自己那一套，最后统一 `_publish_selection()`。
3. `on_timeline_select` 里 `type_` 是 `video_clip` / `sub` / `audio` 时清掉 `video_canvas._selected_item` 和 `_selected_rect`。
4. `on_canvas_drag` 兜底分支以 `prop_panel.current_type` 为准，不再看残留的 `selected_overlay`。
5. 画布点击命中也要走同一套互斥：在画布上点中视频就选中视频、清掉 overlay，反之亦然。
   整幅画布大小的透明图片层**不能**永远抢走点击——命中时看该像素是否不透明，透明处穿透到下面。

## 验收（修前必红，pytest-qt offscreen，参照 `tests/test_q33_timeline.py`）

- `test_q77_single_selection_video_text_image`：一条视频轨、一条文字轨、一条图片轨各一个对象，依次 `QTest.mouseClick` 视频→文字→图片，
  **每次点击后断言七套状态里只有一套非空**。修前点完文字 `selected_video_clip` 仍非空。
- `test_q77_reverse_order`：先文字后视频，断言 `selected_overlay is None`。
- `test_q77_panel_follows_last_click`：每次点击后属性面板的 `current_type` 等于刚点的对象类型。
- `test_q77_canvas_click_through_transparent_image`：画布上点在全屏透明图片的透明区域，选中的是下面的视频。
- golden 与 UI 基线必须不变。
