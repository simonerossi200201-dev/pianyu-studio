## 一、「调了没反应」的直接原因 —— 是交互陷阱，不是阴影算错

`raster.py` 里：
```python
if sh.distance_em <= 0 or sh.strength <= 0:
    return
```
而 `ShadowSpec.distance_em` **默认 0**（`spec.py:194`，`_parse_shadow` 里也是 `d.get("distance_em", 0)`）。

所以：**只要用户没先把「光源距离」拉起来，整段阴影的每一个旋钮都没有任何效果**——
包括光源大小、角度、衰减、颜色、强度。Luca 调的就是光源大小。

Q21 的任务书原文写过：「**新设计里不许再有「必须先拉某个参数，别的才生效」**」——
这条被违反了，只是把当年的 `sigma_em` 换成了今天的 `distance_em`。

`test_t21_shadow_size` 之所以是绿的，是因为它在测试里先把 `distance_em` 设成了非 0。
**测试测的对象和用户操作的对象不一样** —— 这是本仓库反复出现的那个模式。

**修法**：段头开关打开时给一组「立刻看得见」的默认值
（`distance_em` 0.18、`size_em` 0.10、`strength` 0.6），并且**取消 `distance_em <= 0` 的早退**——
距离为 0 就是贴在字底下的接触阴影，那是合法且常用的效果，不是"关闭"。
关闭只由段头开关负责。

## 二、物理上缺的东西（这才是「只做了外表」的实质）

现在的实现：把 mask 按距离平移出 3 份叠起来，**最后统一做一次 σ = size_px 的高斯模糊**。
代码注释自己承认了：「3 separate blurs blew the frame budget」——
也就是说，为了性能把物理的那一部分**砍掉了**，只留下一次均匀模糊。

缺的四条，按重要性排：

1. **没有接触硬化（contact hardening）**。这是真实软阴影最显著的视觉特征：
   紧贴物体的地方**锐利**，越远越虚。现在整片影子软硬一致，所以看起来像"贴了张模糊图"。
   Blender 里你调面光源半径，最直观的变化就是这个梯度。
2. **半影宽度不随距离变化**。物理上半影宽 `w ≈ R · s / (D − s)`
   （R 光源半径、s 遮挡物到接收面的距离、D 光源到遮挡物的距离）。
   现在只有 `size_em` 影响模糊，距离完全不参与 → 把影子拉远，软硬不变，物理上不可能。
3. **点光源根本没有半影堆叠**。`light == "point"` 那条分支只做了一次 `_radial_scale`，
   `n_layers` / `weights` 在这条路上压根没用上 → 点光只有"放射拉伸"这个外形，没有发散变虚。
4. **点光源没有强度衰减**。真实点光离得越近越亮、影子越浓越短；现在只改形状不改浓度。

## 三、要做的模型（不做光线追踪，做一个物理上说得通的近似）

把字形当作悬在背景上方的遮挡物，面光源半径 `size_em`、方向 `angle_deg`、距离 `distance_em`。

**核心改动：把"一次统一模糊"换成"沿影子长度递增的模糊"。**

```
N = 4（预览降级时 1）
对 i in 1..N:
    t   = i / N                      # 沿影子方向的归一化位置
    off = distance_px * t            # 该层的位移
    σ_i = penumbra(t)                # 关键：σ 随 t 增长 → 接触硬化
    layer_i = blur(shift(mask, off, angle), σ_i) * w_i
acc = Σ layer_i
```

其中半影宽度按物理式给：
```
σ(t) = size_px * t * (distance_em / (distance_em + K))      # K 取 0.5 左右，标定后写死
```
- `t → 0`（贴着字）σ → 0：**锐利**
- `t → 1`（影子梢）σ 最大：**虚**
- `distance_em` 增大 → 整体更虚（第 2 条修好）
- `size_em` 增大 → 整体更虚，且梯度更明显（Luca 要的那个手感）

**点光源**：每层除了位移还要按背离光源方向做放射缩放
`scale(t) = 1 + k·t/distance_em`，σ 增长更快，并乘一个强度衰减
`I(t) = 1 / (1 + (t·distance_em)²)` 的归一化形式。

**性能怎么办**（这是上次砍掉物理的原因，必须正面解决）：
- 越远的层越虚 → **在半分辨率甚至 1/4 分辨率上模糊再放大**，肉眼分辨不出，成本降到 1/4~1/16
- 层数 N=4 写死，不做成用户参数
- 整个影子层进现有的 ROI / 层缓存（和 glow 同一套键）
- `skip_blur`（预览降级）时退回单层
- **必须量**：开启投影前后的 ms/帧，进 `docs/plan/reports/Q41_投影性能.md`。
  涨幅 > 15% 就停下报 Claude，不许硬上。

## 四、门禁（每一条都针对上面某一条物理性质）

- `test_q41_knobs_live_from_default`：**段头开关一打开就用默认值渲染**，
  然后**只改 `size_em`**（不碰 distance）→ 像素必须变。这条直接锁住 Luca 报的现象。
- `test_q41_contact_hardening`：沿影子中轴取靠近字形的一段和梢部一段，
  各算边缘 alpha 的一阶差分最大值 → **近端必须明显大于远端（≥ 1.8 倍）**。
  这是"物理软阴影"的判据，光看整体模糊度看不出来。
- `test_q41_penumbra_scales_with_distance`：`size_em` 固定，`distance_em` 0.15 → 0.6，
  梢部的边缘梯度最大值下降 > 35%（越远越虚）。
- `test_q41_penumbra_scales_with_size`：`distance_em` 固定，`size_em` 0.05 → 0.4，同样下降 > 35%。
- `test_q41_point_diverges`：点光，影子外接框面积随 `1/distance_em` 增大；
  且**梢部宽度 > 根部宽度**（放射发散，不是整体平移）。
- `test_q41_point_intensity`：点光 `distance_em` 0.6 → 0.2，影子峰值 alpha 上升 > 20%。
- `test_q41_angle`：0° / 90° / 180° / 270°，影子质心分别落在四个方向（质心坐标断言）。
- `test_q41_toggle_off_is_noop`：段头关 → 与"从未设置过投影"逐字节相同。
- `test_q41_legacy_byte_identical`：只带旧键 `sigma_em/dx_em/dy_em` 的老工程**逐字节不变**
  （`_legacy` 那条路不许动）。
- **视觉证据**：渲一张 5×5 联系图（`size_em` 五档 × `distance_em` 五档），
