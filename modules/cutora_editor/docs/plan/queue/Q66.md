# Q66 · 段头开关存盘重开丢值 + 字幕背景段复用文本那套

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

## 1. 段头开关存盘重开会丢值

`SectionToggle` 关的时候把值**写成 0**，快照只在内存里（`section_toggle.py:133-135`）。
字幕侧更糟：每次 `load_data` 都会 `reset()`（`subtitle_style.py:1585-1616`）。
文本侧按 id 记在 `_ov_toggle_snaps`（`property.py:2151-2170`），重开也会丢。

用户看到的：描边调到 0.2 → 关掉 → 存盘 → 重开 → 再打开，**变成默认 0.08**。

**根治**：`SectionToggle` 改成 `enabled` 布尔语义——`stroke.enabled` / `glow.enabled` / `bg.enabled` / `shadow.enabled`（投影已经是这样了），
**渲染端读 `enabled`，不再用「值清零」表示关闭**。值本身永远保留在工程里。
老工程迁移：`width_em == 0` 的迁成 `enabled=False` 且 `width_em` 用默认值。

## 2. 字幕面板的背景段没动

Q52 只拆了文本侧。字幕侧仍是 `mount_bg_glass`：「启用渐变」死勾选还在（`fx_fields.py:312`）；
玻璃 6 项用 `setEnabled` 常驻灰显（`fx_fields.py:398-421`），不是隐藏；
**`bg.type` 仍由 4 个控件同时写**：`sub_box`、`fx_bg_type`、`fx_bg_glass_toggle`、`sub_texture_en`。

**做法**：字幕面板复用 `mount_overlay_bg` + `_sync_overlay_bg`，删掉 `mount_bg_glass` 和 `fx_bg_glass_toggle`。

## 3. 两边标签词汇分叉

同一个 fx 键在两个面板叫法不同：文本侧用新名字（描边拐角 / 发光柔度 / 背景框上渐隐），
字幕表还是旧名（接头样式 / 发光 σ (em) / 衰减 / 强度 / 上渐隐，`subtitle_layout.py:60-89`）。
**做法**：标签只留一个来源（fx_fields 里定义，两边都从那取）。

## 4. 文本侧的段开关不灰显内容

描边、背景、发光、投影传的是 `toggle_widget` 没有 `gray_content`（`property.py:617-637`），关掉以后旋钮仍亮着。
加 `gray_content=True`。

## 5. 文本面板里有无效提示

「自动着色」段里挂着「打开『跟随单词』并勾选『换字色』后…」（`fx_fields.py:797-801`），但文本层没有跟随单词。
`mount_emphasis_section` 加 `for_subtitle` 参数。

## 验收

- **`test_q66_toggle_value_survives_save_reopen`**：描边设 0.2 → 关 → **真实存盘 → 真实重开** → 开，断言仍是 0.2。现在必红。
- `test_q66_single_bg_type_writer`：AST 扫字幕面板，写 `bg.type` 的控件只有一个。
- `test_q66_same_label_both_panels`：同一个 fx 路径在两个面板上的标签文字相同。
- golden 必须不变（`enabled` 迁移要保证老工程逐字节不变——这是这条任务最容易出事的地方，重点测）。
