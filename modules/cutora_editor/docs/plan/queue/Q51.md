# Q51 · 高亮色：接错了对象、被覆盖、渐变根本没实现（用户第二次报同一个问题）

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

## 用户原话

> 字幕样式里面的**高亮色**还是不起作用，这个高亮色原本是**突出当前正在读的这个单词**的颜色的，
> 而且**还可以设置渐变色**，但是现在就不起作用了。

「**还是**」——Q19 声称修好过一次。Q19.ok 里每一句陈述都是真的，
但它证明的是「面板 → `fx.emphasis.color` → 渲染器能读到」，
**没有证明用户在 UI 上的实际操作序列（开「跟随单词」）会经过那条读它的代码**。

## 三个病灶叠在一起

### 病灶一：接错了对象

面板上标着「高亮色」的控件是 `fx_emphasis_color`（`dock_panels.py:362`，
它自己的原生标签其实叫「强调色」，`fx_fields.py:628`），写 `fx.emphasis.color`
—— 这是**关键词强调**，靠 `emphasis.words` 列表或 `auto` 检测挑词。

而用户开的是「跟随单词」`sub_dyn` → `fx.follow_word`。
`spec.py:913-914`：`follow_word` 只往 `anim.loop` 追加 `"box_highlight"` 一个 id。
给当前词**字形**上色的 `word_fx.py:183-213 apply_word_color()`，第 188 行：

```python
aid = next((i for i in ids if i in WORD_COLOR and i != "box_highlight"), "")
```

`box_highlight` 被 `and i != "box_highlight"` **显式排除**，`:190-191` `if not aid: return img`。
**开「跟随单词」时，当前词的字形颜色一个像素都不会变。**

（已在你的机器上实跑 `from_style()` 验证：`follow_word=True, emph=#FF0000`
→ `anim.loop='box_highlight'`，`bh.color=''`。）

### 病灶二：唯一还能生效的那条路被硬编码覆盖

词底方块本来会回退到 `emphasis.color`（`word_fx.py:251`），但紧接着 `:256-258`：

```python
bh = getattr(spec, "box_highlight", None)
if bh is not None and getattr(bh, "color", ""):
    color = str(bh.color)          # ← 永远命中
```

而 `subtitle_style.py:2618-2636` 只要 `follow_word` 为真就无条件重建 `fx["box_highlight"]`，
其中 `:2627`：`"color": prev_bh.get("color") or "#22D3EE"` —— **`bh.color` 永远非空**。
所以 `word_fx.py:251` 的 `emphasis.color` 在「跟随单词」场景下是 100% 死代码。

### 病灶三：默认值把第三条路也关死

`EmphasisSpec.words` 和 `.auto` 默认都是空列表（`spec.py:270-271`），
而所有 emphasis 的门都要求二者之一非空（`anim.py:457,703,712`、`pipeline.py:159,189`、`layout.py:516`）。
段头开关的 `default_on` 是 `{"auto": ["numbers"]}`（`subtitle_style.py:383-387`）
—— **就算用户打开「自动着色」，也只有数字会变色**，普通单词还是不变。
这是 Q41 阴影 `distance_em=0` 那个坑的复刻。

### 渐变：不是接线问题，是三层都没有

- `EmphasisSpec`（`spec.py:269-277`）只有 `color: str`，没有 `type`/`colors`/`angle`
  （对比 `FillSpec` `spec.py:176-181` 是有的）。
- 字形 tint：`word_fx.py:157,178` 是 `rgb_tuple` + numpy 混合，**没有 QGradient**。
- 词底方块：`word_fx.py:295-310` 全是 `_qcolor(color, alpha)`，纯色 QColor。
- 关键词强调词：`raster.py:1108-1112` 的 `run.fill_override` 分支**无条件当纯色画掉**，
  直接绕开了 `paint_fill.py:59-74 fill_brush()` 里现成的渐变实现
  （`raster.py:1131,1139` 调用时 `solid=None`，那个形参全仓从没被真正用过）。

## 要做的

### A. 让「跟随单词」真的给当前词字形上色

1. `word_fx.py:188` 的 `and i != "box_highlight"` 是核心开关。
   要么让 `follow_word` 同时追加一个字形着色 id，要么在这里为 `box_highlight`
   补一个 `tint_run_solid` 分支。
2. **先排掉一个雷**：`anim.py:419-427 _anim_ids()` 在收集到第 2 个 id 时就 `break`。
   实测 `_anim_ids('highlight+box_highlight+line_bar')` → `['highlight','box_highlight']`
   —— 同时开「跟随单词」+「跟随句子」时，**底条会被静默丢弃**。
   任何往 `anim.loop` 加 id 的改法都会踩到它，**先把这个上限放宽并补测试**。
3. UI 上要能区分「当前词换字色」和「当前词加底块」，现在 `sub_dyn` 一个开关只表达后者。

### B. 不许再覆盖用户设的颜色

4. `subtitle_style.py:2627`：不要无条件写 `color` 键。
   只在用户点过「弹力色」时才写，让 `word_fx.py:251` 的 `emphasis.color` 回退重新可达。
5. `word_fx.py:256-258`：明确优先级 —— `bh.color` 只在它是**用户显式设过**的值时
   才压过 `spec.emphasis.color`。

### C. 渐变（用户明确要求）

6. `EmphasisSpec` 加 `type` / `colors` / `angle`，照 `FillSpec` 的形状，`_parse_emphasis` 里解析。
7. `fx_fields.py:628` 的 `add_color` 换成色标列表 + 类型/角度（复用 `mount_fill_section` 的互斥显示）。
8. `raster.py:1107-1112`：`fill_override` 是渐变时改调 `paint_fill.ramp_brush()`，不要当纯色画。
9. `word_fx.py:162-181 tint_run_solid()` 要有渐变版本
   （可参考 `word_fx.py:92 tint_run_palette()` 的多段插值，推广成带 angle 的 stops）。
10. `word_fx.py:293-311 draw_box_highlight()` 的四处 `_qcolor` 换成 `QBrush(QLinearGradient)`。

### D. 界面语义

11. 「高亮色/高亮调色板/高亮缩放」（`dock_panels.py:362-364`）和决定它们生不生效的开关
    （`fx_emphasis_auto`/`words`，现在在第 9 段「自动着色」）**被拆在两个不同的段**，
    而且那段默认折叠默认关闭。放同一段，或者加一条明确提示。
12. 「高亮色」这个标签是 Q19 贴上去的（原生叫「强调色」）。
    **决定一个词管一件事**：要么这个控件改回「强调色」、另给当前词一个真正的「高亮色」，
    要么让它真的管当前词。不要再出现两个东西叫同一个名字。

## 验收（三条，修好前都必须是红的）

- **`test_q51_follow_word_tint_follows_emphasis_color`**（核心，直击用户场景）：
  `follow_word=True`，`emphasis.words`/`auto` **保持默认空，不作弊**，
  `bg.type=none`，`anim.loop=none`。在当前词正在被读的时刻取该 run 的 ROI，
  用 `#FF0000` 和 `#00FF00` 各渲一帧，断言当前词 ROI 的 R/G 通道差 > 40，
  **同时断言上一个词的 ROI 两帧间差 < 5**（只动当前词，不是整句染色）。
  现在必红：`word_fx.py:190` 直接 `return img`，两帧完全相同。
- **`test_q51_panel_collect_does_not_clobber`**：**必须经过真实面板 collect**，
  不许手写 style dict —— 这正是 Q19 漏掉的环节。开 `sub_dyn`、拧高亮色为 `#FF00FF`、
  `on_change()`、渲染，断言画面里有 `#FF00FF`；并加白盒断言
  `bh.get("color","").upper() != "#22D3EE"`。
  现在必红：`subtitle_style.py:2627` 无条件写 `#22D3EE`。
- **`test_q51_emphasis_gradient`**：`emphasis` 设成 gradient 红→蓝，
  对**当前词的 ROI** 断言左半 R>B、右半 B>R。现在必红：连字段都没有。
