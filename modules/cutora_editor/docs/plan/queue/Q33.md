## 要做

### 1. 词级时间轴微调（这条对 Luca 的内容最值钱，放第一）
ASR 对齐总有偏差，祷告内容的节奏又特别依赖断点。
- 字幕 clip 展开后显示**逐词的小块**，可以拖词边界（左右边界各自独立）。
- 拖动时相邻词的边界跟着让位，不许出现重叠或负时长。
- 吸附：拖到别的词边界 / 播放头 / 静音段边界时吸附（阈值按像素算，不按秒）。
- 一个词改完，**其余词的时间一个都不许变**（这是回归测试的核心断言）。
- 走命令总线，可撤销。

### 2. 时间线本体
- 轨道高度可拖、可记忆；双击轨道头在「紧凑 / 标准 / 高」三档间切换。
- 缩放：Ctrl+滚轮以**播放头**为锚点（不是以鼠标，也不是以左边缘）；
  `Shift+Z` 缩放到选区，`Z` 全览。
- 吸附总开关 + 吸附到：clip 边界 / 播放头 / 标记 / 静音段边界。
- 多选框选、按住 Alt 拖动复制、`,` / `.` 微移一帧。
- 波形显示：有缓存就画（`audio/waveform.py` 已经有 `get_waveform_cache`），没缓存时**显示"生成中"而不是空白**。

### 3. 标记（Marker）
时间线上打彩色标记 + 备注，`M` 添加，`Shift+↑/↓` 跳转。导出时可选把标记写进章节元数据。

### 4. 性能红线
时间线重绘不许拖慢预览：27 条 clip 的拼接时间线，**拖动播放头时预览帧率下降 < 5%**（用 Q28 的帧率读数量）。
