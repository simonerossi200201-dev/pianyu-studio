# Q63 · 轨道高度存盘重开就丢（测试测错了序列化器）

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

小任务，但属于用户会直接骂的那种：调好的轨道高度，存盘重开就没了。

## 事实

Q33 只改了 `project_io._rj_*`——那是**导出子进程用的渲染任务序列化**（`serialize_render_task`，`project_io.py:536`）。
用户存盘走的是另一条：`command_bodies.py:143` → `collect_project_data` → `main_window.py:5918 _serialize_track`，
**这里没有 `height`**；打开工程时的 `_known_track_keys`（约 `main_window.py:6052`）也不读它。

`test_q33_track_height_persist` 测的就是 `serialize_render_task`——**测错了对象**，所以绿着。

另外：`widget.py:747 set_track_height` 不走命令总线，不能撤销、不标脏；拖动时不刷新纵向滚动范围。

## 要做的

1. `_serialize_track` 写 `height`；加载时读 `height` 并加进 `_known_track_keys`。
2. 高度改变走命令总线（一次拖动一条撤销），标脏。
3. 拖动时调 `update_scroll_range`。
4. 顺手：「所有轨道一起调高度」（Shift+拖动 或 右键菜单）——Resolve 有这个，很常用。
