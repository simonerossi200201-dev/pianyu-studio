## 现象
「描边无法启用，所有描边的参数都无效。」

## 根因（`dock_panels.py:291-304`）
```python
sec = CollapsibleSection("描边", toggle_checkbox=panel.sub_strk, ...)
f.addRow("粗细:", panel.sub_stroke)                       # → border_width    (v1，死)
f.addRow(panel.sub_c_out)                                 # → color_outline   (v1，死)
f.addRow("描边透明度:", _spin_host(panel.sub_out_op, …))   # → opacity_outline (v1，死)
_fx(f, "fx_stroke_width_em", "描边宽度 (em):")             # → fx.stroke.width_em (活)
_fx(f, "fx_stroke_color", "描边色:")                       # → fx.stroke.color    (活)
_fx(f, "fx_stroke_join", "描边接头:")                      # → fx.stroke.join     (活)
```
一个段里**六个控件，三死三活，而且两两重名**（「粗细」和「描边宽度」都是描边宽度）。
Luca 转的是上面三个，所以「全都没用」。
段头开关绑的 `panel.sub_strk` 写 `use_stroke` —— 同样 0 引用，**开关本身也是死的**。
`raster.py:190 / 861` 只看 `spec.stroke.width_em > 0`。

## 要做
1. 删掉 `sub_stroke` / `sub_c_out` / `sub_out_op` 三个控件本身（连同它们的 spin 伴侣）；
   `border_width` / `color_outline` / `opacity_outline` 进 `DEPRECATED_UNPAINTED_KEYS`。
2. 段头开关改成**真开关**：语义 = `fx.stroke.width_em > 0`。
   关 → 记住当前 width_em 后写 0；开 → 恢复上次值（没有就 0.08）。
   和「背景色块」段头（BUG-21 的修法）**共用一个 helper**，别各写各的（T24 会把这个 helper 抽出来，
   你先按 T24 定义的 `SectionToggle` 签名写，两个任务对齐）。
3. 描边透明度：`StrokeSpec` 没有 alpha 字段，但 `parse_color` 已支持 8 位 hex。
   **不要新增 alpha 字段** —— 改成描边色控件支持 alpha（色板带不透明度滑条，写 8 位十六进制），
   `raster.py:863` 的 `_qcolor(spec.stroke.color, 1.0)` 改成读 8 位里的 alpha。
4. 标签定名：「描边宽度」「描边颜色」「接头样式」。不许再出现两个「粗细」。
