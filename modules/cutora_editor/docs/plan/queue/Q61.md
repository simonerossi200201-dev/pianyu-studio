# Q61 · 资产库：放到时间线上根本看不见

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

## Luca 的原话

> 资产库里应该让用户可以把自己本地资产加载进来，而且**可以直接挪用到时间线上使用到画面上**，
> 而且必须要完美的支持带有透明格式的 Gif 文件和带有透明格式的达芬奇软件导出的 mov 格式的大文件。

Q49 把 alpha 解码做对了（ProRes 4444 探测到 `yuva*` 就绕开 OpenCV，交给 ffmpeg 管道 `-pix_fmt bgra`
逐帧读，是流式的）。**但用户根本走不到那一步。**

## 1. 双击元素/边框/贴纸/字幕条，画面上什么都不出

`assets/user.py:207` 把这几类放进 `Track("image").clips`，而渲染端只画 `image_overlays` 字典
（`render/frame_renderer.py:570-590`），**从不读 image 轨的 clips**。时间线上也看不到。

**做法**：图片类走现有的 `_drop_image_file` 路径，生成真正的 image_overlay。

## 2. 双击视频/动图，透明素材被主视频盖住

`user.py:209` 取第一条 video 轨——也就是**主视频轨**——`:221` 直接 append 进去。
预览和导出都按 `start_t` 降序画（`ui/canvas.py:1041`、`render_worker.py:2073`，注释写着「后出现的先画」），
于是播放头大于 0 时，后放上去的叠层先画、主视频后画盖在上面。**只有放在 0 秒时恰好在上层。**

**做法**：视频/动图新建或复用一条**非主** video 叠加轨放在主轨之上。
同轨绘制顺序改成按轨道层级，不按 start_t。

## 3. 面板上没有导入按钮

只能双击空面板（`asset_library.py:145`，而且**只在列表为空时生效**）或者拖文件进来。
空状态文案「此分类还没有资产。」（`:91`）不告诉用户怎么导入。

**做法**：
- 面板顶部加「导入」按钮（文件对话框，多选，按扩展名自动归类）。
- 空状态照 `transcript.py:556-580` 那套（本仓库现成的优秀样板）：图标 + 一句引导 + 一个「导入素材」主按钮。
- 视频/音频资产的缩略图：现在 `QPixmap(path)` 读 .mov 得到空图（`:208`）。改成异步取首帧。
- 动图悬停时播放，不悬停时静止（不要一直占 CPU）。
- 切换分类、每敲一个搜索字时，不要同步重建全部缩略图——做缓存。

## 4. 导入不许冻界面

`user.py:114` 同步 `shutil.copy2`，由 `asset_library.py:158-162` 在 UI 线程调用。
几 GB 的 ProRes 要拷一整份进 UserData，**全程冻住，没有进度**。

**做法**：导入挪到后台线程，显示进度。**大视频（>200MB）默认建引用不拷贝**，
在资产卡片上标一个小图标表示「引用外部文件」；源文件找不到时卡片标红而不是崩。

## 验收（每条都要先改坏确认会红）

- **`test_q61_asset_visible_on_screen`**（核心）：资产库里一张带透明的 PNG，调 `place_on_timeline`，
  走 **ExportRenderer 整帧导出**（不是手填画布），断言图片出现在画面上。现在必红。
- **`test_q61_overlay_above_main_video_at_t1`**：透明 ProRes 放在 **t=1s**（不是 0），下面垫主视频，
  整帧导出，断言透明区域显示的是主视频内容、不透明区域显示的是叠层。现在必红。
- `test_q61_import_button_exists_and_works`：点导入 → 选文件 → 资产出现在列表里。
- `test_q61_import_does_not_block_ui`：导入一个 500MB 文件时，主线程单次阻塞 < 200ms。
- `test_q61_video_thumbnail_not_empty`
- golden 必须不变。
