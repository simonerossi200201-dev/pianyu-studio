## 概念（按 Luca 原话定死，十一报第 5 节）
- **分屏是工程级的，只有一份**：`task["split"]`。任何轨道开启分屏 = 工程开启，
  其他视频轨自动进入分屏模式，只能选「填到哪个格子」。
- **两个独立的东西**：① 分界线的位置/旋转/羽化/描边 —— **全局统一**；
  ② 每个轨道在自己格子里的内容位置/缩放（T33 的轨道变换）—— **各自独立**。
  分上屏后想把人往上挪，动的是②不是①。

## 数据
```
task["split"] = {
  "enabled": true,
  "layout": "top_bottom|left_right|grid_2x2|grid_3x3|left1_right2|top1_bottom2|custom",
  "cells":    [{"id":"A","rect":[0,0,1,0.5]}, {"id":"B","rect":[0,0.5,1,0.5]}],
  "dividers": [{"id":"d1","axis":"h","pos":0.5,"rotation_deg":0.0,"feather_px":24}],
  "border":   {"style":"none|solid|gradient|glass|shadow","width_px":6,"color":"#F2C14E",
               "color2":"#FFFFFF","curve":"straight|wave|arc","shadow_px":12,"glass_sigma":8}
}
track.split_cell = "A" | "B" | None      # None = 不参与，全屏叠最上（比如 logo）
```
`layout` 是预设：选一个 → 生成 cells + dividers；`custom` 允许画面上拖。
改 `dividers[].pos` → 相邻 cells 的 rect 联动重算（`split_layout.recompute(split)`，**纯函数，有单测**）。

## 渲染（`render/split_screen.py`，preview / export 同一函数）
1. 每个参与轨：以格子矩形为「画布」做 fill 适配 → 应用轨道变换 → 用格子 **mask**（羽化 = 高斯边缘 alpha）裁切 → 叠到画布
2. 叠完后画分界线描边：`solid` 直/曲线路径描边；`gradient` 沿线渐变；
   `glass` 取分界带下的画面高斯模糊 + 高光边（复用 `glass_thick` 采样）；`shadow` 两侧投影。
   `curve=wave/arc` 用**同一条路径**同时做 mask 边和描边，保证严丝合缝。
3. **缓存**：mask 与描边路径按 `(cells, dividers, border, canvas)` 哈希缓存，参数不变每帧零重算；
   羽化 mask 是一张 QImage alpha，逐帧只 `drawImage` 带 mask —— **每帧开销 < 1ms**。

## UI
轨道属性页「分屏」段：开关 → 布局选择器（缩略图网格）→ 本轨格子（只列未占用的，已占用灰掉并写占用它的轨名）
→ 分界线组（位置/旋转/羽化）→ 描边组（样式/宽度/颜色/曲线/阴影）。分界线和描边标「全局」。
画面上：分屏开启时画分界线把手（圆点+线），拖=改 pos，`Alt+拖`=旋转，双击回中，羽化在把手旁滚轮。
时间线：参与分屏的轨头带格子编号徽标（A/B/…）。

## 门禁
- 纯函数：每个预设 cells 面积和=1 且互不重叠；拖 `d1.pos` 0.5→0.6 后 A 高 0.6 / B 高 0.4；
  rotation 30° 时 mask 边与描边路径重合（采样 20 点距离 < 1px）
- 渲染：上下分屏 + feather 24 → 分界带 alpha 从 1 到 0 **单调**；glass 描边带内像素方差 > 0；
  导出帧 == 预览帧 MAD ≤ 0.015
- 性能：分屏开 vs 关，T023 导出墙钟差 **< 5%**
