# Q84 · 「重置本段」和每行「↺」必须真的恢复默认值（所有属性页）

**开工前先读 `_RULES_FOR_EVERY_TASK.md`、`_RULES_UI_OWNERSHIP.md`、`docs/plan/UI_INSPECTOR_SPEC.md`。每做完一个子项就提交。**

## 用户原话（2026-09-22）

> 每个参数都有「重置本段」的功能，但是绝大多数的重置都不能恢复默认参数，这个按钮的信号我希望能保证起作用，
> 用户点一下就可以直接恢复原样默认参数。

## 根因（Claude 已查明）

`collapsible.py:_reset_section` 对段里每个 `InspectorRow` 调 `trigger_reset()`；而 `InspectorRow.trigger_reset`
只在构造时传了 `on_reset` 才有动作，否则只打一行 warning。属性面板（文本层 / 图片层 / 视频 clip / 转场 / 轨道 / 调色）
绝大多数行是 `form.addRow(label, widget)`，**没传 `on_reset`**——所以段重置几乎全是空操作。
字幕样式面板走 `build_inspector` + `_row_reset`，那边基本是好的（Q60 测过），别动坏它。

## 做法

1. **默认值只有一个来源**：为每类对象写一个「出厂默认」函数（放在 model / render 层，不在 UI）：
   - 文本覆层 / 图片覆层：新建覆层时用的那份默认字典（`add_text_ov` / `add_img_ov` / `build_image_overlay` 现在各写了一份——合成一个 `overlay_defaults(kind)`，三处都改用它）。
   - 视频 clip：`Clip()` / `MediaSource` 的构造默认 + 调色 `identity_grade()`。
   - 转场：`TransitionItem` 构造默认 + 预设自带参数。
   - 轨道：`Track()` 构造默认 + 分屏 `split_layout` 默认。
   **变换里的位置 / 尺寸**不是常量：图片覆层的默认尺寸 = 素材原始尺寸按「适配画布」算出来的那个，位置 = 居中。写清楚并测。
2. **行重置**：给属性面板每一行都接上 `on_reset`：从上面的默认函数取该字段的值 → 写回控件 → 走和用户手改**完全相同**的保存路径
   （`on_change_ov` / `on_change_video` / `on_change_transition` / `_commit_track_props` / grade 的 `changed`），一次撤销能回来。
   通用做法可以在 `InspectForm.addRow` 增加 `reset_key=` 参数，由面板统一解析；不许每行手抄一个 lambda 抄错。
3. **段重置** = 该段每一行的行重置，**合成一条撤销**（不是 N 条）。段的开关（描边 / 背景 / 发光…）也回到默认。
4. 有关键帧的参数：重置 = 清掉该路径的关键帧并回到默认静态值（与「秒表关掉」同语义），撤销能回来。
5. 没有合理默认值的行（例如「内容」文本、字体名以外的纯数据）**不显示 ↺**，而不是显示一个点了没反应的 ↺。
6. **不改布局 / 尺寸 / QSS**（`_RULES_UI_OWNERSHIP.md`）。

## 验收（修前必红）

- `test_q84_every_visible_reset_restores`：对 PropertyPanel 的每个页面（文本层、图片层、视频 clip、转场、轨道）
  加载一份所有值都改过的数据，展开所有段；对每个可见且可用的 ↺：记下默认值 → 点 → 控件值 == 默认值 **且数据对象里的值也 == 默认值**。
  一个不达标就列出（页面、段、行标签、期望、实际）。
- `test_q84_section_reset_restores_all_rows`：每个段的「重置本段」点一次，段内全部行回到默认；撤销一次全部回来。
- `test_q84_no_dead_reset`：点任何 ↺ 都不产生 `inspector reset with no handler` 日志。
- 字幕样式面板的 `test_q60_*` 不回退。
