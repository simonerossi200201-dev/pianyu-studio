## 现象
「参数的框拉得特别长整个铺满，太难看。弹力色、弹力条色横着拉得很长，还看不出来是什么颜色。
希望参考专业软件的布局设计：有立体感，有留白。所有的分页所有的属性参数都要重新设计。」

参考是 DaVinci Resolve 的检查器（Inspector）。值得照抄的六点：

1. **两列对齐**：左边右对齐的标签列（固定宽度，约 30–35%），右边控件列。标签不和控件混在一行里。
2. **滑条 + 数值框成对**：滑条占中间，右边跟一个**固定宽度**（约 64px）的数值框，右对齐，**不拉伸**。
3. **控件不铺满**：颜色按钮、下拉框都有**最大宽度**，右侧留白。
4. **每段一个标题条**：左侧开关圆点，右侧「重置」小图标，段间有分隔线。
5. **每一行右侧一个小「↺」**：点了把这一个参数恢复默认。这是 Resolve 最好用的细节之一。
6. **层次靠间距不靠线框**：组内行距紧（4–6px），组间距松（14–18px）。

## 要做

### 1. 先写规范，再改代码
产出 `docs/plan/UI_INSPECTOR_SPEC.md`，把上面六条落成**具体数字**（列宽、控件最大宽、行距、段距、字号、色 token）。
所有数字必须来自 `cutora/ui/theme/tokens.py` 里已有的 token，不够就加 token，**不许在代码里写死像素值**。

### 2. 做一套检查器控件 `cutora/ui/widgets/inspector.py`
- `InspectorRow(label, widget, on_reset=None)` —— 两列布局 + 右侧重置按钮
- `SliderSpin(lo, hi, step, decimals)` —— 滑条 + 固定宽数值框，一个控件一个值
- `ColorSwatch(color)` —— **正方形色块按钮（28×28），块里就是那个颜色**，旁边小字显示 hex；
  带 alpha 时用棋盘格底。这直接解决「看不出来是什么颜色」。
- `ColorStops(nmin, nmax)` —— 渐变色标：一排小色块 + 加减按钮，块之间显示渐变预览条
- `SectionHeader(title, toggle=None, on_reset=None)`
- `EnumCombo` —— 最大宽度受限的下拉

### 3. 全面换过去
`dock_panels.py` 里所有 `f.addRow(...)` 换成 `InspectorRow`；
`fx_fields.py` 里 `add_float / add_int / add_color / add_colors / add_enum / add_bool / add_pair`
的**内部实现**换成这套控件，**外部签名不变**（这样 T19–T24 不受影响）。
文本面板（T27）和属性面板一并换。

### 4. 顺序
本任务**放在 T19–T24 之后**。先把信号接对，再改外观 —— 反过来做，一旦出回归就分不清是接线错还是布局错。
