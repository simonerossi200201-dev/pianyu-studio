## 要做（十一报第 4 节）
**模型**：`Track.props = {x, y, scale, rotation, flip_x, flip_y, opacity, blend_mode}`，默认恒等；
`Track.pinned: bool`（会话状态，**不存工程**，同 solo）。

**合成顺序**：clip 自身变换 → 轨道变换（父级），preview / export 走**同一个**
`compose_track_transform(clip_rect, track.props, canvas)`。
轨道 `opacity` 作用于**整轨合成后的图层**（不是逐 clip），blend 同理 ——
所以轨道有非恒等属性时，该轨要先合成到离屏层再叠。

**UI**：轨头名字变成按钮（悬停亮、按下沉、主题金描边）；点击 → 右栏「属性」页切到**轨道模式**：
名字（可改）、变换组、不透明、混合模式、图钉。
图钉：钉住的轨在轨头显示 📌，属性页顶部显示「正在编辑 N 条轨道」，
改一个字段 → **一条命令写 N 条**（`track.set_props {track_ids, patch}`，undo 一次回滚）。
