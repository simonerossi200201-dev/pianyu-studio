（`bg.size_mode` / `bg.width_px` / `bg.height_px` / `bg.offset_x` / `bg.offset_y` 是 Q93 加的，
这条在它上面接着做）。**

Luca 的原话：「字幕样式里的背景色块，它的内边距，根本没有用处，给它去掉。然后换成高度和宽度吧，
现在我都改不了它的背景色块的高度和宽度的。想让它窄一点都做不到。」
「再给背景色块添加一种功能，就是根据文字外框范围来绘制背景的范围，
这样就不仅仅是呆板的矩形，而是包裹着文字的形状，并且也同样支持圆角。」

宽高那一半 Q93 已经做了。这条做剩下两件。

## 1. 内边距（`bg.pad_em`）

**不许直接删这个字段**，它是「贴合文字」模式下唯一决定盒子大小的东西，
删了所有老工程的背景尺寸都会变，`test_q93_bg_fit_text_matches_old_bytes` 的 md5 也会红。

要做的是让它不再碍事：

- `尺寸 = 固定` 时，「内边距」这一行**隐藏**（那时候它对矩形盒子没有任何作用，
  留着就是 Luca 说的「根本没有用处」）。用现有的行显隐机制，不要新造。
- `尺寸 = 贴合文字` 时照旧显示，行为一个字节都不许变。
- 面板里把它排到宽 / 高 / 偏移**后面**，让先看到的是宽高。

## 2. 新增「轮廓包裹」

`bg.size_mode` 加第三个取值 `hug_glyphs`（中文「轮廓包裹」），
和 `fit_text` / `fixed` 并列。**不要新造一个 `bg.type`** —— 它决定的是背景的**形状范围**，
不是画法，所以应该和色块 / 毛玻璃 / 纹理 / 渐变任意组合。

### 画法

在现有的背景绘制之前，先算一张 mask，然后拿它当背景的裁剪蒙版：

1. 取这一段**字形本身的 alpha**（描边算进去，发光不算 —— 发光会把包裹撑得没边）。
2. 按 `bg.hug_pad_em`（新字段，em，默认 0.18，范围 0–1）向外膨胀。
   用 `cv2.distanceTransform` 取「到字形的距离 ≤ r」，不要用方形 kernel 的 `dilate`：
   距离场天然给出**圆的凸角**，这本身就是一半的圆角。
3. 按 `bg.radius_em`（沿用现有那个圆角字段，不要新加）做一次形态学**闭运算**，
   半径 = `radius_em * em`。这一步把字与字之间的**凹角**也抹圆，
   让相邻的字连成一整块包裹形，而不是一串各自为政的圆胶囊。
   `radius_em = 0` 时跳过闭运算（保持纯膨胀的形状）。
4. 结果做一次轻微的羽化（1px 高斯）再当 alpha 用，免得边缘出锯齿。

性能：这张 mask 只跟「文本 + 字号 + 字体 + hug_pad_em + radius_em」有关，
和时间无关，**必须进现有的 raster 缓存**，不许每帧重算。
`cutora/render/textfx/raster.py` 里已经有按 layout 指纹缓存的机制，挂上去。

### 面板

- 「尺寸」下拉多一项「轮廓包裹」。
- `hug_glyphs` 时显示「包裹厚度」（`bg.hug_pad_em`）和现有的「圆角」；
  隐藏宽 / 高 / 内边距（偏移仍然有效，保留）。

### 兼容

- 老工程没有 `hug_pad_em` → 默认 0.18；`size_mode` 没有 → `fit_text`，和现在完全一样。
- `fit_text` / `fixed` 两条路径**一个像素都不许变**。
  `test_q93_bg_fit_text_matches_old_bytes` 的 md5 必须还是 `8a063bb50cd86a78515f330072ee72a3`。

## 测试 `tests/test_q97_bg_hug.py`

至少这几条，每条都要能说明「改之前是红的」：

1. `fit_text` / `fixed` 两条路径的帧字节和 Q93 之后完全一致（沿用 Q93 的 md5）。
2. `hug_glyphs` + 色块：背景 alpha 在字形外 `hug_pad_em * em` 处仍然是实的，
   在 2 倍那个距离处是 0 —— 即它真的贴着字，而不是又变回矩形。
   顺便断言它**不是**矩形：取包围盒四个角的像素，应该是透明的。
3. `radius_em` 从 0 调到 0.5，两个相邻字之间的凹口被填上（那一带的 alpha 覆盖率变高）。
4. `hug_glyphs` + 毛玻璃 / 渐变各一条：形状一致，只是填充不同。
5. 预览和导出同一帧 MAD = 0（毛玻璃那条按 Q93 的先例，比字形中心不比整帧）。
6. 面板：切到「轮廓包裹」时宽/高/内边距隐藏、包裹厚度和圆角显示；
   `_sanitize_overlays` + json 往返后重开面板值还在。
