2. **CUTORA 的交互设计**（给出线框图 ASCII 或 SVG）：
   - 时间线底部「时间线 / 关键帧」切换（或 clip 展开成参数行）；多素材同时显示、独显一个素材；
   - 框选、Shift 多选、拖动整体平移、Alt 拖复制、按比例拉伸一组关键帧；复制粘贴到别的素材（按参数路径对齐）；

   - 零成本上手：第一次使用的引导、默认缓动、撤销粒度。
3. **信号 / 命令清单**：每个操作对应哪条 command bus 命令、撤销粒度、属性面板 / 画布 / 时间线三方如何同步刷新；列出所有可动画参数路径（视频 / 文本 / 图片 / 贴纸 / 字幕样式 / 调色 / 转场）。
