## 二、`dirname = id` 改名
媒体目录用 id 当文件夹名，人看不懂，出问题时没法凭目录名定位。
改成 `<可读名>_<id前8位>`，并且：
- 迁移老工程时**不重命名磁盘目录**（那会打断正在引用它的工程），只在新建时用新规则

## 三、「第三方产品名」测试
软件里不许出现别家产品名（达芬奇、Premiere、CapCut 等）作为功能名或界面文案 —— 品牌合规。
加 `test_q39_no_third_party_names`：扫 `cutora/` 下所有 `.py` 的**用户可见字符串**

**注释和文档里出现是允许的**（我们经常拿它们当参照物），只查会显示给用户的那些。
