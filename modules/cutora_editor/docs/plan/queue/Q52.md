# Q52 · 文本属性面板：Q44 之后变成一团糟，重做

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

## 用户原话

> 现在**文本的属性变得一团糟**，你仔细检查，把文本的属性界面和功能要做得**足够强大**，
> 而且还要**好看好用**。现在界面上**很多奇怪的无用的参数**，**有的属性还看不到**，
> 还有的**界面文字被裁切了一半**。

这是 Q44（`2dce7b2`）的回归。Q44 把字幕面板的全量效果器整段搬进文本面板，
**没有做任何裁剪**：背景段一个段就从 8 行涨到 32 行，整个面板 9 段约 75 行控件。

## 四个结构性问题

### 1. 同一个 fx 键挂了两三个控件，互相打架

- `bg.type`：段头开关 `ov_bg_enable`（`property.py:624`）+ 段内「背景类型」下拉
  （`fx_fields.py:277`）+「背景模糊（毛玻璃）」勾选框（`fx_fields.py:281-285`），三个写同一个值。
- `stroke.width_em`：段头开关 `ov_strk` + 段内「描边宽度」滑条（`fx_fields.py:414-416`）。
- `glow.sigma_em`：段头开关 `ov_glow_enable` +「发光 σ (em)」（`fx_fields.py:422-423`）。

**关掉开关会把滑条值清零，再打开只能恢复到 `SectionToggle` 的 `default_on`，用户调好的值丢了。**

### 2. 一碰面板，这条文本的动画和转场就全废了

`frame_renderer.py:1119-1124`：

```python
if ov.get('type') == 'text' and (ov.get('fx') or ov.get('runs')):
    return paint_text_overlay(...)     # ← early return
```

它跳过了下面 `1125-1215` 的转场（`compute_transition_params`）和入场/出场动画整块逻辑。
而 `property.py:2786` 在文本 overlay 的**任何**一次改动里都会跑 `_write_ov_fx`，
`property.py:1966-1980` 无条件 `ov["fx"] = ...`。

**用户动一下面板，这条文本的转场、入场/出场、漂浮、闪光、多层扩展描边、混合模式全部停止工作
—— 而这些控件还明晃晃留在界面上。**

### 3. 旧工程的投影卡在 legacy，而且会突跳

`overlay_fx_from_legacy`（`text_layer.py:128-142`）同时写新键和旧键；
`spec.py:532-566 _legacy_keys_still_drive` 判定 `_legacy=True` → `raster.py:424-426` 走旧路径，
**光源类型/角度/距离/大小/衰减/强度全部被忽略**。
用户把「光源大小」挪动 >0.02 或角度 >2.5° 时判定翻转，**投影外观一次性突变**。
`fx_fields.py:853-858` 的 `prev_shadow` 合并还在保活旧键，这个状态永远不会自然退出。

### 4. 标签裁切：定宽标签列 × 420px 面板上限，必然裁字

`inspector.py:790-799`：`setFixedWidth(clamp(row_width * 0.32, 32, 160))`，
建标签时（`:722-731`）**没有 setWordWrap、没有 elide、没有 tooltip 兜底**，
而且 `AlignRight` —— 超长时 Qt 从**左边**切，字面意义上的「文字被裁切了一半」。

`main_window.py:2827-2834`：右侧 dock 最小 200 / 最大 420 / 默认 **280**。
按 12px 字号、汉字 advance 12px 算：

| dock 宽 | 标签列 | 能放几个汉字 | 被裁标签数 / 65 |
|---|---|---|---|
| 200 | 44px | 3.7 | **37** |
| 280（默认） | 69px | 5.8 | 3 |
| 420（最大） | 114px | 9.5 | 0 |

`INSPECTOR_LABEL_MAX=160` 需要 dock ≈564px，**超过 420 的硬上限，是永远达不到的死配置**。

## 要做的

### P0 止血

1. **背景段拆开。** 不要直接复用 `mount_bg_glass` + `mount_texture_section`。
   基础 4 行（类型 / 颜色 / 透明度 / 圆角+内边距）常显；
   玻璃 6 项、纹理 2 项、气泡 2 项、渐变、四边渐隐 8 项**按 `bg.type` 用 `_row_visible` 隐藏**
   （`fx_fields.py:534-546` 已有这个函数，`_sync_fill_mode` 就是这么做的），
   而不是现在的 `setEnabled(False)` 常驻置灰 7 行。
2. **标签裁切**（这一条和 Q46 的令牌工作有交集，以先落地的为准，不要各做一遍）：
   标签列宽改成按**本段最长标签的 `QFontMetrics.horizontalAdvance`** 定（上限仍夹住），
   并统一 `setToolTip(text)` + elide 兜底。右侧 dock 最小宽从 200 提到 300。
3. **删掉这些**（清单见下表）：「启用渐变」「混合」「转场」「动画效果」「漂浮参数」
   「闪光高亮参数」「多层扩展描边」整段、`_fill_toggle`、`ov_content_label`、
   三处 `add_header` 造成的重复段标题（「填充」段里再出现一行「填充」小标题）。
4. **「内容」行改成标签在上、编辑器 + 工具条占满整宽。**
   现在工具条需约 276px 而 dock 280 时字段列只有 115px，
   `container.setSizePolicy(Ignored,…)`（`property.py:753`）让 minimumSizeHint 被忽略，
   `scroll` 又关了横向滚动条（`property.py:757`）→ 直接裁掉，「清除格式」看不全。
5. **每行的 ↺ 重置按钮在文本面板一个都没接 handler**（`inspector.py:154-164` 全传 `on_reset=None`），
   点了只打 warning，段头 ↺ 会触发一片 warning。接上 `reset_fx_attr`（`dock_panels.py:66-68` 已有），
   接不上就别画 —— 它白占 24px。

### P1 把「渲染端已经能用」的白拿

这四组的代码路径 overlay 已经走得通（和字幕共用 `layout_event` / `raster_text`），**只差 UI**：

6. `mount_layout_fx`（字距 em + **大小写**，现在文本面板只有 px 字距）
7. `mount_fonts_emphasis`（正文/强调双字体）
8. `mount_emphasis_section`（自动着色 / 强调词）
9. `mount_scatter_section`（弹出散落）

10. 段头开关不要再直接改数值键：改成 `enabled` 语义，或至少关闭时快照、打开时恢复用户原值。
11. 投影 legacy：迁移时就把 `sigma_em/dx_em/dy_em/alpha` 从 `fx.shadow` 里去掉，
    让旧工程一次性落到新模型（`fx_fields.py:853-858` 现在反而在保活它们）。

### P2 真正「足够强大」

12. `paint_text_overlay` 补 `xf`（调 `anim.transform_for`），然后挂 `mount_anim_fx`
    —— 文本层才有和字幕同级的动画能力。现在 `text_layer_paint.py:325` 传的是 `xf=None`。
    顺便给旧的 `ov_anim_*` 一条迁移路径，别直接丢。
13. 富文本工具条补**字体族下拉**（`_restyle_run` 已支持 `font_family` override）。
    注意 Q44 自述：为规避 PySide6 access violation，`document_to_runs` 不再从 fragment 读 fontFamily
    —— 这个坑要先解决，否则选一段改字体再存会丢 override。
14. 「清除格式」现在清成 Qt 默认格式而不是 overlay 的 base，清完颜色字号会跳成系统默认。
15. 取色的对比基准 `property.py:1631` 用 `ov.get("color", "#FFFFFF")`，
    但 `migrate_text_overlay` 已经把 `"color"` 从 overlay 里 pop 掉了（`text_layer.py:206-207`）
    → 基准恒为白色，导致多写或漏写 override。改从 `fx.fill.colors[0]` 取
    （`text_layer.py:308-313` 已有这个逻辑）。

## 该删的控件清单

| 控件 | 标签 | 为什么 |
|---|---|---|
| `fx_bg_grad_enabled` | 启用渐变 | `bg.grad_enabled` 不在 `FX_FIELD_WIDGETS`、不是 `FxSpec` 字段、渲染端零引用，勾了什么都不写 |
| `ov_text_blend` | 混合 | 写 `ov['blend_mode']`，但混合分支在 early return 之后 |
| `ov_anim_in_*` / `ov_anim_out_*` / `ov_float_*` / `ov_flash_*` | 动画效果 / 漂浮 / 闪光 | 同上，有 fx 的文本永远走不到 |
| `ov_transition` / `ov_transition_dur` | 转场 | 同上 |
| `ov_se_*` 整段 | 多层扩展描边 | `stroke_expand_*` 只在旧 QPainter 路径被读；`ov_se_step`/`ov_se_feather` 甚至**根本没 addRow 进任何布局**，却还在 `property.py:1669-1670` 被 setValue |
| `_fill_toggle` | —（无 UI） | 创建后全仓无引用 |
| `ov_content_label` | 内容: | `QLabel` 建了但从未加进布局，孤儿控件 |

## 该改名的（内部术语直接暴露给用户）

「接头样式」→「描边拐角」；「发光 σ (em)」→「发光柔度」（em 放 tooltip）；
「衰减」「强度」→「投影衰减」「投影浓度」（现在是两个裸词，段内没有上下文）；
「上/下/左/右渐隐」→ 说清是**背景框**的渐隐，不是文字渐隐。
