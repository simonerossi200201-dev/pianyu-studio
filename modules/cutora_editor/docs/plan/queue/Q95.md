## 决定（照做，不要打折）

**唯一真源 = 风格包（stylepack）。** `subtitle_style_presets.json` 这套平行存储退役，
「字幕样式」页的预设下拉从此**直接列风格包**，两个入口读写的是同一份数据。没有同步代码，因为没有第二份数据要同步。

1. **存储**：只剩用户风格包目录（现有格式与 `save_pack_dir`）。预设的名字 = 包名；默认预设 = 包上的一个 `default: true` 标记。
   50 个上限取消（包本来就没有上限）。
2. **迁移（一次性，自动，不给开关）**：首次启动把 `subtitle_style_presets.json` 里的每个预设转成一个用户风格包，
   名字、内容、默认标记全部带过去，风格页立刻能看到横条卡片。迁移完把旧 json 改名成 `subtitle_style_presets.json.migrated`
   （只为出事时能人工找回，程序不再读它）。迁移只跑一次，用一个标记文件记住。
3. **创建**：在字幕样式页「新增预设」和在风格页「存成风格包」是同一条命令、同一个结果——
   一张卡片出现在风格页，同一个名字出现在预设下拉。不许出现两条数据、两张卡。
4. **删除**：任意一边删，东西就没了，两边同时消失。删之前一句确认，写明「风格列表和预设下拉都会移除」。
   内置包（builtin）不能删，只能「另存为」成用户包。
5. **重命名 / 更新**：同上，一处改，两处都变。
6. **导入 / 导出**：统一走风格包的格式（`.cutorastyle`）和现有的 `stylepack.import_file` / `stylepack.export_file`。
   字幕样式页那两个「导出预设 / 导入预设」菜单项改为调用同一条命令（可以保留菜单文案）。
   **删掉** `presets.py` 里 json 版的导出 / 导入代码路径，别留着当第二条路。
7. **应用**：选预设 = 应用风格包，走风格页今天那条应用路径（含「同时应用该风格的动画」开关的既有语义）。
   两条入口产出的 style 必须逐键相等。
8. **作用域**：本次只统一「字幕样式预设」与「风格包」。**文本层预设（`text_preset` / `ov_preset_*`）不动**，
   在报告里给出建议：以后是否也并进来、代价是什么。
9. **清理**：`presets.py` 里只服务字幕预设的函数（`load_subtitle_presets` / `save_named_subtitle_preset` /
   `delete_subtitle_preset` / `get_default_subtitle_preset_name` / 导入导出）全部删掉或改成迁移期专用，
   调用点（`subtitle_style.py` 13 处、`main_window.py` 2 处、`command_bodies.py` 2 处、`batch/cli.py` 2 处、`light.py` 1 处、
   `stylepack.py` 1 处）逐个改到新路径。**不许留空壳函数**，死代码会被 `test_no_unreachable_code` 抓。
10. 按 `_RULES_UI_OWNERSHIP.md`：只加控件、接信号，不改检查器行高 / QSS / dock 宽度；风格卡片沿用 5.6:1，不改尺寸。
