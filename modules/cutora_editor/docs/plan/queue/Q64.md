# Q64 · 字幕面板：删掉无用参数，把视觉栅格收口

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

Luca 的原话：「界面上很多奇怪的无用的参数」「要有留白和合理的布局」「UI 没有错误但不美观、简陋」。
Q50 把顶层改成了数据表，但**旧写法只是挪进了盒子里**。

## 一、删掉死段和重复控件（直接回应「奇怪的无用参数」）

- **「音谱动画」整段**：`spectrum_*` 在 `cutora/render` 里零读取。删。
- **「多层扩展描边」整段**：`stroke_expand_*` 只在 overlay 分支读（`frame_renderer.py:1295,1443`）。字幕侧删。
- **v1 动画 8 项 + 对应 8 个 group**（`sub_anim_*` / `sub_fade_*`）：textfx 零引用 `anim_in_type`。删，「动画效果」段头改成 fx 语义的开关。
- **重复**：「入场时长(s)」和「入场时长 (s)」在同一段（`subtitle_layout.py:150,160`）；
  「位置 X/Y」出现两次（`:21-22` 和 `:138-139`）；「逐词出现」勾选与「每条字幕」下拉语义重叠；
  「自动着色」里 fx 词表和 v1 `keyword_colors_ui` 并存。每组只留一个。
- **「启用渐变」**（`fx_bg_grad_enabled`）：全仓零读取。删。
- **「(fx)」后缀**：「入场 (fx) / 循环 (fx) / 出场 (fx) / 缓动 (fx)」（`fx_fields.py:628-643`，`subtitle_layout.py:155-162`）。去掉，用户不需要知道 fx 是什么。

## 二、15 个 QGroupBox 拆成表里的 Row

`subtitle_style.py` 还剩 15 个 `QGroupBox(`、68 处 `.addRow(`。滚动歌词、高级文本框、打字机、弹跳、漂浮……
都是 QFormLayout 岛，塞进表里的一行 `Row("", "xxx_group")`（`subtitle_layout.py:132-178`）。
效果是框套框、标签带冒号、不走 InspectorRow：不 elide、没有 ↺、标签宽度不跟本段对齐，
「弹簧阻尼: / 过渡时长:」这种一行两对的写法在 300px 下挤裁。

- 拆成 `Row`，标签进表，去掉冒号。
- 删掉段标题里的 emoji：「🎨 自动着色」「🎤 滚动歌词模式」「🎵 音谱动画」（`:421,427,782`），它们和段标题重复。
- 删掉 4 处内联冷色 `#7eb8f7` / `#aaa` / `#8ef7a5` / `#888`（`:579,701,712,839`）。
- 修截断标签「已显描边透:」（`:622`）。

## 三、禁用态真的整段变灰

`QWidget#dockSubContent QSpinBox/QComboBox/QPushButton/QCheckBox/QLabel/QSlider::handle` 这些规则**带 ID**，
优先级 (1,0,x)，**压过**通用的 `QSpinBox:disabled`（`theme_dark.qss.j2:174-179` 和 `states.py` 生成的块），
而 dockSubContent 下没写任何 `:disabled`。结果：关掉的段里，输入框、按钮、标签、滑块金把手都保持原样，
只有自绘的色块和开关会变灰。**Q45 修过一次，被 Q46 的选择器优先级又打回去了。**

**做法**：在 `theme_dark.qss.j2` 的 dockSubContent 下补全 `:disabled`；或者更稳的——
`CollapsibleSection._on_enable_toggled` 统一给内容套 `QGraphicsOpacityEffect(0.35)`。
**`test_section_off_all_gray` 必须真的跑在 dockSubContent 里**，它现在显然没测到这条路。

## 四、栅格与节奏

- `InspectorRow` 设 `setFixedHeight(ROW_H)`（令牌在，但 Python 里零引用）；字段控件高度统一 `CONTROL_H`；
  28px 的预设菜单按钮（`subtitle_style.py:219`、`property.py:513`）改 `SQUARE_SM`。
- 行距从 4px 改 `SPACE_1H` 6px——现在行和行几乎贴在一起，Resolve 约 6-8px。
- 字段值字号从 11px 提到 `font_label` 12px——**现在数值比标签还小**，11px 中文不易读。
- 无标签行（149 行里有 37 行 `Row("", …)`）保留标签列宽度，跟字段列对齐，别贴到最左。
- 段头：开关放到标题**右侧**（现在在箭头前面，有开关和没开关的段标题 x 坐标差 40px，一列标题左右跳）；
  箭头统一 `▸/▾`（现在是小三角 `▸` 配大三角 `▼`，`collapsible.py:36-37`）。
- 删掉死 QSS 规则：`#SubtitleStylePanel QComboBox` 的 `radius_ctl`（`:744`，被 dockSubContent 覆盖）、`collapsible*` 三条（`:838-843`）。
