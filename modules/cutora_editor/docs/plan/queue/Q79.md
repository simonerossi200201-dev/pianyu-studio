# Q79 · 转场：所有有边界的转场加羽化；「擦」的角度不起作用

**开工前先读 `_RULES_FOR_EVERY_TASK.md` 和 `_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。**

## 用户原话

> 所有的转场中能看到边界的，我希望都可以给它一个**边界的羽化参数**，参数范围要**给的大给的足一些**，
> 可以适用于一些非常柔和的情况下的需要。还有这个「擦」转场，我实测了，**角度参数不起作用**，也需要修复。

## 1. 「擦」的角度不起作用

截图里属性面板显示：类型「擦」、方向「左」、角度 5.0——画面上仍是一条**竖直**的硬边。
先查清楚：角度字段写进了哪个键？`transitions.py` 里的擦除函数读的是哪个键？
Q68 的审计指出过「旧的 wipe_right/up/down 三个方向都按 wipe_left 画」（`anim_engine.py:978-988`），
可能是新旧两套擦除实现并存、面板写的是新的、渲染走的是旧的。**这就是这个项目头号顽疾「面板写的键和渲染读的键不是同一个」**，找到它。

## 2. 羽化（所有有可见边界的转场）

涉及：擦除（线性 / 圆形 / 时钟 / 百叶窗）、推移、推入推出、滑动、翻页、立方体、分屏类……凡是画面上有一条「A 与 B 的分界线」的。

- 参数名「边缘羽化」，单位用**画面短边的百分比**（这样 720 和 1080 画面效果一致），
  **范围 0–50%**，默认 0（保持现在的硬边，老工程外观不变）。50% 时应该柔和到几乎像溶解。
- 实现：分界处的 mask 做模糊或 smoothstep 渐变，**不要对整帧做高斯模糊**（性能）。
  线性擦除直接用带宽度的线性渐变 mask 就行，成本几乎为零。
- 转场参数面板里加这个控件。**按 `_RULES_UI_OWNERSHIP.md`：只加控件、接信号，不改布局规则。**
- 截图里转场参数面板的「缓动」那一行被切掉一半——这是布局问题，Claude 在整体修，你不用管。

## 验收（修前必红）

- **`test_q79_wipe_angle_changes_pixels`**：同一个擦除，角度 0° 和 45°，t=0.5 的帧不同；45° 时分界线倾斜
  （在两个不同高度上采样分界的 x 坐标，差值符合 tan45°）。修前两帧相同。
- `test_q79_feather_softens_edge`：羽化 0% 时分界处像素的一阶差分很陡；30% 时明显变缓。
- `test_q79_feather_zero_is_unchanged`：羽化 0 时与改动前逐字节相同（老工程外观不变）。
- `test_q79_every_edged_transition_has_feather`：遍历转场库，凡标记为「有边界」的都接受 feather 参数且 feather>0 时像素变化。
- **性能**：羽化 50% 时每种转场的 ms/帧写进报告，不许超过 Q68 报告里对应项的 1.5 倍。
- golden：g19b-2 是交叉溶解（无边界），不该变；变了写 `.stop`。

## Claude 补充（Q83 之后，开工前必读）

Q83 重做了转场参数面板，控件名没变（`trans_*`），但：
- 每个参数一行；角度是 `slider_with_spin(self.trans_angle_sl, self.trans_angle_sp)`。
- **只显示该转场真正读取的参数**：`property.py` 里的 `transition_param_info(preset)` 从渲染函数签名推出
  （有 `direction` 参数 → 显示方向；`wipe_angle` → 显示角度；`motion_blur` → 显示运动模糊……），
  `_sync_transition_rows()` 据此显隐整行。Luca 截图里的「擦」是旧预设 `wipe_left`，它的渲染根本不读角度——
  这正是「面板写的键和渲染读的键不是同一个」。修法二选一并写进报告：让「擦」走 `wipe_angle`（方向映射成角度），或让旧擦除读角度；
  改完后 `transition_param_info` 必须如实反映（它看的是真实签名，所以你让函数接收 `feather`/角度后面板会自动出现对应行）。
- 羽化：给有边界的转场函数加 `feather` 关键字参数；面板里用 `SliderSpin(0, 50, 1, 0)`（后缀 %）加一行「边缘羽化」，
  并在 `transition_param_info` 里加 `"feather": "feather" in params`、在 `_sync_transition_rows` 里据此显隐。不许改行高/QSS。
