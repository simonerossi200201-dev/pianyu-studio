### 4. `--doctor` 体检命令
把 Q18 的像素锁产品化成一条随时可跑的自检：
- 面板写的键没人读 / 渲染读的键没人写（本次这一整批 bug 的形状）
- `DEPRECATED_UNPAINTED_KEYS` 里的键是否还在被写
- 风格包 leftover / reset 是否为 0
- 字体覆盖、模型就位、ffmpeg 可用
启动时后台跑一次（不阻塞），有问题在状态栏挂一个可点的小徽章。
门禁：`test_q34_doctor_catches_dead_key`：人为把一个控件改回写 v1 键 → doctor 报出来。

既是选包画廊的素材，也是「这个包还能正常渲染」的回归测试。
门禁：`test_q34_pack_thumbs`：14 个包各有缩略图且非全黑；改包内容 → 缩略图 md5 变。
