## 1. 日志必须先落地（这一步不做，后面全是空的）

现状：`cutora/core/log.py` 只往 `sys.stderr` 写，**没有任何文件落盘**。
Q101 改成 `pythonw.exe` 启动之后，`sys.stdout` / `sys.stderr` 都是 `None`，
输出直接消失，而且**任何一句裸 `print()` 会当场抛 `AttributeError`**。
这是真正的崩溃风险，先修它。

在 `cutora/core/log.py` 里加：

- **文件处理器**：`RotatingFileHandler`，路径 `user_data_dir()/logs/cutora.log`，
  单文件 4 MB、保留 5 份，UTF-8。现有的 `RedactFilter` 必须挂在它上面
  —— 日志要落盘了，脱敏比以前更重要。
- **环形缓冲处理器** `RingBufferHandler`：内存里保留最近 **5000** 条，线程安全，
  带 `records()` 和一个「有新行」的回调（给界面用）。
- **Qt 消息接管**：`qInstallMessageHandler`，把 Qt 自己的
  warning/critical 转进 logging。现在导出时刷屏的
  `QFont::setPixelSize: Pixel size <= 0 (-1)` 就是这类，接管之后它会进日志文件，
  方便以后定位（**本条不要去修那个 -1，它另有任务**）。
- **无控制台兜底**：`sys.stdout` / `sys.stderr` 为 `None` 时，用一个只写进 logging 的
  轻量流对象替换它们，保证任何库里的 `print()` 都不会炸。有控制台时保持原样，不要改。

以上全部在 `setup_logging()` 里完成，保持幂等。

## 3. 最小化 → 悬浮图标

### 3.0 总开关（Luca 2026-09-24 补充，必做）

原话：「这个要在设置里，也让用户可以选择是否使用这个悬浮按钮，用户可以选择用，
也可以选择不用，但是默认安装完，必须是开启使用的，后续用户可以自己取消勾选。」

- 设置里加一项「最小化时显示悬浮图标」，**默认开**。
  全新安装（设置文件里没有这个键）时读出来必须是 `True` —— 这条要有单测钉住。
- **关掉之后**：最小化就是 Windows 的标准最小化（缩进任务栏），悬浮图标不出现；
  已经显示着的图标立刻隐藏。**不许**出现「关了开关但还有个图标赖在屏幕上」。
- 关掉时，第 4 节的「贴边隐藏」那一项**跟着置灰**（它是悬浮图标的子选项，
  没有图标就无从贴边），但不要改它自己存的值 —— 重新打开总开关时恢复原样。
- 开关切换**立即生效**，不需要重启软件。
- 这个键和第 4 节的贴边隐藏、以及图标的位置/边长，都存在同一份设置里，
  用现有的「只改自己的键」的写法，别把别人的冲掉。

### 3.1 图标本身

新文件 `cutora/ui/floating_badge.py`。

- `FloatingBadge(QWidget)`，flags `Qt.Tool | Qt.FramelessWindowHint |
  Qt.WindowStaysOnTopHint`，`WA_TranslucentBackground`。
  用 `resources/brand/app.png`（Q101 放进去的那张圆形图）按当前边长平滑缩放绘制。
  **必须用 `Qt.Tool` 而不是 `Qt.Window`**，否则它会在任务栏多出一个按钮。
- 主窗口 `changeEvent` 收到 `WindowStateChange` 且变成 `WindowMinimized` 时：
  `hide()` 主窗口 + `show()` 悬浮图标。
- 悬浮图标上**单击**（按下与松开之间位移 < 4 px 才算单击，否则是拖动）→
  主窗口 `showNormal()` + `raise_()` + `activateWindow()`，图标 `hide()`。
- **拖动**：按住左键拖，位置实时跟随。
- **缩放**：滚轮，边长在 **48–256 px** 之间，步长 8。右键菜单里也给
  「小 / 中 / 大」三档和「重置位置」「退出片语 Studio」。
- 位置和边长存进设置，下次启动沿用。
- **越界保护**：显示前把矩形夹回当前某块屏幕的可见区域。多屏拔掉一块、
  或分辨率变了之后，图标不许留在看不见的地方。设置里另给一项
  「重置悬浮图标位置」，作为用户找不回来时的退路。
- **保持置顶**：除了 flag，另开一个 **5 秒**一次的低频定时器重新置顶一次
  （别更频繁，会抢焦点）。

**诚实地写进报告**：Windows 上的置顶压不住另一个同样声明置顶的窗口、
独占全屏的播放器/游戏、以及 UAC 提权弹窗。这是系统限制，不是 bug，
不要为此去做钩子或轮询提权之类的事。

## 4. 贴边隐藏（可开关）

设置里加一项「悬浮图标贴边隐藏」，默认**关**。

打开后：拖动松手时，若图标中心距某条屏幕边 < 12 px，
则滑到只露出 **8 px** 在屏幕内（带一个 150 ms 的动画）。
鼠标移上去（或从屏幕边缘推过去）→ 滑回完整位置；移开 800 ms 后再缩回去。
贴边状态也要存盘。关掉这个开关时，已经贴边的图标立刻滑回来。

## 测试 `tests/test_q102_console_badge.py`（登记进 `tests/qt_isolate.py`）

每条都要能说明「改之前是红的」：

1. `RingBufferHandler` 上限 5000：灌 6000 条，长度是 5000 且保留的是最后那批。
2. 脱敏仍生效：往文件处理器灌一条带 `xai-xxxxxxxx` 的日志，读回文件里是 `***`。
3. 无控制台兜底：把 `sys.stdout` / `sys.stderr` 置为 `None` 再 `setup_logging()`，
   然后 `print("hi")` **不抛异常**，且 "hi" 出现在环形缓冲里。改之前这条必炸。
4. Qt 消息接管：`qWarning("boom")` 之后环形缓冲里有 "boom"。
5. 悬浮图标 flags：`Qt.Tool`、`FramelessWindowHint`、`WindowStaysOnTopHint` 三个都在，
   且 `WA_TranslucentBackground` 为真。
5b. **总开关默认开**：拿一份空设置（没有这个键）读出来是 `True`。
5c. **关掉总开关**：先最小化让图标出现，再把开关关掉 → 图标立刻 `isHidden()`；
    此时再最小化一次，图标**不出现**，主窗口走标准最小化（`isMinimized()` 为真、
    没有被 `hide()` 掉）。再把开关打开，最小化又能出图标。
5d. 关掉总开关时「贴边隐藏」那一项 `isEnabled()` 为假，但它存盘的值不变；
    重新打开总开关后恢复原状态。
6. 最小化联动：主窗口 `showMinimized()` → 主窗口 `isHidden()` 为真、图标 `isVisible()` 为真；
   在图标上模拟一次单击 → 主窗口可见、图标隐藏。
7. 单击 vs 拖动：按下后移动 20 px 再松开，**不许**触发还原。
8. 缩放夹紧：连滚 100 格，边长停在 48 / 256 不越界。
9. 越界保护：把存盘位置写成 `(-5000, -5000)`，显示后矩形与某块屏幕的可见区域有交集。
10. 贴边：开关打开、把图标放到距左边 5 px 松手，x 落到「只露 8 px」的位置；
    关掉开关，x 立刻回到屏幕内完整可见。
11. 控制台窗口：自动滚动在用户向上滚后停止、回到底部后恢复；级别过滤只留 WARNING 以上时行数正确。
12. 日志目录在便携模式下跟着 `user_data_dir()` 走（设 `CUTORA_USER_DATA` 验证）。
