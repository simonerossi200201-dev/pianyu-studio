# Q86 · 分屏：羽化不再透黑、玻璃分界线做精致、参考线可隐藏、分屏提速

**开工前先读 `_RULES_FOR_EVERY_TASK.md`、`_RULES_UI_OWNERSHIP.md`。每做完一个子项就提交。改前后都截图放 `docs/plan/reports/Q86/`。**

## 用户原话

> 分屏的边缘羽化过渡的部分有点发黑，好像是两个素材同时开启羽化，交叉的部分就出现了透明的现象就会导致发黑。
> 羽化是为了两个视频直接柔和过渡，而不应该透出黑色来。交界线的玻璃质感等做得也很粗糙，这些都要精美一些。
> 中间的分界线和原点属于参考性质，默认现在这样是可以的，但希望有个隐藏开关，关掉参考线能看到最终成品合成效果。

## 根因（Claude 已查明，`cutora/render/split_screen.py`）

1. **透黑是合成公式错了**。同一条分界线两侧格子的 mask 是互补的线性坡 `a = t`、`b = 1 − t`（`_feather_alpha`），
   但两层是依次 SourceOver 叠到**透明**的离屏图上：合成 alpha = `a + b(1 − a)`，t=0.5 时只有 0.75，
   剩下 25% 露出底下的黑。正确做法二选一：
   - 第一个格子**不加 mask 铺满**（作为底），后面的格子按 mask SourceOver 叠上去；或
   - 所有格子用 `CompositionMode_Plus` 叠加互补 mask（和恒为 1）。
   多条分界线（2×2、3×3、左1右2…）时要保证**任意像素所有格子权重之和 = 1**：建议对所有格子的原始 mask 做归一化（w_i / Σw），在 `_build_masks` 里一次算好缓存。
2. **羽化带落在格子矩形外面时没有像素**：每个格子只画了 `cell rect` 大小的图层（`layer = QImage(cw, ch)`），
   羽化向外延伸的那一半根本没有该素材的像素 → 透明 → 黑。图层要按羽化宽度向外**扩边**（overscan：rect 四周各加 feather_px，
   素材按同样的 fit 规则画得更大一点），mask 与扩边后的矩形对齐。
3. **玻璃带粗糙且慢**：`_draw_glass_band` 每一帧对**整帧**做 GaussianBlur，还用 numpy 对整帧算到折线（每 16 个点取一段）的距离——
   既慢又有折角。改成：带状区域的距离场 / 软 mask 在 `_SplitCache` 里按几何**只算一次**；模糊只在带的外接矩形 ROI 上做；
   折线采样足够密（沿线每 ≤4px 一个点）不出折角。
4. **分界线描边**：用 `QPainterPath` + 抗锯齿描，线帽圆头；实线 / 渐变 / 玻璃 / 阴影各自在 2× 放大截图里边缘平滑无锯齿。

## 做法

1. 修 1、2：任意布局、任意羽化值（0–200px）、任意曲线（直线 / 波浪 / 弧线），合成后没有任何像素比两侧素材都暗（见验收）。
2. 玻璃质感重做（Claude 给的外观目标）：分界带 = 带内背景高斯模糊（σ 随宽度）+ 5–8% 白色提亮 + 带两侧 1px 高光 / 1px 暗边（像一块磨砂玻璃条），
   带边缘软过渡，不是硬边矩形。参数沿用现有 width / sigma / color，默认值调到好看为止并在报告里给前后对比图。
3. **参考线开关**：分界线中间那条参考线 + 圆点手柄是编辑辅助，只在预览里画、导出从来不画（先确认导出确实不画；画了就是 bug 一起修）。
   - 预览画布工具条加一个开关「分屏参考线」（默认开），关掉后预览 = 导出成片效果；状态存 app 设置，不存工程。
   - 选中分屏轨道或拖动分界线时参考线临时显示，松手后按开关状态。
   - 按 `_RULES_UI_OWNERSHIP.md`：只加控件接信号，外观用已有的工具条按钮样式。
4. **提速**（和 Q88 一起看，但分屏部分在这里做完）：分屏合成每帧不许有整帧 numpy 运算；mask / 带 / 路径全部走缓存；
   能用 QPainter 的地方不用 numpy。
