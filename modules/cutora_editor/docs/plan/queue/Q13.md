## T22-b 切缝（三报 #7）
切缝 = 同一轨上相邻两个 clip 的接点。
- 悬停 ±4px 高亮（金色竖条），点击选中（更亮 + 两侧 clip 端部微光）
- **Backspace / Delete**：两侧同 source、`left.out_t == right.in_t`（±1 帧）、speed 相同、无转场
  → 合回一个 clip（命令 `timeline.join_clips`，undo）；不满足 → **状态栏说明为什么不能合**（不静默）
- 选中接缝后右键「添加转场…」或从转场面板拖到接缝 → `TransitionItem`；已有转场时选中的是转场

## T20-f 转场面板（三报 #10）
