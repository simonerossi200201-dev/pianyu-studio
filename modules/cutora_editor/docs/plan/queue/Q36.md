#### 硬约束

1. **不许新增 `direction` 键。** 沿用已落盘的 `style["writing_mode"]`，
   取值从 `horizontal` / `vertical` **扩**成 `horizontal` / `vertical_rl` / `vertical_lr`。
   老工程里的 `"vertical"` 必须读成 `vertical_rl`（中日传统，从右往左），
   写一个迁移测试锁住这条。`text_layout` 不动。
2. **`_stack_vertical` 必须删掉**，不是留着当兜底。竖排逻辑进 `layout.py`，
   在 `_measure_and_place` / `_place_line` 里按方向出 `LineBox`，
   让 `LayoutResult` 自己就是竖排的 —— 背景 / 描边 / 投影 / 动画吃的都是它，
   这样才不用写第二份。
3. **字幕和叠加走同一条路径。** `pipeline.py:150` 和 `text_layer_paint.py` 都只调
   `layout_event()`，绘制侧不许再有任何 `if writing == ...` 的事后分支。
4. `text_orientation` ∈ `mixed`（默认，半角数字与拉丁横向旋转 90°）/ `upright`，
   和 `writing_mode` 平级，同样落 `style_schema.py`。
5. UI：`property.py:566-569` 的下拉框从两项扩到三项（横排 / 竖排·从右往左 / 竖排·从左往右）。
