## 为什么这是最深的一条

`cutora/ui/widgets/dock_panels.py:198-204` 的函数文档自己写明白了：

```
def apply_dock_style(panel):
    """Transform a SubtitleStylePanel that was built with a flat QFormLayout
    into a collapsible-section layout.
    Called AFTER init_ui() completes — all widgets & signals already exist.
    We only reorganise the visual layout; no functionality is changed."""
```

流程是：`subtitle_style.py:225-1049` 的 `init_ui()` 先用**旧的扁平 QFormLayout** 造一遍
（`form.setSpacing(8)` / `setContentsMargins(10, 12, 10, 12)`，10 和 12 都不是令牌；
段标题是 `QLabel("  基本排版")`，靠两个空格缩进），
然后 `apply_dock_style()` 把这些控件**逐个 reparent** 进 `CollapsibleSection` + `InspectorRow`，
最后 `old_widget.deleteLater()`（`dock_panels.py:648`）。

三个后果：

1. **`subtitle_style.py` 从未导入过任何 Q25 控件。**
   grep `InspectForm|InspectorRow|add_inspect_row|SectionHeader|SliderSpin|ColorSwatch|EnumCombo` → 零命中。
   这个 2695 行、Luca 点名抱怨「框拉得特别长整个铺满」的面板，本体至今是旧写法；
   新外观是外面套上去的。
2. **漏接 = 静默销毁。** 任何在 `init_ui()` 里新建、而 `apply_dock_style()` 忘了 `_row()` 的控件，
   会跟着 `old_widget.deleteLater()` 一起消失。
3. **新增参数默认不继承设计。** 加一个控件要改两个文件；只改一个，它要么长得不一样，要么不见了。

**设计不是面板的构造方式，是一道后处理。后处理必然有覆盖不到的角落，
而且角落的数量随功能增长单调递增。** 这是「有些细节还容易存在缺陷」的制度性来源。

## 要做的

废掉 `apply_dock_style()` 的 reparent 流程。`subtitle_style.py` 只负责
**创建控件 + 接信号**，不摆布局；段落结构写成一张数据表：

```python
INSPECTOR_LAYOUT = [
    Section("基本排版", toggle=None, rows=[
        Row("预设", "sub_preset_combo", reset="preset"),
        Row("字体", "sub_font"),
        Row("大小", "sub_size"),
    ]),
    Section("填充", toggle="fill", gray_when_off=True, rows=[...]),
    ...
]
```

由 `build_inspector(panel, INSPECTOR_LAYOUT)` 统一渲染。

顺带解决的：

- **三套段落容器合并成一份** —— `collapsible.py:143 CollapsibleSection`、
  `dock_panels.py:71 CollapsibleSection`（同名不同类）、`inspector.py:605 SectionHeader`。
  折叠箭头现在是两种字符：`collapsible.py:222,227` 用 `▶`，
  `dock_panels.py:165,192` 和 `inspector.py:644` 用 `▸` —— 同一个窗口里两种三角形。
- **三套滑条+数值框合并** —— `inspector.py:202 SliderSpin`、
  `dock_panels.py:280-295 _spin_host()` 手工拼的同一个东西、裸 `QSlider`。
- **开关统一到 23 段** —— 现在是 `subtitle_style.py` 里 17 处 `labeled_toggle`
  （开关右边跟一整句中文，例如 `:242` 的「启用字块分离 (从原文流中脱离，支持独立位移/旋转/缩放)」）
  加 6 处裸 `ToggleSwitch`（Q24 新加的）。`Section(toggle=...)` 天然吸收。
- **段头开关的 ON 值不该改字色。** `subtitle_style.py:373-377`：
  ```python
  self._fill_toggle = SectionToggle("fill",
      {"type": "solid", "colors": [DEFAULT_FILL]},
      {"type": "gradient", "colors": ["#22D3EE", DEFAULT_FILL]})
  ```
  段头叫「配色方案」，打开它 = 把字色直接写成青→米渐变。
  而当工程的 fill 恰好等于产品默认时，这个段默认是关的（`:1899` 用 `is_on(fx_now)`），
  字色控件被 `_sync_section_content_enabled`（`:1930-1937`）整段灰掉 ——
  用户想改字色得先打开一个会顺手把字变成渐变的开关。
  改成「纯 UI 开关，只负责解灰，不写 fx」。
