# Q48 · preview ≠ export 的三处，和 Q30 缺失的那条锁

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

这个项目已经在「面板改了预览变了导出没变，或者反过来」上翻过四次车。审计又查出三处。

## 一、Q13 音频转场：预览完全没有

`grep -rn apply_audio_transition_fades cutora/` 只有两处：
`model/seams.py:145`（定义）和 `render/render_worker.py:1766`（导出）。

`cutora/asr/timeline_wav.py` 的预览混音（`:262-268`）只读 `clip.fade_in_dur/fade_out_dur`，
**完全不知道音频 TransitionItem 的存在，也不支持 `fade_curve`**。
用户在接缝上放一条等功率交叉淡化 → 导出有、预览没有。

要做：`asr/timeline_wav.py:mix_rows_for_task` 引入 `apply_audio_transition_fades` 并支持 `fade_curve`
（导出侧用的是 `curve=esin`，`render_worker.py:1095-1100`）。

## 二、Q17 玻璃分界线：画布预览里永不绘制

`render/split_screen.py:494`：
```python
if dev is not None and hasattr(dev, "copy") and border_style == "glass":
    composed = dev.copy()
```
导出时 painter 的 device 是 QImage，`copy()` 成立。
**画布预览（`ui/canvas.py:_draw_preview_local`）的 painter 直接画在 QWidget 上，
QWidget 没有 `copy()` → `composed = None` → `_draw_borders`（`:318`）跳过 `_draw_glass_band`。**
而且即便有，widget 的 device 是窗口坐标系、带 UI 边框，取到的底也是错的。

另外三条渲染路径过滤轨道的规则各不相同：
`preview/engine.py:334-339` 先按 `visible` 过滤再传入；
`ui/canvas.py:740-744` 不过滤（在 `_paint_one` 里才判）；
`render_worker.py` 用 `_video_tracks_for_export`。

要做：玻璃描边的取底改成「总是先合成到离屏 QImage 再 blit」，三条路径走同一条；
三处的轨道过滤规则合并成一个函数。

## 三、Q17 的测试测的是产品不跑的函数

`render/split_screen.py:418 composite_layers` —— `grep -rn composite_layers cutora/`
只有定义处和一行注释，**产品路径一律走 `paint_split_video_tracks`（`:450`）**。
而所有渲染类测试（glass 方差、export/preview MAD、缓存性能）用的都是 `composite_layers`。
**两条不同的实现，测哪条锁哪条。**

更糟的是 `tests/test_t34_split.py:156 test_split_export_preview_mad` 是同义反复：
`a = composite_layers(...)`、`b = composite_layers(...)` 同参数调两次比 MAD。
这不是「导出帧 == 预览帧」，这是「纯函数是确定性的」。

要做：把 `paint_split_video_tracks` 内部抽出和 `composite_layers` 共用的一份，
或者干脆删掉 `composite_layers` 让测试改调产品函数；
`test_split_export_preview_mad` 改成一边跑 `ExportRenderer.render_frame`、
一边跑 `PreviewEngine` 同一帧比 MAD。

`test_split_glass_band_variance`（`:125`）在红/蓝两格交界处取带算方差 ——
没有玻璃也必然 >0，锁不住任何东西，一并改掉。

## 四、Q30：「不开这个功能时导出音频逐字节不变」零覆盖

这是 Luca 点名要的那条锁，**全仓库没有**。

- `grep -rn "04deefb" tests/` → 0 命中，只在 `docs/plan/reports/Q30_filter_diff.txt:74` 的文字里。
- golden 十二例只由 `tools/golden_check.py` 把关，那是 `CHECK_BASELINE.bat` 手动跑的工具，
  **不在 pytest 里**（`tests/test_golden_check.py` 只测指纹格式化函数，不跑导出）。
- 更关键：迁移把 g08 那条 clip 从 stored `False` 翻成 `True`
  （`model/project_io.py:41-44`，`tests/test_t30_spatial.py:277` 断言 `clips[4]` 是 True）。
  **所以现有 golden 锁的是「功能开着导出不变」，反过来那个场景无人断言。**
  上次就是这里翻的车。

要做：
- `test_t30_golden_audio_unchanged`：用 g08 fixture 走 `RenderWorker._build_audio_tracks`
  组出 `filter_complex` 字符串，和一份钉死的期望字符串逐字符比。
  （不需要真导出 —— `Q30_filter_diff.txt` 已经证明字符串相同就等价。）
- `test_t30_disabled_has_no_reverb`：`clip.spatial_enabled=False` 时 filter 链里没有 `afir`。

  —— `spatial.py:456` 已完全不读它，**这就是上次翻车的那个占位符**，留着迟早再咬人。
