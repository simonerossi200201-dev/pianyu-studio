`cutora/render/textfx/spec.py:642` 的 `from_style()` **只读 `style["fx"]` 和 `font_family`**，别的什么都不读。
我对整个 `cutora/render/textfx/` 目录逐个 grep 过这些 v1 扁平键：

也就是说：**面板里任何还在写 v1 扁平键的控件，都是死控件** —— 不是偶尔失效，是按构造不可能生效。


## 现象（Luca 实测）
「配色方案的 字色 启用渐变 和 高亮 启用渐变，启用渐变是黑色字根本看不清；字色和高亮色作用不到画面上，信号是断的。」

## 根因
`dock_panels.py:245-251` 的「配色方案」段挂的是 `panel.panel_text` / `panel.panel_high` / `panel.panel_bg`
三个 v1 色板子控件，它们写 `color_text` / `color_high` 一族扁平键 —— 按共同根因那张表，**引用数 0**。
渲染器实际用的是：

- 正文颜色 → `fx.fill`（`FillSpec: type / colors / angle / metal`，`spec.py:157`）
- 高亮颜色 → `fx.emphasis.color` / `fx.emphasis.palette`（`spec.py:241`）

「启用渐变是黑色字」是因为渐变路径根本没接上，落到了兜底分支。

## 要做
1. 「配色方案」段**整段重建**，每个控件绑定恰好一个 fx 路径：
   - 字色：填充类型（纯色 / 渐变 / 金属）→ `fill.type`；色标列表 → `fill.colors`；
     渐变角度 → `fill.angle`；金属预设 → `fill.metal`。
     选「纯色」只显示一个色块；「渐变」显示色标列表（可加可删，2–5 个）；「金属」显示金属预设下拉。
     **互斥显示，不是全堆在一起。**
   - 高亮：`emphasis.color`、`emphasis.palette`、`emphasis.scale`。
   - 背景色仍归「背景色块」段（已经是 fx.bg，不要动）。
2. `panel_text` / `panel_high` 里的 v1 色板控件**连控件一起删**，不是 `.hide()`。
   `color_text` / `color_high` 进 `DEPRECATED_UNPAINTED_KEYS`。
3. 渐变色标必须**看得见颜色**：每个色标是带颜色填充的小方块按钮（≥ 24×24），
   不是一个写着"渐变色标"的长条按钮。外观按 T25 的规范；T25 还没做时先用正方形色块顶上。
4. 检查 `fill.type == "gradient"` 在 `raster.paint_stroke_fill`（`raster.py:882-908`）里的分支：
   colors 少于 2 个时要有合理兜底（用第一个色当纯色），**不许落成黑色**。
