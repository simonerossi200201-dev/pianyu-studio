## 这是什么
里程碑 **T30 关键帧系统**。Luca 很早就提过，一直排在「深水区」没做。
这是把 CUTORA 从「批量套模板」变成「能做动效」的分水岭 —— 没有关键帧，所有动画只能是预设。

## 现状（Claude 核实）
仓库里**已经有动画**，但全是「整段一个参数」：
`fx.anim`（in / loop / out + unit + stagger + easing）、`floating_amplitude/period`、
`char_bounce_*`、`letter_jump_*` 等，都是**在 spec 里给一个常数，由 anim.py 按 t 算曲线**。
`render/textfx/anim.py` 已经有完整的 easing 和 `xf`（变换）管线 —— **关键帧要接在这里，不要另起炉灶**。

## 要做

### 1. 数据结构（先定，落进 `docs/plan/KEYFRAME_SPEC.md` 再写代码）
```
"keyframes": {
    "<参数路径>": [
        {"t": 0.0, "v": <值>, "ease": "linear|ease_in|ease_out|ease_in_out|hold|bezier",
         "bez": [x1,y1,x2,y2]}      # ease=bezier 时才有
    ]
}
```
- 挂在**被动画的对象**上：clip（位置/缩放/旋转/不透明度/音量）、text_overlay、image_overlay、字幕样式。
- `t` 是**相对该对象起点**的秒数，不是时间线绝对时间 —— 这样剪切/移动 clip 时关键帧跟着走。
- 参数路径用已有的 fx 路径写法（`fill.colors[0]`、`shadow.angle_deg`、`x`、`scale`、`opacity`）。
- **取值函数唯一**：`keyframe.value_at(obj, path, t_local, fallback)`，预览和导出都调它，
  一个参数只有一条取值路径。

### 2. 支持的参数（第一批，够用就行，别一次铺满）
clip：`x / y / scale / rotation / opacity`；音频：`gain_db`；
文本与字幕：`opacity / scale / tracking_em / fill.colors[0] / shadow.angle_deg / shadow.distance_em`。
颜色插值走 **OKLab**，不要在 sRGB 里线性插（会出现发灰的中间色）。

### 3. 时间线 UI
- clip 上有关键帧时，轨道条下方出现一条**关键帧带**，每个关键帧一个小菱形。
- 选中 clip 后属性面板每一行右侧出现一个**秒表图标**：点亮 = 该参数启用关键帧；
  播放头在某关键帧上时菱形实心，不在时空心；改值自动在当前播放头打一个关键帧。
  （这套交互是 AE / Resolve 的通用习惯，用户不用学。）
- 右键关键帧：删除 / 改缓动 / 复制 / 粘贴。
- **Ctrl+Z 必须能撤销每一次关键帧操作** —— 走命令总线，不许直接改数据。

### 4. 曲线编辑器（本任务**不做**，写进 `.ok` 的欠账）
第一版只做菱形 + 六种缓动下拉。贝塞尔手柄编辑留到下一条。
