# Q81 · 批量加载：预览直接用软件画布；参数区留白

**开工前先读 `_RULES_FOR_EVERY_TASK.md`。每做完一个子项就提交。**

## 用户原话

> 批量加载右侧的预览窗口，并不是我想要的样子。我希望这个预览窗口**就直接接入软件画布同样的窗口**，
> **完全同样的比例、同样的属性和功能**。当用户在图片或视频分页里点击某个图片的时候，这个图片就在右边的画布上直接预览出来，
> 它显示出来的位置、显示出来的大小**就是直接在画布上呈现出来的最终结果**，这样用户才能准确的知道图片应该放在什么位置、应该放多大。
> 这个坐标和缩放是和软件的画布有统一标准的，可以说它就是直接在画布上显示的，而不是另辟一个很差劲的预览框。
>
> 还有这个批量加载的参数框也是拉得太长，不够美观，记得多留出一些界面上的留白，不要都拉长填满，不好看。

截图里现在的样子：右侧是一个把图片放大裁切的预览框（显示的是图片局部，不是它在画面里的样子）；
参数区每一个下拉框和数值框都横向拉满将近 900px。

## 1. 预览 = 真的画布

- 右侧放一个**真正的 `VideoCanvas`**（主窗口画布那个类），画布尺寸 = 当前工程画布（720×1280 就是 9:16 竖屏）。
  背景显示所选视频在「起始帧」那一刻的画面（左侧勾选的第一条视频），这样用户看到的就是**最终合成效果**。
- 点击图片/视频缩略图 → 画布上立刻以当前参数（适配方式、缩放、位置偏移、混合模式）显示它。
- **双向同步**：在画布上直接**拖动**图片 = 改「位置偏移」X/Y；拖**角手柄**缩放 = 改「缩放」（默认锁定宽高比，Shift 反转，和 Q78 一致）；
  改参数框 = 画布即时更新。
- 坐标系与主画布**完全同一套**（像素、原点、缩放基准），插入到时间线后在主画布上看到的位置与这里一模一样。
  这一点要有测试锁住。
- 不要另写一个预览类。现有的 `batch_preview.py` 里自己画的那套删掉。

## 2. 参数区的布局（给出具体规格，照做）

- 对话框三栏：左栏视频列表 **固定 260px**；中栏参数区 **最大宽度 420px**；右栏画布**占满剩余**。
  （现在是中栏拉到 900px、画布被挤到最右边一小条。）
- 参数区内：标签列宽按最长标签实测，控件**不拉满**——数值框宽 96px、下拉框宽 180px，右侧留白。
  「位置偏移」X / Y 两个数值框并排、各 96px。
- 分组：「素材」（目录、缩略图网格、路径）/「时间」（单位、起止、留空）/「外观」（入出场动画、混合、适配、缩放、位置）/
  「多平台」（折叠，默认收起）/「导出」。组与组之间 16px，组标题用现有的段标题样式。
- 缩略图网格：每格固定 96×96 缩略 + 下方文件名单行省略（现在文件名换三行、有的没缩略图）。
- 所有间距用 `tokens.py` 里的令牌，不许写 10 / 14 这种非栅格值。
