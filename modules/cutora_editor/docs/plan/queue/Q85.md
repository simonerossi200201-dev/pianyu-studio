# Q85 · 时间线上选中转场按 Delete 删除（并补齐撤销）

**开工前先读 `_RULES_FOR_EVERY_TASK.md`。每做完一个子项就提交。**

## 用户原话

> 添加到时间线上的转场，在选中的状态下，也无法删除，我希望在时间线上选中转场，直接按 Delete 键就可以把这个转场给删掉。

## 根因（Claude 已查明）

`cutora/ui/timeline/widget.py` 的 `keyPressEvent`：点转场会设 `self.selected_transition = (track, trans)`（约 2653 行），
但 Delete 分支只处理了 字幕段 / 音频 / 接缝 / 视频 clip / 覆层，**没有转场分支**，事件落到 `QWidget.keyPressEvent` 被吞掉。
另外视频 clip 那个 Delete 分支（约 4824 行）是直接 `v_track.clips.remove(...)`，**不走命令总线、不能撤销**。

## 做法

1. 新命令 `timeline.delete_transition`（走 command bus，可撤销，撤销后转场原样回到原位置、参数不丢）。
2. `keyPressEvent`：`selected_transition` 不为空时，Delete / Backspace 执行上面的命令，清空选中，刷新属性面板（回到空页）。
   这个分支要放在视频 clip 分支**之前**（选中转场时 `selected_video_clip` 也可能还挂着值——先确认 Q77 的互斥选中是否已保证，没保证就在这里保证）。
3. 右键转场菜单加「删除转场」（同一条命令）。
4. 顺手把视频 clip 的 Delete 也改成走命令总线（`timeline.delete_clips` 若已存在就用它），能撤销。
5. 检查 `main_window.py:5155` 的 Delete 处理：焦点在时间线时不能被它抢走。

## 验收（修前必红）

- `test_q85_delete_selected_transition`：两段视频之间放一个转场，模拟点中转场 → 按 Delete → 转场没了，两个 clip 不受影响。
- `test_q85_undo_restores_transition`：撤销后转场回来，preset / 时长 / 方向 / 羽化等参数与删前完全一致。
- `test_q85_delete_video_clip_undoable`：选中视频 clip 按 Delete，撤销能恢复。
- 导出 golden 不变。

## Claude 裁决（2026-09-22）

上一轮不是撞墙 —— Grok **异常退出**（退出码 1，但没提交、没 .stop、没 .ok，HEAD 没动，golden 无新增失败）。任务前提和根因都还成立，直接重做。报告里刷屏的 `QFont::setPixelSize` 是导出路径本来就有的告警，不是崩因。

复核过源码，落地要点（详见 `_blocked/Q85.ruling.md`）：

1. **撤销是整树快照**（`main_window.push_undo` → deepcopy tasks）。所以删除转场只要做成**总线命令 + `undoable=True`** 就**自动完整可撤销、参数一个不丢**，不用手写逆操作。
2. 新命令 `command_delete_transition` 放 `cutora/ui/command_bodies.py`（仿 `command_set_transition` 的轨道/转场查找，命中后 `tr.transitions.remove`）；注册进 `cutora/core/cmds/specs_edit.py`（`undoable=True`）+ `cutora/core/cmds/gui.py`（仿 `cmd_timeline_add_transition`）。
3. `keyPressEvent`（`cutora/ui/timeline/widget.py` ~4700）加 `selected_transition` 的 Delete/Backspace 分支，放在视频 clip 分支（~4818）**之前**，走 `timeline.delete_transition`，删后清选中 + `_publish_selection()` 让属性面板回空。
4. 互斥选中**已由 `_arm_transition`→`_reset_selection` 保证**（选中转场时 `selected_video_clip` 必为 None），Q77 那点不用再处理。
5. 视频 clip 的 Delete（widget.py ~4824）现在是直删不可撤销，改成走总线（没有 `timeline.delete_clips`，需新建）。右键转场菜单加「删除转场」。核对 `main_window.py:5155` 别抢 Delete。
6. 三个验收测试目前**不存在**，先写、修前必红。
