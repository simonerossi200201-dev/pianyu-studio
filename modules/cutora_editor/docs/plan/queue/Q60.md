# Q60 · 字幕面板：用户第一个碰的几个控件拨了没反应

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`，尤其第八节：每做完一个子项就提交。**

这一条只修「拨了没反应」，不做外观改动。每一项都是用户打开字幕面板几秒内就会碰到的。

## 1. 「基本排版 → 字体」拨了不改字

`cutora/render/textfx/layout.py:566`：`family = spec.fonts.body or style["font_family"]`。
**14 个内置风格包全部带 `fx.fonts.body`**（逐个读 style.json 核实过），而面板从不把
`sub_font` 同步到 `fonts.body`。结果：套任何一个包之后，「字体」下拉都是死的。
真正能改字体的「正文字体」藏在默认折叠、而且灰掉的「双字体」段里（`subtitle_layout.py:191`）。

**做法**：「字体」直接绑到 `fx.fonts.body`，删掉「双字体」段里重复的「正文字体」。
「双字体」段只保留「强调字体」一项。老工程的 `font_family` 迁移到 `fonts.body`。

## 2. 「旋转」是死的

`sub_rot` 写 `s['rotation']`（`subtitle_style.py:2013`），字幕渲染路径里没有任何地方读 style 的 rotation
（grep 只在 overlay 和 clip 分支命中）。

**做法**：给字幕渲染补上 rotation（在 `textfx` 最终合成 ROI 时绕文本中心旋转），预览和导出同一条路。
如果判断补不了，就**删掉这个控件**，不要留一个拨了没反应的旋钮。

## 3. 高亮弹力块的「偏移」是死的

`sub_dyn_off_y` 写 `box_highlight.offset_y_em`，而 `word_fx.py:285-380 draw_box_highlight` 不读它。
**做法**：`draw_box_highlight` 按 `offset_y_em * em` 平移底块。

## 4. 点了只打 warning 的 ↺

- 5 行显示 ↺ 但无效：`fx_emphasis_color_hint`、`fx_emphasis_auto_hint`、`fx_bg_fade_hint`（这 3 行是提示文字，根本不该有 ↺）、
  `fx_bg_grad_enabled`、`fx_bg_glass_toggle`。原因是 `inspector.py:744 _row_reset` 只按 `fx_` 前缀判断，
  而 `fx_fields.py:1098-1102 reset_fx_attr` 在 `FX_FIELD_WIDGETS` 里查不到就 return。
- 段头「重置本段」（`collapsible.py:316-325`）在高亮弹力块、滚动歌词、高级文本框、音谱、多层描边这 5 段里，
  行全是 `sub_*`、没有 handler，点了静默无效。

**做法**：`_row_reset` 改成按 `FX_FIELD_WIDGETS` 判断能否重置，**查不到就不画 ↺**；
提示文字行永远不画；段头 ↺ 在本段没有任何可重置行时隐藏；`sub_*` 行能接 reset 的接上。

## 5. `build_inspector` 静默丢行

`inspector.py:804` 遇到缺失属性直接 `continue`，`test_inspector_layout_complete` 只扫 `sub_*`/`fx_*` 前缀。
`btn_*`、`chk_*`、`*_group` 这类漏登记会被 `scroll.setWidget`（`:813`）静默销毁。

**做法**：缺属性时抛错；完整性测试改成扫 panel 上**全部** QWidget 属性。

## 验收（每条都要先改坏确认会红）

- `test_q60_font_changes_pixels`：套一个内置风格包 → 改「字体」→ 出帧，**像素变**。现在必红。
- `test_q60_rotation_changes_pixels`（或 `test_q60_rotation_removed`）
- `test_q60_box_offset_moves_block`：改偏移，底块的纵向质心移动。
- `test_q60_no_dead_reset_buttons`：遍历面板每个可见 ↺，点一下，断言有值被恢复（没有 warning 日志）。
- `test_q60_layout_complete_all_widgets`：扫全部 QWidget 属性。
- golden 必须不变（这些是接线修复，不该动已有工程的渲染，除了用户显式改了字体/旋转的情况）。
