## 现象
「发光正常，阴影不起作用；阴影没有开关，和别的段不统一；发光底下那些投影参数好像也完全不起作用。」

## 根因
1. `dock_panels.py:309-313` 「阴影 / 发光」段头三行又是 v1 死控件：
   `sub_blur`→`shadow_blur`、`sub_c_shadow`→`color_shadow`、`sub_shadow_op`→`opacity_shadow`，引用数全 0。
2. 下面的 `fx_shadow_*` 是活的（`raster.py:1084` 确实调 `paint_shadow`），但
   `raster.py:281` 是 `if spec.shadow.sigma_em <= 0: return`，而 `ShadowSpec.sigma_em` **默认 0**。
   → 不先把「投影 σ」拉起来，dx/dy/色/透明度**全都没有任何可见效果**。用户先动 dx 看不到反应，
   就认为整段坏了。**这是交互设计错误，不只是接线问题** —— 新设计里不许再有「必须先拉某个参数，别的才生效」。
3. 该段**没有段头开关**，而背景色块 / 描边 / 多层扩展描边都有 —— 外观不统一。

## 要做

### 1. 清掉死的、拆成两段
删掉 `sub_blur` / `sub_c_shadow` / `sub_shadow_op`；三个键进 `DEPRECATED_UNPAINTED_KEYS`。
「阴影 / 发光」拆成 **「发光」**（现状不动，它是好的）和 **「投影」**（下面重做），两段各有段头开关。

### 2. 投影改成光源模型（Luca 原话：用真实的光源和阴影的关系来控制）
`ShadowSpec` 换成一组有物理含义的参数。**先加后退役**：旧的 `sigma_em / dx_em / dy_em` 保留为兼容输入，
`from_style` 里折算成新参数；新参数存在时以新的为准。

| 参数 | 键 | 范围 | 含义 |
|---|---|---|---|
| 光源类型 | `shadow.light` | `parallel` / `point` | 平行光 = 所有字投影方向一致；点光 = 投影朝背离光源方向发散 |
| 光源角度 | `shadow.angle_deg` | 0–360 | 平行光方向；点光时是光源相对文字中心的方位 |
| 光源距离 | `shadow.distance_em` | 0–3 | 越近影子越长、越发散 |
| 光源大小 | `shadow.size_em` | 0–1 | 面光源半径；越大边缘越虚（决定半影 → 映射到模糊 σ） |
| 衰减 | `shadow.falloff` | 0–1 | 影子从根部到梢部的透明度衰减，0 = 不衰减 |
| 颜色 | `shadow.color` | 8 位 hex | 带 alpha |
| 强度 | `shadow.strength` | 0–1.5 | 整体不透明度倍率 |

实现要点（**不要做真正的光线追踪，做一个看起来对的近似**）：

- **平行光**：字形 mask 按 `angle_deg` 平移 `distance_em * em`，再按 `size_em` 高斯模糊。
  这是现有 `paint_shadow` 的直接推广，改动最小。
- **点光**：影子不是平移而是**从光源方向做放射状拉伸**。以光源在画布上的投影点为中心，
  对 mask 做一次沿背离光源方向的仿射拉长（倍数 = `1 + k / distance_em`），再模糊。
- **半影**：模糊 σ 沿影子长度递增（根部实、梢部虚）。最简做法：渲 **3 层**不同 σ / 不同 alpha 的影子叠加。
  层数写死 3，**不要做成用户参数**。
- **衰减**：沿影子方向乘一个 alpha 梯度。
- 性能：三层叠加**必须进 ROI / 层缓存**（和现有 glow 同一套缓存键策略）；`skip_blur`（预览降级）时退回单层。
  **做完要量**：贴开启投影前后的 ms/帧，涨幅 > 15% 要说明并优化。

### 3. ROI 必须放大
影子会超出现有文字 ROI。layout 的 ROI padding 要把 `distance_em + size_em * 3` 算进去，
否则影子被裁掉 —— 这很可能是「dx/dy 调了也看不见」的第二个原因。
**做之前先用一张截图证实或证伪，结论写进 `.ok`。**
