# Q70 · 把 preview≠export 的锁换成真的

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

这个项目在 preview≠export 上翻过至少四次车。Q48 修了三处症状，但**锁住它们的测试仍然是假的**。
假的锁比没有锁更危险——它让人以为安全。

## 1. 分屏的 MAD 测试仍是同一个函数跑两遍

`tests/test_t34_split.py:277 test_split_export_preview_mad`：导出侧用的 `draw_background=draw_bg`
就是 `eng._draw_video`（PreviewEngine 的函数），视频层、分屏、玻璃在两边都由预览函数画。
`test_split_glass_band_variance`（`:139`）和 `test_split_cache_frame_cost`（`:308`）还在测产品不走的
`composite_layers`（`split_screen.py:432`）——**Q48 的任务书明确要求改掉，没改。**

**做法**：导出侧改走 `RenderWorker` 的真实 `_video_tracks_for_export` 路径（或 ExportRenderer 整帧）；
删掉 `composite_layers`，相关测试迁到 `paint_split_video_tracks`。

## 2. Q30：Luca 点名要的那条锁仍然没有

「**不开空间立体声时，导出音频逐字节不变**」——`test_t30_disabled_has_no_reverb`（`test_t30_spatial.py:567`）
只断言 filter 里没有 `afir` 和 `amovie`。关闭状态下多塞一个 `volume` 或 `aformat`，测试照样过。

**做法**：g08 关闭空间立体声的版本，**钉死完整的 `export_audio_filter_complex` 字符串**；
再加一个真跑 ffmpeg 混音、比 md5 的测试（g08 前 3 秒就够，控制耗时）。

## 3. 预览音频是另一份手写的 filter

`asr/timeline_wav.py:214-300` 和 `render_worker.py:1200-1240` 是两份独立的 filter 构造。
测试只比 rec 字段、只查 `'curve=esin' in fc` 子串。
**做法**：预览音频**直接复用** `RenderWorker.export_audio_filter_complex`，删掉 timeline_wav 里手写的那份。
这样从结构上就不可能再分叉。

## 4. canvas 不分屏路径自己判断轨道可见性

`ui/canvas.py:746-755` 在循环里自己判断 visible/muted，没调 `video_tracks_for_render`。改掉。

## 验收

- `test_q70_split_preview_vs_real_export`：一边 `PreviewEngine`，一边 `RenderWorker` 真实导出一帧，比 MAD。
  用**有纹理**的素材。在 `.ok` 里写明：把预览侧的玻璃描边故意关掉，这条会红。
- `test_q70_spatial_off_filter_pinned`：钉死的字符串逐字符相等。
- `test_q70_spatial_off_audio_md5`：真跑 ffmpeg，md5 相等。
- `test_q70_preview_audio_uses_export_filter`：AST 断言 `timeline_wav.py` 不再自己拼 filter，而是调导出的函数。
- grep 全仓 `composite_layers` 为 0。
- golden 必须逐字节不变。
