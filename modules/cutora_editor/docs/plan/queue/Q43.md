# Q43 · 阴影：距离为 0 和降级预览下，光源大小仍然完全无效（P0）

**开工前先读 `docs/plan/queue/_RULES_FOR_EVERY_TASK.md`。**

Q41 把物理真的写进了表达式，这部分是对的，不要推翻。但 Luca 最初那句抱怨
——「我调整了光源大小之后，影子没有任何反应」——**在两个常见场景里原样复现**。

## 病灶一：`distance_em == 0` 时 sigma 恒为 0

`cutora/render/textfx/raster.py`：

```
:428   dist_term = dist_em / (dist_em + _SHADOW_K)      # _SHADOW_K = 0.5
:447   sigma = size_px * t * dist_term
:448   dx = int(round(dist_px * t * cos_a))
```

`distance_em == 0` ⟹ `dist_term == 0` ⟹ **每一层 sigma 都是 0**，同时 `dx = dy = 0`。
四层退化成四份完全重合、完全不模糊的字形 mask，落在字形正下方，
`raster_text`（`:1280`）先画阴影后画填充，于是被填充整个盖住。

**Q21 声称删掉的那个早退（`if distance_em <= 0: return`），等价地活在这个乘法里。**
Q41 任务书写的「距离为 0 就是贴在字底下的接触阴影，那是合法且常用的效果」没有实现。
`test_q41_knobs_live_from_default` 用段头默认值 0.18 测的，所以测不到。

## 病灶二：降级预览里 `size_em` 100% 无效

```
:424   n_layers = 1 if skip_blur else _SHADOW_LAYERS
:463   if (not skip_blur) and sigma > 0.05:      # 平行光唯一用 sigma 的地方
```

`skip_blur=True` 时平行光只做一次平移、一次也不模糊，上一行算出的 `sigma` 是死值。
`pipeline.py:370` `skip_blur = preview and _degraded`，降级条件是「预览连续 10 帧 > 12 ms」
（`pipeline.py:96-100`）。而 `docs/plan/reports/Q41_投影性能.md` 自己量的**点光导出是 20.385 ms/帧**。

**用点光的用户，预览必然在十几帧内降级，然后又回到「调光源大小影子没反应」。**

## 病灶三：falloff 的跨度取错了

`:471-472` `_shadow_falloff(acc.shape, cx, cy, cos_a, sin_a, sh.falloff, max(dist_px, 1.0))`
—— `span = dist_px`，而 `_shadow_falloff`（`:314-326`）从**字形质心**起算。
段头默认 `distance_em=0.18`（em=96 时 span≈17 px），字形半宽就有三四十 px，
于是整片阴影的下风侧全部 `t=1`，**衰减退化成按质心一刀切的均匀乘法**，不是根部实梢部虚的梯度。

## 病灶四：点光的 scale 直接乘进 alpha

`:460` `acc += (layer/255.0) * (w_i * i_t * scale)`。`scale` 在 `dist_em=0.2` 时最大到 5.25，
乘完 `np.clip(acc, 0, 1)`（`:475`）大片饱和成纯色块，半影梯度被削平。
`test_q41_point_intensity` 只测峰值 alpha，饱和了照样绿。

## 病灶五：点光 ROI pad 和实际放大倍数对不上

`spec.py:906-908` `extra = (0.85/max(distance_em,0.15))*4.0; sh += min(extra, 3.2)*em`，
封顶 3.2 em；而 `raster.py:452` 实际每层放大 `1 + 0.85·t/max(dist,0.15)`，`dist=0.2` 时 5.25 倍。
近距离点光的外扩像素落在 ROI 外，画了也看不见。`test_t21_shadow_roi` 只测平行光。

## 病灶六：老工程经面板往返后 `_legacy` 路径永久走不到

`fx_fields.py:826-838 save_from_panel` 重建 `fx["shadow"]` 时只写 `schema_paths()` 里的键，
而 `shadow.sigma_em/dx_em/dy_em/alpha` 在 `fx_schema.py:24-27 _SKIP_SPEC_PATHS` 里被排除；
`:834` 的兜底 `for key, value in prev.items(): if key not in fx` **只在顶层合并**，
`"shadow"` 已经在 `fx` 里了 → 旧键被整体丢弃。
`raster.py:274 _paint_shadow_legacy` 从此走不到，老工程阴影外观改变。
渲染层的 `test_q41_legacy_byte_identical` 是绿的，但它没走面板这条路。

## 要做的

1. **`:428` 给 `dist_term` 一个接触地板**：
   `dist_term = (dist_em + CONTACT_EM) / (dist_em + _SHADOW_K)`，`CONTACT_EM ≈ 0.02`。
   同时距离为 0 时给阴影一点各向同性外扩（`raster.py:89` 已有 `dilate_u8`），
   否则零位移的阴影仍然被字盖住 —— 真实的接触阴影是「字周围一圈渗出来的暗」。
2. **`:463` 的 `skip_blur` 分支不要丢弃 sigma**：改成廉价近似，
   单层 + 在 1/4 分辨率上做一次模糊（成本约 1/16），或 `cv2.blur` 盒滤波两遍。
   「算了 sigma 不用」是白算。顺带把 `pipeline.py:96` 的 12 ms 阈值和点光 20.4 ms 的实测
   放在一起重新定 —— 现在这个阈值保证了点光必定降级。
3. **`:471` 的 span 改成阴影真实长度**：`span = dist_px + 字形沿光线方向的长度`，
   起点从质心改成字形沿光线方向的**下风边界**（`mask_u8` 投影的 max）。
4. **`:452-460` 点光不要靠乘 scale 补偿**：放射缩放把 mask 摊薄 `1/scale²`，
   要补就在 clip 之前做能量归一，不要靠 `np.clip` 削平半影。
5. **`spec.py:906` 的 pad 用和 `raster.py:452` 同一个 scale 公式算**，别另写常数。
6. **`fx_fields.py:834` 改成对 `fx["shadow"]` 逐键合并**，把 `_SKIP_SPEC_PATHS` 覆盖的旧键补回去。
7. **`tests/test_q41_shadow.py:497` 的合成公式错了**：`out = src * a + dst * (1.0 - a)`，
   而 `src` 是 `Format_ARGB32_Premultiplied` 已经乘过 alpha 的，正确是 `out = src + dst * (1.0 - a)`。
   `docs/plan/reports/Q41_shadow_grid.png` 这张给 Luca 看的证据图是失真的，改完重出。
