# Q174 · 调整轨道（纯色块 + 局部效果）（2026-10-06）

Luca 的需求：时间线上新增一种「调整」轨道。轨道头的「+」会建一块纯色矩形，可以设置圆角、不透明度、边框，也可以关掉填充。打开「效果」后，这块形状就变成一个范围，它下面的所有画面在这个范围里做镜头模糊、局部调色等效果。形状可以铺满全屏，也可以再加遮罩。它支持移动、旋转、缩放，所以能接跟踪数据。效果连文字和字幕一起影响（Luca 确认过）。

## 第一、二期（这次完成）

### 数据

- 轨道：`Track("adjust")`，属于视觉域。新建时放在视觉域的最上面，也就是盖在所有视频、图片、文字、字幕的上面。之后新加的视频轨会插到它下面。
- 每一段：放在 `task["image_overlays"]` 里，`type == "adjust"`，`_track_id` 指向调整轨。因为放在覆层列表里，所以覆层已有的能力都能直接用，包括位置、大小、旋转、缩放、不透明度、关键帧、遮罩和跟踪（烘焙到关键帧）。
  - `solid`：`on` / `color` / `opacity` / `radius`（短边的比例）/ `border_on` / `border_width` / `border_color`。
  - `effect`：`on` / `kind`（`lens_blur` 镜头模糊 / `blur` 高斯模糊 / `mosaic` 马赛克 / `grade` 调色）/ `amount` / `highlights`（镜头模糊的光斑）/ `mix` / `grade{exposure, contrast, saturation, temperature}`。
  - `feather`：边缘羽化，单位是画布像素。
- 存盘和读盘不需要改：轨道类型 `adjust` 和覆层字段原样保存、原样读回。

### 渲染（`cutora/render/adjust_layer.py`）

- 统一叠压（`visual_stack`）里新增 `("adjust", 轨道)` 这一层。画到这一层时：
  1. 把画布上到这里为止已经画好的内容取出来；
  2. 只在形状的外接框（再加上模糊半径的余量）里处理；
  3. 处理完再合回去。
- 结果是：调整层下面的视频、图片、文字、字幕都会被处理，上面的不受影响。
- 预览、导出、主画布、中央监视器走的都是同一个函数。测试逐像素比对过：预览和导出完全一致，画布和预览也完全一致。
- 形状的组成：
  - 圆角矩形：用 Qt 抗锯齿光栅化，旋转和缩放后直接画到画布坐标上；
  - 乘上羽化；
  - 再乘上遮罩面板里画的遮罩。
  - 几何不变时，形状有缓存。
- 合成顺序：先做效果，再盖填充色（可以做「半透明色块 + 底下模糊」），最后画边框。
- 效果强度按整幅画面的长边换算，所以预览缩小了，看起来也和导出一样。大半径的模糊先缩小、模糊完再放大，速度快一个数量级，看上去没有差别。
- 每帧耗时：

  | 分辨率 | 形状 | 效果 | 耗时 |
  |---|---|---|---|
  | 1080×1920 | 60% 大小 | 高斯模糊 | 约 17 ms |
  | 1080×1920 | 60% 大小 | 镜头模糊 | 约 24 ms |
  | 1080×1920 | 全屏 | 各种效果 | 约 30–55 ms |
  | 540 预览 | — | 各种效果 | 约 5–25 ms |

  改之前是 200–400 ms。

### 界面

- 新建调整轨的入口：
  - 菜单「编辑 → 添加轨道 → 调整轨道（纯色 / 局部效果）」；
  - 时间线右键「添加轨道 → 调整」；
  - 快捷键 `Alt+J`。
- 新建时会在播放头位置直接放一块纯色矩形，一步撤销。时间线会自动滚到这条轨道。
- 轨道头「+」：在这条调整轨的播放头位置再放一块。
- 时间线配色：
  - 银灰底，无彩色，跟哪个主题都搭；
  - 画成拉丝金属的质感：顶上一道反光、腰部一条暗缝、底部压暗，亮度在中灰，不扎眼；
  - 字和图标用主题色，不够深时沿主题色压暗，保证对比度 ≥ 6；
  - 轨道头的名字块用同样的金属质感。
- 每一段左边有一个小图标：开了纯色是实心色块（就是填充色），开了效果是虚线框。名字显示为「调整 · 镜头模糊」。
- 画布：点选、拖动、缩放和旋转把手都能用；只开了效果、看不到填充色的段也点得中。
- 右侧属性面板：
  - 选中调整段时，显示「变换」和「调整图层」两组；
  - 「调整图层」里有：纯色 / 效果开关、填充色、填充不透明度、圆角、边框（开关 + 颜色）、边框宽度、效果种类、强度、光斑（只在镜头模糊时显示）、效果混合；调色时显示曝光 / 对比 / 饱和 / 色温；最后是边缘羽化；
  - 每一行都有单独的重置按钮，标题栏的重置按钮会把整组重置；
  - 一次连续调整只算一步撤销，不会多出一条「操作」。

### 顺带修的

- 时间线把没有 `_track_id` 的老覆层分给同类第一条轨道时，会把老图片分到调整轨上。现在调整轨只认调整图层，图片轨也不认调整图层。
- 关监视器时，如果退出顺序不对，`TileRenderer.shutdown` 会碰到已经删掉的 C++ 对象而报错，现在会吞掉这个错误。
- 「预览里透明的地方画棋盘格」的检测会把调整图层上的遮罩误当成透明，现在跳过调整图层。图层搬运（layer_transfer）这一期也先不搬调整图层。
