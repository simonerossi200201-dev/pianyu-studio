共同规律（设计依据）：
1. **快捷键跟着焦点走**：Premiere / Resolve 同一个键在时间线和查看器里做各自的事（Resolve 的 Shift+Z 在查看器是「适应画面」，在时间线是「全览」）。
2. **修饰键语义固定**：Shift = 约束（锁方向 / 等比 / 角度步进），Alt = 复制或「从中心」，Ctrl = 另一种变换（缩放）或临时关吸附。
3. **一个手势一次撤销**：连续按方向键微移只算一次撤销。
4. **拖动时降画质、松手再精修**：AE 的 Fast Draft、Resolve 的代理，全都是「交互时省、停下来准」。
5. **键位可改、有预设**：从别的软件转过来的人能用回自己的习惯。

来源：Premiere 键位表（editorskeys.com）、Resolve 21 键位（davincishortcuts.com）、Final Cut Pro 官方键位（support.apple.com）、After Effects（skillademia.com / helpx.adobe.com）、CapCut 桌面版（skillademia.com）。

## 2. Cutora 现状审计（2026-09-29，HEAD 85f9007）

**已经有、而且做得不错的**：
- 画布：Alpha 精确点选，Alt+点可穿透透明区。Shift+点多选、框选、成组拖动；8 个缩放手柄加旋转手柄。
- 画布：文本角柄缩字号、边柄改折行宽；Shift 锁方向或反转等比；按住 N 临时关吸附。
- 画布：吸附到画布、分屏格子、其他对象的边和中心；对齐与等距分布；Ctrl+Alt+C / V 复制粘贴文字样式。
- 画布：分界线可拖位置、Alt 拖旋转、双击复位、滚轮调羽化。
- 时间线：Alt+拖复制；, / . 按帧微移；Ctrl+B / S 切割；Ctrl+滚轮缩放，Shift+滚轮横移；Z / Shift+Z 全览和缩放到选区；磁铁吸附可分类开关。
- 全局：J/K/L 变速播放、I/O 入出点、M 标记、Alt+←/→ 与 Shift+↑/↓ 跳标记、F 全屏、Shift+S 安全区。
- 性能：拖动时视频层半分辨率合成；只取最新一帧的后台合成线程；可见区域缩略图队列；波形缓存。

**缺口 / 问题**（按影响排序）：
1. 画布几乎没有键盘操作：不能用方向键微移（方向键被全局逐帧抢走）；Delete、Ctrl+C / V / D、Esc 取消选择、Ctrl+A 全都没有。
2. 画布没有 Alt+拖复制；没有 Ctrl+拖以光标为中心缩放；旋转没有 15° 步进；缩放手柄不能从中心缩放；分界线拖动不吸附 1/3、1/2、2/3。
3. 画布不能缩放、平移视图，看不了 100% 细节，也不能放大后对齐。
4. 逐帧写死 33 ms，不是按工程帧率。
5. 时间线：
   - 缺少：波纹删除快捷键、Q / W 波纹修剪、↑ / ↓ 跳剪辑点、Shift 加倍的微移、Ctrl+D / Ctrl+X、工具快捷键、拖播放头擦洗。
   - 行为问题：Ctrl+滚轮是以播放头为中心缩放（应该以光标为中心）；多选后只拖得动一条；文字 / 图片不能多选。
6. 有几处时间线编辑绕过了命令总线，可能撤销不了：音频删除 / 粘贴、覆层删除 / 粘贴、兜底 Ctrl+B、裁剪手柄。
7. 属性面板：没有「拖标签改数值」；没有 Shift / Ctrl 粗调细调；滚轮没聚焦也会改数值（容易误改）。
8. 中央监视器是独立窗口：主窗口的全局快捷键（方向键逐帧、S 切割等）会抢它的按键。
9. 键位不能自定义；帮助表里还写着「J 在后续实现」，已经过时。

## 3. Cutora 统一手势语法（所有画面：主画布 = 中央监视器）

| 手势 | 含义 | 状态 |
|---|---|---|
| 拖 | 移动（文字 / 图片 / 视频画面 / 分界线） | ✅ |
| Shift + 拖 | 锁横 / 竖方向 | ✅ |
| Alt + 拖 | **复制一份再拖**（本条内，或拖到监视器里别的视频） | 🆕 画布 / ✅ 监视器 / ✅ 时间线 |
| Ctrl + 拖 | **以按下点为中心缩放**（视频画面、分屏格子、文字、图片） | 🆕 画布 / ✅ 监视器 |
| Ctrl + 滚轮 | 缩放「选中的、在光标下的」对象；没有选中对象时缩放视图 | 🆕 |
| Alt + 滚轮 | 缩放视图（以光标为中心） | 🆕 |
| 中键拖 / 按住 H 拖 | 平移视图 | 🆕 |
| 按住 N | 临时关吸附（画布、监视器、时间线同一个键） | ✅ 画布 / 时间线，🆕 监视器 |
| 双击 | 文字：进入编辑；分界线：复位；视频画面或格子：重置平移和缩放 | ✅ / 🆕 |
| Esc | 正在拖：取消并恢复原样；否则清空选择 | 🆕 |
| 方向键 | 有选中对象：微移 1 px（Shift ×10）；没有：逐帧（Shift ±1 s） | 🆕 焦点路由 |
| Delete / Backspace | 删除选中的文字 / 图片 | 🆕 |
| Ctrl+C / X / V / D | 复制、剪切、粘贴、原地复制；**画布和监视器共用一个剪贴板，可跨视频粘贴** | 🆕 |
| Ctrl+Alt+C / V | 复制 / 粘贴样式 | ✅ |
| Ctrl+A | 全选（当前焦点区域内） | 🆕 画布 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 | ✅ |

**焦点路由规则**：键盘焦点在画布、并且画布上有选中对象时，方向键、Delete、Ctrl+C / X / V / D / A、Esc、Ctrl+= / − / 0、Shift+Z 归画布；否则照旧（逐帧、时间线操作）。实现方式是 Qt 的 `ShortcutOverride`：画布先声明「这个键我要」，全局快捷键就不触发。中央监视器也一样，主窗口的全局键不再抢它的按键。

## 5. 取舍说明
- **Space 永远是播放**，所以平移视图用中键或按住 H（Premiere 的抓手工具也是 H），不用 Photoshop 的「按住空格」。
- **S 保留为切割**（Cutora 老用户习惯）；Premiere 用 S 开关吸附，Cutora 用按住 N，和 Resolve / FCP 一致。
- **画布上 Alt 按下不动 = 穿透选择，按下拖动 = 复制**，两个功能靠「有没有拖动」区分，互不影响。
- **Ctrl+滚轮在画布上要先选中对象才缩放对象**：主视频铺满整个画面，不加这个条件，Ctrl+滚轮就永远在改视频、没法缩放视图。监视器的格子很小、本来就是用来改内容的，所以直接缩放格子内容。
- **监视器和主画布改的是同一个东西：片段本身的位置 / 缩放**（Q145 紧急修复 f8efc9e）。Q144 最初改的是轨道变换，那是嵌套语义（先按格子裁再移动），出格的原画面会变成黑边、导出也黑；已改为片段变换，老数据在打开工程 / 打开监视器时自动并入片段。属性面板里手动设的轨道变换仍保持嵌套语义。

## 7. 第二期实现记录（2026-09-29）
- 时间线按键都在 `cutora/ui/timeline/ops.py`（`TimelineOpsMixin`），焦点在时间线时生效；V / C / R 切工具时工具栏按钮跟着亮。
