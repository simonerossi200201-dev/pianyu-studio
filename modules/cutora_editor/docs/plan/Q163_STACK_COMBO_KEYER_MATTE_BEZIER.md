## Q163 · 所有视觉轨道按时间线顺序统一叠压

**问题**：以前视频轨全部先画，图片 / 文本 / 字幕永远压在所有视频上面（再按类型分块）。时间线上把文本轨挪到视频下面，
画面上它照样在最上面 —— 视频抠像后想把字放到人后面根本做不到。

**约定**（和视频轨一直以来的规则一样）：`timeline.tracks` 下标 0 = 最底层（先画）；时间线界面里越靠上的一行 = 画面里越在底下。

**实现**：`cutora/render/visual_stack.py`

- `build_stack(task)`：底→顶的一摞：`("video", [轨…])`（连续的视频轨合成一张「视频带」；整幅背景轨永远在最底那段；
  分屏格子的轨道作为一个整体放在第一条格子轨那段）、`("overlay", 轨)`（一条图片 / 文本 / 字幕轨）、`("subs_orphan", None)`（有字幕没字幕轨的老工程）。
- `needs_stack(task)`：这一摞和老画法一样（视频全在下、覆层按类型成块在上）→ False → **走老代码，逐字节不变（golden 不动）**；
  否则按这一摞逐层画。
- 预览（`PreviewEngine.frame_at` / 预览工作线程按视频带出多张图 / 画布 `_paint_stacked_scene`）、导出（`render_frame(paint_video_band=…)`，
  需要逐层时合成退回串行）、中央监视器小格（`_compose_stacked`）三条路径同一套。
- `FrameRenderer.draw_layers(only_track=…)`：只画一条覆层轨。
- 老工程：`migrate_old_order` 打开时一次性把排在覆层后面的视频轨挪到第一条覆层轨之前（保持相对顺序），打上 `z_order_v2`，画面和以前一样。
- 新加视频轨放在最上面那条视频轨之后（不会一加就盖住字幕）。拖动轨道顺序走撤销（`调整轨道顺序`）并立刻刷新画面。

## Q164 · 下拉菜单显示全部选项

`cutora/ui/theme/combo_popup.py`：应用级事件过滤器，所有 QComboBox `maxVisibleItems=30`，弹出时把弹层撑到放得下全部行（≤ 30 行、不超出屏幕），
隐藏上下滚动箭头。根因：检查器里的下拉弹层视口被限制在 116 px（6 行 × 22 px 只露 5 行），底部还多一个滚动条。

## Q165 · 蓝绿幕抠像

- 「抠了但不透明」：alpha 一直是对的，是**画布在画面底下先铺了一层黑**，抠掉的地方看着还是黑。现在画面里有抠像 / AI 抠像 / 遮罩时底下铺棋盘格
  （`cutora/ui/alpha_checker.py`，画布右键「透明处显示棋盘格」可关）。导出照旧：透明处露出下面的轨道，下面什么都没有就是黑（mp4 没有透明通道）。
- 「消除溢色」单独开关（默认关 = 只抠像，画面颜色一点不改）+ 强度 + 方式（标准：只压屏幕色通道超出的那一截 / 强力：老算法）+
  范围（只处理边缘 / 半透明处 · 整个画面）。老工程按老样子（开、强力、整个画面），画面不变。
- 透明阈值 / 不透明阈值（= 蒙版黑 / 白裁切 = 蒙版对比度）挪到主区，带说明。
