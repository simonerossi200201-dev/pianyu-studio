## 二、根因：为什么每一条都合格，加起来却不优秀

这不是「Grok 偷懒」。三条机制加起来，必然产出这个结果。

### 机制一：及格线是每个任务自己现划的

`tests/test_t25_inspector.py:65-83` 的 `test_t25_no_hardcoded_px`，检查范围**硬编码为两个文件**：

```python
for rel in (
    os.path.join("cutora", "ui", "widgets", "inspector.py"),
    os.path.join("cutora", "ui", "panels", "fx_fields.py"),

```

正好是 Q25 碰过的两个文件。QSS 模板里 338 个裸 px、`subtitle_style.py`、`property.py`、
`main_window.py` 全部不在检查范围。

`test_t24_toggle_uniform` 的文档字符串写「六个新胶囊与已有四个一致」，
但循环体只遍历 `SIX_CAPSULES` —— 另外 **17 个 `labeled_toggle` 从未被检查**。

**质量成了「上一个任务的局部属性」，不是全局不变量。** 每个任务都合格，应用整体持续漂移。
这就是「多数时候算是合格，但达不到优秀」的字面机制：**每一次都合格，是因为每一次的及格线都是现划的。**

## 三、必须马上修的（P0，两天内一定要做完）

### P0-1 · `SliderSpin` 接线

### P0-2 · 阴影：`distance_em = 0` 时光源大小仍然无效

`raster.py:428` `dist_term = dist_em / (dist_em + 0.5)`，`:447` `sigma = size_px * t * dist_term`。
`distance_em == 0` ⟹ `dist_term == 0` ⟹ 每一层 sigma 都是 0，同时 `dx = dy = 0`，
四层退化成四份完全重合、完全不模糊的字形，被填充整个盖住。

**你抱怨的「调了光源大小影子没反应」，在 distance=0 这个点上原样复现。**
Q21 声称删掉的那个早退，等价地活在这个乘法里 —— 只是被段头默认值 0.18 挡住了，没有被拔掉。

### P0-3 · 降级预览里光源大小 100% 无反应

`raster.py:463` `if (not skip_blur) and sigma > 0.05` —— `skip_blur=True` 时平行光
只做一次平移、一次也不模糊，上一行算出的 `sigma` 是死值。

`pipeline.py:370` `skip_blur = preview and _degraded`，降级条件是「预览连续 10 帧 > 12 ms」。
而 `docs/plan/reports/Q41_投影性能.md` 自己量的点光导出是 **20.385 ms/帧**。
**用点光的用户，预览必然在十几帧内降级，然后又回到「调光源大小影子没反应」。**

### P0-4 · Q27 在文本侧原样重造了静默失败 #19

## 四、UI「简陋」的结构性原因

先说一句公道话：`cutora/ui/theme/tokens.py` 是一份认真的令牌表，
`theme_dark.qss.j2` 里**硬编码颜色 0 处**，颜色全部走模板变量。
标签右对齐弱化、标签列定宽按比例夹紧、控件不铺满右侧留白、色块即颜色本身 ——
这四项已经追平 Resolve，**不要推倒重来**。

问题在别处。

### 外观是「事后改造」，不是构造方式 —— 这是最深的一条

`dock_panels.py:198-204` 的函数文档自己写明白了：

```
def apply_dock_style(panel):
    """Transform a SubtitleStylePanel that was built with a flat QFormLayout
    into a collapsible-section layout.
    Called AFTER init_ui() completes — all widgets & signals already exist."""
```

流程是：`subtitle_style.py` 先用**旧的扁平 QFormLayout** 造一遍
（段标题是 `QLabel("  基本排版")`，靠两个空格缩进），
然后 `apply_dock_style()` 把控件逐个 reparent 进新容器，最后 `old_widget.deleteLater()`。

- **`subtitle_style.py` 从未导入过任何 Q25 控件。** grep `InspectorRow|SliderSpin|ColorSwatch|SectionHeader` → 零命中。
  这个 2695 行、你点名抱怨「框拉得特别长整个铺满」的面板，本体至今是旧写法。
- **漏接 = 静默销毁。** 任何在 `init_ui()` 里新建、而 `apply_dock_style()` 忘了接的控件，
  会跟着 `deleteLater()` 一起消失。
- **新增参数默认不继承设计。** 加一个控件要改两个文件；只改一个，它要么长得不一样，要么不见了。

**设计不是面板的构造方式，是一道后处理。后处理必然有覆盖不到的角落，
而且角落的数量随功能增长单调递增。**

### 其余五条（证据从略，细节见第六节）

- **令牌只覆盖一座孤岛。** 全 UI 引用 `SPACE_*/RADIUS_*/FONT_SIZE_*` 共 20 处，
  其中 8 处在一个文件里；同期字面量 `setSpacing/setContentsMargins` **157 处**。
  实际在用 **12 种间距值，6 种不在 8pt 栅格上**。
- **QSS 是法外之地。** 颜色 100% 模板化，像素只有 14%。裸 px **338 处**，
  其中 48% 不在 4 栅格上。圆角在用 **12 种**，令牌只定义 3 种，
  而**用得最多的两种（4px 17 次、8px 15 次）恰恰都不是令牌** —— 令牌值脱离实际所以被绕过。
- **排版层级是倒置的。** `inspector.py:630` 给段标题设 13px，
  但 QSS `:757` `QLabel#dockSectionTitle { font-size: 11px }` 覆盖了它（Qt 里 QSS 覆盖 setFont），
  而行标签是 12px —— **段标题比它管辖的行标签还小**。
- **同一个控件三套实现。** 段落容器三套（`collapsible.py:143` / `dock_panels.py:71` / `inspector.py:605`），
  连折叠箭头都是两种字符（`▶` 和 `▸`，同一个窗口里两种三角形）；
  滑条+数值框三套；开关两套（17 处 `labeled_toggle` vs 6 处 `ToggleSwitch`）；
  方形按钮四种尺寸；输入控件六种行高；图标四种尺寸。
- **状态机只做了 hover。** `:hover` 40 处、`:pressed` 8 处、`:focus` 8 处 ——
  焦点环只给了文本输入类，按钮/滑条/复选框/色块/开关**一个 `:focus` 都没有**，键盘走查完全不可见。
  检查器里最显眼的 28×28 色块，鼠标移上去毫无反应（`ColorSwatch` 无 `enterEvent`）。
- **空状态只有两个面板做了。** `transcript.py:556-580` 是**本仓库现成的优秀样板**
  （分「无媒体 / 有字幕但读不出 / 真空」三态，各配文案和动作按钮）；
  `media_list` / `style_gallery` / `sticker_panel` / `recipes` 一个都没有，列表为空就是一片空白。

## 五、preview ≠ export（这个项目反复吃的亏，又出现三处）

- **Q13 音频转场**：只在导出侧生效（`render_worker.py:1766`）。
  `asr/timeline_wav.py` 的预览混音完全不知道 TransitionItem 的存在，也不支持 `fade_curve`。

  而且三条渲染路径（画布预览 / PreviewEngine / 导出）过滤轨道的规则各不相同。
- **Q30 空间立体声**：`_proxy_ready` 为 False 的窗口（预览 wav 还没生成）仍走旧代理轨，
  只渲第一段 —— **你报的「第二段没有立体声」在那个窗口里仍会复现**。

而这次迁移把 g08 那条 clip 从 `False` 翻成了 `True`，
所以 golden 锁的是「功能**开**着导出不变」——
**「不开这个功能时导出音频逐字节不变」这个场景，零覆盖。**
