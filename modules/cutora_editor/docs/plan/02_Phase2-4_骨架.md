# Phase 2 – 4 骨架（Phase 1 验收后再细写）

> 每一项将来都会展开成与 `phase1_tasks/` 同格式的任务书。这里只记"做什么 + 验收一句话"，避免任务书在 Phase 1 实现之前就过时。
> 所有阶段延续三条原则：AI 提议 → 用户确认 → 真实时间线操作 → 可撤销；所有新功能注册为命令并可批量；安全红线不变。

## Phase 3 — AI 协同剪辑

| 编号 | 任务 | 验收一句话 |
|---|---|---|
| P3-01 | "Ask 片语" 命令框：自然语言 → LLM 输出**操作计划 JSON**（只允许 T13 注册的命令）→ 差异预览（将删除/移动的片段高亮）→ 确认 → 执行 → 一次撤销回滚整组 | 不生成 MP4，生成时间线操作 |
| P3-02 | 内置意图库：剪紧凑、去废话、压到 N 秒、挑 N 个 Shorts、套用默认风格、音乐压低、把开头做钩子、统一字幕风格、按说话人分色 | 每个意图有测试用例 |
| P3-03 | Shorts 候选评分：钩子强度（LLM）、完整句边界、时长窗口、静音占比、说话人稳定 → 候选列表 → 一键生成 N 个 9:16 子工程 | 30 分钟视频 → 5 个候选 |
| P3-04 | 本地 TTS（Piper / Kokoro，MIT/Apache，模型自 HF 官方）+ 用户自带 API 的 TTS 提供商；配音轨、与字幕对齐、口播替换 | 意/英/中各一段 |
| P3-05 | B-roll 建议：从用户自有素材库按 transcript 关键词/标签匹配 → 建议列表 → 拖入或一键铺 | 不接在线素材库 |
| P3-06 | 音频 AI 评估：是否引入 RNNoise / DeepFilterNet（MIT/Apache）做更强降噪；与 T07 预设并列 | A/B 盲听 |
| P3-07 | 多语言批量：一个工程 → N 语字幕 → N 版本导出（配方多维度） | 一键 3 语 |
