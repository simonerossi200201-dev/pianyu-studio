# Q169 · 时间线实色色块 / 轨道头把手 / 视频条缩略图（2026-10-05）

Luca：时间线上图片条、文本条、视频条只有一圈描边，分不清；专业软件用色块，又清楚又好看。
参考油画配色「红黄绿蓝」，红换成紫；轨道头颜色也要明显，中等偏低饱和度 / 亮度；字保留白色。
视频条不显示缩略图一定要修。轨道头加个拖拽按钮。

## 颜色（六套主题共用，`resources/theme/palettes/*.json` + `tokens.py`）

| 轨道 | 色 | HSL | fg0 白字对比度 |
|---|---|---|---|
| 视频 | `#405D82` 蓝 | 214° 34% 38% | 5.5 |
| 图片 | `#684B81` 紫 | 272° 26% 40% | 5.9 |
| 文字 | `#7F6230` 赭黄 | 38° 52% 33% | 4.7 |
| 音频 | `#3E6F53` 绿 | 145° 28% 34% | 4.75 |
| 字幕 | `#396A6A` 青绿（铜绿） | 180° 30% 32% | 5.0 |

五个色相两两相差 ≥ 25°。换主题换的是面板底色，轨道颜色语义不变（像专业 NLE）。

## 片段色块（`cutora/ui/timeline/widget.py::_paint_clip_chrome`）

- 填充 = 轨道色，顶→底 +7% / −5% 的轻渐变（有体积感不抢眼）；1px 深 38% 的同色描边把色块从轨道底上切出来；
  一圈很淡的同色浅边（内发光复用原来的 9-slice 缓存，alpha 58）。
- 悬停：整体提亮 8%；选中：提亮 16% + 主题高亮色 2px 描边。
- 预合成组 / 字幕角色色 / 超速提示仍按各自颜色发光（那是另有含义的颜色）。
- 片段上的字一律 fg0（暖白，不是纯白），按剩余宽度省略；视频 / 图片条文件名放在缩略图右边。
- 音频波形改成音频色的浅调（以前是 ok 色，压在绿块上看不清）。

## 视频条缩略图（真 bug）

`_queue_visible_thumbs` 里行高写死 `28` → 请求的尺寸键 (64, 22)；绘制按真实行高（默认 40）查 (64, 34) —— 缓存永远
对不上，视频条从来没显示过缩略图（图片条不走这套缓存所以一直正常）。现在排队和绘制都用 `video_thumb_size(真实行高)`，
改行高后重新排队。顺带：

- 够宽的片段多一张片尾缩略图（像 Resolve 的头尾帧）。
- ffmpeg 抽帧改成铺满后居中裁切（竖版视频以前是黑边 + 中间一条细图）。
- 缩略图四角圆一点、外面一圈 1px 暗边，嵌在色块上。
- 图片条的 `QPixmap(path)` 以前每次重绘整张解码；现在按 (路径, mtime) 缓存一张 160px 高的小图。

## 轨道头（`cutora/ui/timeline/header.py`）

- 每行最左边 14px 一条轨道色「把手」（grip 图标），行底掺 18% 轨道色，名字按钮用轨道色底 + fg0 字。
- 拖把手（行身也行）上下挪：超过 4px 才算拖，拖动中这一行半透明、两行之间出现金色插入线（时间线那边同一条线横穿过去），
  松手落到线的位置；鼠标在上半 / 下半决定插前 / 插后；拖出视觉域范围贴到两头，不会插进音频域；放回原位不发命令。
- `reorder_timeline_track(src, dst, after=False)`：以前只能「插到目标前面」，现在按插入线精确落位；落回原位不记撤销。
- 悬停把手：手形光标 + 提示「越靠上 = 画面里越在底下」。
