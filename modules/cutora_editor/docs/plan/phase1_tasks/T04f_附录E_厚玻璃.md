# T04f 附录 E — 毛玻璃要有"玻璃的厚度"（并入 T04f-2-fix2 同一轮）

> Luca 看过 `bg-glass_frame.png` 之后的原话：「模糊的效果是有了，但是玻璃质感的边缘没有玻璃那种不同切面不同折射角度的玻璃的厚度的感觉。」
> 他说得对。现在的玻璃 = 模糊 + 叠色 + 一条 1 px 的边，那是一块**磨砂亚克力贴纸**，不是一块**有厚度的玻璃**。
> 本附录并入 `T04f-2-fix2`，与撕纸/亚麻同一轮出图、同一轮验片。

## 1. 玻璃之所以像玻璃，靠的是边缘，不是中间

一块厚玻璃板放在画面上，中间确实只是模糊+略微变色；**让人感到"这是玻璃"的全部信息都在边缘 1–2 个字号宽的那一圈**：

| 现象 | 物理来源 | 我们怎么画 |
|---|---|---|
| **边缘折射**：靠近边缘处，玻璃背后的画面被"弯"了一下，且比中间更清晰 | 板边的曲面把光线折向内侧 | 边缘一圈的底图**沿法线向内位移**采样，且用**更弱的模糊**（绝对值 `σ_rim = 0.04 em`，不是主模糊 σ/3） |
| **倒角高光**：迎光那一侧（左上）边缘有一条柔亮的棱，背光侧（右下）是暗的 | 斜切面反射光源 | 按"法线·光方向"给边缘一圈加亮/加暗，是**渐变带**不是 1 px 线 |
| **内圈台阶**：距边缘一个厚度处，还有一条更细的暗线 | 板的下底面边缘 | 距离场上第二条较弱的暗线，就是"厚度" |
| **顶面光泽**：整块面上一道斜的、很淡的白色光带 | 顶面镜面反射 | 20° 斜向线性渐变，白 α 0.10→0 |
| **内阴影**：背光侧内缘略暗 | 厚度遮挡 | 距离场上背光侧一条暗带 |

**不要做的**：色散彩边（容易做过火）、噪点、任何会让边缘出现台阶/圈层的东西。

## 2. schema 新增（`bg` 下，默认值让现有 `glass-white` 直接变好看）

| 路径 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `bg.glass_thickness_em` | 0–0.5 | **0.14** | 边缘那一圈的宽度；0 = 退回现在这种平贴纸 |
| `bg.glass_refraction` | 0–1 | **0.55** | 边缘折射位移强度 |
| `bg.glass_bevel` | 0–1 | **0.7** | 倒角明暗强度 |
| `bg.glass_sheen` | 0–1 | **0.45** | 顶面光泽强度 |
| `bg.glass_light_deg` | 0–360 | **315** | 光源方向（315 = 左上） |

五个字段都要进面板（注册表测试会逼你），放在「背景色块 → 毛玻璃」子组，滑杆显示 0–100。

## 3. 实现（全在 `raster_bg` 的 glass 分支，ROI 内，cv2 + numpy，零新依赖）

几何相关的中间量只依赖 `(rect, radius, thickness, light_deg)`，**按这个键缓存**；每帧只做第 ③ 步的 remap 和合成。

1. **距离场**：圆角矩形 mask → `cv2.distanceTransform(mask, DIST_L2, 5)` 得到每个像素到边缘的距离 `d`；`np.gradient(d)` 归一化得到**指向内部的法线** `n`。
2. **边缘权重**：`w = thickness_em × em`；`t = clip(1 − d / w, 0, 1)`；`k = t²`（靠边缘处最强，向内平滑归零）。
3. **折射采样**：`disp = n × k × refraction × w × 0.6`；用 `cv2.remap` 从**弱模糊底图**（`σ_rim = 0.04 em`，上限约 1.2 px，不是主模糊 σ/3）按 `(x + disp_x, y + disp_y)` 采样，得到 `refr`。最终底图 = `blur_strong × (1 − k) + refr × k`。这一步做完，边缘处的画面会被"弯"进来、且比中间清楚——这就是 Luca 要的"折射角度"。
4. **倒角**：`L = (cos θ, sin θ)`（θ 从 `glass_light_deg` 来，屏幕坐标 y 向下要取负）；`s = dot(n, L)`；加亮 = `clip(s, 0, 1) × k × bevel × 0.55`（叠白），加暗 = `clip(−s, 0, 1) × k × bevel × 0.35`（叠 `#0B1A33`，**不是纯黑**）。这是一条随距离渐变的带，不是线。
5. **内圈台阶**：`k2 = exp(−((d − w) / (0.08 × em))²)`，暗 `k2 × bevel × 0.18`。
6. **顶面光泽**：沿 20° 的线性渐变，从面板上沿 15% 到 55% 位置，白 α `sheen × 0.10 → 0`；`CompositionMode_Screen`。
7. **叠色**：现在的 `bg.color`/`bg.alpha` 最后叠。
8. **原来那条 1 px 三段渐变边**保留但强度减半——倒角带已经承担了它的工作。
9. `bg.fade` 四边渐隐在所有这些之后作用于整个背景层 alpha（与 fix 那轮一致）。

`thickness_em = 0` 时**必须逐字节等于现在的输出**——给一条测试锁住，免得改坏了 `glass-white` 的既有观感基线。

## 4. 质量标准（我按这个验）

- 4× 放大图上：倒角是**平滑渐变**，无台阶；边缘折射处的底图**能看出被弯了一下**、且比中间清晰；无光晕、无振铃（remap 用 `INTER_LINEAR`，边界 `BORDER_REFLECT`）。
- 深底纯色上：玻璃仍应看得出**厚度**（靠倒角 + 内圈 + 光泽），不能变回一个矩形。
- 真帧上：与 `thickness_em = 0` 并排对比，一眼能感到"一块玻璃"与"一层贴纸"的差别。

## 6. 性能

新增成本只在玻璃开启时：一次 `distanceTransform`（缓存）+ 每帧一次 ROI `remap`。停留态命中帧缓存不重算；播放态预计 +1 ms，仍在 8 ms 内。bench 两组照旧写进报告。
