# T11 — 资产库与预设系统：资产包格式、资产库面板、静态画布（封面）模式、首批设计元素/特效/动画/音效/氛围配乐/项目模板

> 前提：T13、T04、T05 完成。先读 `docs/plan/01_GROK_通用规范.md` 与总体计划 §2.7。
> 这是"不再需要打开 Canva"的基础。golden 规则 B。**所有内容必须原创**，不得临摹任何现有模板库；不得使用任何在线素材 API。

## 1. 资产包格式：`cutora/assets/pack.py`

- 资产包 = 目录或 `.cutorapack`（zip）：`pack.json`（id、名称、版本、作者=CUTORA、许可、类别、标签、语言）+ `items/<id>/` 每项：`item.json`（类型、名称、标签、适用比例、参数 schema 与默认值、预览文件）+ 源文件（SVG / JSON / WAV / 模板）。
- 类型：`element`（参数化 SVG 设计元素）、`frame`（边框/相框，SVG，九宫格拉伸）、`card`（多图层组合：形状 + 文本槽 + 图片槽）、`effect`（视觉特效参数集）、`animation`（anim_engine 参数集）、`sfx`、`music`、`template`（整个工程模板）、`stylepack`（T04 的风格包也纳入同一体系）。
- 参数化 SVG：SVG 里用 `{{color.primary}}`、`{{text.title}}`、`{{radius}}` 占位；`item.json` 声明每个参数的类型（color/text/number/bool/enum）、默认值、中文标签。渲染时替换后交 `QSvgRenderer`，缓存位图按（item, params, size）哈希。
- 内置包在 `resources/packs/`，用户包在 `USER_DATA\packs\`；导入/导出 `.cutorapack`。

## 2. 资产库面板：`cutora/ui/panels/asset_library.py`（左栏第三个 Tab）

- 顶部类别 Tab：`元素 · 边框 · 卡片 · 特效 · 动画 · 音效 · 配乐 · 模板 · 我的`；搜索 + 标签筛选 + 比例筛选（竖/横/方/全部）+ 收藏。
- 网格缩略图，悬停：元素/卡片显示大图，动画/特效播放 1.5 s 预览，音效/配乐播放（带波形与时长）。
- 拖到画布 = 添加覆层（元素/边框/卡片 → 图形/图片覆层；已有 PropertyPanel 的变换/层级/混合模式全部可用）；拖到时间线 = 音效/配乐片段；双击特效/动画 = 应用到当前选中图层/片段；双击模板 = 新建工程（确认对话框）。
- "我的"：用户文件夹（图片/视频/音乐/字体）挂载、打标签、收藏；`右键 → 保存为元素`（把当前选中的图层组合存进用户包）。

## 3. 静态画布（封面/缩略图）模式：`cutora/ui/modes/canvas_mode.py`

- `文件 → 新建 → 静态画布`（预设尺寸：1280×720、1920×1080、1080×1080、1080×1350、1080×1920、自定义），或 `导出 → 把当前帧设计为封面`（把当前帧作为底图新开画布）。
- 复用 VideoCanvas + PropertyPanel + 资产库；没有时间线（隐藏）；导出 PNG/JPG/WebP，可选 2× 尺寸；可保存为 `.cutora`（`kind: "canvas"`）。
- 文本图层补齐 Canva 级基本能力（如果 T03/T04 后仍缺）：字距、行距、文本弯曲（沿圆弧，用 QPainterPath 逐字排布）、文本填充图片/渐变、描边渐变。

## 5. 视觉特效：`cutora/render/effects/`

每个特效 = 一个 `(frame: np.ndarray, t, params) -> np.ndarray` 函数 + 参数 schema，作用于片段级或调整层级（本任务只做片段级），进 `FrameRenderer` 的片段绘制之后、覆层之前；关闭时不进链（golden）。首批：亮度/对比/饱和/色温/色调、暗角、颗粒、高斯模糊、锐化、镜头推拉（Ken Burns，参数化起止框）、抖动（可控频率幅度）、闪白、光漏（程序生成的柔光斑）、色差、老电影（划痕 + 抖动 + 褪色）、黑白、双色调、像素化、马赛克区域（含可拖框，隐私打码）、镜像、速度线（漫画感）。
- GPU 不是必需；用 OpenCV/NumPy，每帧 1080p 在 ≤ 8 ms（报告测）。超时的特效标"慢"并在预览里降采样。
- 视频层级 LUT：支持导入 `.cube` 文件（用户自有）——**不内置任何 LUT**（LUT 常有版权）。

## 6. 氛围配乐生成器：`cutora/audio/music_gen.py`

- 程序化、无样本、无版权：合成 pad（多振荡器 + 低通 + 混响，复用 `spatial_ir`）、drone、钢琴/电钢琶音（Karplus-Strong 或 FM 合成简单音色）、心跳/脉冲节奏、风铃随机音列。参数：调性（大/小/多利亚/五声）、BPM、时长、密度、亮度、"情绪"预设（平静/庄严/温暖/紧张/希望）。
- 输出 48 kHz wav，可"再生成一个"（新随机种子，种子存进片段以便复现）。
- 预生成 12 首 60 s 放 `resources/packs/music_ambient/`。
- CC0 曲目包：本任务**只搭骨架**（`music_cc0` 包，空），曲目复核与加入放 Phase 2 P2-00，由 Claude 逐首审 URL/许可证。
