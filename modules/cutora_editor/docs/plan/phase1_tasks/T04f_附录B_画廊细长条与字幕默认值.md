## 1. 画廊卡片重做（取代 §3.1）

### 1.1 几何

- **目标比例 5.6 : 1**（Luca 给的参考图 507×90 = 5.63，我量的）。
- 卡片宽 = 栏宽；高 = 宽 / 5.6。
- **裁切窗口**：宽 = 整幅宽；高 = 宽 / 5.6；垂直中心对齐**字幕 bbox 中心**；上下钳制在画面内。横屏竖屏同一套规则，不再按画幅比例分支。
- **装不下时才降比例**：若字幕 bbox 高度 > 窗口高 × 0.8，就加高窗口直到装得下，比例下限 **2.5 : 1**。**整个画廊用同一个比例**——取所有内置包里最需要的那一个，保证所有卡片等高（`QListWidget` 的 `IconMode` 需要统一 `gridSize`）。
- 卡片**外缘圆角 10 px**，外描一圈 1 px `#2A3242`。缩略图按圆角裁切（`QPainterPath` + `setClipPath`），不要用一张带圆角的遮罩图盖上去。
- 栏宽反推卡片宽：`卡片宽 = (面板可用宽 − 左右边距 − 栏间距×(栏数−1)) / 栏数`。**不要先定死卡片宽再看塞得下几栏**——上一版横屏就是这样只排了一栏、右边空掉一大片。栏数：面板 < 320 px 一栏，否则两栏。
- 「＋ 把当前样式存成风格包」卡片用同一个 `card_size`，比例要和别的卡一致。

### 1.2 背景

- **不模糊、不压暗、不加任何滤镜。** 原帧直接裁。我之前写的「σ = 0.6 em 模糊 + 压暗 35%」整条删掉——那条既是 Luca 不要的，也正是把「毛玻璃·白」渲染成一块灰板的原因（把背景先糊一遍，再放一个靠糊背景出效果的风格上去，当然什么都看不见）。
- 卡片 = **真实渲染结果的一条裁切**，不做任何额外处理。文字看不清是该风格自己的问题（描边/底条/毛玻璃是它们各自的事），不靠画廊帮它们压暗背景。
- **背景帧跟着当前选中的视频走**：用户在媒体列表点了另一个视频，画廊要换成那个视频的一帧并重建缩略图。取帧时刻沿用现在的逻辑（当前播放头；`far_playhead` 判断要不要重取）。媒体列表的选中信号接到画廊的 `reload()`，缓存 key 里加上视频标识，换视频即失效。

### 1.3 样例文字

- 卡片样例保持**一行**：每个包的 `meta.json` 里 `sample` 用 **2–3 个短词**（字号 ×2 之后，长句在竖屏会折成两行，细长条就装不下）。
- 现有的 `"Find its place"` 可以留着，但要实测竖屏 ×2 字号下是否仍是一行；超了就换成两个词。

## 2. 内置风格包默认值：位置与字号（Luca 确认要改成片）

### 2.1 位置：字幕块中心移到画面高度 **58%**

现在 `anchor: bottom-center` + `offset_y_pct: -0.2448` → 字幕中心在 **75.5%** 高度（我用 `t04f0_fix_t1s.png` 量过：框在 y 1561–1637 / 1920，中心 83.3%，对应 glass-white 的 −0.1667，映射关系是 `中心高度% = 1 + offset_y_pct`，对得上）。

**全部内置包改成 `offset_y_pct = -0.42`**（→ 中心 58% 高度，"中间偏下一点点"）。`anchor` 不动，仍是 `bottom-center`，免得牵动 T04e 的几何解析。

改完用三个画幅（1080×1920 / 1920×1080 / 1080×1080）各截一张，量字幕块中心的高度百分比，断言在 **56%–60%** 之间。

### 2.2 字号：`fontsize_pct` **×2**

每个内置包的 `fontsize_pct` 乘 2（例：0.033333 → 0.066667）。用倍数表达，不要去算像素——这样不依赖 `fontsize_pct` 到底乘的是哪个基准维度。

### 2.3 ×2 之后必须解决的溢出（这条同时把 g09 seg3 那个老账收掉）

字号翻倍之后，`max_chars_per_line: 32` 这种写死的值一定会横向溢出（g09 seg3 已经暴露过一次「文字跑出画面」）。

**改成按实测宽度推算，包里的 `max_chars_per_line` 只当上限**：

```
可用宽 = 画幅宽 × (1 - 2 × 安全边距)        # 安全边距默认 0.08
每行最大字符数 = min(包里的 max_chars_per_line,
                    floor(可用宽 / 当前字体在当前字号下的平均字符宽))
```

平均字符宽用 `QFontMetricsF.horizontalAdvance("abcdefghijklmnopqrstuvwxyz") / 26`，按实际字体实际字号算，不要用经验系数。

**测试**：对每个内置包、三个画幅、一条长句（≥ 60 字符），断言渲染后的字幕 bbox **完全落在画面内**且不超出安全边距。这条测试以后任何人改字号都会被拦下。
