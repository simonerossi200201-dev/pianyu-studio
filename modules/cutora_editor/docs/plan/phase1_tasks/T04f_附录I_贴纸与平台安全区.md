## 1. 贴纸

### 1.1 素材与授权（这块出错的代价最大，先定死）

- 只用 **Twemoji**。**不许**打包 Apple / Segoe / 微软 / 三星 等任何系统 emoji 字体或其位图——那些是有版权的。
- Twemoji 图形是 **CC-BY 4.0**，代码是 MIT。**必须署名。**
  - 从你实际取用的那个仓库/版本里**原样复制 LICENSE 全文**进 `resources/stickers/LICENSE-twemoji.txt`，并在 `THIRD_PARTY_LICENSES.md` 里加一条，写明来源仓库、**具体 commit 或 release tag**、许可证名称。不要凭记忆写授权条款，以你下载到的那份文件为准。
  - 如果拿到的版本许可证与上述不符，**停下报我**，不要自行判断能不能用。
- **完全离线**：素材随仓库/安装包分发，运行时**一次网络请求都不许有**。不接受任何 CDN 兜底。
- **不要 vendored 整套 3600+ 个 emoji**（仓库会胖得离谱）。挑一个约 **150–250 个**的常用子集（表情、手势、箭头、星星、爱心、火、勾叉、常见物件），列一份清单进任务报告。
- 素材用 **SVG**；渲染时按目标尺寸栅格化，不要用固定分辨率 PNG 放大。

### 1.2 实现：不要新建子系统

贴纸就是一个**图片元素**。走现有 `draw_image_element` 的 `kind == "image"` 那条路，这样位置、缩放、旋转、不透明度、混合模式、**以及 T04f-2b 那套四边渐隐**全部免费继承，属性面板也不用重做。

只加最小的东西：
- 元素上标一个 `sticker_id`（Twemoji 的 codepoint），渲染时按当前显示尺寸从 SVG 栅格化并缓存（缓存键 = `sticker_id` + 整数像素尺寸）。
- 插入贴纸的命令走总线、可撤销、headless。

### 1.3 UI

- 贴纸面板：分类标签 + 可搜索的网格（按 emoji 的英文名与关键字搜索）。
- 点击插入到画面中心，默认尺寸为画面短边的 12%。
- 插入后就是普通图片元素，用现有控件调整。

### 1.4 动画

本片贴纸只支持 **淡入 / 淡出 / 缩放入**三种，复用 `ANIMS` 里已有的实现，**不要另写一套**。完整动画库接到贴纸上留 T04f-6 之后再议。

## 2. 平台安全区参考层

### 2.1 铁律：这是参考线，永远不许进导出

**必须有一条测试证明它不进成片**：同一工程，开启安全区参考层 vs 关闭，导出结果**逐字节相同**。这条不过，本片直接不通过。

参考层只画在预览画布上，导出路径连读都不该读它。

### 2.2 数据驱动，不许硬编码

各平台的 UI 遮挡区会随 App 版本变，所以：

- 放 `resources/safe_zones.json`，每个预设写明：`name`、`aspect`、四边不安全带的**比例**、以及 `derived_on` 日期和一句来源说明。
- 代码里**不许出现任何魔数**，全部读这份 JSON。
- 面板上标注"参考值，随平台版本变化"——这是给用户的诚实提示，不要让它看起来像精确规范。

预设至少覆盖：YouTube 横屏、YouTube Shorts、TikTok、Instagram Reels、Instagram 方图。

### 2.3 显示

- 不安全区域盖一层半透明暗色 + 边界虚线 + 角上小字标签（"TikTok 底部 UI"之类）。
- 视图菜单里总开关，加每个预设的单独开关；可以同时开多个（取并集时颜色要能区分）。
- 状态持久化走 `user_data`，新键要有默认值，老工程读不到时按"关闭"处理。

### 2.4 一个真正有用的联动

字幕框与任一**已开启**的不安全带相交时，在字幕参数面板上给一条**软提示**（一行文字 + 一个"移到安全区"的按钮，点了就把 `offset_y_pct` 调到刚好避开）。

**只能是提示，不许自动改用户的参数**，也不许阻止用户把字幕放在那里。Luca 的字幕默认在 58% 高度，TikTok 底部 UI 吃掉的区域不小，这个提示会实际用得上。
