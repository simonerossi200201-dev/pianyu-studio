## 三、不可破坏的东西（每条都有测试或验收在盯）

1. **启动顺序**：`init_torch_runtime()` 必须先于任何 `PyQt6` import（`tests/test_runtime_dll_order.py`）；迁移对话框必须在 splash 之前（`tests/test_startup_order.py`）；splash 显示期间不得有任何 `QDialog.exec()`。T03 会大改 `app.py` 的 import 顺序，**这两条测试是硬闸**。
2. **品牌**：窗口标题「片语 Studio」、`app.ico`、splash 背景与其上只画进度文字/进度条的规范（`docs/plan/brand_final/README_接线说明.md` §四）。T03 不许重画任何品牌图。
3. **字体启用的红线**：把 `fonts_pending` 里的 Inter / JetBrains Mono / Noto Sans 注册进 Qt 字体库，可能改变字幕渲染的字体回退 → 可能改变 golden。所以：注册后**立刻**跑 `golden --all --repeat 3`。若有任何 case 变化，**停下写进报告交 Claude**，不许重录基线、不许"顺手"改字幕默认字体。启用的字体各自附许可证并更新 `FONTS_MANIFEST.json` 与 `THIRD_PARTY_LICENSES.md`。
4. **不改渲染、不改 ASR、不改批量算法。** T03 是换皮与重新布局，一行算法都不动。
