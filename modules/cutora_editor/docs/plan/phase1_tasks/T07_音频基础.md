# T07 — 音频基础：响度标准化、人声清理预设、音乐闪避、静音检测

> 前提：T13 完成。先读 `docs/plan/01_GROK_通用规范.md`。
> 全部用 FFmpeg 滤镜实现，**零新依赖**。golden 规则 B（新功能关闭时逐字节一致）。

## 1. 音频处理图：`cutora/audio/graph.py`

把现在散在 `spatial_audio.py` 里的滤镜链构造统一成"每轨一条链 + 总线一条链"的描述对象，最终生成一条 `-filter_complex`。顺序固定：
```
每个音频源: [预处理: 增益/淡入淡出] → [人声清理预设] → [空间立体声(已有)] → 轨道音量/静音
总线:      [音乐闪避 sidechain] → [响度标准化 loudnorm] → [限制器 alimiter] → 输出
```
现有 `resolve_spatial_for_track` 逻辑原样迁入；新节点默认关闭 → 输出不变。

## 2. 人声清理预设：`cutora/audio/voice_presets.py`

用户只看到名字和一个"强度"滑块（弱/中/强），不看到参数：
| 预设 | 链 |
|---|---|
| 播客人声 | `highpass=f=80, afftdn=nf=-25(强度映射 -20/-25/-30), deesser=i=0.3, acompressor=threshold=-18dB:ratio=3:attack=5:release=80, equalizer 轻微 3 kHz +2dB` |
| YouTube 讲解 | 同上但压缩更轻、高频略亮 |
| 采访/讲道（大厅） | `afftdn` 更强 + `anlmdn` 可选 + 低切 100 Hz + 去回声不做（没有可靠 FFmpeg 方案，注明） |
| 电话/录屏 | 带通 300–3400 + 压缩 |
| 仅去噪 | `afftdn` |
| 关闭 | — |
- 预览：选中片段 → 点"试听 5 秒"，后台渲染到 `USER_DATA\cache\preview_audio\`，用 `QMediaPlayer` 播放（已有 `_preview_audio` 机制，迁过来）。
- A/B 对比按钮。

## 3. 响度标准化：`cutora/audio/loudness.py`

- 导出设置里"目标响度"：`-14 LUFS（YouTube/TikTok/IG）`、`-16 LUFS（播客/Apple）`、`-23 LUFS（广播 EBU R128）`、`关闭`；真峰值上限 -1 dBTP。
- 两遍 `loudnorm`（第一遍 `print_format=json` 测量，第二遍带 measured_* 参数），测量结果缓存在工程里（按音频链哈希）。
- `音频 → 分析响度` 显示当前工程整体 LUFS / LRA / 峰值；时间线音频片段上可显示"过响/过轻"标识。

## 4. 音乐闪避：`cutora/audio/ducking.py`

- 音乐轨（轨类型 `music`，新增；或任何轨上勾选"作为背景音乐"）自动被人声轨侧链压缩：`sidechaincompress=threshold=0.05:ratio=6:attack=20:release=400`，UI 暴露"闪避深度"（-6/-12/-18 dB）与"恢复速度"（快/中/慢）。
- 关闭时不进图。

## 5. 静音检测（只出数据，删除在 Phase 2）：`cutora/audio/silence.py`

- `silencedetect=noise=-35dB:d=0.8` 参数可调；结果写入工程 `analysis.silences: [{start,end}]`；时间线上以浅色区块显示；`音频 → 检测静音…` 对话框列出并可"添加标记"。
- 命令 `audio.detect_silence`；Phase 2 的"删除长停顿"直接消费这份数据。

## 6. 音频片段基础
- 片段级：增益（-24…+24 dB）、淡入/淡出（拖片段角上的把手）、静音、声像（L/R）。
- 轨级：音量、静音、独奏（T05 轨头已做，本任务接到音频图）。
- 音量表：预览播放时状态栏/时间线右侧显示 L/R 峰值表（用 `QAudioSink` 的缓冲或 `ebur128` 抽样，轻量即可）。

- [ ] 关闭全部新节点 → golden 七个 case 逐字节一致。

- [ ] 五个人声预设各出一段 10 s 试听（原始/处理后），文件放报告目录，Claude 听。
- [ ] 闪避：人声出现时音乐电平下降到设定深度 ±2 dB（用 `astats` 分段测）。
- [ ] 静音检测在 g03 上找到的区间与人工听感一致（报告列出）。
- [ ] 全部命令注册（`audio.*` ≥ 12 条）；配方里可用（如 `audio.voice_preset.apply {"preset":"podcast","strength":"medium"}`）。
- [ ] pytest：滤镜链字符串生成的快照测试（每个预设/强度组合固定输出字符串）。
