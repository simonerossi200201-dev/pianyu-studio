## 0. 这次要解决什么（先看懂目标，再看切片）

Luca 看过 T04e 之后的结论：风格切换已经正常，但**风格本身太单调**，画廊也不够直观。他给了 16 张专业工具的参考截图，要求做出同等水平的风格与动画库。归纳成四个目标：

1. **画廊要一眼看出风格长什么样**：卡片只显示视频底部三分之一（字幕所在的那一条），字幕占卡片主体，背景压暗，风格差异一眼可辨。
2. **视觉基础要专业**：柔和外发光、毛玻璃、金属渐变、3D 厚字、霓虹、纹理背景、分行圆角气泡……**全部必须细腻柔和，禁止像素感与分层感**（现在的 `holy_glow` 用同心描边叠出来的那种一圈圈的效果，正是反面教材）。
3. **动画库要丰富且可组合**：参考截图里的 None / Box Highlight / Flip Clock / Highlight / Karaoke / Impact / Reveal / Float In / Scale In / Drop In / Impact Pop / Colour Highlight / Rotate & Flip / Rotate & Highlight / Stack / Stomp，加上 Luca 点名的：单词随机大小位置弹出、双词紫青弹出、擦除揭示（大→正常、模糊→清晰）、逐字翻牌、描边→填充、字间距收拢入场、慢速持续缩放、贴纸动画、划线强调、现有的滚动字幕作为一种风格。
4. **两条硬规则**：
   - **纯黑禁令**：文字色、描边色、背景底色、投影色、发光色**一律不许 `#000000` 或接近纯黑**（三通道都 ≤ `0x10` 即视为纯黑）。改用深蓝 `#0B1A33`、深青 `#062E2E`、深酒红 `#3A0A14`、炭蓝 `#141A26` 这类"有色的深色"。内置风格包由测试强制，用户手填的颜色只提示不拦。
   - **圣咏/外发光那一套不要了**：`chant` 风格包重做（衬线 + 金属金渐变 + 深酒红柔影，无发光）；`holy_glow` 动画类型**代码保留**（老工程要能打开，golden 规则 A），但从 UI 列表和所有内置包里移除。

另外新增两个 Luca 明确点名的功能：**平台参考层**（YouTube 16:9 / Shorts / TikTok / IG Reel / IG Story / IG Post 的透明线框叠在预览上，帮用户避开各平台 UI 遮挡区）和**贴纸**（附着在字幕上的小图动画）。

### 1.2 新管线：`cutora/render/textfx/`（v2 渲染路径）

```
cutora/render/textfx/
    __init__.py      draw(painter, event, style, t, video_w, video_h, backdrop=None)   # 唯一对外入口
    spec.py          FxSpec dataclass + from_style(dict) + 校验 + 默认值 + 纯黑检查
    layout.py        Segment.lines + words → LineBox / WordRun / GlyphBox（视频像素坐标；字体、字号、对齐、字距 per run）
    anim.py          动画注册表 ANIMS；unit_progress(t, unit, spec)；错峰(stagger)；seeded 随机
    raster.py        ROI 离屏光栅：fill(纯色/渐变/金属)、stroke、glow、shadow、neon、extrude、glass、texture、bubble
    cache.py         LRU：key=(seg_id, style_hash, 量化后的动画状态) → (QImage, origin)
```

- **入口分支只有一处**：`FrameRenderer.draw_subtitle` 开头  
  `if isinstance(s.get("fx"), dict): return textfx.draw(painter, event, s, current_time, video_w, video_h, backdrop)`  
  没有 `fx` 键 → 走旧代码，一个字节都不改。这就是 golden 规则 A 的保证。
- **所有几何单位相对化**：字号 `fontsize_pct`（T04e 已有）、发光/投影/描边/圆角/间距一律以 **em**（当前字号的倍数）为单位，1080p 与 4K 导出观感一致。时间单位秒。
- **确定性**：`draw()` 必须是 `t` 的纯函数。"随机大小/随机位置"用 `random.Random(hash(segment.id, word_index, spec.seed))`，同一工程每次渲染结果一致，预览 = 导出，golden 可录。
- **ROI 光栅**：每个 segment 只分配"文字包围盒 + 最大外扩（发光/投影/3D 位移）"大小的 ARGB premultiplied `QImage`，**不许分配整帧大小的缓冲**。画完后 `painter.drawImage(origin, img)`，由 painter 现有的 transform 负责预览缩放。
- **缓存**：静态停留态（入场结束、出场未开始、无循环动画）的 ROI 图缓存一次，之后每帧只 `drawImage`；动画进行中每帧重算，但发光/模糊只对 ROI 做。`cache.py` LRU 上限 64 张，工程/风格改变即清空。

### 1.3 模糊与发光的唯一做法

`raster.py` 里只允许一种模糊：把 QImage 以 numpy 视图（`np.frombuffer` + `QImage.bits()`，格式 `Format_ARGB32_Premultiplied`）交给 `cv2.GaussianBlur(src, (0,0), sigmaX=σ)`。σ 以 em 表达（如 `glow.sigma_em = 0.12`）。**禁止**：同心描边叠圈、多方向偏移重绘、`QGraphicsBlurEffect`（需要 QGraphicsScene，慢且预览导出不一致）。

- **柔光 (glow)**：文字 alpha 蒙版 → 膨胀 `spread_em` → 高斯模糊 σ → 用 glow 颜色着色 → 以 `strength` 乘 alpha → 画在文字下方。
- **霓虹 (neon)**：两层：紧的高亮核心（σ 小、颜色偏白）+ 宽的彩色光晕（σ 大），光晕用 `CompositionMode_Screen` 合成；字面本身用略亮于光晕的颜色。附录 A 有参数表。
- **柔影 (shadow)**：同 glow，但只做一次模糊，加偏移 `(dx_em, dy_em)`。
- **毛玻璃 (glass)**：取 `backdrop` 的 ROI → 高斯模糊 σ（em 制）→ 叠一层半透明色（默认 `#0B1A33` α 0.35，**不许纯黑**）→ 圆角裁切 → 描一圈 1px 的渐变边（顶部亮、底部暗，模拟玻璃反光）→ 文字画在上面。`backdrop is None` 时退化成同色半透明圆角框，并在 `logger.debug` 里记一次（不刷屏）。
- **模糊→清晰入场**：对整个 ROI 做 σ 从 `max` 到 0 的高斯，与缩放同步。

### 1.4 底图（backdrop）怎么传

`FrameRenderer.draw_layers(..., backdrop: QImage | None = None)` 加一个关键字参数，一路透传到 `draw_subtitle` → `textfx.draw`。

- 预览：`canvas.paintEvent` 已经持有当前帧图像，传进去（**视频原始像素尺寸**的 QImage，不是显示尺寸）。
- 导出：`render_worker` 有每帧的 numpy BGR 帧，转成 `QImage`（`Format_RGB888`，注意 stride）后传给 `export_renderer.render_frame` → `draw_layers`。只在任务里存在 `fx.bg.type == "glass"` 的字幕时才转换，避免无谓开销（先扫一次任务，缓存判断结果）。
- 没有传 backdrop 的所有旧调用点行为不变。

### 1.7 素材版权（纹理、贴纸、平台线框）

- **纹理**（撕纸 / 亚麻 / 网格）：**全部程序生成**，`tools/gen_textures.py` 用 numpy 噪声 + 固定 seed 生成 `resources/textures/<name>.png`（1024² 灰度 + alpha，平铺无缝），脚本入库，随时可重生成。零外部素材，零版权问题。
- **贴纸**：只用许可证白名单里的来源。选 **Twemoji**（CC-BY-4.0，白名单内）SVG，从官方仓库 `twitter/twemoji` 固定 commit 挑 **60 个**（表情、箭头、星星、火焰、爱心、对勾、问号、灯泡、钱、火箭等泛用类），转成 256² PNG 放 `resources/stickers/`，`SOURCES.json` 记 commit、每个文件 sha256、原始文件名；`关于` 面板与 `NOTICE.md` 加署名（CC-BY 要求）。**不许**用 OpenMoji（CC-BY-SA，不在白名单）、不许用任何来路不明的贴纸包。

### 1.8 性能（T14 的教训：先量再改，只信数据）

- 每个切片交付前跑 `python tools/preview_bench.py`（T14 的脚本）两组：v1 内置包、本切片新增的最重的 v2 包。**v2 静态停留态每帧 `draw_subtitle` ≤ 4 ms（1080p，`CUTORA_PERF=1` 分段计时），动画进行中 ≤ 8 ms。** 超了先找 ROI 是否算大了、缓存是否失效了，再考虑降参数。厚玻璃播放 **dropped 必须 = 0**（T04f-2-fix3 审核）；≤ 10 ms 且 dropped=0 可过。T04f-2-fix4：厚播放 p50 7.42 ms / dropped 0。
- 预览可以在超时（单帧 > 12 ms 连续 10 帧）时**自动降级**：跳过 glow/shadow 模糊、用缓存的静态图；**导出永远不降级**。降级时在预览角落显示一个小标记「⚡预览简化」，日志记一次。
- **不许碰解码器**（`readers.py` / `AsyncVideoDecoder`）。

## 3. 各片细则

### 3.1 T04f-1 画廊卡片（Luca 的原话：只显示底部的三分之一，把顶部多余的三分之二去掉）

- **裁切窗口**：默认取视频帧 **底部 1/3**（`y ∈ [0.667h, h]`）。若该风格的 `subtitle_bbox` 中心不在底部 1/3（例如居中弹出词），则窗口高度仍为 `h/3`，**以 bbox 中心为中心**，上下钳制在画面内。
- **卡片比例**：宽 = 列宽，高 = 宽 × 0.42（接近参考截图）。裁切窗口按"cover"缩放到卡片，超出的左右两侧裁掉。
- **背景处理**：底图先 σ = 0.6 em 轻微模糊 + 压暗 35%（叠 `#0B1A33` α 0.35，不许纯黑），让文字成为主体。
- **样例文字**：短，2–4 个词（`SAMPLE_EN` 改成 `"Find its place"` 这种长度；每个风格包 `meta.json` 可指定自己的 `sample`，比如弹出词风格用 `"WOW"`，气泡风格用两行）。字号按 `fontsize_pct × 1.35` 放大，保证卡片上可读。
- **悬停**：已有 `_hover_tick`，改为循环播放该风格的 `anim.in`（0 → in_s → 停 0.6 s → 重来），静态时显示停留态。
- **两列**布局，窗口窄时自动一列。「＋ 把当前样式存成风格包」卡片保留在最前。
- 缓存 key 加上裁切窗口与 sample，工程换帧时重算（沿用 `far_playhead`）。

### 3.2 T04f-2 视觉效果验收（每一项在附录 A 里有参数与算法）

`tools/fx_contact_sheet.py --project <当前工程> --out D:\0_Dev\CUTORA\build\fx_contact_sheet.png`：对附录 A §2 的每个静态效果，用当前工程的真实帧 + 同一句样例，渲染成 4 列网格，每格下方标效果名与参数。Claude 用这张图验片，重点看：
