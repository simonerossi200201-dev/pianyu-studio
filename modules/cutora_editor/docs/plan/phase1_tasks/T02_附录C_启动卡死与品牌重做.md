# 一、启动卡死在「加载界面…」——不是卡，是弹窗被压在 splash 底下

`cutora/app.py` 312–318 行：
```python
splash_message(splash, "加载界面…")
try:
    from cutora.core.migrate_user_data import prompt_and_import
    prompt_and_import(parent=None)        # ← QMessageBox.exec()，parent=None
except Exception:
    pass
```
`prompt_and_import` 里 `box.exec()` 开的是**模态对话框**，而 `QSplashScreen` 默认带 `WindowStaysOnTopHint`。于是首次启动时：对话框弹在 splash **底下**，用户看不见也点不到，主线程停在 `exec()` 里等一个永远等不到的点击 → 表现为"进度条不动、卡在加载界面"。

**Luca 现在要解开**：按 `Enter`（默认按钮是"是"），或 `Alt+Tab` 切到那个看不见的"导入设置"对话框再回答。

**修法**：
1. 把 `prompt_and_import(...)` 移到 `splash = make_splash()` / `splash.show()` **之前**——首次迁移本来就该在界面出现前问完。
2. 对话框仍要 `raise_()` + `activateWindow()`，并设 `WindowStaysOnTopHint`，双保险。
3. 去掉 `except Exception: pass`——迁移失败必须写 ERROR 日志（这次要不是弹窗，任何异常都会被这三行悄悄吃掉）。
4. 回归测试 `tests/test_startup_order.py`：monkeypatch 记录调用顺序，断言 `prompt_and_import` 在 `make_splash` 之前被调用；并断言 splash 显示期间没有任何 `QDialog.exec()` 被调用。
5. 自查全仓库：启动路径上还有没有别的 `exec()` / `QMessageBox` 会在 splash 期间弹（`load_embedded_fonts` 字体缺失时就会弹——把它也挪到 splash 之前，或改成写日志后退出）。清单写进报告。

# 三、图标：重画，要有寓意、有质感、经得起放大也认得出缩小

Luca 的原话：三版都像"随便乱乱的形状堆砌"、"业余积木"。这个批评是对的——之前那几版只有几何形，没有概念，也没有工艺。

## 3.1 三个新方向（每版都要能一句话说清寓意）

**A · 拱（Arch）**
罗马拱：两根柱 + 拱券 + 正中一块**楔石**（keystone）。楔石用金色点亮。
寓意：**拱靠正中那一块石头立住；一支片子靠关键的那一句话立住。** 拱券的弧线本身就是 CUTORA 的「C」。拱下一道细金线 = 字幕行 / 门槛的光。
质感：石块有极轻的顶部受光斜面与接缝阴影。

**B · 马赛克成句（Tesserae）**
一条由小方块（罗马马赛克镶嵌片）拼成的横带，左段金色"已点亮"、右段石色未亮。
寓意：**碎片拼成话语——"片"成"语"**；点亮的那一段正是逐字高亮字幕。
质感：每片轻微倒角 + 灰缝暗线，尺寸有微小不规则（不要像进度条）。
注意：16px 下容易读成进度条 → 用两行错位排布或轻微弧度化解。

**C · 刻字（Inscription）** ← Claude 推荐
石面上一道**凿刻的 V 形凹槽**：左端是声波的起伏，向右逐渐收拢成一条笔直的刻线。
寓意：**语音被刻成文字**——这正是本软件的核心动作，而且"刻"意味着留存、专业、经得起时间。
质感：V 槽天然有立体感（左上受光面亮、右下背光面暗，取罗马碑刻的打光），槽内可做描金。

## 3.2 工艺规则（不遵守就还是"业余积木"）
1. **先剪影，后质感。** 纯黑剪影版必须在 16px 一眼认出；立体和材质只是叠在上面的一层，**永远不能承担识别功能**。报告里必须附剪影版作为证明。
2. 光源固定左上 45°，全套一致。
3. **质感预算**（超了就腻）：内斜面 ≤ 2px@512；渐变亮度跨度 ≤ 18%；一道柔和内阴影；一道 1px 顶部高光；可选 2–4% 颗粒噪点，只加在图形面上。**禁止**：外投影、Web2.0 果冻高光、塑料反光、多重描边、彩虹渐变。
4. 描边粗细最多两档；几何落在网格上；对齐用视觉对齐而非数学居中。
5. 图形四周留白 ≥ 画布 8%，不许顶到圆角方块的边。
6. **禁止**任何"圆形被斜线贯穿"的构图（= 禁止符号）。
7. 全部原创；不得临摹任何现有软件图标或任何具体的罗马建筑照片。

## 3.3 交付
每版五张：`512 深底` / `512 浅底` / `512 单色` / `16px 放大 8 倍对照` / `纯剪影`。全部摆在报告最上面，并各写一句寓意说明。默认接 **C** 进软件，等 Luca 定。

# 四、Splash：换掉纯黑背景，做"罗马的光"

## 4.1 背景（原创矢量 / 程序生成，不许用照片、不许描摹任何现有图像）
主方向：**黄昏的石与光**。
- 底：`bg0 #141210` 的暖石色，**不是纯黑**。
- 左上角一片极柔的暖光晕（从 `#3A2A18` 到透明，像晚照打在石灰华上），亮度跨度控制在 12% 以内。
- 中远景：一排**通用的罗马拱券 / 柱廊**剪影，透视向右退去，不透明度 6–10%——只做气氛，绝不抢文字。**画的是"拱与柱"这种通用形式，不是某个可辨认的具体建筑。**
- 一道细的古金水平线作地平/分隔，位置落在三分线上。
- 2–3% 胶片颗粒铺满，去掉数字感的"干净得发假"。
- 右下角可有一块极淡的石灰华纹理（程序生成的大理石脉络，对比 ≤ 8%）。

## 4.2 排版（简约但不空洞）
- 12 栏网格。左 5 栏放图标（图标外围留足呼吸），中间一道 1px `line` 竖向分隔，右 7 栏放文字块。
- 文字块自上而下：`片语 Studio`（fg0，大字）→ `CUTORA`（accent，小号、字距放宽 0.15em）→ 标语（info 铜绿，中号）→ `v7.0.0`（fg2，小号）。
- 底部进度槽横贯，`bg2` 槽 + `accent` 填充，高度 4px，两端圆角。
- 进度文字（"加载字体…"）放在进度槽正上方左对齐，`fg1`，不要浮在中间。
- 四周外边距 ≥ 64px；文字块内部行距按 8pt 网格。

## 4.3 标语：换掉 T02 原文那句中英直译
那句失败在于它是英文口号的直译——抽象、没有动作感、像机翻。
四个候选，**Luca 选一个**（报告里把四句都排进 splash 各出一张图，让他看着选）：
1. **「先听懂，再剪辑。」** / *Understand first. Then cut.* ← Claude 推荐：一句话说清本软件与 Premiere 的根本差别
2. **「让每一句话，找到它的位置。」** / *Every word finds its place.* ← 与拱 / 马赛克的寓意呼应，更有温度
3. **「从一句话，到一部作品。」** / *From a sentence to a story.*
4. **「碎片成句，句成篇。」** ← 最贴"片语"二字，但英文难对译

关于框、快捷方式说明等处同步换。
