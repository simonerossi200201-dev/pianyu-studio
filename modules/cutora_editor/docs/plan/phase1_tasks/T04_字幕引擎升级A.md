## 1. 数据模型：`cutora/subtitle/model.py`

把散落在工程 JSON 里的 `segments` 正式化（不改现有字段名，只加类型与访问器）：
```python
@dataclass
class Word:   text: str; start: float; end: float; score: float | None
@dataclass
class Segment: id: str; start: float; end: float; text: str; words: list[Word]; speaker: str | None; lang: str | None; style_ref: str | None; locked: bool
```
- `locked=True` 的句子不被自动断行/时间轴优化改动（用户手改过）。
- 读写函数保证与现有 `deserialize_render_task` 完全兼容（多出的字段可缺省）。

## 2. 字幕文件进出口：`cutora/subtitle/formats/`

| 格式 | 读 | 写 | 备注 |
|---|---|---|---|
| SRT | ✓ | ✓ | UTF-8 with/without BOM 都读；写默认 UTF-8 无 BOM，可选 BOM |
| WebVTT | ✓ | ✓ | 读时忽略 STYLE/REGION 块；写支持位置行 `line:` |
| ASS/SSA | ✓（只取 Dialogue 文本与时间，样式转成默认） | ✓（把当前风格的字体/大小/主色/描边/阴影/位置映射为 ASS Style；卡拉OK逐字用 `\k` 标签导出，一版即可） | |
| TXT | ✓（纯文本，按句切分，等待对齐；用于"先有文案再对齐"的场景，对接 `script_stitcher` 的文案格式） | ✓ | |
| JSON（片语原生） | ✓ | ✓ | 含 words/speaker/lang |

入口：`字幕 → 导入字幕文件…`（替换当前 / 追加 / 新建字幕轨）、`字幕 → 导出字幕文件…`；导出对话框（T08）里加"同时导出 SRT/VTT 侧车"复选。时间码解析必须容忍 `,` 与 `.` 毫秒分隔、缺省小时位。写 pytest：往返（读 → 写 → 读）等价；20 个畸形样本不崩溃。

## 3. Transcript 面板：`cutora/ui/panels/transcript.py`

左栏新 Tab "字幕文本"：
- 每句一行卡片：时间码（等宽字体）、文本（可编辑，`QPlainTextEdit` 行内）、说话人标签（Phase 2 才有数据，先显示占位）、CPS 徽章（超标变 warn 色）、锁定图标。
- 播放时当前句高亮并自动滚动；点击句 → 播放头跳到句首；双击 → 进入编辑。
- 编辑文本后：若该句有 words，用**最长公共子序列**把旧 words 的时间映射到新文本（改错字不丢时间），映射不到的词按字符长度在句内线性插值；改动后 `locked=True`。
- 右键：合并到上一句 / 下一句、在光标处拆分（时间按字符比例切）、删除句（只删字幕，不动视频——删视频是 Phase 2）、锁定/解锁、跳到时间线。
- 顶部：查找/替换（支持正则开关、区分大小写）、"全部大写/首字母大写/全部小写"、"移除句末标点"、"批量替换词典"（导入两列 CSV）。
- 全部操作进 `HistoryManager`（可撤销）。

## 4. 智能断行与阅读速度：`cutora/subtitle/layout.py`

`break_lines(segment, rules) -> list[str]`，规则对象保存在风格包里：
- `max_chars_per_line`（默认：拉丁 42、CJK 16）、`max_lines`（默认 2）、`balance_lines`（两行长度尽量均衡）
- 拉丁：只在空格处断，标点优先（`, . ; : — …` 之后），不拆数字/连字符词；避免行尾冠词/介词（a, the, of, in, e, di, il, la…，列表按语言在 `resources/data/linebreak_<lang>.json`）。
- CJK：不在标点前断；不拆引号、书名号内短语；可在逗号句号后优先断。
- 泰/高棉等无空格且无 ICU：按 `max_chars` 硬切（标记"近似"）。
- `cps(segment)`：字符数 ÷ 时长；阈值默认拉丁 17、CJK 9（可在风格包改）；面板与时间线上都标警告，`字幕 → 检查阅读速度` 列出全部超标句并可"自动延长显示时间（不超过下一句开始 - min_gap）"。

**渲染层**：现在的换行由 `FrameRenderer` 内部处理；本任务把"行文本"作为输入交给渲染器（`segment.lines`），渲染器若发现 `lines` 存在就直接用，不存在则走旧逻辑——这样旧工程逐字节不变（规则 B）。

## 5. 时间轴优化：`cutora/subtitle/timing.py`

`optimize_timing(segments, opts)`：最短显示 `min_duration`（默认 1.0 s）、最小间隔 `min_gap`（默认 0.08 s，两句间隔小于此则贴合）、最长显示 `max_duration`（默认 7 s，超长拆句）、`extend_to_next` 让句尾延到下一句前 `min_gap`（按 CPS 需要才延）、镜头切换处对齐（Phase 2 有场景检测才做，本任务留参数）。可撤销；对 `locked` 句跳过。入口 `字幕 → 优化时间轴…` 带预览对话框（前后对比列表）。

## 6. 风格包与画廊：`cutora/subtitle/stylepack.py` + `ui/panels/style_gallery.py`

- **风格包 = 一个目录**：`style.json`（现有 SubtitleStyle 全部字段 + `layout_rules` + `keyword_rules` + `animation` + `version`）、`preview.png`（自动生成：在 480×270 的深/浅两种示例帧上渲染"片语 Studio · 让每一句话，找到它的位置。"示例文字）、`meta.json`（名称、标签、适用比例、作者=CUTORA、许可）。
- 内置目录 `resources/stylepacks/`，用户目录 `USER_DATA\presets\stylepacks\`。现有 `preset_manager` 的三类预设（文本/字幕/关键词）保留读取，并提供"转换为风格包"。
- 画廊面板（快速模式右栏默认）：缩略图网格、标签筛选（竖屏/横屏/讲道/播客/教程/新闻/语录/极简/霓虹）、悬停播放 1.5 s 动画预览（用 `PreviewFxWorker`）、点击即应用到当前工程、"保存当前为风格包"、导入/导出 `.cutorastyle`（zip）。
- **首批内置 12 套**（全部原创，名字不得含任何平台或品牌名）：
  `极简白` `字幕条·黑` `琥珀高亮`（逐字卡拉OK，主色 accent）`圣咏`（衬线、金色描边、柔光，宗教内容）`播客卡片`（圆角底卡 + 说话人色块位）`新闻下横条` `弹跳词`（弹力条）`霓虹` `打字机` `手写引言` `教程强调`（关键词规则示例：数字/专有名词）`双语上下`（为 Phase 2 双语预留：主字幕 + 副字幕位）。
  每套要在竖屏与横屏上都好看；用 T00 的素材渲染 12×2 张截图放报告。
