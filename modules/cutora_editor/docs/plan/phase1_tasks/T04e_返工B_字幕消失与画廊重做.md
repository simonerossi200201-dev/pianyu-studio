## 1. 一个一分钟就能分辨的判定

我读了 `resources/stylepacks/*/style.json`，最大嫌疑很具体：

```json
"pos_x": 540,  "pos_y": 1480      // chant
"pos_x": 540,  "pos_y": 1450      // minimal-white
```

**这是写死的绝对像素坐标，按 1080×1920 竖屏画布算的。** 如果 Luca 当前工程的画布不是 1080×1920（比如 1920×1080 横屏，或者他在新建工程时选了别的尺寸），`pos_y = 1480` 就落在画面底边之外——**字幕被画到了画布外面，所以什么都看不见**。

**判定方法**（让 Luca 点一下就知道，或者你自己用两个不同画布尺寸的工程各试一次）：
- `极简白` 的 `anim_in_type` 是 `none`，`圣咏` 是 `holy_glow`。
- **如果 `极简白` 也让字幕消失** → 与动画无关，就是**坐标越界**，按 §2 修。
- **如果只有 `圣咏` 消失、`极简白` 正常** → 是 `holy_glow` 这个入场动画类型在当前时间点算出了"不可见"，去查 `anim_engine` 对它的处理。
- 同时把当前工程的画布尺寸（`task` 里的 `canvas_w/h` 或等价字段）打进日志，和 `style["pos_y"]` 一起贴进报告。

**另外先把眼睛打开**：`cutora/ui/canvas.py` 的 `paintEvent` 里是
```python
except Exception as e:
    print("[PaintError]", e)
```
——任何绘制异常都被吞成一行 print，**结果就是"东西悄悄不见了"而不是报错**。改成带 traceback 的 `logger.exception(...)`，并且在 `CUTORA_PERF=1` 或调试开关下把这类错误显式抛出来。这一条不管根因是什么都要做，否则以后每个绘制 bug 都要靠肉眼猜。

## 2. 真正的修法：风格包里的位置必须是相对的

不管这次是不是坐标越界，**绝对像素坐标本身就是设计缺陷**：一个包只能在它被制作时的画布尺寸上正确工作，用户换个画幅就废了。

- `style.json` 里的位置改成**相对值**：`pos_x_pct` / `pos_y_pct`（0–1，相对画布宽高），或者「锚点 + 偏移」（`anchor: "bottom-center"` + `offset_y_pct`）。**后者更好**，因为竖屏和横屏的"贴底居中"是同一个意图。
- 字号同理：`fontsize` 也是按 1080 宽写死的，换画幅会忽大忽小。改成**相对画布宽度的比例**（例如 `fontsize_pct: 0.035`），渲染时乘以实际宽度取整。
- 载入旧格式（绝对值）时按 1080×1920 折算成相对值，保证已存的用户包不失效。
- **加一条测试**：同一个风格包分别应用到 1080×1920、1920×1080、1080×1080 三种画布，断言字幕的包围盒**始终完全落在画面内**，且相对位置一致。这条测试先写、先红。

## 3. 画廊重做：缩略图直接画在用户自己的画面上

Luca 的原话：**「这风格库太不直观了，为什么还要分成上下两屏的形式很占地方」**。他说得对——上下两半（深色 / 浅色示例）是我上一轮定的方案，用意是展示两种底色下的可读性，但对**挑风格**这件事来说它既占地方又不直观。

改成：**每个缩略图直接用当前工程的一帧真实画面渲染**。
- 取当前播放头附近的一帧（有字幕的时刻优先），把每套风格渲上去，缩到卡片大小。**这样画廊显示的就是"我的视频套上这套风格长什么样"**，一眼就懂，也不需要深浅两半了。
- 没有打开工程时，退回用一张打包的中性示例帧。
- 缩略图**按需生成 + 缓存**（键 = 包 id + 帧的时间戳 + 画布尺寸），不要每次打开面板都重渲一遍；工程切换或播放头移动很远时失效重算。
- 卡片下面只留包名，别的都去掉。

## 4. 「保存自己的风格」要让人看得见

Luca 问：**「以后用户能不能自己添加并保存风格？」** —— **这个功能其实已经有了**（画廊顶部的 `导入` / `导出` / `保存当前`），但他用了半天没意识到。功能存在而用户看不见，等于没有。

- 在网格**最后加一张卡片**：`＋ 把当前样式存成风格包`，样式与其他卡片一致但用虚线边框。点它弹一个小对话框填名称与标签。
- 顶部那三个按钮保留，但把 `保存当前` 改名为更明确的 `保存当前样式为风格包`。
- 用户自己的包在卡片角上打一个小标记（区别于内置），右键可**重命名 / 删除 / 导出**。
- 文档里写一句：用户包存在 `USER_DATA\presets\stylepacks\`，可以整个目录拷给别人，或用 `导出` 生成 `.cutorastyle` 单文件。
