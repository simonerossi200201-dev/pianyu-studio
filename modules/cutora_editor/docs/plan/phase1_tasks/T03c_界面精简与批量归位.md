## 二、多选 + 右键批量（这条最影响效率，要仔细做）

**媒体库**：
- 开 `ExtendedSelection`：`Ctrl` 点选、`Shift` 范围选、`Ctrl+A` 全选。
- **必须先厘清"勾选框"与"选中态"的关系**（现在每项前面有勾选框）：
  - **目标集 = 勾选项**；若一个都没勾，则**目标集 = 当前选中项**。
  - **源 = 右键点中的那一项**（不论它是否在目标集里；若它在目标集里，执行时自动排除自己）。
  - 菜单项文字必须把这两件事写出来，不能让人猜：
    `以「T007.mp4」的字幕样式套用到 3 个视频`
    `以「T007.mp4」的轨道共享到 3 个视频…`
    目标为 0 时该项禁用，tooltip 写「请先勾选或选中目标视频」。
- 右键菜单里这两项单独成组，放在现有项（导出首帧/删除/重命名…）下方，用分隔线隔开。
- 执行前弹一次确认，列出源、目标数量、将要覆盖的内容；执行后状态栏提示结果。**必须可撤销**（走 `push_undo`）。

> 与后续任务的衔接：T13 会把这些做成命令总线上的命令。**本任务先把 UI 与逻辑做对，函数签名写成 `(source_id, target_ids, options)` 这种纯参数形式**，T13 直接包一层即可，不要把逻辑写死在菜单回调里。

## 三、快速模式补齐

1. **自动字幕必须有进度**（现在点了没有任何反馈，用户不知道跑没跑）：
   在四步工具带下方加一条细进度条 + 一行状态文字（`正在识别… 45%`），接 `AlignmentWorker.progress` / `error`（错误条 T03a 已经接好，复用）。**专业模式也要有**——检查现在是否只有专业模式有、快速模式没有，两边统一。导出时同样显示（复用同一条）。
2. **右侧字幕样式不能只剩「基本排版 + 配色」**。快速模式至少要有：
   - `基本排版`（已有）

   其余高级分区（阴影发光、多层描边、音谱动画…）仍只在专业模式出现。

## 四、「逐词出现」开关（不是新功能，是暴露已有能力）

`cutora/render/anim_engine.py` 已有动画类型 `("节奏逐词", "metronome")`，`subtitle_style.py` 里已有 `metro_group` / `metronome_bpm`，只是埋在动画类型下拉里、名字不直白。

做法：
- 在「字幕排版」分区里加一个开关 **`逐词出现`**（一个词一个词地蹦出来）。打开 = 把动画类型设为 `metronome` 并展开原有的 `节奏逐词参数`（BPM 等）；关闭 = 恢复到用户上一次的动画类型（记住旧值，别粗暴设成"无"）。
- **不要新写渲染逻辑**，不要动 `compute_metronome_word_visible`。golden 必须不变。
- 旧工程里已经选了 `metronome` 的，打开面板时这个开关应显示为已开启。

## 五、右侧面板宽度自适应

现象：面板宽度拖不动 / 拖了内容也不跟着展开，参数挤在一起。

## 六之二、时间线区域（Luca 补充反馈，两条都要修）

### 1. 轨道下方一大片无意义的黑区
现象：轨道只排到 `Video 5`，其下约 200px 全是纯黑，横向滚动条和「总时长」被推到这片黑区的最底部。

要求：
- 时间线画布高度 = **轨道实际总高**，不要向下无限延伸出空洞。
- 横向滚动条紧贴最后一条轨道下方，不要漂在黑区底部。
- 轨道区域比画布短时，下方留白用 `bg1`（而不是纯黑），并且这片留白**可点击用于取消选择**，不是死区。
- 顺带看一下：新建空工程时默认给了 5 条视频轨 + 若干文本轨，对只放一条视频的用户是噪音。**默认轨道数减到「1 视频 + 1 字幕 + 1 音频」**，其余按需 `+` 添加（`+` 按钮已在轨头）。这条改动要确认不影响 `script_stitcher` / 批量插图那些会往固定轨道号写数据的代码——**如果有代码假设了轨道索引，就不要改默认轨道数，只在报告里说明原因**。

### 2. 时间线只有中间一个小点能拖动
现象：编辑区与时间线之间的分隔，只有正中间那个「⋯⋯」小把手能拖，整条边拖不动。

根因方向：T03b 把 Dock 标题栏换成了 6px 把手（`setTitleBarWidget`），结果**可拖区域缩成了那个把手控件本身**；真正的 `QMainWindow` 分隔条（separator）命中区又太窄。

要求：
- `QMainWindow::separator` 在 QSS 里给到 **6px 高 / 宽**，hover 时变 `accent`，光标切成 `SplitVCursor` / `SplitHCursor`。
- 自定义把手控件**横向铺满整条边**（不是居中一小截），高度 6px，中间画三个点作为视觉提示即可——**视觉是点，命中区是整条**。
- 三个 Dock（左/右/时间线）都要能从整条边拖动；左右面板同样适用（配合 §五 的宽度自适应）。
- 验收：在边缘任意水平位置按下都能拖动，不用去找那个点。

## 八、皮肤（配色方案）切换

T03a 已经把颜色收进 `cutora/ui/theme/tokens.py`，并由 `tools/build_qss.py` 生成 QSS——所以换肤就是换一组 token 再重新生成一次，**不要另起一套样式系统**。

### 8.1 主题定义
- 每个主题 = 一份 JSON，放 `resources/theme/palettes/<id>.json`，字段与现有 token **完全一致**（`bg0..bg3` / `line` / `fg0..fg2` / `accent` / `accent_hi` / `accent_dim` / `info` / `ok` / `warn` / `err` / 五个轨道色），外加 `name_zh` / `name_en` / `is_dark`。
- `tokens.py` 改成从当前主题 JSON 载入；`罗马金` 就是现在这套值，**一个数都不许改**（它是默认，也是回归基准）。
- **中性色跟着主题一起换，不要只换强调色**：暖金配暖石、冷蓝配冷灰，否则蓝紫色放在暖棕底上会发浑。

### 8.2 内置六套（全部深色）
| id | 中文名 | 性格 |
|---|---|---|
| `roma-gold` | 罗马金 | 默认，现状 |
| `midnight-blue` | 午夜蓝 | 冷灰底 + 钢蓝 |
| `amethyst` | 紫晶 | 冷灰底 + 紫罗兰 |
| `rose` | 玫瑰 | 微暖灰底 + 玫瑰粉 |
| `pine` | 松绿 | 中性灰底 + 松针绿 |
| `graphite` | 石墨 | 纯中性，无彩色强调（给不想要颜色的人） |

`is_dark` 字段现在全是 true，但结构要留着——以后加浅色主题不用改代码。

### 8.3 对比度必须验证（这条不能省）
新增 `tools/check_theme_contrast.py`，对每套主题校验：
- `fg0` on `bg1` ≥ **7:1**
- `fg1` on `bg1` ≥ **4.5:1**
- `fg2` on `bg1` ≥ **3:1**
- `accent` on `bg1` ≥ **3:1**（UI 元素/大字标准）
- `accent` 上的文字（按钮实心态）与 `accent` 底 ≥ **4.5:1**
任一不达标 → 脚本非零退出。**这个检查进 pytest**，以后谁加主题都过不了这一关就合不了。粉色和紫色最容易踩这个坑。

### 8.4 运行时切换（不要求重启）
- `设置 → 外观`（新页，放在第一位）：六个色卡缩略图（每张画一个小按钮 + 一段文字 + 一条轨道，直观），点选即时生效。
- 生效动作：重新生成 QSS 字符串（**在内存里生成，不要只能写文件**）→ `app.setStyleSheet()` → **清空 `cutora/ui/icons.py` 的图标缓存并重新着色**（图标是按颜色缓存的，不清会留着旧色）→ 刷新时间线轨道色 → 刷新自绘控件（`ToggleSwitch`、波形、播放头等凡是硬取 token 值的地方）。
- 选择存进设置，下次启动沿用。
- 底部加「恢复默认（罗马金）」。
- **可选加分项**：`自定义强调色` 取色器，选一个颜色后自动推导 `accent_hi`（提亮 18%）/ `accent_dim`（压暗 30%），推导完同样跑 8.3 的对比度校验，不达标就提示并拒绝。

### 8.5 红线
1. **品牌不跟着换。** 应用图标、splash、关于框里的标志**永远是金色的那枚**——那是品牌资产，不是主题色。Grok 不许给它重新着色。
2. **不许影响导出。** 字幕颜色、覆层颜色来自工程数据，与界面主题无关。切完主题必须跑 `golden --all --repeat 3`，**任何一个 case 变化都说明主题污染了渲染路径**，停下报告。
3. 主题只动界面，不动 `resources/stylepacks`（T04 的字幕风格包）和资产库素材色（T11）——**这三样是三回事，不要在代码里混用同一组常量**。

### 8.6 与后续任务的衔接
T13 落地后注册为命令 `app.theme.set(theme_id)`；本任务把切换逻辑写成 `apply_theme(theme_id) -> None` 的纯函数，菜单/设置页只是调用方。
