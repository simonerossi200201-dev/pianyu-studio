# T03 — 设计系统与新界面外壳：主题、布局、快速/专业模式、快捷键、欢迎页

> 前提：T02 完成。先读 `docs/plan/01_GROK_通用规范.md` 与总体计划 §3。
> 目标是"换皮 + 分层"，**每一个既有面板的功能都必须原样可用**，只是被重新安置。golden 规则 A。

## 1. 设计系统 "Studio Graphite"

写成 `cutora/ui/theme/tokens.py`（单一事实源）+ 由它**生成** `theme_dark.qss`（写一个 `tools/build_qss.py`，用 Jinja2 模板渲染，不要手写两份）。

### 1.2 尺寸与字体
- 8pt 网格：间距 4/8/12/16/24/32；圆角 6（控件）/10（卡片）/14（对话框）。
- 字体：界面 `Inter`（拉丁）+ `Noto Sans SC`（中文），13px 正文 / 12px 次要 / 15px 标题 / 20px 页标题；等宽 `JetBrains Mono` 用于时间码。三者均 OFL，放 `resources/fonts_ui/` 并附许可证。
- 图标：Lucide（ISC），只取用到的 SVG，放 `resources/icons/lucide/`，通过 `cutora/ui/icons.py::icon(name, color)` 按 token 颜色着色（QSvgRenderer + QPainter 换色，缓存）。删除旧 `resources/icons/*.svg` 里被替代的。
- 控件：`QToolButton` 扁平、悬停 bg3、按下 accent_dim；输入框 bg2 + line 边 + 聚焦 accent 边；滑块轨道 line / 填充 info；复选用 `ToggleSwitch`（已有）；下拉菜单 bg1 + 圆角 + 阴影。
- 动效：面板展开/收起 150ms ease-out；不做任何会拖慢渲染线程的动画。

### 1.3 兼容
旧 `legacy.qss` 删除；旧代码里内联的 `setStyleSheet("color:#fff…")` 逐个改成用 token（grep `setStyleSheet(` 全部处理，报告列数量）。

## 2. 布局

```
┌──────────────────────────────────────────────────────────────────────┐
│ 标题栏：logo · 片语 Studio · 项目名        [快速模式 | 专业模式]  ⚙  ?   │
├──────────────────────────────────────────────────────────────────────┤
│ 快速工具带（仅快速模式）： ① 导入  →  ② 自动字幕  →  ③ 选风格  →  ④ 导出 │
├────────────┬─────────────────────────────────┬───────────────────────┤
│ 左栏(Tab)  │           预览画布              │  右栏 检查器(Tab)      │
│ 媒体库     │  (VideoCanvas，安全区叠加开关)  │  字幕样式 / 属性 /     │
│ 字幕文本   │                                 │  角色 / 关键词 / 字块  │
│ 资产库(T11)│  播放控制条 + 时间码 + 缩放      │  音频效果              │
├────────────┴─────────────────────────────────┴───────────────────────┤
│ 时间线（TimelineContainer；轨头 + 轨道 + 标尺 + 缩放）                   │
├──────────────────────────────────────────────────────────────────────┤
│ 状态栏：GPU/显存 · 任务进度 · 自动保存时间 · 版本                        │
└──────────────────────────────────────────────────────────────────────┘
```
- 用 `QDockWidget`（可拖、可隐藏、布局可保存到 settings，`视图 → 重置布局`）。
- **快速模式**：左栏只显示"媒体库"，右栏只显示"风格包画廊"（T04 提供；本任务先放"字幕样式"面板的精简版：字体、大小、颜色、位置、预设下拉），时间线折叠成一条缩略轨（可展开）。
- **专业模式**：所有面板全部出现，等价于现在的功能面。
- 模式记忆在 settings；首次启动默认快速模式。

## 3. 菜单与快捷键

菜单重排为：`文件 · 编辑 · 视图 · 字幕 · 音频 · 批量 · 导出 · 性能 · 帮助`。原"脚本"菜单的三个功能（片段智能拼接、片段散落、批量插图）+ 工程队列 + 自动拆分 → `批量`。原"音效"→`音频`。
快捷键（`cutora/ui/shortcuts.py` 集中定义，`帮助 → 快捷键` 列表对话框）：
```
Space 播放/暂停   J/K/L 倒放/停/正放（本任务只做 K/L，J 在 T05）
← → 前/后一帧    Shift+← → 前/后 1 秒    Home/End 首/尾
S 在播放头分割（T05 实现，本任务注册）  Del 删除选中  Ctrl+Z/Y 撤销重做
Ctrl+S 保存  Ctrl+Shift+S 另存  Ctrl+O 打开  Ctrl+N 新建  Ctrl+I 导入媒体
Ctrl+E 导出  Ctrl+Shift+E 批量导出  M 添加标记（T05）  Ctrl+, 设置
Tab 切换快速/专业模式   F 全屏预览   +/- 时间线缩放
```

## 4. 欢迎页

无项目时显示 `WelcomePage`：左侧"新建项目（竖屏/横屏/自定义）"、"打开项目"、"最近项目"列表（缩略图 + 名称 + 时间）；右侧三张"3 步出片"引导卡；底部"导入 AutoSub v6 设置"（复用 T02 迁移）。拖入视频到欢迎页直接新建项目并进入快速模式。

## 5. 设置对话框

`设置`（Ctrl+,）分页：`通用`（语言占位、模式、自动保存间隔占位）、`性能`（并行进程数、GPU 开关、显存信息——原性能菜单内容搬进来，菜单保留入口）、`AI 提供商`（T09 填充，本任务放空页）、`路径`（模型、缓存、FFmpeg）、`快捷键`（只读列表）。

## 7. 不要做

- 不改渲染、不改时间线交互逻辑（T05）。
- 不改字幕算法。
- 不引入 QML / Qt Quick；坚持 QWidget + QSS。
- 不引入任何第三方 UI 库（`qt-material`、`qdarkstyle` 等都不要，自己的 token 系统足够）。
