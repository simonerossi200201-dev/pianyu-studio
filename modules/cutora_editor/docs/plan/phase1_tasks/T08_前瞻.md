## (a) 「跟源尺寸」编码参数

名字已经诚实（跟宽高/帧率/采样率，不是画质），行为仍是 CRF 0 / QP 0 + yuv420p。

**T08c 已改成 CRF 15 / NVENC CQ 15。**
