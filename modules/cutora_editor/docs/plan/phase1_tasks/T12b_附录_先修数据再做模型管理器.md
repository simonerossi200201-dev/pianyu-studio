## 提交 2：`fix(T12a): detect language before recognising, not after`

现在是整段识别跑完才提示低置信——用户已经把一两分钟花掉了。改成：

- **单文件路径**：先调 `asr.detect_language`（只听前 30 秒）。置信度 ≥ 0.6 → **不打扰，直接开始识别**；< 0.6 → 弹一次确认框（下拉预选检测结果 + 置信度百分比 + "仍然使用"/"改为…"两个出口），确认后再识别。用户在菜单里显式选了具体语言时，**不做检测也不弹窗**。
- **批量路径**：**一律不弹窗**。检测结果与置信度写进批量结果表两列；置信度 < 0.6 的行标 `warn` 色；用户可以改这些行的语言后**只重跑标黄的行**。
- 阈值 0.6 写进设置（`asr.detect_confidence_threshold`），默认 0.6。
- 测试：mock 一个返回低置信的检测器 → 单文件路径断言弹窗出现且识别在确认后才启动；批量路径断言**没有**任何模态窗口且结果表里有那两列。
