## 0. 现象
Luca 原话：**「风格和句子都能看到，但是好像不起作用，应用不到画面上」**。画廊里五套都列出来了、示例句子也在，但点了之后预览画面没有变化。

## 1. 先做三步判定（十分钟，能把原因锁死）

在 `CUTORA_PERF=1` 或一个临时的 debug 开关下加日志，然后**在真机上点一次「圣咏」**，把三段输出贴进报告：

1. **命令有没有被执行、参数对不对**：`bus.execute("stylepack.apply", ...)` 的入参与返回值，以及 `commands.jsonl` 里对应那条记录。
2. **数据有没有真的写进去**：应用**前后**分别 dump `self.tasks[self.curr_idx]["style"]` 的若干关键字段（`font` / `size` / `color` / `stroke_*` / `bg_*` / `anim_in_type`）与 `task["layout_rules"]`。判断：写进去了吗？
3. **写进去之后画面为什么不变**：应用后立刻手动调一次 `self.video_canvas.set_data(task, pos/1000.0)` + `update()`，看画面是否变化；再等 1 秒（心跳过一轮）后再看一次是否**又变回原样**。

三种结果对应三种根因，改法完全不同：

| 判定 | 根因 | 改法 |
|---|---|---|
| 第 2 步显示 `style` **没变** | 命令体拿到的不是活的 task（比如拿到了副本，或 `curr_idx` 不对） | 让命令体作用于 `self.tasks[curr_idx]` 本身 |
| `style` **变了**，手动 `set_data` 后画面**变了** | 只是**没有触发刷新** | 应用后主动刷新（见 §2.1） |
| `style` **变了**，但过一拍**又变回去** | 被回写覆盖 —— `SubtitleStylePanel` 的控件值才是实际来源，心跳或某个 `refresh` 把面板里的旧值写回了 task | 见 §2.2，这是最需要认真改的一种 |

## 2. 三种情况的改法

### 2.1 只是没刷新
`stylepack.apply` 的命令体在写完之后必须：
- `push_undo("应用风格包 <名称>")`（**注意顺序：先 push 再改**，T13a 已经定过这条规矩）；
- 让 **字幕样式面板**（`SubtitleStylePanel`）从 `task["style"]` 重新读一遍并刷新控件；
- 刷新画布与时间线（`video_canvas.set_data(...)`、`timeline.update()`）；
- 这些都通过 `bus.executed` 的回调做，别在命令体里直接碰 Qt 控件（T13 的 D2 规矩）。

### 2.2 被面板回写覆盖（我认为可能性最大）
如果 `SubtitleStylePanel` 的控件是"实际生效的那份数据"，那么任何绕过面板写 `task["style"]` 的操作都会被下一次回写抹掉。**这不是风格包一个功能的问题，是数据来源有两份。** 要定一个方向：

**`task["style"]` 是唯一事实来源，面板只是它的编辑器。** 具体：
- 面板控件变化 → 写入 `task["style"]` → 发信号 → 画布刷新；
- 任何其他来源（风格包、命令、配方、API）改了 `task["style"]` → 发同一个信号 → **面板从 task 重新载入控件值** → 画布刷新；
- 面板**不得**在刷新时把自己的控件值反向写回 task。

改完加一条测试：离屏起主窗口 → 记下当前 `style["font"]` → `bus.execute("stylepack.apply", {...})` → 断言 `task["style"]["font"]` 变成了包里的字体 → **再跑 20 次心跳（processEvents + 手动触发 sync_ui）** → 断言它**仍然**是包里的字体（不被回写）。**这条测试先写、先红。**

### 2.3 命令体拿到的是副本
让它作用在 `self.tasks[curr_idx]` 这个活对象上；加断言防止以后又变成副本。

## 3. 顺手改一个交互（与 bug 无关，但 Luca 马上会遇到）

现在**点每一个风格包都会弹一个模态框问「应用到当前视频？」还带一个复选框**。画廊的用法是"一个个点过去比较"，每点一次弹一次框，比较十二套就要点二十四次确认。

改成：
- **点击即应用**，立刻可见，并且**可撤销**（`Ctrl+Z` 回到上一套）；
- 「同时应用该风格的动画」从模态框里挪到**画廊顶部当一个常驻开关**（记住上次选择；用户改过动画时默认关闭，并在开关旁给一行小字说明）；
- 底部给一句「已应用 圣咏 · Ctrl+Z 撤销」的提示（沿用现在的 `hint` 标签）。
