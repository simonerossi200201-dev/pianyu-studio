## 2. 新政策：行数是硬约束，装不下就重新切句

三层，缺一不可：

### A. 断句层（`relayout_task` / `break_lines`）— 用真实的 `max_lines`

- ① 和 ② 全部改成传**用户设的值**（1 / 2 / 3 …），不再 `max(8, …)`、不再硬编 8。
- 装不下时的处理顺序（照附录 C §3.2）：
  1. **重新切分 segment**：把这一条拆成两条（在词边界、按词时间切；没有词时间按字符比例），或与下一条合并，直到每条都能在 `max_lines` 行内、以当前字号放下。
  2. **单个词本身比一行还宽**（超长专有名词）→ 只对这一个词按比例缩字号，Transcript 那条打黄标。
  3. **任何情况下输出行数 ≤ `max_lines`。**
- `逐词出现` / 单字模式 → 严格一词一条，不许两个词。
- 「装得下」的判定必须用**渲染时同一套度量**（同一 `QFont`、同一 `SAFE_MARGIN`、同一 `expansion_px` + `box_padding_x`），不能字符数估一遍、像素再算一遍——两套尺子不一致就是行数对不上的下一个坑。把 `_pixel_wrap_lines` 里算 `max_w` 的那几行抽成一个函数，两边共用。

### B. 渲染层（v2 `_fit_event_lines`）— 尊重 `segment.lines`，绝不加行

- 有 `event["lines"]` 且 `len ≤ max_lines` → **原样使用**，不 join、不重新断行。④ 那段 `_char_wrap_lines` 只在**没有** `lines` 时才走，并且传真实 `max_lines`。
- `_pixel_wrap_lines` 加参数 `max_lines`，产出**永远 ≤ max_lines**。
- `_fit_event_lines` 末尾那个按画幅高度裁行的兜底保留，但**再加一道 `lines = lines[:max_lines]` 之前**必须先走 C——不许静默丢词。

### C. 兜底（用户刚改了字号/边距还没重排的一瞬间）— 缩这一条，不加行

- 渲染时某一行像素宽度仍超出 `max_w` → 对**这一条字幕**把 `em` 按比例缩到装下，下限 **70%**；Transcript 打黄标「字号已临时缩小，点『重新断句』」。
- 缩到 70% 仍装不下（极端情况）→ `lines[:max_lines]` 硬截并**红标**，绝不多出一行。
- **让 C 成为瞬时状态**：`fontsize` / `max_lines` / 左右范围 / 字体 / 粗斜体 / `tracking_em` / `letter_case` / 描边扩边 / 底框内边距——**任一改动**都触发 `subtitle.auto_relayout`（设置默认开，附录 B 已有），改完下一帧就重新切好句了。

> 关于「不缩字号」：附录 C 之前我担心的是句与句之间字号跳动。A 层用重新切句解决了绝大多数情况，C 层只在参数刚改、还没重排的一瞬间出现，重排后消失。**Luca 如果连这一瞬间也不接受，就把 C 改成「硬截 + 红标」，报告里问一句。**

### D. 手动入口（附录 C §3.3 原文）

命令 `subtitle.relayout`（headless、undoable、`doc_zh` ≥ 40 字）：按当前排版参数重新断行 + 重新切分，保留原文与词时间，不重跑 ASR。菜单「字幕 → 按当前排版重新断句」；字幕排版那一组参数改动后面板上出一个「重新断句」按钮。**与 `auto_relayout` 共用同一个实现。**

## 4. 测试（本片最重要的产出）

1. **渲染层不加行**：构造 `event={"lines":["they still enter the"]}`、`max_lines=1`，字号大到像素超宽 → `layout_event(...).lines` 长度 **== 1**（走的是 C 的缩字号，不是加行）。
2. **渲染层尊重预设**：`event["lines"]` 有 2 行、`max_lines=2`、像素都装得下 → `_fit_event_lines` 返回值 **== 输入的 lines**（一个字符都没动，证明 ④ 修掉了）。
3. **20 条真实字幕、`max_lines=1`** 跑 `subtitle.relayout` → 每一条渲染后**正好 1 行**，bbox 都在安全边距内；切分后的时间区间首尾相接、不重叠、总时长不变。
4. `max_lines=2` → 每条 ≤ 2 行。
5. 单字模式 → 每条词数 == 1。
6. **两套尺子一致**：随机 100 条句子 × 3 个字号，A 层判「装得下」的，B 层渲染出来行数一定 ≤ `max_lines` 且没触发 C。
7. **参数联动**：改 `fontsize` → `auto_relayout` 被触发（用计数断言），下一帧无黄标。
8. 现有 `docs/linebreak.md` 优先级测试和 g09 stills 不变。
