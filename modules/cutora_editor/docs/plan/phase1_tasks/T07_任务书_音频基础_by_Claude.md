## T07a · 还 T05g 的音频账（第一块，其余都等它）

**1. 分路依据改对**
`tr.type == "audio"|"bgm"` 这个判断作废 —— **`type=="bgm"` 的轨不存在**。
主声 / BGM / SFX 的区分依据统一到 **`clip.audio_role ∈ {main, bgm, sfx}`**。
全仓把按 `Track.type` 分音频路的地方找出来，一处不留。

**2. 接到和视觉同一套**
音频的 mute/solo 走 `track_outputs` / `track_is_muted`，
不要在音频侧另写一份判断 —— 两份判断迟早对不上（这次就是）。

**3. 导出侧要有对等入口**
视觉侧是 `compute_export_render_order(task_data)`，**签名里没有 `solo_ids`**，
所以 solo 结构性地进不了成片。音频侧照做一个
（例如 `compute_export_audio_tracks(task_data)`，同样不收 `solo_ids`）。
**测试用 `inspect.signature` 断言无该形参** —— 和视觉侧一模一样的锁。

**4. SFX 播放器池要认 mute/solo**
最多 4 路的那个池现在完全不理。

**5. 测试（这条比实现重要）**
- `mute` 主声轨 → **只有主声没了**，BGM / SFX 照常
- `mute` BGM → 只有 BGM 没了
- `mute` SFX → 只有 SFX 没了
- 三条各自：**预览判定结果 == 导出判定结果**（同一个函数、同一个结论）
- `solo` 任意一条 → 预览生效，**导出完全不受影响**
- 断言方式用**混音前的轨道清单**，不要靠听

**门禁**：`pytest 0 failed` · **golden 全不变**（音频路由不该动画面；动了说明改到了别处）

## T07b · 响度标准化（第二块，用户感知最强）

摸底确认：**零**。无 `loudnorm` / LUFS / EBU，全仓无 `loudnorm`/`lufs`/`ebur128`。
多轨才 `alimiter=limit=0.97`，单轨只 `anull`。
`amix ... normalize=0` 是「不要按轨数自动衰减」，**不是响度标准**。

**为什么排第二**：批量产出的片子响度忽大忽小，是观众第一时间会抱怨的事，
而它对用户是「什么都不用设」的改善。

- 目标：**-14 LUFS 短视频档**（可在设置里改），真峰值上限 -1 dBTP
- 用 `loudnorm` 双趟（先测再压），不是单趟动态模式 —— 单趟在短片上会抽
- 设置里一个下拉：关 / -14 LUFS / -16 LUFS / 自定义
- **命令**：`audio.loudness.set {mode, target_lufs}`，`undoable=True`，`portable=True`
- **测试**：合成一段已知响度的音频，跑完测量值落在目标 ±0.5 LUFS
