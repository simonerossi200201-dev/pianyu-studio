## 2. 【裁决】你问的两件事

### 裁决 A：**包扩到全集，不是面板缩到包**

Luca 的原话是硬要求：
> 「风格预设和字幕参数都必须是一一对应的，而不是写死的」

面板缩到 22 个键 = 把 T04 做的功能从预设体系里踢出去。不接受。

**但不是简单地「把 180 全塞进包」** —— 因为那 180 本身就不是 180 个参数。
从对照表里能直接看出三类：

| 类 | 例子 | 处置 |
|---|---|---|
| **真参数** | `spectrum_*` / `adv_*` / `lyrics_*` / `stroke_expand_*` | 进全集，包必须带 |
| **历史别名** | `stroke` / `stroke_width` / `shadow` / `shadow_offset` / `bg_enabled` / `bg_opacity` / `bg_padding` / `bg_radius` / `color` / `stroke_color` / `bg_color` | 收敛到规范名，读时迁移 |
| **重复/死键** | `shadow_blur`×2；`shadow_*` 家族与 `color_shadow`/`opacity_shadow`/`shadow_enabled` 重叠 | 去重 / 删 |

先规范化再补全，否则等于把重复固化进 14 个包，以后永远拆不掉。

### 裁决 B：**两套文本预设合并到新的那套**

`text_presets.json`（`credit.default` / 署名）是保留方。
`text_style_presets.json`（旧「AI 署名」/「Mio 署名」）只读一次、迁移、**此后永不写入**。
CLI `add_text_overlay` 改读新的。

理由：队列自动署名已经走 `text_preset.*`，CLI 走旧的 = 同一个功能两条真相。
留着只会让「为什么我改了署名没生效」变成永久 bug 源。

### 保持不变的：套用 = 「default 重建 + update」

这个机制**是对的，别改**。它保证「同一个预设 → 同样的结果」，
和 Luca 那条「设置成一行就必须是一行，不可以偶然出现两行」是同一个要求。
问题不在重建，在于**包只带了 25 个键，其余 155 个的结果由默认值决定，而不是由预设决定**。
包带全了，重建就等于完全确定。

`geom_user_set` 那种「保留用户手动几何」的豁免可以有，但必须是**显式白名单**，
写在一个地方，有注释说明为什么豁免。

### T11g · 单路径化：干掉「没选风格包」这个状态（Luca 本轮追加 + 更正）

**Luca 的更正很关键，我上一版写错了**：这些参数**不是死的**。

> 「默认自动字幕走完之后，是一个粉色的底，那是很旧很旧的参数预设，不知道为什么一直沿用至今。
> 当用户没有选中任何风格包的时候，这些参数就是好用的，但是当用户选择了风格包，这些参数就失去了作用。
> 这说明有一条旧路径是多余的，我要的就是只留新路径，这样就不会走岔道了。」

所以问题的本质**不是「有一堆没用的参数」，是「有两条渲染路径」**：

```
没选风格包  →  v1 背景参数生效（粉底就是从这儿来的）
选了风格包  →  fx.bg 生效，v1 参数被架空
```

**两条路径就是两套真相。** 这和 T04 那些静默回退是同一个病：
用户改了一个看起来该管用的东西，它在某个状态下管用、另一个状态下不管用，而且没有任何提示。

**目标：消灭「没选风格包」这个状态。** 自动字幕跑完就落在一个默认风格包上，
从此只有一条路径：**pack → fx**。v1 参数连同粉底一起退休。

这比「删掉多余参数」根本，也让 T11b 的「包带全集」真正成立 ——
因为不存在「不由包决定的样式」了。
