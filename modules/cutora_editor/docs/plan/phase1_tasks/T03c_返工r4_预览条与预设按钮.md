## A. 画布下面现在是两行，浪费约 50px

现状（`main_window.py` 1994–2056）：`preview_tools`（固定 48px：左边 匹配字幕/导出，中间 T/图片/音乐）是一行，`_play_ctrl`（居中一个 120×34 的「▷ 播放」）又是一行，两行加起来 90px 左右，其中大半是空的。

改成**一条 40px 的传送带**（transport bar），从左到右：

```
[匹配字幕][导出][停止导出*]   ·   [⏮][▶/⏸][⏭]  00:00:12.34 / 03:47.21   ·   [T][图片][音乐]
```
- 左组：现有 `btn_ai` / `btn_exp` / `btn_exp_stop`（*仅导出中显示），32×32。
- 中组（居中）：`跳到开头`（Home）、`播放/暂停`（Space，图标随状态切换 `play`/`pause`）、`跳到结尾`（End），32×32 图标按钮；右侧一个等宽字体（JetBrains Mono）时间码 `当前 / 总时长`，`fg1` 色，`_timeline_ms` 变化时刷新（用现有播放头位置信号，不要加定时器）。**保留 `btn_start` 这个属性名和 `btn_play` objectName**，`toggle_play` 与现有测试都靠它。
- 右组：`btnAddText` / `btnAddImage` / `btnAddAudio`，32×32。
- 删掉 `_play_ctrl` 那一行；`preview_tools.setFixedHeight(40)`；画布 `video_wrap` 拿回多出来的高度（stretch 已是 10，确认没有别的固定高度挡着）。
- 三组之间用 `addStretch(1)` 分开；窗口窄到 900px 时时间码可以隐藏（`fg2` 的 elide 不要），三组按钮不许挤在一起。
- 快速模式也用这条传送带（快速模式原本就没有单独的播放行）。

## B. 右栏的「⋯ 预设 & 样式管理」按钮藏在角落，而且显示成了一个「.」

现状（`subtitle_style.py` 1067–1085）：`bottom_bar` 单独一行、右对齐一个 36×28 的 `QPushButton("⋯")`；截图里它渲染成了一个点——**Inter/Noto 对 `⋯`（U+22EF）的字形回退不对**，所以看起来像个坏掉的按钮，一般人根本不会去点。

改法：
- 删除 `bottom_bar` 整行。把这个菜单按钮放进「预设:」那一行，`[预设 ▾ 下拉框（伸展）][⋯ 28×28]`，紧挨着下拉框右侧——用户看到预设就看到管理入口。
- 按钮图标改用 Lucide `ellipsis`（`bind_icon(btn, "ellipsis", size=16)`），**不要用文字字形**；tooltip「预设：新增 / 更新 / 重命名 / 删除 / 导入导出」。
- 菜单项前面的 emoji（⭐ ➕ 💾 ✏️ 🗑 📤 📥）全部去掉，改成 Lucide 图标（`star` / `plus` / `save` / `pencil` / `trash-2` / `upload` / `download`）——emoji 在 Windows 上是彩色的，和整套单色图标不搭，而且随主题换色时它们不跟。
- `grep -rn "⋯" cutora/ui/` 找一下别的面板有没有同样的「⋯」文字按钮（属性 / 角色映射 / 字块样式 / 资产库），有就一并改成同样的做法；报告里列出。
- 「设为默认预设」放菜单第一项不变。
