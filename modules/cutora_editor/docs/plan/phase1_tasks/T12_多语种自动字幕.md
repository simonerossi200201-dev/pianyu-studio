# T12 — 多语种自动字幕：全语种识别、自动检测、30+ 语言词级对齐、回退策略、模型管理器、CJK/RTL 断行与渲染

> 前提：T13 完成（T09 的模型下载器基础若已做则复用）。先读 `docs/plan/01_GROK_通用规范.md` 与总体计划 §2.8。golden 规则 A（en/it 旧路径输出不变）。

## 1. 识别引擎：`cutora/asr/engine.py`

- 语言：开放 faster-whisper 全部语言（从 `faster_whisper.tokenizer._LANGUAGE_CODES` 读，不手写清单）；UI 下拉按"常用（中/英/意/西/法/德/葡/日/韩/俄/阿）+ 全部（按本地语名排序）"两段显示，语名用 `resources/data/languages.json`（代码 → 英文名 → 本地语名 → 中文名 → 脚本类型 latin/cjk/rtl/thai/other）。
- `language="auto"`：用 faster-whisper 的 `detect_language`（前 30 s）+ 置信度；置信度 < 0.6 时在 UI 提示"检测为 xx（低置信），请确认"。
- 模型档位：`small / medium / large-v3 / large-v3-turbo`（CTranslate2 版本：前三档来自 `huggingface.co/Systran/faster-whisper-*` 官方仓库；turbo 由社区转换（`mobiuslabsgmbh/faster-whisper-large-v3-turbo` 或 `deepdml/faster-whisper-large-v3-turbo-ct2`），Grok 需核对其许可证为 MIT 且文件 SHA256 固定后才可列入 `models.json`）；设置里按 GPU 显存推荐（≤ 6 GB → small，8–12 → medium/turbo，≥ 16 → large-v3）。
- 参数暴露：`beam_size`、`vad_filter`（默认开）、`initial_prompt`（可从项目"术语表"自动拼，见 §5）、`hotwords`。
- 保留 `_LazyModule`、显存回收、`trim_gpu_cache` 机制；模型缓存键加上 `(size, device, compute_type)`。

## 2. 词级对齐：`cutora/asr/align.py`

- 对齐模型表 `resources/data/align_models.json`：从 whisperX 的 `DEFAULT_ALIGN_MODELS_TORCH` / `DEFAULT_ALIGN_MODELS_HF` 导出（en/fr/de/es/it/ja/zh/nl/uk/pt/ar/cs/ru/pl/hu/fi/fa/el/tr/da/he/vi/ko/ur/te/hi/ca/ml/no/nn/sk/sl/hr/eu/gl/ka/lv/tl 等），每条：语言、HF 仓库、大小、许可证、SHA256（首次下载后写入）。**逐个核对仓库许可证**，非 MIT/Apache/CC-BY 的标记并默认不启用（报告列表）。
- 现有 en（`WAV2VEC2_ASR_LARGE_LV60K_960H`）与 it（`VOXPOPULI_ASR_BASE_10K_IT`）路径**原样保留**，golden 依赖它们。
- 回退：语言无对齐模型 → `faster-whisper word_timestamps=True`，`Segment.words[*].score=None`，UI 与 Transcript 面板标"近似词级"；对齐失败（OOM、模型损坏）→ 同样回退并提示，不中断批量。
- 数字/符号处理：wav2vec2 对齐会丢数字，沿用 whisperX 的 `interpolate_method="nearest"`，并在报告里说明中文数字的处理。

## 3. 模型管理器：`设置 → 模型` + `cutora/asr/download.py`

- 列表：识别模型 4 档 + 对齐模型按语言 + VAD + （Phase 2）diarization；每行：状态（未下载/下载中/已就绪/校验失败）、大小、许可证、"下载/删除"。
- 下载只从 `huggingface.co`，`HF_ENDPOINT` 非官方时忽略并警告；SHA256 校验；断点续传；并发 1。
- 首次执行"自动字幕"时若所需模型未就绪 → 弹出"需要下载 xx（NNN MB）"确认，不静默联网。
- 存储位置 `runtime\models\`（便携版）或 `%LOCALAPPDATA%\CUTORA\models\`（安装版），设置可改；迁移旧目录的模型（`asr_small` 等）自动识别。

## 4. 多脚本断行与渲染（配合 T04 `layout.py`）

- 按 `languages.json` 的脚本类型选断行策略：`latin`（空格/标点）、`cjk`（按字符，避免标点开头，禁则处理：`、。，！？」』）` 不在行首，`「『（` 不在行尾）、`thai/khmer/lao/burmese`（无空格无标点：用 `PyICU`？——**不引入 ICU**，太重；用简单的最大字符数硬切 + "近似"标记）、`rtl`（阿拉伯/希伯来/波斯/乌尔都：不拆词，行序不变，渲染用 `Qt.LayoutDirection.RightToLeft` + `QTextOption`；阿拉伯连写形态由 Qt 处理，验证 `QPainter.drawText` 输出正确连写；卡拉OK逐字高亮在 RTL 下按视觉顺序从右向左推进）。
- 字体回退链：每种脚本指定默认字体（Noto Sans / Noto Sans SC / Noto Sans JP / Noto Sans KR / Noto Sans Arabic / Noto Sans Hebrew / Noto Sans Devanagari / Noto Sans Thai …，来自 T09 字体扩充），用户风格包指定的字体不含该字形时 `QFont` 回退（`QFontDatabase` 检查 `supportsCharacter`，逐段落回退，避免豆腐块）。
- 验证集：`tests/data/multilang/` 放 12 种语言各 3 句（自写文本 + SAPI/`espeak-ng`（GPL，仅测试用，不随软件分发）朗读 → 识别 → 对齐 → 渲染），报告贴 12 张渲染截图。

## 5. 术语表（提高识别准确率，服务宗教/专业内容）
- 工程级"术语表"（`项目 → 术语表`）：人名、地名、经文引用、专业词，每行一个；自动拼进 `initial_prompt`（前 200 token）与 `hotwords`；也作为 T04 Transcript 面板"批量替换"的候选。
- 全局术语表在 `USER_DATA\presets\glossary.txt`。

## 6. 批量维度
- `subtitle.auto` 命令支持 `language` 列表：同一素材依次识别多种语言（用于多语版本；翻译在 Phase 2）。
- 批量对话框可对多文件设"自动检测"并在结果表里显示每个文件检测到的语言与置信度，允许纠正后重跑。

## 7. 验收标准
- [ ] en/it 走旧模型 → golden 全绿。
- [ ] 12 语种验证集：识别不崩溃、词级时间戳存在（对齐或回退）、渲染截图无豆腐块、CJK 无标点开头行、阿拉伯语连写正确且从右到左高亮。
- [ ] 自动检测：12 个样本 ≥ 11 个正确；低置信提示出现。
- [ ] 模型管理器：下载 `large-v3-turbo` 与 `zh` 对齐模型 → 校验通过 → 删除 → 重新下载走断点续传（报告贴日志）。
- [ ] `HF_ENDPOINT=https://hf-mirror.com` 时被忽略并警告（pytest）。
- [ ] 对齐模型许可证表（报告）。
- [ ] 命令：`subtitle.auto` 的 schema 含 `language`（enum 全语种 + auto）、`model`、`glossary`；`asr.models.list/download/delete` 注册。
- [ ] 16 GB 显存上 `large-v3` + 对齐后 `trim_gpu_cache` 使保留显存 ≤ 2 GB（`app.gpu_info` 输出）。
