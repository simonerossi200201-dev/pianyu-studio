# T10 — 打包分发：安装包 + 便携 zip、首启模型下载器、构建脚本、CI、可复现构建

> **每次出包先走 `PACK_GATE.md`。** pytest 红着不许出包；必须真的启动一次主窗口。

> 前提：Phase 1 其余任务全部完成。先读 `docs/plan/01_GROK_通用规范.md`。
> 交付物：`CUTORA-Setup-7.0.0.exe`、`CUTORA-7.0.0-portable.zip`、`SHA256SUMS.txt`。

## 1. 运行时策略（决定）

torch+CUDA 让 PyInstaller 单文件方案不现实（体积 5 GB+、启动慢、杀毒误报多）。采用 **"嵌入式 Python 运行时目录"** 方案：
```
CUTORA\
├── CUTORA.exe            # 小型启动器（见 §2）
├── runtime\
│   ├── python\           # Python 3.10 embeddable + 已安装的 site-packages（从锁文件离线安装）
│   ├── ffmpeg\           # ffmpeg.exe / ffprobe.exe（gyan.dev 或 BtbN GitHub 官方构建，GPL 版本，附 LICENSE 与源码链接）
│   └── models\           # 首次启动按需下载（安装包不含），便携版可选内含 small
├── cutora\ resources\ docs\
├── portable.flag         # 仅便携版
└── LICENSES\
```
- 安装包分两档：**标准版**（~1.5 GB，含 CPU torch，安装后可选下载 CUDA torch）与**完整版**（~5 GB，含 CUDA torch）。Luca 的目标用户有 NVIDIA 卡的多，**默认产出完整版**，标准版作为 CI 的第二产物。
- 便携 zip 只出完整版。

## 2. 启动器 `CUTORA.exe`
- 不用 PyInstaller 打业务代码；用一个极小的启动器：C# WinExe 或 用 `pyinstaller --onefile` 只打一个 20 行的 launcher（推荐后者，工具链一致）：设置工作目录、`CUTORA_HOME`、调用 `runtime\python\python.exe -m cutora`，把崩溃退出码写日志。图标 `app.ico`，版本信息资源（公司 CUTORA、产品 片语 Studio、版本 7.0.0）。
- `.cutora` 文件关联（安装版注册，便携版不注册）；双击工程文件启动并打开。

## 3. 首启模型下载器：`cutora/asr/download.py` + `ui/dialogs/model_manager.py`
- 模型清单 `resources/data/models.json`：每个条目 `id, kind(asr|align|vad|diar), lang, size_mb, repo("huggingface.co/...")、files[{path, sha256}]、license、required(bool)`。
- 下载只从 `huggingface.co`（官方，通过 `huggingface_hub`，禁用 `HF_ENDPOINT` 环境变量覆盖——启动时若检测到该变量指向非 `huggingface.co` 则忽略并警告），断点续传，完成后 SHA256 校验，失败删除重下。
- 首启向导：检测 GPU → 推荐模型档位 → 勾选语言 → 下载进度 → 完成。可跳过，之后在 `设置 → 模型管理` 下载。
- pyannote 等门控模型：说明需要用户自己在 HF 接受条款并填 HF token（token 走 keyring）；不内置任何绕过。

## 4. 构建脚本：`build/build.ps1`
```
build.ps1 -Version 7.0.0 [-Variant full|standard] [-Portable] [-Installer] [-Sign]
```
步骤：清理 → 从 `requirements.lock` 离线安装到 `runtime\python`（先 `pip download` 到 `build\wheels\`，再 `--no-index --find-links`，保证可复现）→ 复制代码与资源 → 运行 `tools/gen_api_docs.py` 并比对（不同则失败）→ 跑 pytest + golden → 生成 `THIRD_PARTY_LICENSES.md` 并比对 → 剔除 `__pycache__`、tests、docs/plan/reports → 便携 zip（`7z`/`Compress-Archive`）→ Inno Setup 编译（`installer.iss`）→ `SHA256SUMS.txt` → 可选 `signtool`（证书路径由环境变量给，没有则跳过并警告）。
- `installer.iss`：中文/英文双语安装界面、安装到 `%ProgramFiles%\CUTORA`、用户数据在 `%LOCALAPPDATA%\CUTORA`、开始菜单"片语 Studio"、可选桌面快捷方式、`.cutora` 关联、卸载时询问是否删除用户数据、检测已安装旧版并升级（保留用户数据）、检测 NVIDIA 驱动版本（低于 CUDA 12.8 要求时提示但不阻止）。
- Inno Setup 从官方 `jrsoftware.org` 下载，版本写死。

## 5. CI：`.github/workflows/release.yml`（重写现有）
- 触发：tag `v*`；`windows-latest` runner。
- 步骤：checkout → 安装 Python 3.10 → `build.ps1 -Variant full -Portable -Installer` → `build.ps1 -Variant standard -Installer` → `actions/attest-build-provenance@v2`（保留现有做法）→ 上传 release 附件 + `SHA256SUMS.txt` + `THIRD_PARTY_LICENSES.md`。
- 另一个 `ci.yml`：每次 push 跑 `security_scan.ps1`、`pip-audit`、pytest（不含 golden，golden 只在本机跑，因为需要 GPU 与素材）。
- 不使用任何第三方 Action 除 `actions/*`、`softprops/action-gh-release`（已在用，锁 SHA）。

## 6. 应用内"检查更新"
- `帮助 → 检查更新`：**仅用户点击时**请求 `https://api.github.com/repos/<owner>/CUTORA/releases/latest`，比较版本，显示更新说明与"打开下载页"按钮；**不自动下载、不自动安装**。

## 7. 验收标准
- [ ] 在一台干净的 Windows 11 虚拟机（无 Python、无 VC++ 之外的东西；VC++ 运行库若需要由安装包携带官方 `vc_redist.x64.exe`）安装 `CUTORA-Setup-7.0.0.exe` → 首启向导下载 `small` 模型 → 完成总体计划 §8 第二条的快速流程（录屏）。
- [ ] 便携 zip 解压到含中文与空格的路径（如 `D:\测试 目录\CUTORA`）可运行，用户数据落在其 `UserData\`。
- [ ] 两次执行 `build.ps1` 产出的 zip 内容哈希一致（去除时间戳后；报告说明怎么做到的）。
- [ ] 安装包体积、安装时间、首启时间、冷启动到主窗口时间（报告表）。
- [ ] 卸载后 `%ProgramFiles%\CUTORA` 无残留；选择保留用户数据时 `%LOCALAPPDATA%\CUTORA` 仍在。
- [ ] `SHA256SUMS.txt` 与 GitHub attestation 可验证（贴 `gh attestation verify` 输出）。
- [ ] Windows Defender 与 VirusTotal（上传安装包，公开扫描是可接受的）零检出；有误报的话记录引擎名与处理建议（这是签名证书的决策依据）。
- [ ] `HF_ENDPOINT` 指向黑名单域名时被忽略并警告（pytest）。

## 8. 不要做
- 不做自动更新器、不做在线激活/许可证系统、不做统计上报。
- 不打包任何模型进安装包（便携版可选含 small，报告说明体积差）。
