## 一、对三版的判断（Claude 已逐版看过 512px 深底与单色）

### 概念 1（当前接进软件的这版）— **必须换掉**
致命问题：**圆形 + 一道贯穿的斜线 = 禁止符号**。这是全世界通用的视觉语法（🚫、"禁止入内"、"功能已禁用"）。任务栏 32px 上，用户看到的第一眼是「一个被划掉的 C」，不是「被剪开的话语」。单色版把这一点暴露得更彻底。
次要问题：那条青色波纹太细太小，像一根蹭上去的头发；16px 时完全消失。斜线还顶到了圆角方块的角，构图失衡。

### 概念 2（错位引号 + 刀口）— **想法最好，执行最弱**
「引号被切成两半、错位」在概念上最贴「片语」：话语的碎片。但画出来的两块读不出是引号，像俄罗斯方块；青色斜线像划痕不像刀口。

### 概念 3（胶片框 + 卡拉OK 半高亮）— **最耐看，但太"通用播放器"**
小尺寸辨识度最好，中间那条半填充的横条真的说出了「逐字高亮字幕」——这是本产品的招牌功能。问题是：胶片齿孔是用滥了的老符号（而且现在的年轻用户根本没见过胶片），整体像个视频文件图标，跟"语言/话语"没关系。

**结论：概念 1 不能用；第二轮从概念 3 的克制 + 概念 2 的语义出发重画。**

## 二、第二轮的方向（出 3 版新的，A/B/C）

统一底：深色圆角方块 `#0E1116`，主形琥珀 `#F5B700`，青 `#5CE1E6` 只做**一处**点缀（不要两处以上）。

- **A · 字幕条 + 切口**（最保险）：方块内两条横向圆角条＝两行字幕。上条整条琥珀；下条**左半琥珀、右半暗色**（正在被逐字高亮）。两条之间一道细的垂直切口线（琥珀或青），暗示"剪"。极简、16px 也成立。
- **B · 引号即刀口**（概念 2 重做）：把两个**真正读得出来的**引号形（圆头逗点，不是方块）上下错位排布，错位的空隙本身就是那道切口，青色只用在切口的一道细高光上。要点：先让人认出引号，再让人看见切口。
- **C · 话语气泡 + 半高亮**（概念 3 转语义）：去掉胶片齿孔，保留半填充横条，把外框从"胶片"改成**对话气泡**（圆角矩形 + 一个小尖角）。气泡＝话语，内条＝逐字高亮字幕。

硬要求（三版都要满足，报告里逐条自检）：
1. **不得出现"圆形被斜线贯穿"的构图**——那是禁止符号。
2. 16×16 缩略图仍能认出主形（把 16px 放大 8 倍贴进报告，别只给 512px）。
3. 单色版必须成立（不靠颜色区分层次）。
4. 主形不要顶到圆角方块的边角，四周留白 ≥ 画布 8%。
5. 全部原创，不得像任何现有软件图标。

交付：每版给 512 深底 / 512 浅底 / 512 单色 / **16px 放大对照** 四张，摆在报告最上面。默认仍接 A 进软件，等 Luca 定。
