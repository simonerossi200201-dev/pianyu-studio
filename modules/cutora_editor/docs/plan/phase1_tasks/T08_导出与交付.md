## 1. 导出配置对象：`cutora/render/export_profile.py`

```python
@dataclass
class ExportProfile:
    name: str; width: int; height: int; fps: float | None   # None = 跟随源
    container: "mp4|mov|mkv|webm"; vcodec: "h264|hevc|av1|prores"; encoder_pref: ["nvenc","amf","qsv","x264"]
    quality: "compressed|high|original"; bitrate_mode: "crf|cq|cbr"; target_loudness: "-14|-16|-23|off"
    reframe: "center|manual|keep"; reframe_offset: (x, y)   # manual = 用户在预览上拖框
    sidecar: {"srt": bool, "vtt": bool, "chapters": bool, "thumbnail": bool}
    filename_template: "{project}_{profile}_{date}"
```
- 内置预设（名称只描述尺寸/用途，不含平台商标）：`横屏 16:9 1080p`、`横屏 16:9 4K`、`竖屏 9:16 1080×1920`、`竖屏 9:16 4K`、`方形 1:1 1080`、`竖幅 4:5 1080×1350`、`原始尺寸`、`ProRes 422（交付给剪辑师）`、`仅音频 m4a`、`仅字幕`。预设描述里可以写"适合 YouTube / Shorts / Reels / TikTok / LinkedIn"作为用途说明文字。
- 用户可保存自定义预设；预设随风格包一样可导入导出。

## 2. 多版本导出（一个工程 → N 个尺寸）

- 导出对话框重做：左侧勾选多个预设，右侧每个预设一行：输出文件名（模板可改）、构图（居中 / 手动 / 保持）、单独覆盖画质。
- **构图**：画布比例不同时的转换规则——`center` 中心裁切（fill）；`manual` 在预览里给一个可拖动的裁切框，每个预设各存一份偏移；`keep` 加黑边/模糊背景（`boxblur` 放大同源当背景，是短视频常用样式）。字幕与覆层按"锚点"重新定位：每个覆层新增 `anchor`（九宫格）与"相对画布百分比"坐标，切比例时按锚点重算——**旧工程无 anchor 字段时按左上像素坐标不变**，保证 golden。
- 进度：复用 `ParallelExportManager`，多版本 = 多任务；进度对话框显示每个版本的进度、剩余时间、可取消单个。

## 3. 安全区叠加（预览用，不导出）
`视图 → 安全区`：竖屏 9:16 显示"顶部 UI 区（约 12%）/ 底部操作区（约 18%）/ 右侧按钮列（约 15%）"的半透明遮罩与文字说明，横屏显示标题安全区/动作安全区（90%/80%）。数值放 `resources/data/safezones.json` 可改；不画任何平台的图标。

## 4. 侧车与附件
- SRT / VTT 侧车（T04 的写出器）；文件名与视频同名。
- 章节文件：由 T05 的"章节标记"生成 `chapters.txt`（`00:00 开场` 格式，可直接粘贴到视频描述）与 mp4 内嵌章节（`-map_metadata` + ffmetadata）。
- 封面帧：导出对话框可选"封面：当前帧 / 指定时间 / 首帧"，输出 `jpg`（质量 92）与 `png`；可选"带字幕/不带字幕"。
- 导出报告 `.export.json`：参数、耗时、编码器、响度测量、输出文件哈希——给流水线与代理机器人用。

## 5. 硬件编码器探测：`cutora/render/encoders.py`
- 启动时一次性探测：`h264_nvenc / hevc_nvenc / av1_nvenc / h264_amf / hevc_amf / h264_qsv / hevc_qsv / av1_qsv / libx264 / libx265 / libsvtav1 / prores_ks`，用 `ffmpeg -f lavfi -i testsrc2 -t 0.1 -c:v <enc> -f null -` 实测可用性；缓存到设置，`设置 → 性能 → 重新探测`。
- 现有 NVENC 参数（含 `-preset p1 -rc constqp -qp 12` 的开场预转码方案）**原样保留**；AMF/QSV 参数按各自文档给等价画质档。
- 编码器不可用时静默回退 x264 并在导出报告里注明。
