# T04f 附录 F — 叠层四方向透明度渐隐（T04f-2b）

> 来源：Luca 原话——"背景的渐变，记得也要给一个透明度的渐变，所有的色块或者是背景包括图片或视频，都要支持上、下、左、右四个方向上的透明度的渐变，有的时候需要用到这样的效果。"
> 字幕背景的四边渐隐已在 T04f-2 完成（`textfx/fade.py::apply_edge_fade`，接在 `raster.py` 的 `bg.fade`）。本片是把**同一个函数**推广到叠层，不许另写一套。

## 1. 覆盖范围

必须支持四边渐隐的元素，一个都不能少：

| 元素 | 位置 |
|---|---|
| 图片元素 | `frame_renderer.py::draw_image_element`，`kind == "image"` |
| 色块 / 形状元素 | 同上，`kind == "shape"` |
| 视频 / 图片轨道片段 | `frame_renderer.py::draw_layers`，`layer_type == "image"` |
| 字幕背景 | 已完成，不动 |

文字元素（`kind == "text"`）本片**不做**——文字的边缘渐隐要和描边/发光的关系单独设计，留到 T04f-4 之后再议。

## 2. 数据结构

每个受支持元素上加四个字段，与 `bg.fade` 完全同名同语义、同取值范围：

```
fade_top, fade_bottom, fade_left, fade_right : float, 0.0 – 0.5, 默认 0.0
```

- 单位是**该元素自身包围盒的比例**，不是像素、不是 em。`0.25` = 从该边起 25% 的宽/高范围内做 alpha 渐变。
- 四个方向互相独立，可同时开。两边同时开且和 > 1.0 时，按各自独立计算后取乘积（不是相加），保证中心不会被压到负数。
- **默认 0.0，且字段缺失 == 0.0**。这是规则 A 的要求：老工程没有这四个字段，渲染结果必须与本片之前**逐字节相同**。

## 3. 实现要求

1. **复用 `textfx/fade.py::apply_edge_fade`**，不许在 `frame_renderer.py` 里另写一份。若现有签名不适配叠层（例如需要接受任意 QImage 而非 ROI），就**改造 `fade.py` 让两边共用**，然后把字幕背景那一侧一并切过去，并跑一次字幕背景的像素锁证明没变。
   —— 这条是硬要求。本项目已经因为"同一个功能两条路径"栽过一次（宽度溢出只修了 v2，v1 还在漏）。
2. 渐变必须作用在 **alpha 通道**上，不是把颜色往背景色混。混色在非纯色背景上会露馅。
3. 渐变曲线用 `smoothstep`（`t*t*(3-2t)`），不要线性——线性在渐隐末端会有一条可见的硬边。
4. 只在 `max(四个值) > 0` 时才进入渐隐代码路径；为 0 时必须走原来的绘制调用，不许多一次 QImage 拷贝。
5. 与元素自身的整体不透明度、混合模式（blend mode）叠加时，顺序是：**先四边渐隐 → 再整体不透明度 → 再混合模式**。

## 4. UI（一一对应，这条 Luca 特别强调过）

- 属性面板里每个受支持元素类型都要有这四个滑杆，标注"上 / 下 / 左 / 右 渐隐"，范围 0–50%，步进 1%。
- 四个滑杆旁边加一个"四边同步"复选框：勾上时拖任一滑杆，四个一起动。
- 全部走命令总线，可撤销，headless 可执行。
- **注册表测试必须覆盖**：参照 `tests/test_t04f_fx_panel.py` 的做法，新字段进 `FX_FIELD_WIDGETS`（或叠层对应的等价注册表），漏接一个控件测试就必须红。

## 5. 验收

1. 四类元素各出一张开启渐隐的静帧（每类至少测两个方向同时开），加 4× 边缘放大裁切。
2. **规则 A**：`golden --all --repeat 3` PASS；另外单独证明——同一工程，元素上不写这四个字段 vs 写入四个 `0.0`，渲染结果 sha256 相同。
3. 字幕背景的现有像素锁不变（若按 §3.1 改造了 `fade.py`，这条尤其重要）。
4. 渐隐开到 0.5 时，画面上不应出现色带（banding）。在纯色浅底上截图，沿渐变方向取一条剖面，相邻像素 alpha 差 ≤ 2/255。
5. 性能：叠层渐隐开启后，`preview_bench` 播放 p50 增量 ≤ 0.5 ms，`dropped=0`（跑三遍）。
6. pytest 0 failed；无新增依赖。
7. 标签 `T04f-2b-done`，报告 `docs/plan/reports/T04f-2b_report.md`，停下等审。**不要顺手开 T04f-3。**
