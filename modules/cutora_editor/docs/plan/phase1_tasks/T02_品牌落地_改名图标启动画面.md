## 1. 命名规范（全仓库统一）

| 场景 | 用法 |
|---|---|
| 中文界面可见名 | **片语 Studio** |
| 英文界面可见名 / 文件名 / 目录 / 包 / 进程 / 注册表 / 安装目录 | **CUTORA**（全大写用于产品名与目录，`cutora` 用于包名与命令） |
| 窗口标题 | `片语 Studio` + ` — <项目名>`；未保存加 `*` |
| 项目文件扩展名 | `.cutora`（T06 定义格式；本任务先把保存/打开对话框的过滤器改成 `片语工程 (*.cutora *.asproj)`，保存仍写 `.asproj` 内容但扩展名用 `.cutora`，读两种） |
| 用户数据目录 | `%LOCALAPPDATA%\CUTORA\`（`settings\`、`presets\`、`autosave\`、`logs\`、`cache\`） |
| 环境变量前缀 | `CUTORA_`（原 `AUTOSUB_RENDER_CHILD` → `CUTORA_RENDER_CHILD`，两者都读，旧的标记废弃） |
| CLI | `cutora_cli.bat` → `python -m cutora.batch.cli`；旧 `autosub_cli` 名不再出现 |
| 版本 | `7.0.0`（AutoSub 到 v6，片语 Studio 从 7 开始，关于框写"前身 AutoSub v6"） |
| 品牌语 | 中：**让每一句话，找到它的位置。** 英：**Every word finds its place.** |

全仓库 grep `AutoSub|autosub|Auto Sub` 逐个替换（日志前缀、进度窗标题、临时文件前缀、`export_state.json` 里的字段名如果含 autosub 也改，并保持对旧文件的读取兼容）。`docs/` 里的历史文档不改。

## 2. 图标与视觉资产

按总体计划 §3 的三个概念各出一版 SVG（`resources/brand/concept_1.svg` … `concept_3.svg`），并把三版渲染成 512px PNG 放 `docs/plan/reports/img/`，让 Luca 选。**默认先用概念 1**（C 字形被斜切 + 波形）接入软件；Luca 选定后替换。

要求：
- 主色 `#0E1116`，强调 `#F5B700`，辅色 `#5CE1E6`；提供深底与浅底两版；提供纯单色版（用于任务栏小尺寸与安装程序）。
- 用 Python（`cairosvg` 或 Qt 的 `QSvgRenderer` 离线渲染，都是 MIT/LGPL，不联网）生成 `app.ico`（16/24/32/48/64/128/256 多尺寸）、`app_256.png`、`splash.png`（1280×720，深底、左侧图标、右侧"片语 Studio"大字 + "CUTORA" 小字 + 品牌语 + 版本号，底部一条加载进度槽）。
- 文件类型图标 `cutora_file.ico`（文档形 + 小 logo）。
- 所有 SVG 必须原创；不得用任何现有 logo 作为参考描摹。

## 3. 启动流程

`cutora/app.py`：
1. `QApplication` 创建后立即显示 `QSplashScreen`（`splash.png`），进度文本依次：`加载字体…` → `检测显卡…` → `加载界面…`；字体加载（232 个字体注册目前耗时 0.5–1 s）改为在 splash 显示后进行。
2. 应用 `app.ico` 为窗口图标；`QApplication.setApplicationName("CUTORA")`、`setApplicationDisplayName("片语 Studio")`、`setOrganizationName("CUTORA")`、`setApplicationVersion`。
3. Windows 任务栏分组：`ctypes.windll.shell32.SetCurrentProcessExplicitAppUserModelID("CUTORA.Studio")`。
4. 主窗口显示后 `splash.finish()`。

## 5. 用户数据迁移

- `cutora/core/paths.py`：`USER_DATA = %LOCALAPPDATA%\CUTORA`；子目录按 §1。全部原来写 `user_data/…` 的地方改走 `paths`。
- 首次启动（`USER_DATA\settings\app_settings.json` 不存在）时：检测 `D:\0_Dev\AutoSub_v6\core\user_data\` 与 `<程序目录>\core\user_data\`（两处），若存在弹一次对话框"检测到 AutoSub v6 的设置与预设，是否导入？"，导入内容：`app_settings.json`（**跳过任何 `*_api_key` 字段**）、`default_style.json`、预设文件、`recent_projects.json`（路径仍有效的才保留）、`stitch_naming.json`、`project_queue.json`。不导入 `export_state.json`、`jobs/`、`_preview_audio/`。
- 便携版（T10 会定义 `portable.flag`）：若程序目录存在 `portable.flag`，则 `USER_DATA = <程序目录>\UserData\`。本任务先实现这个判断。
