## A. 全屏预览：`F` 进得去出不来，`Esc` 也没用，关窗后画面丢失

现象：视图 → 全屏预览（快捷键 F）能全屏；全屏后按 F 或 Esc 都没反应；只能关掉那个窗口，回到主窗口后画布是空的，要再去菜单点一次才回来。

根因（已读 `main_window.py:2593` `toggle_preview_fullscreen`）：
- 全屏时 `canvas.setWindowFlags(Window)` 把画布变成了**独立顶层窗口**，键盘焦点在它身上；而 `F` 是挂在主窗口 `QAction` 上的快捷键（默认 `WindowShortcut` 上下文），**只在主窗口是活动窗口时生效**——所以全屏后 F 失效。Esc 根本没接。
- 用户点关闭 → 顶层窗口被 `close()` 隐藏，画布没被放回 `video_wrap`，主窗口里就是空的。

改法：
1. `act_full.setShortcutContext(Qt.ShortcutContext.ApplicationShortcut)`；另给 `VideoCanvas` 接一个 `QShortcut(QKeySequence.Cancel)`（= Esc）和 `QShortcut("F")`，两者都调 `MainWindow.toggle_preview_fullscreen`（用信号，不要让 canvas 直接引用 MainWindow）。Esc 只在全屏态起作用，非全屏时 Esc 保持原有语义（取消行内编辑）。
2. `VideoCanvas.closeEvent`：若处于全屏态 → `event.ignore()` 并触发退出全屏（同一条路径），**永远不让画布被 close 掉**。
3. 退出全屏的顺序必须是：`setWindowFlags(Widget)` → `video_wrap.layout().addWidget(canvas)` → `canvas.show()`（不是 `showNormal()`）→ 恢复之前的播放状态与当前帧（记录进入前的 `position` / `is_playing`）。进入前把 `video_wrap` 的 stretch 记下，退出后恢复，避免画布回来后尺寸变了。
4. 全屏期间：右下角 3 秒后淡出一行提示「F / Esc 退出全屏」（`fg2`，不遮画面），有鼠标移动再显示。
5. 测试 `tests/test_fullscreen_preview.py`（offscreen）：进入 → `canvas.isFullScreen()` 为真 → `QTest.keyClick(canvas, Qt.Key_F)` → 回到 `video_wrap` 里且 `canvas.parent() is video_wrap`，画布 `isVisible()`；再走一遍用 `Key_Escape`；第三遍在全屏态调 `canvas.close()`，断言画布仍在 `video_wrap` 内可见。三条都要过。

## B. 「添加文本 / 添加图片」入口和文本轨道不见了

现象（Luca 真机 + r2 截图一致）：画布下方那一排（匹配字幕 / 导出 / 添加文本 / 添加图片 / 添加背景音乐）**一个都看不见**，`T03c_r2_pro.png` 里画布与「播放」之间是一条空带；导入视频后时间线只有视频/字幕/音频三条轨，添加的文本没有地方落。

两个原因，都要修：

### B1. 那一排按钮为什么不显示
`main_window.py:1882–1924` 的 `top_btn_row` 代码还在，图标别名（`tool_text → type` 等）也在。**先查清楚再改**，不许猜：在 offscreen 里 `show_editor()` 后打印 `btnAddText.isVisible() / size() / icon().isNull() / parentWidget()` 与 `btn_ai` 同项，把输出贴进报告。可疑方向按顺序排查：(a) T03c §一清场时把 `tl.setStretch(1, 0)` 之类改动让这一行高度为 0；(b) `_set_ui_mode` / `_set_style_compact` 把 `top_btn_row` 里的控件 hide 了；(c) 图标着色用了 `fg0` 但 QSS 给 `QToolButton[autoRaise]` 的背景是同色。找到根因写进报告，然后修。
修完这一排应是：`匹配字幕`、`导出`、`停止导出`（仅导出中显示）居左；`添加文本`、`添加图片`、`添加背景音乐` 居中；图标 `fg1` 色、hover `accent`，tooltip 保留。**这三项同时进 `字幕` / `编辑` 菜单**（`编辑 → 添加文本 Ctrl+T`、`添加图片 Ctrl+Shift+I`、`音频 → 添加背景音乐`），菜单是主入口，按钮是快捷入口。
`tests/test_ui_actions_smoke.py` 加断言：`show_editor()` 后这六个按钮 `isVisible()` 且 `not icon().isNull()`。

### B2. 文本/图片没有轨道可落
r2 §A5 把默认轨道改成「1 视频 + 1 字幕 + 1 音频」是对的，但 `add_text_ov`（9257 行起）只往 `text_overlays` 追加，**不会建文本轨**，而时间线是按轨道类型显示覆层的——于是新建的文本在画布上有、时间线上没有。图片同理。
改法：
- `add_text_ov` / `add_img_ov` 开头调 `get_or_create_track(timeline, "text")` / `"image"`，把新覆层的 `_track_id` 指到该轨（有多条时用**最上面一条未锁定**的）。
- 轨头右键菜单加「添加轨道 ▸ 视频 / 文本 / 图片 / 音频」和「删除此轨（空轨才允许）」；时间线空白处右键同样有「添加轨道」。**轨道数量无上限。**
- 轨头上已有的 `+`（"导入素材到此轨道"）保留，但把 tooltip 改成「导入素材到此轨」，别让用户误以为它是"加轨道"——r2 任务书里我就是这么误会的。
- 新增文本时若时间线为空（还没导视频），也允许：建一条文本轨，时长取默认 10 s。
- 这些操作进 `HistoryManager`（可撤销），并在报告里列出，T13 时注册为 `timeline.add_track` / `timeline.remove_track` 命令。
- 旧工程加载时仍垫 5/4/3 轨（r2 没改的那段 `4709` 行）：**改成只垫到"有内容的最高轨号"**，空轨不再凭空补——否则打开旧工程又是一屏空轨。golden 七个 case 是旧工程，改完必须 `--all --repeat 3` PASS（渲染只看覆层的 `_track_id`，不看空轨，理论上不会变；变了就停下报告）。

### B3. 记入 T05（本单不做）
Luca 的最终要求是**像 Resolve / Premiere 那样：文本、图片、视频片段都放在"视频轨"上，任意轨道都能放任意可视内容，轨道无限**——而不是现在"文本轨只能放文本、图片轨只能放图片"。这是数据模型改动（覆层从 `text_overlays / image_overlays` 列表迁到 `Clip`），必须等 T13 命令总线之后在 T05 做。本单只做上面的过渡方案，让文本和图片**现在就能用**。Claude 已把这条写进 `T05_时间线专业化.md` §0。

## C. 三条分隔线太粗太亮，把界面割成四块

现象（Luca 真机截图）：左栏|画布、画布|右栏、编辑区|时间线之间的三条 8px `sep` 色分隔条常态可见，割裂感很强。r2 让它"常态可见"是为了让用户找得到拖拽位置——方向错了，专业软件的做法是**平时看不见，鼠标悬停才亮**。

改法（只改 QSS 与 token，不改命中区）：
- `QMainWindow::separator` 的 `width/height` **保持 8px**（这是命中区，缩了就又拖不动了），常态 `background: {{ bg0 }}`（与窗口底色相同，等于看不见）；`:hover` 时亮起。优先做法：hover 态 `background: {{ accent }}; border: 3px solid {{ bg0 }};`——这样命中区还是 8px，亮的只有中间 2px 一条细线。若 Qt 对 separator 不吃 `border`，退一步 hover 态整条 8px 用 `{{ accent_dim }}`，**不要用 `accent` 全亮**。做出来截图放报告，Luca 看效果。
- `sep` token 保留（别的地方可能用），但 separator 不再引用它。
- `_DockEdgeHandle` 的三个点：常态 `fg2` 的 35% 透明度，hover 100%——它现在也在"三条线"的视觉噪音里。
- 各 Dock 与中央区之间**不要再有别的边框**：检查 `QDockWidget`、`QWidget#dockHandle`、`TimelineContainer`、左右面板容器的 QSS 有没有 `border-top/left/right`，有就去掉，让四块只靠 `bg0 / bg1` 的明度差分开。
- 六套主题都要看一遍：`bg0` 各不相同，separator 常态色必须跟着 token 走，不能写死。
- 验收截图：专业模式整窗，鼠标不在分隔线上（三条线看不见）+ 鼠标悬停在时间线上边缘（只那一条亮）。
