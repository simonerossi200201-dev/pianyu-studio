# T06 — 媒体库与项目可靠性：标签/搜索/缩略图、重新链接、自动保存、崩溃恢复、版本快照、`.cutora` 格式

> 前提：T13 完成。先读 `docs/plan/01_GROK_通用规范.md`。golden 规则 A。

## 1. `.cutora` 项目格式：`cutora/model/project_io.py`

- JSON，顶层 `{"format": "cutora-project", "schema_version": 1, "app_version": "...", "created": ..., "modified": ..., "canvas": {...}, "media": [...], "timeline": {...}, "subtitles": {...}, "styles": {...}, "audio": {...}, "markers": [...], "export": {...}, "meta": {"title", "tags", "notes"}}`。
- 媒体路径**同时**存绝对路径与相对于工程文件的相对路径，打开时先试相对再试绝对；再不行进入重新链接（§3）。
- 读旧 `.asproj`：`migrate_v6(data) -> dict`，一次性转换并在保存时写为 `.cutora`（原文件不动）。写 pytest：用 T00 七个 golden 工程做迁移 → 导出 → sha256 与 expected 相同。
- 写入用"写临时文件 + `os.replace`"原子替换；文件末尾附 `sha256` 字段用于损坏检测。
- 禁止 pickle；`json.loads` 前限制大小（≤ 200 MB）。

## 2. 媒体库：`cutora/ui/panels/media_library.py`（重做 `DraggableListWidget`，保留其拖入行为）

- 网格/列表两种视图；缩略图（视频取 1 s 处帧，图片直接，音频画波形缩略）后台生成，缓存 `USER_DATA\cache\thumbs\<sha1(path+mtime)>.jpg`。
- 元数据：时长、分辨率、fps、编码、音频通道、采样率、文件大小、创建时间（ffprobe 一次性读取，缓存在工程里）。
- 文件夹（已有）+ **标签**（多标签，颜色）+ **收藏** + **搜索**（文件名/标签/元数据表达式如 `dur>60 res:1080`）+ 排序（名称/时长/日期/分辨率）。
- 右键：在资源管理器中显示、重新链接、移到文件夹、打标签、导出首/尾帧（已有）、从工程移除（`dangerous`）。
- 拖到时间线：拖到轨道 = overwrite，`Ctrl` 拖 = insert；拖到画布 = 作为覆层（图片）。
- 多选批量：同时打标签、同时加入队列（对接 `批量`）。
- 导入时可选"复制到工程文件夹 `<project>_media\`"（便于打包搬迁）。
- 重复检测：导入相同 sha1 的文件提示。

## 3. 离线媒体与重新链接：`cutora/model/relink.py`

- 打开工程时逐个检查媒体存在性；缺失的在媒体库与时间线上以红色斜纹显示"离线"，工程仍可打开、可编辑、可保存。
- `文件 → 重新链接媒体…`：列表显示缺失文件，"选择文件夹自动搜索"（按文件名 + 大小匹配；同名不同大小标黄）、逐个手选；一次搜索可解决同目录下全部缺失。
- 复用 `media_guard.inspect_clip` 做健康检查（损坏文件提示，不静默跳过——这是 v6 时代的教训）。

## 4. 自动保存与崩溃恢复：`cutora/core/autosave.py`

- 间隔可设（默认 2 分钟，设置里 30 s–10 min），只在工程有改动时写 `USER_DATA\autosave\<project-id>\<timestamp>.cutora`，保留最近 20 份。
- 主线程异常钩子 + `faulthandler` 写 `USER_DATA\logs\crash-<time>.log`；`export_guard` 的心跳机制保留。
- 启动时若发现比工程文件新的自动保存 → 恢复对话框（显示时间差、"恢复 / 打开原文件 / 稍后"）。
- 状态栏显示"已自动保存 HH:MM"。

## 5. 版本快照：`文件 → 版本历史…`

- 每次手动保存自动留一份快照（`<project>.cutora.versions\v0007_<time>.cutora`，保留最近 30 份，可设）；也可手动"创建命名版本"。
- 版本历史对话框：列表 + 备注 + "恢复到此版本"（恢复前把当前状态也存一份）+ "另存为新工程"。
- 不做 diff 视图。

## 6. 备份与打包
- `文件 → 打包工程…`：把工程 + 所有媒体（或只有用到的段落？——**不做**裁切，整文件复制）+ 风格包 + 字体依赖清单复制到一个文件夹，路径改为相对；可选 zip。
