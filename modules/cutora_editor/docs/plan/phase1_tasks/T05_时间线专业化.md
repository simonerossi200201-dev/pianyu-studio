## 0. 前置改动（Luca 2026-09-09 补充，做 §1 之前先做）— 统一可视轨道

现状：`text_overlays` / `image_overlays` 是任务字典里的两个列表，靠 `_track_id` 挂到类型为 `text` / `image` 的专用轨道上；视频片段才是 `Clip`。Luca 的要求是 **Resolve / Premiere 的模型：文本、图片、视频片段都是同一种"可视片段"，可以放在任意视频轨上，轨道无限，上层盖下层。**

- 模型：`Clip` 增加 `kind: "video" | "text" | "image" | "shape"`，文本/图片的属性（现在 overlay 字典里的字段）原样挂到 `clip.payload`；轨道类型只剩 `video` / `subs` / `audio`。
- 迁移：`project_io` 读旧工程时把 `text_overlays` / `image_overlays` 转成对应视频轨上的 `Clip`（原 `text` 轨 → 新建一条视频轨，顺序保持），写盘时用新格式并把 `schema_version` +1；**旧格式继续可读**，并在 `docs/` 记录字段对照。
- 渲染：`FrameRenderer` 收到的仍是同样的字段（由一层薄适配把 `Clip.payload` 展开成它现在吃的 dict），golden 规则 A：七个旧工程导出逐字节一致。
- 交互：任意可视片段可拖到任意视频轨；轨道 `+` 无上限；文本片段在轨道上显示前几个字，图片片段显示缩略图。
- 验收：加载 golden 的任一旧工程 → 时间线上文本/图片出现在视频轨上 → 导出 sha 不变。

## 1. 模型层：`cutora/model/timeline_ops.py`

在 `Timeline / Track / Clip` 之上写纯函数（无 Qt），全部可单元测试：
- `split_clip(clip, t)`；`trim_in/trim_out(clip, new_edge, ripple: bool)`；`ripple_delete(track, clip)`（后续片段前移，跨轨可选"链接轨道一起动"）；`move_clip(clip, track, new_start, mode="overwrite|insert")`；`close_gaps(track)`；`nudge(clips, dt)`；`add_marker(t, text, color)`；`snap_points(timeline)` → 所有片段边、标记、播放头、字幕边、秒刻度。
- 片段间的**链接**：视频片段与其源音频默认链接（一起移/切/删），`Alt` 临时解链；字幕轨可设为"跟随视频轨"（视频 ripple 时字幕同步位移）——这是"简版磁性时间线"。
- 每个操作是一条命令（`timeline.*`），可撤销。

## 2. 交互层：`cutora/ui/timeline/widget.py`（本任务把它拆成 `widget.py` 画布 + `interaction.py` 状态机 + `ruler.py` + `clipitem.py`）

- 片段两端 8px 抓手：拖动 = trim；按住 `Ctrl` = ripple trim；光标形状随之改变；拖动时显示时间码浮标与 delta。
- `S` 键在播放头处分割选中片段（无选中则分割播放头下所有轨的片段）；刀片模式 `B` 点击分割。
- `Del` 删除保留间隙；`Shift+Del` ripple 删除；`Backspace` = Del。
- 吸附：`N` 开关；吸附阈值 8px（按缩放换算）；吸附到 §1 的全部点；吸附时画一条竖线并轻微"粘"。
- 多选：框选、`Ctrl` 点选、`Shift` 范围选；选中集统一移动/删除/复制粘贴（`Ctrl+C/V` 粘贴到播放头）。
- 标记：`M` 在播放头加标记，标尺上显示旗标，双击改文字/颜色，右键删除；`Shift+M` 加"章节标记"（T08 导出章节文件用）。
- 播放：`J/K/L`（J 连按 -2x/-4x，L 连按 2x/4x；K 停）、`Space`、`←/→` 逐帧、`Shift+←/→` 1 秒、`Home/End`、`I/O` 设入点出点（用于导出范围与"导出选区"）。
- 缩放：`Ctrl+滚轮` 以鼠标为中心缩放、`Shift+滚轮` 水平滚动、`+/-`、`Shift+Z` 适配全部；时间标尺按缩放显示 帧/秒/分 刻度。
- 波形：音频片段与视频片段（含音轨）上绘制波形（复用 `waveform.py`，缓存到 `USER_DATA\cache\waveforms\<hash>.npy`，后台线程生成，未生成时显示占位）；字幕轨片段显示文本前几字；图片片段显示缩略图。
- 轨头：静音 `M`、独奏 `S`、锁定、隐藏（视频）、轨高三档、重命名；拖动轨头排序。
- 间隙：右键间隙 → "闭合间隙"/"闭合本轨全部间隙"。
- 右键片段：分割、删除、ripple 删除、复制、（解）链接、重命名、属性（跳到检查器）。
- 渲染性能：时间线绘制用脏矩形；1 小时工程、200 片段下拖动播放头保持 ≥ 30 fps（报告测）。
