# Q154 · 预合成（原位分组）· 连线导入第二代（一行一组）· 中央监视器每格播放

> 状态（2026-10-02）：**第一批已实现**。三块互相咬合：连线导入里分好的「组」进时间线就是预合成；
> 预合成在时间线上是原位分组；中央监视器照旧能看、能播。

## 1. 预合成 = 原位分组（`cutora/model/clip_groups.py`，无 Qt）

- 片段留在原轨道上，每条身上多一个 `group` 字典（同组每条一份、内容一样）：
  `{"id", "name", "color", "locked", "loop_fill", "repeat", "repeat_of"}`；另加 `uid`（稳定 id，撤销深拷贝后不变）。
  两个键都进 `CLIP_KEYS`，工程 / 渲染任务都带着。
- **锁住（默认）**：时间线上点一条 = 整组选上，拖一条 = 整组一起走（复用 Q145 的多选整组拖）；
  检查器里改一条的外观参数（变换 / 裁切 / 渐隐 / 调色 / 抠像 / 遮罩 / 节点图 / 混合…）→ `sync_props` 抄给整组。
  时间（start / in / out）、变速、循环**不**同步，那是每条自己的位置。
- **解锁**：各条单独改；横杠变虚线提醒。
- **循环铺满到视频结尾**（`loop_fill`）：以整组时长为周期，`resync` 把整组复制续接到视频时长，最后一份超出的裁掉。
  复制出来的叫重复份（`repeat=True`，斜纹 + ↻），不能单独裁，点它 = 选整组；组里真身一改自动重算（幂等，签名不变不动）。
  重复份就是普通片段 → 渲染 / 导出 / 中央监视器 / 分屏零改动。
- 重算时机：命令总线跑完（`_on_command_executed`）、检查器改完（`param_changed`）、时间线松手（`item_dragged`）。
- 命令：`group.create / ungroup / join / detach / set`（都可撤销、无头可用）。
- 时间线：Ctrl+G / Ctrl+Shift+G；片段右键「预合成片段」「预合成 · 组名 ▸ 解除 / 锁定或解锁 / 循环铺满 / 重命名 / 组颜色 / 分离」「加入预合成组 ▸」。
  片段顶上一条组色横杠，组里第一条写组名。Alt 复制 / Ctrl+D 复制出来的是新片段，不带进组；切开的右半同组、新 uid。
- 检查器：「预合成组」一节（组名 / 颜色 / 锁定 / 循环铺满 / 解除）。图层面板：没打颜色标签的用组色，重复份标 ↻。

## 2. 连线导入第二代（`ui/link_group_graph.py` + `batch/link_groups.py` + `batch/link_import.py`）

- 右边一行 = 一个预合成组（行内顺序 = 拼接顺序）。「每组片段数」按文件顺序 N 段一组；「按文件名前缀分组」
  `video01_a / _b / _c` 一组（前缀 = 最后一个 `_ - 空格 .` 之前；尾巴是 a / 01 / part12 这类序号）。
- 之后随便拖：同行换位、拖到别的行（插在松手处）、拖到最下面虚线框另起一组；框选 / Ctrl / Shift 多选一起拖；
  右键「合并成一组 / 各自单独成组 / 另起一组」。空行自动消失，连线跟着「行首那一段」走。
- 连线：媒体右端口 → 行的任何位置；行左端口 → 媒体卡片。一条媒体可连几组，一组可连几条媒体。
  右键媒体 / 片段批量连；Ctrl 划刀割线；双击 / Delete 删线；自动连线 = 第 i 条媒体连第 i 组。
- 节点大 / 中 / 小三档，缩略图一直有（后台算、回来补），Ctrl+滚轮整体缩放。行色 = 导入后时间线上那个组的颜色。
- **只保存连线**（`link_plan`），不动时间线：回到批量加载「视频」分页，按钮上写着「已记住 N 条连线」，
  点「插入到所选视频」才按那一页的循环 / 静音 / 分屏写进去；中间可以再打开改。
- 导入：一组一条新轨道，多段的组首尾相接 + `clip_groups.create(locked=True, loop_fill=循环)`；一段的组走老行为（片段级循环 / 匹配）。
  不循环时多段超出视频时长的裁掉。老计划格式 `{"paths": [...]}` 仍认。
- 分屏：原视频第一格，各组依次进后面的格子；**一条媒体正好两组、布局还是默认上下 → 自动「上 1 下 2」**（`pick_split_layout`）。
  用户自己选了别的布局 / 三组以上不自动换。

## 3. 中央监视器（`ui/central_monitor.py`）

- 每格底部一条播放条：左下 ▶ / ⏸，中间可拖进度，右边 `当前 / 总长`。按在进度条上直接跳、拖着走，不改选中。
- 各格独立播放（只看画面，不出声），按真实时间走、到头循环；后台合成跟不上就丢帧，每格队列里最多一帧。
- 工具条「全部播放」「进度条」总开关；顶部总滑块一动，全部格子跟过去（正在播的从那个时间接着播）；关进度条 = 全停。
- 原有的分屏 / 拖画面 / 覆层拖拽 / 批量布局都没动。
